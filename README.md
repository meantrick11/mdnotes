## 阅读方式

可以直接在 GitHub 浏览 Markdown 文件，也可以将仓库作为 Obsidian 仓库打开。建议从感兴趣的主题目录进入，再通过目录和文内链接继续查阅。

笔记处于持续整理中，深度和完成度不一。部分内容参考了外部资料或借助 AI 辅助整理；涉及技术决策时，请结合原始资料和实际场景核对。
