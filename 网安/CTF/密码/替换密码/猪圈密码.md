# 猪圈密码（共济会密码）笔记

## 一、基础概念
猪圈密码（又称共济会密码）是一种**基于图形替代的简单替换式密码**，核心逻辑是用字母所在的“格子轮廓+点”替代字母本身，实现加密/解密。

- **加密**：将明文的每个字母，替换为其在对应格子中的轮廓符号（含点/无点）。
- **解密**：根据符号的轮廓和点的特征，反推出对应的字母。

---

## 二、核心规则与字母映射
### 1. 分组规律
26个字母分为4组，每组的符号特征清晰可辨：

| 字母范围 | 基础图形 | 点特征 | 核心规律 |
|----------|----------|--------|----------|
| A-I      | 九宫格   | 无点   | 用字母所在格子的边框表示 |
| J-R      | 九宫格   | 带1个点 | 与A-I轮廓相同，加点区分 |
| S-V      | 叉形（X）| 无点   | 用X形的四条边表示 |
| W-Z      | 叉形（X）| 带1个点 | 与S-V轮廓相同，加点区分 |

---

### 2. 详细字母-符号对照表
#### （1）无点九宫格（A-I）
```
A | B | C
---------
D | E | F
---------
G | H | I
```
- A：左上角格子 → `┌`
- B：上中格子 → `┬`
- C：右上角格子 → `┐`
- D：左中格子 → `├`
- E：中心格子 → `┼`
- F：右中格子 → `┤`
- G：左下格子 → `└`
- H：下中格子 → `┴`
- I：右下格子 → `┘`

#### （2）带点九宫格（J-R）
```
J·| K·| L·
-----------
M·| N·| O·
-----------
P·| Q·| R·
```
- J：对应A → `┌·`
- K：对应B → `┬·`
- L：对应C → `┐·`
- M：对应D → `├·`
- N：对应E → `┼·`
- O：对应F → `┤·`
- P：对应G → `└·`
- Q：对应H → `┴·`
- R：对应I → `┘·`

#### （3）无点叉形格（S-V）
```
  S
T   U
  V
```
- S：上半部分 → `∧`
- T：左半部分 → `<`
- U：右半部分 → `>`
- V：下半部分 → `∨`

#### （4）带点叉形格（W-Z）
```
  W
X·  Y·
  Z·
```
- W：对应S → `∧·`
- X：对应T → `<·`
- Y：对应U → `>·`
- Z：对应V → `∨·`

---

## 三、加密/解密示例
### 1. 加密示例：明文 `HELLO`
- H：下中无点九宫格 → `┴`
- E：中心无点九宫格 → `┼`
- L：上右带点九宫格 → `┐·`
- L：同上 → `┐·`
- O：右中带点九宫格 → `┤·`
- 密文：`┴ ┼ ┐· ┐· ┤·`

### 2. 解密示例：密文 `┌· < ┼ ┴`
- `┌·`：对应J → J
- `<`：对应T → T
- `┼`：对应E → E
- `┴`：对应H → H
- 明文：`JTEH`（若为完整单词，可组合为可读文本）

---

## 四、易错点与注意事项
1.  **点的区分**：A-I与J-R、S-V与W-Z的轮廓完全相同，必须通过“是否带点”区分，否则会解密错误。
2.  **轮廓方向**：九宫格和叉形的轮廓方向固定，不要混淆左右/上下（如`└`和`┘`对应不同字母）。
3.  **空格处理**：猪圈密码本身不加密空格，可直接保留空格分隔单词，也可省略空格（解密时需自行断句）。
