# 目录扫描

## 目录扫描的简介

目录扫描时为了爆破网站所有隐藏路径、后台地址、敏感文件，找漏洞入口,扩大攻击面

## 一、核心作用
1. **找后台登录地址**
扫出：`/admin`、`/login`、`/manager`、`/后台`、`/phpmyadmin`
拿到后台登录口，就能尝试弱口令、爆破登录。

2. **扫敏感配置/备份文件**
扫出：
- 数据库备份：`db.sql`、`backup.sql`
- 源码备份：`www.zip`、`site.rar`
- 配置文件：`config.php`、`env`、`database.ini`
**拿到就能直接看账号密码、数据库信息**。

3. **扫未授权访问目录**
比如：
- `/upload` 上传目录
- `/files` 文件目录
- `/phpinfo.php` 信息泄露
可以直接访问、上传木马、看源码。

4. **发现隐藏漏洞页面**
很多网站有遗留后台、测试页面、漏洞接口，官网不暴露，**目录扫描能扫出来**，作为渗透突破口。

5. **探测网站架构和源码**
通过扫到的目录判断：用的 **ThinkPHP、SpringBoot、WordPress** 等，针对性找对应漏洞。

## 二、常用目录扫描工具

- 御剑（Windows 老牌）
- Dirsearch（Python编写 ）
- Dirb、Dirbuster
- 蚁剑自带目录扫描插件

## 三、通俗理解
网站就像一栋楼，**目录扫描就是挨个试房门、窗户、后门、地下室**，
把管理员**藏起来没公开的所有入口、隐私文件全部扒出来**，是渗透测试**第一步必做**。

### Dirbuster

`Gobuster` 是 Kali 里一款**高性能的命令行工具**，专门用于“目录/文件爆破”、“DNS 子域名枚举”和“虚拟主机发现”等任务。作为一款基于 **Go 语言**开发的工具，它的核心优势就是**运行速度快、系统资源占用低**。

### ⚙️ 第一步：安装与准备

如果你的 Kali 尚未安装，可以通过包管理器快速安装：
```bash
sudo apt update && sudo apt install gobuster -y
```
安装后，用以下命令确认安装并查看帮助：
```bash
gobuster --help
```
**准备字典文件**：Gobuster 需要配合字典文件才能工作。Kali 内置了多种字典，通常位于 `/usr/share/wordlists/` 目录下。推荐的字典库是 **SecLists**，你可以根据需要下载使用。

---

### 🚀 第二步：核心用法与命令实战

Gobuster 有几种不同的工作模式，主要通过 **`dir`**、**`dns`**、**`vhost`** 等子命令来指定。其基础语法如下：
```bash
gobuster [模式] -u [目标] -w [字典路径] [其他选项]
```

以下是最常用的三种模式，后面都附上了可直接使用的命令示例。

#### 🗂️ 模式一：目录与文件爆破 (`dir`)
用于发现网站中隐藏的目录或文件，如后台路径、备份文件等。

*   **基础用法**：
    ```bash
    gobuster dir -u http://example.com -w /usr/share/wordlists/dirb/common.txt
    ```
*   **进阶用法（带扩展名）**：通过 `-x` 指定想查找的文件类型，例如 PHP 或 `.txt` 文件。
    ```bash
    gobuster dir -u http://example.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,html
    ```
*   **实战案例**：下面的命令使用了更强大的字典，并设置了 40 个线程来提升扫描效率。
    ```bash
    gobuster dir -u http://10.10.10.31 -w /usr/share/wordlists/dirbuster/directory-list-2.3-small.txt -x php -t 40
    ```

#### 🌐 模式二：DNS 子域名枚举 (`dns`)
用于发现目标域名下的子域名，扩大攻击面。

*   **基础用法**：
    ```bash
    gobuster dns -d example.com -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt
    ```
*   **进阶用法（显示 IP）**：通过 `-i` 选项，显示解析到的子域名 IP 地址。
    ```bash
    gobuster dns -d example.com -w subdomains.txt -i
    ```

#### 🖥️ 模式三：虚拟主机枚举 (`vhost`)
用于发现同一台服务器上可能托管的其他网站。

*   **基础用法**：
    ```bash
    gobuster vhost -u http://example.com -w /path/to/vhosts.txt -t 50
    ```

### 🛠️ 第三步：常用命令选项 (`flags`)

通过添加 `flags`，可以精细化控制扫描行为。以下是一些常用选项：

| 选项 (`flag`) | 解释 | 示例 |
| :--- | :--- | :--- |
| `-t` | 设置并发线程数，数字越大扫描越快。**默认 10**。 | `-t 50` |
| `-o` | 将扫描结果保存到指定文件中，以便事后分析。 | `-o results.txt` |
| `-x` | 指定要查找的文件扩展名，以逗号分隔。 | `-x php,html,zip` |
| `-s` | 仅显示指定的 HTTP 状态码（如 200, 301, 403）。 | `-s 200,204,301,302` |
| `-b` | 在结果中**排除**指定的 HTTP 状态码。 | `-b 404,403` |
| `-c` | 在请求中添加 Cookie，用于访问需要登录的页面。 | `-c "session=abc123"` |
| `-k` | **跳过 SSL 证书验证**，用于目标使用自签名证书时。 | `-k` |
| `-q` | 安静模式，不显示标题和横幅，让输出更干净。 | `-q` |

### 💡 高级技巧与最佳实践

*   **提升效率**：用 `-t` 增加线程数；用 `-o` 保存结果。
*   **准确筛选**：用 `-s` 只显示 `200,301,302` 等成功状态码；或用 `-b 404` 过滤无用的 404 页面。
*   **字典选择**：字典在精不在多。**小规模**或**实战扫描**建议用 `/usr/share/wordlists/dirb/common.txt` 这类精简列表；**深度测试**再用 `/usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt` 这类大字典。
*   **深入扫描**：部分新版本支持 `-r` 递归扫描，但会更耗时和发出更多请求，请谨慎使用。

### 🧐 补充：Gobuster 与其他工具

| 工具 | 核心优势与定位 |
| :--- | :--- |
| **Gobuster** | 命令简洁，默认集成于 Kali，轻量高效，适合快速扫描。 |
| **ffuf** | 功能强大灵活，支持多字典组合、复杂模糊测试和高度定制过滤。 |
| **Feroxbuster** | Rust 编写，支持自动递归扫描，能智能过滤虚假路径，适合深度内容发现。 |
| **Dirsearch** | Python 编写，可定制性强，适合需要复杂规则或代理的中小规模扫描。 |

总之，`Gobuster` 因其简洁和高效成为了基础扫描的利器，而 `ffuf` 和 `Feroxbuster` 则像是它的进阶版，提供了更强大的功能。
