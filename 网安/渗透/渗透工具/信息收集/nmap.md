# nmap 教程

## Nmap (Network Mapper)
Nmap（Network Mapper）是一款用于网络发现和安全审计的开源工具。它最初由 Gordon Lyon（也被称为 Fyodor Vaskovich）开发，是一款功能强大且广泛使用的网络扫描工具。Nmap 允许用户在网络上执行主机发现、端口扫描、服务识别和版本检测等操作，以帮助评估网络的安全性、发现主机和服务、以及识别潜在的安全威胁。

## Nmap的核心功能
- **主机发现**：探测网络中的存活设备（如`-sP`扫描局域网存活主机）
- **端口扫描**：识别开放端口及状态（开放/关闭/过滤）
- **服务识别**：检测端口对应的服务及版本（如`-sV`参数）
- **操作系统检测**：通过指纹识别目标系统（如`-O`参数）
- **脚本扩展**：使用NSE脚本实现漏洞扫描、密码爆破等高级功能

## 二、Nmap安装
- **Windows**：官网下载安装包（https://nmap.org），默认包含图形化工具Zenmap
- **Linux/Kali**：通过包管理器安装：

```bash
sudo apt update && sudo apt install nmap
```

## 三、namp的常规使用



### 3.1基础扫描指令（入门必记）

#### 3.1.1 基础扫描：nmap 目标IP/域名
```bash
nmap 192.168.1.100
```
- **作用**：对目标 IP 执行默认扫描（扫描前1000个常用TCP端口）
- **原理**：默认使用 SYN 扫描（需要root/管理员权限），完成端口探测后返回开放端口和服务信息
- **适用场景**：快速摸底目标开放端口

#### 3.1.2 主机存活探测（Ping扫描）：-sn
```bash
nmap -sn 192.168.1.0/24
```
- **作用**：只探测网段内哪些主机在线，**不扫端口**
- **原理**：发送 ICMP Echo、TCP SYN/ACK 包，收到响应即判定主机存活
- **适用场景**：内网快速找在线设备，避免对离线主机做无用扫描

#### 3.1.3 指定端口扫描：-p
```bash
# 单个端口
nmap -p 80 192.168.1.100

# 多个端口
nmap -p 80,443,3306 192.168.1.100

# 端口范围
nmap -p 1-1000 192.168.1.100

# 全端口扫描（1-65535）
nmap -p- 192.168.1.100
```
- **作用**：自定义扫描端口，精准定位目标端口
- **原理**：对指定端口发送探测包，根据响应判断端口状态
- **注意**：`-p-` 全端口扫描较慢，建议配合 `-T4` 加速

### 3.2 进阶信息收集指令（渗透必备）

#### 3.2.1服务版本识别：-sV
```bash
nmap -sV 192.168.1.100
```
- **作用**：识别开放端口对应的**服务及版本号**（如Apache/2.4.41、OpenSSH/7.6p1）
- **原理**：向端口发送定制化探测报文，根据返回的banner/响应特征，匹配内置服务指纹库
- **适用场景**：后续漏洞利用的关键步骤，知道版本才能找对应CVE

#### 3.2.2 操作系统检测：-O
```bash
nmap -O 192.168.1.100
```
- **作用**：识别目标主机的操作系统类型和版本
- **原理**：发送特制TCP/IP数据包，分析响应特征（TTL、窗口大小、初始序列号等），匹配内置OS指纹库
- **注意**：需要root权限，准确率受目标系统和防火墙影响

#### 3.2.3 脚本引擎扫描（NSE）：--script
```bash
# 使用指定脚本
nmap --script=http-enum 192.168.1.100

# 使用脚本类别（如漏洞扫描类）
nmap --script=vuln 192.168.1.100

# 同时使用多个脚本/类别
nmap --script=http-enum,ssh-brute 192.168.1.100
```
- **作用**：调用Lua脚本实现高级功能（目录枚举、弱口令爆破、漏洞检测等）
- **原理**：脚本会对目标端口发送定制化请求，解析响应内容匹配预设规则
- **常用类别**：
  - `vuln`：漏洞检测脚本
  - `brute`：弱口令爆破脚本
  - `discovery`：信息收集脚本
  - `safe`：无风险脚本（适合生产环境）

### 3.3扫描类型指令（不同探测方式）

#### 3.3.1 SYN半开扫描（默认）：-sS
```bash
nmap -sS 192.168.1.100
```
- **作用**：半开扫描，不完成TCP三次握手，隐蔽性强
- **原理**：发送SYN包，收到SYN+ACK判定端口开放，收到RST判定关闭，无响应判定过滤
- **注意**：需要root/管理员权限，不会在目标主机留下完整连接日志

#### 3.3.2 Connect全连接扫描：-sT
```bash
nmap -sT 192.168.1.100
```
- **作用**：调用系统connect()函数，完成完整TCP三次握手
- **原理**：连接成功判定端口开放，失败判定关闭
- **特点**：无需root权限，但会留下连接日志，容易被IDS/防火墙检测

#### 3.3.3 UDP端口扫描：-sU
```bash
nmap -sU 192.168.1.100
```
- **作用**：探测目标主机开放的UDP端口（如DNS 53、SNMP 161）
- **原理**：发送空UDP包，收到ICMP端口不可达判定关闭，收到UDP响应判定开放，无响应可能开放或被过滤
- **注意**：UDP扫描速度慢，建议配合 `-T4` 加速，且需要root权限

### 3.4 速度与输出控制指令

#### 3.4.1 扫描速度控制：-T（0-5）
```bash
nmap -T4 192.168.1.100
```
- **作用**：设置扫描速度，T0最慢，T5最快
- **等级说明**：
  - T0-T2：极慢，隐蔽性高，适合绕过严格防火墙
  - T3：默认速度，平衡扫描效率和隐蔽性
  - T4：较快，适合内网环境，实战中最常用
  - T5：最快，容易被防火墙拦截，仅适合无防护目标

#### 3.4.2 输出结果保存：-oX / -oN / -oG
```bash
# 保存为XML格式（适合后续工具解析）
nmap -oX scan_result.xml 192.168.1.100

# 保存为普通文本格式
nmap -oN scan_result.txt 192.168.1.100

# 保存为Grepable格式（适合命令行工具处理）
nmap -oG scan_result.gnmap 192.168.1.100
```
- **作用**：将扫描结果保存到文件，方便后续分析或导入其他工具（如Metasploit）

### 3.5 常用组合指令（直接复制就能用）

#### 3.5.1 快速摸底扫描（内网主机）
```bash
nmap -sn 192.168.1.0/24 && nmap -T4 -sV -O 192.168.1.100
```
- 先找存活主机，再对目标主机做服务版本和OS检测

#### 3.5.2 全端口+服务版本扫描（深度探测）
```bash
nmap -T4 -p- -sV 192.168.1.100
```
- 扫描所有端口并识别服务版本，适合找冷门端口服务

#### 3.5.3 漏洞扫描组合
```bash
nmap -T4 -sV --script=vuln 192.168.1.100
```
- 先识别服务版本，再调用漏洞脚本检测对应CVE
