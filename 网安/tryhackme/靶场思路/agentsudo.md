# Agent Sudo

太棒了！回顾你在 `Agent Sudo` 靶场中的全通关过程，这是一次非常标准且精彩的 **Boot2Root（从外网打点到内网提权）** 的渗透测试实战。

为了帮你巩固知识点，这里为你将整个渗透流程以及每个阶段所使用的工具进行系统性地总结，你可以把它作为一份完美的 CTF 战术复盘：

---

### 🗺️ 第一阶段：网络测绘与信息收集 (Reconnaissance)

**目标**：探测目标机器开放的端口，寻找脆弱的服务切入点。

* 
**使用工具**：`Nmap` 


* **通关流程**：
1. 通过 `Nmap` 针对目标 IP 运行全端口扫描，成功发现服务器对外开放了 **21 (FTP)**、**22 (SSH)**、以及 **80 (HTTP)** 三个核心端口 。


2. 根据 “遇事不决先看 Web” 的原则，将突破口锁定在 80 端口的 Web 网站上 。





---

### 🕵️ 第二阶段：外网打点与身份伪造 (Initial Access)

**目标**：突破 Web 服务的权限限制，拿到敏感的底层账号凭证。

* 
**使用工具**：`dirsearch` (辅助目录扫描)、浏览器 / `curl` (网络请求发起) 


* **通关流程**：
1. 访问 Web 页面时发现无法直接获取线索，使用 `dirsearch` 扫描目录也未果，推断网站在后台对访问身份进行了某种校验 。


2. 结合靶场名字，尝试修改 HTTP 请求头中的 **User-Agent** 字段来伪造特工身份 。


3. 将 User-Agent 修改为大写字母 **`C`** 触发重定向，成功追踪到隐藏的绝密页面并获得关键情报 ：**确认目标账号为 `chris**`，且得知其 **FTP 密码非常薄弱 (Weak)** 。





---

### ⚔️ 第三阶段：密码暴破与内网渗透 (Brute-Force)

**目标**：利用弱口令缺陷，暴力破解 FTP 服务。

* 
**使用工具**：`Hydra` (九头蛇密码暴破器) 


* 
**密码字典**：`rockyou.txt` 


* **通关流程**：
1. 使用 `Hydra` 挂载解压后的经典字典 `rockyou.txt`，针对账号 `chris` 的 FTP 服务发起暴力破解 。


2. 在一分钟内成功爆破出 FTP 的真实凭证：`chris / crystal` 。





---

### 💾 第四阶段：数据剥离与隐写术破译 (Steganography)

**目标**：从 FTP 搜刮战利品，解开层层加密，拿到登录主机的 SSH 凭证。

* 
**使用工具**：`ftp`客户端、`binwalk` (文件结构扫描)、`7z` (高级解压)、`John the Ripper` (哈希爆破工具)、`base64` (解码)、`steghide` (图片隐写工具) 


* **通关流程**：
1. 登录 FTP 成功下载了三份战利品：一封提示信 `To_agentJ.txt` 和两张外星人图片 。


2. 使用 `binwalk` 检测图片内部结构，敏锐地发现 `cutie.png` 肚子里捆绑隐藏了一个加密的 ZIP 压缩包 。


3. 由于直接解压被系统拒绝（由于 PKZIP 5.1 AES 新版加密缺陷） ，使用 `zip2john` 将其提取为密码哈希 ，然后配合 `john` 工具一瞬间秒杀出 ZIP 压缩包密码为 **`alien`** 。


4. 使用 `7z x` 带着密码解压，拿到隐藏文本 `To_agentR.txt` ，得到一段 Base64 暗号 `'QXJlYTUx'` 。在终端将其解码，破译出密码为 **`Area51`** 。


5. 将这串字符作为隐写术密码，使用 `steghide extract -sf` 对最后一张图片 `cute-alien.jpg` 进行剥离 ，成功提取出隐藏的最终字条 。


6. 字条直接暴露了特工 **`james`** 真正的 SSH 登录密码：**`hackerrules!`** 。





---

### 👑 第五阶段：远程登录与终极提权 (Privilege Escalation)

**目标**：打入主机内网，利用系统配置缺陷夺取最高 root 权限。

* 
**使用工具**：`SSH` (安全外壳协议连接)、Linux `sudo` 机制缺陷 


* 
**对应漏洞**：**`CVE-2019-14287`** (Sudo 安全策略绕过漏洞) 


* **通关流程**：
1. 使用凭证 `james / hackerrules!` 成功通过 SSH 登录到服务器内部，在家目录下斩获了第一个 Flag（`user_flag.txt`） 。


2. 在终端输入 `sudo -l` 检查 james 的特权，发现了一行存在严重配置缺陷的规则 ：`(ALL, !root) /bin/bash` 。


3. 巧妙利用系统安装的旧版本 `sudo` 中存在的 `CVE-2019-14287` 漏洞（当指定 UID 为 `-1` 时可以绕过对 root 用户限制的缺陷） ，在终端敲下攻击连招：


```bash
sudo -u#-1 /bin/bash

```


4. 回车后瞬间偷天换日，直接提权变身为 **`root`（最高管理员身份）** ！


5. 最后进入 `/root` 目录一举夺得最终的 Root Flag（`root.txt`） ，并挖出了隐藏在幕后的第三位特工 R 的真实身份：**`DesKel`** ，达成 100% 完美通关 ！





---

### 💡 核心思维总结

通过这台靶机，你完整体会到了黑客攻击的精髓：**“连点成线”**。
没有任何一个防线是一下子崩溃的，你先从一个微小的 **User-Agent 假身份** 开始，套出了 **FTP 弱口令**，再通过 **图片隐写** 顺藤摸瓜拿到 **SSH 密码**，最终利用 **Sudo 提权漏洞** 登上顶峰。每一个环节拿到的“小线索”，都是解开下一个庞大锁扣的钥匙。
