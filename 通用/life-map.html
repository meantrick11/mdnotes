职业阶段：每一次升级，核心问题都在变化

初级开发｜能否正确完成明确任务？
编码基础、Debug、Git、数据库、API、测试、基础工程规范、AI 辅助开发。

中级开发｜能否独立负责完整模块？
需求理解、模块设计、接口与数据设计、模块边界、异常处理、测试与验收、AI 驱动效率。

高级 / 资深｜能否设计复杂模块并处理复杂问题？
系统设计、性能、稳定性、可维护性、技术选型、Trade-off、复杂问题定位、跨模块理解。

Tech Lead / 架构师｜能否让多人和多模块形成稳定系统？
系统边界、技术架构、数据流、技术决策、架构演进、复杂度控制、团队协作、技术风险管理。

技术负责人 / CTO｜能否让技术服务业务和组织？
业务理解、技术战略、团队建设、成本与收益、产品判断、资源配置、人才判断、长期技术规划和公司战略。

创业者｜如果机会和条件允许。
从个人能力、项目、产品、系统与团队出发，逐步构建组织与企业；这是一条可选择的分支。

六项能力：从执行到判断，再到组织

业务能力
理解用户和客户是谁、真正的问题、业务流程、商业价值及成功标准；从“别人告诉我做什么”走向“自己判断应该做什么”。

需求能力
澄清模糊需求，拆解目标、场景、功能、优先级、边界、输入输出、异常和验收标准，让想法可开发、可测试、可验收。

工程能力
积累项目结构、模块边界、数据流、API、数据库、状态、日志、测试、部署、可维护性和可观测性，让系统长期运行和迭代。

技术能力
当前方向：Python、后端、PostgreSQL、Redis、Docker、AI 应用、LLM、RAG、Agent、LangChain、LangGraph、Runtime、Tool、Memory、Context Engineering、Eval。优先理解它解决什么问题、位于哪里、核心机制、适用与不适用场景、取舍。

架构能力
长期理解模块拆解、系统边界、数据流、状态归属、技术选型、扩展性、性能、稳定性、成本、安全和复杂度控制。架构是在约束下做合理取舍。

组织与领导能力
逐步积累沟通、文档、决策、推动、协调、分工、招聘、培养、团队建设和冲突处理，组织一群人解决更大的问题。

AI 协作：放大执行，保留人的关键判断

工作链：人的业务理解 → 需求拆解 → 系统设计 → 模块拆解 → 给 AI 足够上下文 → 加载对应 Skill / 专业知识 → Agent 实现 → 自动测试 / Eval → 人做关键 Review → 验收 → 复盘 → 继续迭代。

AI 可承担：调研、方案生成、技术比较、编码、测试、重构、Debug、文档、Review 和数据分析。

人重点掌控：为什么做、做什么、不做什么、模块边界、关键技术决策、Trade-off、成本、风险与验收标准。

学习与实践：以真实问题形成判断力

学习链：问题驱动 → 找到技术 → 明确它在系统里的作用 → 理解核心机制 → 做最小实践 → AI 辅助实现 → 实际项目验证 → 复盘 → 形成判断力。无需以学完所有技术为目标。

值得亲手实践：关键机制、核心抽象、数据流、异步、并发、状态管理、数据库事务、系统边界、Debug、性能问题。重复 CRUD、模板与样板代码可以交给 AI。

实践链：小功能 → 独立模块 → 完整项目 → 完整产品 → 多模块系统 → 多人协作 → 复杂系统 → 团队 → 业务 → 企业。

每次复盘：问题是什么？为什么做？怎么拆？为什么这样设计？如何实现和验收？哪些判断错了？下一次怎么改？最终沉淀工程直觉、技术判断、业务判断和系统判断。

人生底盘：长期运行的四个支撑系统

财务｜增加长期选择权
先保证安全，再追求增长。约 20% 用于安全资金 / 低风险储蓄，约 30% 长期投资自己，其余依人生阶段和风险承受能力配置，比例动态调整。投资自己包括 AI 会员、工具、学习、设备、生产力、必要的衣着与形象、有价值的体验。

身体｜所有系统的基础设施
不追求形式化自律，追求自己能够明显感受到、且长期可持续的健康状态。关注睡眠、饮食、运动、精力与情绪。

关系｜减少长期内耗
重视家庭、伴侣、朋友、同学、同事、导师与合作者。主动沟通、解决问题、保持边界，与积极、有行动力和成长意愿的人建立连接。

心态｜错误也是训练数据
允许判断错误、失败与后悔；不沉溺、不长期自责。复盘，更新认知模型，继续学习和行动。
