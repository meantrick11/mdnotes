# 查询参数模型

## 定义

与其每次函数定义都重新写多次重复的查询参数，那么可以考虑和Post方法中构造特定请求体的方式构造一个参数模型。有以下好处：
- 一次性声明参数声明验证和元数据
- 允许多个地方复用

## 使用Pydantic模型的查询参数

在Pydantic模型中声明需要查询的参数，然后让参数声明为Query

```python
from typing import Annotated, Literal

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()


class FilterParams(BaseModel):
    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@app.get("/items/")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```

**如果没有上述的声明为Query，fastapi底层会将上述参数解释为请求体而不是查询参数**

## 禁止额外的查询参数

使用Pydantic的模型配置来forbid任何extra字段：

```python
from typing import Annotated, Literal

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()


class FilterParams(BaseModel):
    model_config = {"extra": "forbid"}

    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@app.get("/items/")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```
