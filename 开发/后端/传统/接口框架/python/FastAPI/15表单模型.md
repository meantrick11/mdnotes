# 表单模型

和参数模型、请求体、Cookie、Header模型等等模型以外，Form同样可以使用模型获取参数

## Pydantic的表单模型

```python

from typing import Annotated

from fastapi import FastAPI, Form
from pydantic import BaseModel

app = FastAPI()


class FormData(BaseModel):
    username: str
    password: str


@app.post("/login/")
async def login(data: Annotated[FormData, Form()]):
    return data
```

## 禁止使用额外的表单字段

某些特殊的情况下，可以使用Pydantic声明仅仅限制在Pydantic模型中声明过的字段，并禁止任何额外的字段。

```python
from typing import Annotated

from fastapi import FastAPI, Form
from pydantic import BaseModel

app = FastAPI()


class FormData(BaseModel):
    username: str
    password: str
    model_config = {"extra": "forbid"}


@app.post("/login/")
async def login(data: Annotated[FormData, Form()]):
    return data
```
