# 路径参数和数值校验

## 导入Path

首先从fastapi导入Path和从typing中导入Annotated,Path同参数校验的Query

```python
from typing import Annotated
from fastapi inport FastAPI,Path,Query

app = FastAPI()

@app.get("/item/{item_id}")
async def read_item(
    item_id:Annotated[int,Path(title="The ID of item to get")],
    q:Annotated[str|None,Query(alias="item-query")]
):#定义一个路径参数使用Path校验和一个Query校验的查询参数
    return = {"item_id":item_id}

```

## 声明元数据

Path同Query一样，可以声明多个元数据进行校验

有以下参数可选：
| 参数名 | 作用 | 类型 / 默认值 |
| ---- | ---- | ---- |
| default | 参数默认值，设为 ... 表示必填 | Any / None |
| alias | 参数别名（URL 用别名，代码用原变量名） | str / None |
| title | 参数标题（OpenAPI 文档展示） | str / None |
| description | 参数描述（接口文档说明） | str / None |
| gt | 数值大于指定值 | float / None |
| ge | 数值大于等于指定值 | float / None |
| lt | 数值小于指定值 | float / None |
| le | 数值小于等于指定值 | float / None |
| min_length | 字符串最小长度 | int / None |
| max_length | 字符串最大长度 | int / None |
| pattern | 正则匹配（字符串必须符合规则） | str / None |

所以如果你想要设置默认值可以通过直接设置Path或Query内部的default参数或者直接Python语法的=也是可以的

## 按需对参数排序

在Python中，定义一个函数，可选参数必须排在必选参数之后，否则会报错。对于fastapi而言，它会通过Query、Path等来检测参数，而无需关心顺序。

```python
from fastapi import FastAPI, Path

app = FastAPI()


@app.get("/items/{item_id}")
async def read_items(q: str, item_id: int = Path(title="The ID of the item to get")):
    results = {"item_id": item_id}
    if q:
        results.update({"q": q})
    return results
```

上述代码中的有Path默认值的路径查询本应该放在参数查询字段之前的，fastapi会自动处理参数顺序问题。

但是如果使用Annotated就不用关注此问题：
```python
from typing import Annotated

from fastapi import FastAPI, Path

app = FastAPI()


@app.get("/items/{item_id}")
async def read_items(
    q: str, item_id: Annotated[int, Path(title="The ID of the item to get")]
):
    results = {"item_id": item_id}
    if q:
        results.update({"q": q})
    return results
```

**十分推荐使用Annotated定义函数参数的默认值**

## 数值校验

**适用于int和float的校验**

如果使用Query或者Path，可以声明数值约束，这里的ge=1,表示该参数的数值应该[greater than or equal],表示传入的参数数值应该大于等于1：

```python
from typing import Annotated

from fastapi import FastAPI, Path

app = FastAPI()


@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(title="The ID of the item to get", ge=1)], q: str
):
    results = {"item_id": item_id}
    if q:
        results.update({"q": q})
    return results
```

其他的大小比较,gt(greater than),le(less than or equel),lt(less than)

```python
from typing import Annotated

from fastapi import FastAPI, Path

app = FastAPI()


@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(title="The ID of the item to get", gt=0, le=1000)],
    q: str,
):
    results = {"item_id": item_id}
    if q:
        results.update({"q": q})
    return results
```
