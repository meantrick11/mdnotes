# 查询参数

**查询参数+数据校验+默认参数**

## 简单阐述

查询参数不是路径参数，就不是url中的/?字段，而是?a&b...这种字段，比如http://127.0.0.1:8000/items/?skip=0&limit=10

**代码实例**：
```python
import asycio
from fastapi import FastAPI

app = FastAPI()#创建一个app实例

@app.get("/item/{item}")
async def read_item(item,skip:int=10,limit:int=0):
    return fake_items_db[skip:skip+limit]

```

以上的item字段就是路径参数，而没有在'get'方法中的由函数定义的字段则是查询字段，所有应用于路径参数的流程也适用于查询参数：
- 编辑器支持
- 数据'解析'
- 数据校验(pydantic)
- 自动文档(docs/redoc)

## 默认值

设定函数中的查询参数有默认值

## 可选参数

设定函数查询参数的默认值为None

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

## 查询参数的类型转换

如果声明某个参数查询值为bool类型，那么所有非False or 0的元素都是True，完成自动转换

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None, short: bool = False):
    item = {"item_id": item_id}
    if q:
        item.update({"q": q})
    if not short:
        item.update(
            {"description": "This is an amazing item that has a long description"}
        )
    return item
```

访问`http://127.0.0.1:8000/items/foo?short=1`和`http://127.0.0.1:8000/items/foo?short=True`的效果是一样的。

## 多个路径参数和查询参数

可以声明多个路径参数和查询参数，由于url的路径先于查询，所以函数中的参数也应该保持路径参数在前，查询参数在后：

```python

from fastapi import FastAPI

app = FastAPI()

@app.get("/user/{user_id}/items/{item_id}")
async def read_user_item(user_id:int,item_id:str,q:str | None = None,shot:bool=False):
    item = {"item_id": item_id, "owner_id": user_id}
    if q:
        item.update({"q": q})
    if not short:
        item.update(
            {"description": "This is an amazing item that has a long description"}
        )
    return item
```

## 必选查询参数

如果查询参数默认设置为None，那么参数就不是必选的；
如果设置参数没有声明默认值，那么查询参数就是必选的。

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_user_item(
    item_id: str, needy: str, skip: int = 0, limit: int | None = None
):
    item = {"item_id": item_id, "needy": needy, "skip": skip, "limit": limit}
    return item
```

其中路径参数是必须的，否则不能路由，查询参数中的needy也是必须的，其他的查询参数有默认值，为非必须参数。
