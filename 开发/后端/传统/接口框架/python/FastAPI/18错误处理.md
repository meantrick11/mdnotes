# 错误处理
某种情况下，需要向API客户端返回错误提示，这些客户端包括前端浏览器、他人代码、物联网设备等。

你可能需要告诉客户端：
- 客户端有没有执行该操作的权限
- 客户端有没有访问该资源的权限
- 客户端访问的项目是否存在

遇到这些情况，通常需要返回400-199范围内的HTTP状态码。

## 使用HTTPEception

向客户端返回HTTP错误响应，额可以使用HTTPEception。

```python
from fastapi import FastAPI,HTTPEception

app = FastAPI()
items = {"foo":"The Foo Wreslers"}

@app.get("/item/{item_id}")
async def read_item(item_id:str):
    if item_id not in items:
        raise HTTPEception(status_code=404,detail="Item not found")
    return {"item":item[item_id]}
```

HTTPException 是额外包含了和 API 有关数据的常规 Python 异常。

因为是 Python 异常，所以不能 return，只能 raise。

这也意味着，如果你在路径操作函数里调用的某个工具函数内部触发了 HTTPException，那么路径操作函数中后续的代码将不会继续执行，请求会立刻终止，并把 HTTPException 的 HTTP 错误发送给客户端。

## 添加HTTP错误自定义响应头

HTTPEception的headers参数

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}


@app.get("/items-header/{item_id}")
async def read_item_header(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=404,
            detail="Item not found",
            headers={"X-Error": "There goes my error"},
        )
    return {"item": items[item_id]}
```

## 自定义异常处理器

可以使用与 Starlette 相同的异常处理工具添加自定义异常处理器。

如果HTTPEception的错误返回满足不了错误需求，那么可以使用JSONResponse自定义错误处理。

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse


class UnicornException(Exception):  #定义错误类型
    def __init__(self, name: str):
        self.name = name


app = FastAPI()


@app.exception_handler(UnicornException)
async def unicorn_exception_handler(request: Request, exc: UnicornException):   #添加app的错误处理逻辑，HTTPEception底层也是这么定义的
    return JSONResponse(
        status_code=418,
        content={"message": f"Oops! {exc.name} did something. There goes a rainbow..."},
    )


@app.get("/unicorns/{name}")
async def read_unicorn(name: str):  #使用UnicornEception错误
    if name == "yolo":
        raise UnicornException(name=name)
    return {"unicorn_name": name}
```


## 覆盖默认异常处理器

FastAPI 自带了一些默认异常处理器。

当你触发 HTTPException，或者请求中包含无效数据时，这些处理器负责返回默认的 JSON 响应。

你也可以用自己的处理器覆盖它们。

覆盖请求验证异常¶
请求中包含无效数据时，FastAPI 内部会触发 RequestValidationError。

它也内置了该异常的默认处理器。

要覆盖它，导入 RequestValidationError，并用 @app.exception_handler(RequestValidationError) 装饰你的异常处理器。

异常处理器会接收 Request 和该异常。

```python
from fastapi import FastAPI, HTTPException
from fastapi.exceptions import RequestValidationError
from fastapi.responses import PlainTextResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()


@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request, exc):
    return PlainTextResponse(str(exc.detail), status_code=exc.status_code)


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc: RequestValidationError):
    message = "Validation errors:"
    for error in exc.errors():
        message += f"\nField: {error['loc']}, Error: {error['msg']}"
    return PlainTextResponse(message, status_code=400)


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}
```

## 覆盖HTTPEception错误处理器
同理，也可以覆盖 HTTPException 的处理器。

例如，只为这些错误返回纯文本响应，而不是 JSON：


```python
from fastapi import FastAPI, HTTPException
from fastapi.exceptions import RequestValidationError
from fastapi.responses import PlainTextResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()


@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request, exc):
    return PlainTextResponse(str(exc.detail), status_code=exc.status_code)


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc: RequestValidationError):
    message = "Validation errors:"
    for error in exc.errors():
        message += f"\nField: {error['loc']}, Error: {error['msg']}"
    return PlainTextResponse(message, status_code=400)


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}
```
