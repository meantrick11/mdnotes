# 请求体-多个参数

## 混合使用Path、Query和请求体参数

三者分别独立，所以你可以混合使用，这里做一点区分：
- Path每次只接收一个参数校验，不支持先模型化
- 查询参数可以单参数，fastapi会优先将单参数解释为查询参数，同时也可以先模型化，此时需要在Annotated[item,Query()]中声明Query，fastapi才能解释为对应的查询参数

- 请求体参数由于是Body部分，所以声明的时候就要先模型化，就算是body中的单参数也需要使用Body()进行声明(importance:Annotated[int,Body()]),此时声明imporce是Body传递的参数，而不是查询参数

```python

from typing import Annotated

from fastapi import FastAPI, Path
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


@app.put("/items/{item_id}")
async def update_item(
    item_id: Annotated[int, Path(title="The ID of the item to get", ge=0, le=1000)],
    q: str | None = None,
    item: Item | None = None,
):
    results = {"item_id": item_id}
    if q:
        results.update({"q": q})
    if item:
        results.update({"item": item})
    return results
```
以上代码期望接收以下的JSON数据：
```json
{
    "name": "Foo",
    "description": "The pretender",
    "price": 42.0,
    "tax": 3.2
}
```

## 多个请求体参数

同样可以声明多个请求体：
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


class User(BaseModel):
    username: str
    full_name: str | None = None


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, user: User):
    results = {"item_id": item_id, "item": item, "user": user}
    return results
```

多个请求体声明之后期望接收以下JSON数据：
```json
{
    "item": {
        "name": "Foo",
        "description": "The pretender",
        "price": 42.0,
        "tax": 3.2
    },
    "user": {
        "username": "dave",
        "full_name": "Dave Grohl"
    }
}
```

## 请求体中的单一值

由于如果声明单一键，那么fastapi会将其解释为查询参数，这显然不是我们想要的。只需要我们在参数中添加Body()函数声明以下就可以变为Body的单一值了：

```python
from typing import Annotated

from fastapi import Body, FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


class User(BaseModel):
    username: str
    full_name: str | None = None


@app.put("/items/{item_id}")
async def update_item(
    item_id: int, item: Item, user: User, importance: Annotated[int, Body()]
):
    results = {"item_id": item_id, "item": item, "user": user, "importance": importance}
    return results
```

以上代码期望接收以下的JSON数据：
```json
{
    "item": {
        "name": "Foo",
        "description": "The pretender",
        "price": 42.0,
        "tax": 3.2
    },
    "user": {
        "username": "dave",
        "full_name": "Dave Grohl"
    },
    "importance": 5
}
```

## 多个请求体和查询参数

至此，已经了解了路径参数、查询参数的各个用法，那么可以进阶地混合使用他们

**注意：单一没有声明Body()的参数会默认解释为查询参数**

```python

from typing import Annotated

from fastapi import Body, FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


class User(BaseModel):
    username: str
    full_name: str | None = None


@app.put("/items/{item_id}")
async def update_item(
    *,
    item_id: int,
    item: Item,
    user: User,
    importance: Annotated[int, Body(gt=0)],
    q: str | None = None,
):
    results = {"item_id": item_id, "item": item, "user": user, "importance": importance}
    if q:
        results.update({"q": q})
    return results
```

## 嵌入单个请求体参数


原来(只在参数中声明单个请求体(item:Annotated[Item,Body()])),那么期望接收以下JSON数据：
```json
{
    "name": "Foo",
    "description": "The pretender",
    "price": 42.0,
    "tax": 3.2
}
```

如果想要实现嵌入单个请求体参数，接收如下JSON数据，如何做呢？
```json
{
    "item": {
        "name": "Foo",
        "description": "The pretender",
        "price": 42.0,
        "tax": 3.2
    }
}
```

只需要将Body()内部的参数embed设置为True就可以了：

```python
from typing import Annotated

from fastapi import Body, FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Annotated[Item, Body(embed=True)]):
    results = {"item_id": item_id, "item": item}
    return results
```
