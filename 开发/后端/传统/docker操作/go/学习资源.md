## 推荐资源

| 用途 | 资源 | 怎么用 |
| --- | --- | --- |
| 主文档 | [Docker Engine API](https://docs.docker.com/reference/api/engine/latest/) | 每天只查当天那一组 endpoint，不要通读 |
| Go SDK | [pkg.go.dev/github.com/moby/moby/client](https://pkg.go.dev/github.com/moby/moby/client) | 以 `go.mod` 里的版本为准，看 Options / Result 类型 |
| 任务书里的旧包名 | [github.com/docker/docker/client](https://pkg.go.dev/github.com/docker/docker/client) | 知道它在迁到 moby；新代码用 moby/client，概念相同 |
| 端口映射 | [go-connections/nat](https://pkg.go.dev/github.com/docker/go-connections/nat) | 只学 Port / PortSet / PortMap / PortBinding |
| 网络概念 | [Docker Engine networking](https://docs.docker.com/engine/network/) | 搞清 bridge vs 自定义网；沙箱不要用 host 网络 |
