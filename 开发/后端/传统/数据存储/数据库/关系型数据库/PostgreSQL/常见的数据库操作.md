# PostgreSQL 核心SQL速查笔记（开发高频精简版）
## 一、数据类型（业务开发常用，剔除冷门类型）
### 1. 数字类型
| 类型 | 用途 | 适用场景 |
| ---- | ---- | -------- |
| int | 整数 | 主键ID、数量、年龄、状态码（最常用） |
| bigint | 大整数 | 超大自增ID、流水号、设备编号 |
| numeric(m,n) | 高精度小数 | 金额、价格（禁止float存钱） |
| float8 | 浮点数 | 温度、百分比、非精确统计值 |

### 2. 字符串类型
| 类型 | 用途 | 适用场景 |
| ---- | ---- | -------- |
| varchar(n) | 可变长度字符串 | 姓名、手机号、地址、账号（日常主力） |
| text | 无限长文本 | 商品详情、评论、长备注 |
| char(n) | 固定长度 | 身份证、编码等固定位数字符（极少用） |

### 3. 时间类型
| 类型 | 用途 |
| ---- | ---- |
| timestamp | 年月日时分秒 | 创建时间、更新时间（开发标配） |
| date | 仅日期 | 生日、下单日期 |
| time | 仅时分秒 | 营业时间 |

### 4. 布尔 & 特殊类型
- boolean：true/false，标记是否启用、是否删除
- uuid：唯一标识，分布式业务主键
- jsonb：存储JSON结构化数据，支持索引查询（前端复杂参数）

## 二、DDL 表结构操作（操作表、字段、约束，不操作数据）
### 1. 创建表 CREATE TABLE
语法模板
```sql
CREATE TABLE 表名 (
    字段名 数据类型 约束,
    字段名 数据类型 约束
);
```
常用约束：`PRIMARY KEY`主键、`NOT NULL`非空、`UNIQUE`唯一、`DEFAULT 默认值`、`REFERENCES 关联表(主键)`外键、`CHECK`条件校验

### 2. 修改表 ALTER TABLE
1. 新增字段
```sql
ALTER TABLE 表名 ADD COLUMN 字段名 类型 约束;
```
2. 删除字段
```sql
ALTER TABLE 表名 DROP COLUMN 字段名;
```
3. 修改字段类型/约束
```sql
ALTER TABLE 表名 ALTER COLUMN 字段名 TYPE 新类型;
ALTER TABLE 表名 ALTER COLUMN 字段名 SET NOT NULL;
```
4. 表重命名
```sql
ALTER TABLE 旧表名 RENAME TO 新表名;
```

### 3. 删除整张表 DROP TABLE
```sql
DROP TABLE IF EXISTS 表名;
```

### DDL小结
- 增表：CREATE TABLE
- 改表结构：ALTER TABLE
- 删表：DROP TABLE
- DDL无查询操作，仅维护表结构

## 三、DML 数据操作（操作表内行数据，行业统称CRUD）
### C 新增数据 INSERT
```sql
-- 指定字段插入
INSERT INTO 表名(字段1,字段2) VALUES(值1,值2);
-- 批量插入多行
INSERT INTO 表名(字段1,字段2) VALUES(值1,值2),(值3,值4);
```

### R 查询数据 SELECT（使用频率最高）
#### 标准完整模板
```sql
SELECT 字段1,字段2 别名
FROM 表名
WHERE 行过滤条件
GROUP BY 分组字段
HAVING 分组后聚合过滤
ORDER BY 排序字段 DESC/ASC;
```
#### 执行固定顺序
`FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY`
- WHERE：分组前过滤原始数据，不能用聚合函数
- HAVING：分组完成后过滤，仅支持sum/count等聚合函数

### U 修改数据 UPDATE
```sql
UPDATE 表名
SET 字段1=值1,字段2=值2
WHERE 筛选条件;
-- 必须加WHERE，否则全表数据被修改
```

### D 删除数据 DELETE
```sql
DELETE FROM 表名 WHERE 筛选条件;
-- 仅删除行数据，表结构保留；不加WHERE清空全表
```

### DML 配套补充
1. TRUNCATE：快速清空表所有数据，保留表结构
```sql
TRUNCATE TABLE 表名;
```
2. DROP / DELETE / TRUNCATE 区分
- DROP TABLE：删除整张表，结构+数据全部销毁
- DELETE：删除指定行，可回滚，速度慢
- TRUNCATE：清空全部数据，不可回滚，速度极快

## 四、DDL与DML核心区分对照表
| 分类 | 全称 | 操作对象 | 核心语句 | CRUD对应 |
| ---- | ---- | -------- | -------- | -------- |
| DDL 数据定义语言 | Data Definition Language | 表结构、字段、约束 | CREATE / ALTER / DROP | 仅增、改、删表，无查询 |
| DML 数据操纵语言 | Data Manipulation Language | 表内存储的行数据 | INSERT / SELECT / UPDATE / DELETE | 标准CRUD（增查改删） |

## 五、高频开发常用关键字汇总
1. 查询筛选：WHERE、AND、OR、LIKE、IN、IS NULL
2. 聚合统计：COUNT、SUM、AVG、MAX、MIN
3. 分组排序：GROUP BY、HAVING、ORDER BY、LIMIT 分页
4. 表关联：JOIN、LEFT JOIN、INNER JOIN
