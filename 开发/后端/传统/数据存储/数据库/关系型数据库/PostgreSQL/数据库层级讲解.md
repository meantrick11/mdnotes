
PostgreSQL实例（整个PG服务，5432端口那个进程）
├─ 数据库A(database)  ← 就是你代码里 `dbname=test` 填的这个！
│   ├─ public（默认schema模式）
│   │   ├─ test表
│   │   └─ user表
│   └─ schema_other（自己新建的模式）
│       └─ orders表
├─ 数据库B(database)
│   └─ public
│       └─ ...表
└─ 用户/角色（全局，属于整个实例，不是属于某个数据库）
    ├─ postgres（超级管理员账号，代码里`user=postgres`）
    └─ dev_user（普通账号）
