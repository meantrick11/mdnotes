# 表单数据

## From()

通过fastapi中的Form类获取普通表单的数据，而不是JSON数据如：`username=Musk&passward=123456`，但是JSON为绝对的主流:
{
    username:Musk,
    password:123456,
}

## 使用From()获取表单数据

```python
from typing import Annotated

from fastapi import FastAPI, Form

app = FastAPI()


@app.post("/login/")
async def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    return {"username": username}
```

**你可以在一个路径操作中声明多个 Form 参数，但不能同时再声明要接收为 JSON 的 Body 字段，因为此时请求体会使用 application/x-www-form-urlencoded 而不是 application/json 进行编码。**

**这不是 FastAPI 的限制，而是 HTTP 协议的一部分。**
