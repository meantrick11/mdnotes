# 简单使用

## 简单实例

构造一个简单的FastAPI实例，然后在终端使用命令`fastapi dev (路径名,默认为main.py)`

```python
# 导入类
from fastapi import FastAPI
# 创建一个实例
app = FastAPI()

# 创建路径
@app.get("/")#实例之中规定方法，还有@app.post()@app.put()@app.delete()等等
async def root():
    return {"message": "Hello World"}
```

## OpenAPI
 
FastAPI定义API的OpenAPI标准为所有的API生成一个模式。

**模式**是对某事物的定义或者描述，他不是该事物的代码，仅仅是一种抽象描述。

**API模式**：这种情况下，OpenAPI是一项规范，它规定了如何定义API的模式。

**数据模式**：可能代指某种数据的形状，如JSON内容。这种情况下意味着JSON属性、数据类型等。

OpenAPI 为你的 API 定义了一个 API 模式。该模式使用 JSON Schema（JSON 数据模式的标准）包含了 API 发送和接收的数据定义（或“模式”）

可以通过访问`127.0.0.1:8000/openapi.json`查看，大抵长这样：
```json
{
    "openapi": "3.1.0",
    "info": {

        "version": "0.1.0"
    },
    "paths": {
        "/items/": {

                        "content": {
                            "application/json": {




                            }
                        }
                    }
                }
            }
        }
    }
}
```

### OpenAPI的用途

OpenAPI模式是驱动所包含的两个交互式文档系统的基础。

此外还有许多其他替代方案，它们全部基于 OpenAPI。你可以轻松地将这些替代方案添加到使用 FastAPI 构建的应用程序中。

你还可以使用它为与你的 API 通信的客户端自动生成代码。例如，前端、移动或物联网 (IoT) 应用程序。

## 总结一个简单web应用的流程

- 导入FastAPI
- 创建一个app实例
- 使用类似`@app.get("\")`的装饰器编写路径操作装饰器
- 定义一个路径操作数；比如，`def root:...`。
- 使用命令`fastapi dev (file/path)`行开发服务器
- 选择性地使用`fast deploy`部署应用
