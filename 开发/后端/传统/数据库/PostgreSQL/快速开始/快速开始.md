# 快速开始

本教程适用于PostgreSQL的初学者，主要讲PostgreSQL数据库的安装、连接、查询等基础操作。

本节聚焦PostgreSQL的背景，安装、连接数据库、加载.tar类型的数据到数据库四个方面。

> PostgreSQL 是一款先进的开源关系型数据库，独立开发者、大型企业都在广泛使用，本文介绍的内容适用于任何环境部署的 Postgres。

### 1.1 概述
通过本文，你将了解 PostgreSQL 及其适用场景。

### 1.2 什么是 PostgreSQL
先从基础问题入手：什么是 PostgreSQL？

PostgreSQL 是一套先进、企业级、开源的关系型数据库系统，**同时支持 SQL（关系型数据）与 JSON（非关系型数据）查询**。

经过开源社区二十余年持续迭代，PostgreSQL 拥有极高稳定性。
大量Web应用、移动端程序、数据分析系统都将 PostgreSQL 作为主数据库。

社区标准读音：/ˈpoʊstɡrɛs ˌkjuː ˈɛl/

### 1.3 PostgreSQL 发展历史
PostgreSQL 项目始于1986年，诞生于加州大学伯克利分校计算机系。

项目最初命名为 POSTGRES，取名自伯克利同期开发的 Ingres 数据库。POSTGRES 的开发目标：增加基础能力，用来支持多种自定义数据类型。

1996年，项目正式更名为 PostgreSQL，直观体现它对SQL标准的支持。日常交流中大家常简称为 Postgres。

此后，由全球开发者组成的 PostgreSQL 全球开发小组持续维护、迭代这个免费开源数据库。

PostgreSQL 最初仅能在类 Unix 系统运行，后续逐步支持 Windows、macOS、Solaris 等各类操作系统。

### 1.4 PostgreSQL 典型应用场景
#### 1. LAPP 技术栈可靠数据库
LAPP = Linux、Apache、PostgreSQL、PHP（也可替换为 Python、Perl）。
PostgreSQL 常作为后端数据库，支撑大量动态网站与Web服务。

#### 2. 通用事务型主数据库
无论是大型企业还是初创公司，都经常使用 PostgreSQL 作为业务核心数据库，支撑软件产品。

#### 3. 地理空间数据库
搭配 PostGIS 扩展后，PostgreSQL 可以作为地理信息系统（GIS）的空间数据库。

### 1.5支持的编程语言
PostgreSQL 兼容主流开发语言：
- Python
- PHP
- Java
- C#
- C/C++
- Ruby

### 1.6 PostgreSQL 核心特性亮点
具备众多商业级数据库才有的高级能力：
- 用户自定义数据类型
- 表继承
- 完善的锁机制
- 外键参照完整性
- 视图、规则、子查询
- 嵌套事务（保存点 Savepoint）
- 多版本并发控制（MVCC）
- 异步复制

新版本持续新增能力：
- 原生 Windows 服务端版本
- 表空间（Tablespaces）
- 时间点恢复（PITR）

PostgreSQL 高度可扩展：你可以自定义数据类型、索引类型、函数语言等。
如果你需要定制能力，还可以开发插件，例如扩展查询优化器。

### 1.7哪些企业在使用 PostgreSQL
大量企业基于 PostgreSQL 搭建产品与解决方案，知名厂商：苹果、富士通、红帽、思科、瞻博网络、Instagram 等。

## 2.0 Postgres的安装

### 2.1 Windows上的安装

> 说明：无论你线上生产环境使用哪种Postgres，Windows本地安装流程完全通用。如果不想本地部署，可使用Neon免费云Postgres，无需信用卡。
> PostgreSQL 原生为类Unix系统开发，但具备良好跨平台能力，可运行在 macOS、Solaris、Windows 系统。

#### 2.1.1 整体安装三大步骤
1. 下载 Windows 版 PostgreSQL 安装程序
2. 通过安装向导完成数据库部署
3. 将 PostgreSQL 的 bin 目录添加到系统 PATH 环境变量

##### 2.1.2下载 Windows 安装包
1. 打开 https://www.enterprisedb.com/downloads/postgres-postgresql-downloads 官方下载页面
2. 下载 Windows x86-64 版本（16.1或最新版），等待下载完成
![下载地址](./pictures/EDB下载地址.png)
##### 2.1.3 Windows 分步安装教程
**安装程序需要管理员权限运行**
1. 双击安装包，启动可视化安装向导，按需自定义配置
![安装1](./pictures/安装1.png)
2. 点击 `Next` 下一步
3. 选择程序安装目录，可自定义路径或使用默认路径，点击 `Next`‘
![安装2](./pictures/安装2.png)
4. 选择需要安装的组件：
    - **PostgreSQL Server**：数据库核心服务（必选）
    - **pgAdmin 4**：图形化数据库管理工具（必选）
    - **Stack Builder**：扩展/驱动下载工具，可取消勾选
    - **Command Line Tools**：命令行工具（psql、pg_restore等，必选）
    取消 Stack Builder 后点击 `Next`，进入数据目录设置
![安装3](../PostgreSQL/pictures/安装3.png)
5. 设置数据库数据存放目录（数据库真实存储位置），自定义或默认，点击 `Next`
![安装4](./pictures/安装4.png)
6. 设置超级用户 `postgres` 的登录密码，重复输入确认，点击 `Next`
7. 设置数据库监听端口，默认 `5432`，确认端口未被其他程序占用，点击 `Next`
![安装5](./pictures/安装5.png)
8. 设置服务器默认区域语言（Locale），保持 `DEFAULT` 会自动读取系统区域配置，点击 `Next`
9. 汇总页面核对所有配置，无误点 `Next`；需修改则点 `Back` 返回调整
![安装6](./pictures/安装6.png)
10. 确认开始安装，等待几分钟完成部署
![安装7](./pictures/安装7.png)
11. 点击 `Finish` 结束安装

##### 2.1.4 配置 PATH 环境变量（关键）
将 bin 目录加入环境变量后，任意文件夹下都能直接执行 psql、pg_restore 等命令，无需切换目录。

###### 1. 找到 bin 目录路径
*bin目录就在你安装目录之下的子目录中*
默认路径格式：
```
C:\Program Files\PostgreSQL\<版本号>\bin
```
示例（16版本）：
```
C:\Program Files\PostgreSQL\16\bin
```


###### 2. 打开环境变量面板
1. 快捷键 `Win + R` 打开运行窗口
2. 输入 `sysdm.cpl` 回车，打开系统属性
3. 切换到【高级】选项卡，点击【环境变量】

窗口分为两块：
- 用户变量：仅当前Windows账户生效
- 系统变量：本机所有账户全局生效（私人电脑推荐使用）

###### 3. 添加路径到PATH
1. 在【系统变量】列表找到 `Path`，选中后点击【编辑】
2. 弹窗点击【新建】
3. 粘贴你的 PostgreSQL bin 完整路径，确认保存
4. 依次关闭所有弹窗，全部点击【确定】

#### 2.1.5 完成
至此本地 PostgreSQL 服务安装配置完毕，下一步学习如何连接数据库。


### 2.2 Linux上的安装

#### 2.2.1 说明
无论你在笔记本、虚拟机还是生产服务器部署 Linux 版 PostgreSQL，操作流程统一；文中教程适用于所有标准 PostgreSQL 发行版。
替代本地安装方案：Neon 提供免费云 PostgreSQL，无需绑定信用卡，开箱即用。

主流 Linux（Debian、CentOS/CentOS、SUSE、Ubuntu）都内置 PostgreSQL 软件源，**推荐使用系统包管理器安装**，可自动完成系统适配、补丁更新、版本管理。

#### 2.2.2 在 Ubuntu 22.04 安装 PostgreSQL 16
##### 步骤1：添加 PostgreSQL 官方软件源
1. 更新软件索引，安装依赖工具
```bash
sudo apt update
sudo apt install gnupg2 wget
```
2. 写入 PostgreSQL 官方源配置
```bash
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
```
3. 导入软件源校验密钥
```bash
curl -fsSL https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/postgresql.gpg
```
4. 再次更新软件包列表，加载新源
```bash
sudo apt update
```

##### 步骤2：安装 PostgreSQL 16
1. 安装数据库核心与扩展工具集
```bash
sudo apt install postgresql-16 postgresql-contrib-16
```
2. 启动 PostgreSQL 服务
```bash
sudo systemctl start postgresql
```
3. 设置开机自启
```bash
sudo systemctl enable postgresql
```

##### 步骤3：配置数据库（开启远程访问）
PostgreSQL 配置文件存放路径：`postgresql.conf`，可用 nano/vim 编辑。
```bash
sudo nano /etc/postgresql/16/main/postgresql.conf
```
修改监听地址，允许外部设备连接：
```ini
listen_addresses = '*'
```

修改身份认证配置文件 `pg_hba.conf`，开启密码登录与全网访问：
```bash
# 修改本地与局域网认证方式
sudo sed -i '/^host/s/ident/md5/' /etc/postgresql/16/main/pg_hba.conf
sudo sed -i '/^local/s/peer/trust/' /etc/postgresql/16/main/pg_hba.conf
# 允许所有IP通过密码访问所有库
echo "host all all 0.0.0.0/0 md5" | sudo tee -a /etc/postgresql/16/main/pg_hba.conf
```

修改配置后重启服务生效：
```bash
sudo systemctl restart postgresql
```

放行防火墙 5432 数据库端口：
```bash
sudo ufw allow 5432/tcp
```

#### 2.2.3 连接 PostgreSQL 数据库
1. 切换到 postgres 系统用户，进入 psql 命令行
```bash
sudo -u postgres psql
```
2. 给超级用户 postgres 设置登录密码，替换`<password>`为自定义密码
```sql
ALTER USER postgres PASSWORD '<password>';
```
3. 退出 psql 终端
```sql
\q
```

#### 2.2.4 导入 dvdrental 练习示例库
1. 下载示例库压缩包
```bash
curl -O https://neon.com/postgresqltutorial/dvdrental.zip
```
2. 解压得到 tar 备份文件
```bash
unzip dvdrental.zip
```
3. 登录数据库
```bash
sudo -u postgres psql
```
4. 创建 dvdrental 空数据库
```sql
create database dvdrental;
```
5. 退出 psql
```sql
\q
```
6. 使用 pg_restore 恢复数据
```bash
pg_restore -U postgres --dbname=dvdrental --verbose dvdrental.tar
```
7. 重新登录数据库
```bash
psql
```
8. 切换至 dvdrental 库
```sql
\c dvdrental
```
9. 校验数据（查询影片总条数，正常返回1000）
```sql
select count(*) from film;
```
输出结果：
```
count
-------
  1000
(1 row)
```

## 3.0 数据库的连接

### 3.1 概述
无论PostgreSQL部署在本地、虚拟机还是云服务器，使用psql、pgAdmin连接的操作逻辑完全一致。
本文讲解两种主流连接方式：命令行工具`psql`、图形化管理工具`pgAdmin`。
安装PostgreSQL时会自动附带这两款客户端工具。

### 3.2 使用 psql 命令行连接数据库
psql是PostgreSQL内置交互式终端工具，可执行SQL、管理数据表、数据库对象。

### 3.2.1 操作步骤
1. Windows打开CMD，Linux/macOS打开终端
2. 执行连接命令：
```cmd
psql -U postgres
```
参数说明：
- `psql`：启动命令行客户端
- `-U postgres`：指定登录用户名postgres（参数U必须大写）

3. 提示输入密码：
```
Password for user postgres:
```
输入安装数据库时设置的postgres管理员密码，回车确认。

4. 登录成功，提示符变为：
```
postgres=#
```
此时默认连接系统自带`postgres`库，建立持久会话，可执行多条SQL。

### 3.2.2 常用查询验证语句
1. 查看当前PostgreSQL版本（SQL末尾必须带分号;）
```sql
SELECT version();
```
示例输出：
```
version
------------------------------------------------------------
PostgreSQL 16.1, compiled by Visual C++ build 1937, 64-bit
(1 row)
```

2. 查看当前正在使用的数据库
```sql
SELECT current_database();
```
输出：
```
current_database
------------------
postgres
(1 row)
```

3. 查看当前连接的IP与端口
```sql
SELECT inet_server_addr(), inet_server_port();
```
本地连接输出：
```
inet_server_addr | inet_server_port
------------------+------------------
127.0.0.1        | 5432
(1 row)
```
### 3.2.3 psql的常见操作
psql是PostgreSQL的内置中断操作程序，以一下常见操作（除基础的SQL语法外）：
```
\l        列出所有数据库（list databases）
\c 库名    切换/连接到指定数据库（connect）
\dt       查看当前库下所有数据表（display tables）
\dt+      查看表+额外信息（大小、注释）
\df       查看函数
\dv       查看视图
\di       查看索引
\ds       查看序列
\d 表名    查看一张表的结构、字段、主键、外键（最重要！）
\d+ 表名   表结构详细信息
\du       列出所有数据库用户
\password 用户名  修改用户密码
\q        退出 psql 终端（quit）
\h        查看SQL语法帮助
\?        查看全部psql元命令帮助
\x        开启/关闭横向/纵向展示查询结果（查询长数据超好用）
\i 文件路径  执行外部sql脚本文件
```

### 3.3 使用 pgAdmin 图形化工具连接数据库
pgAdmin可视化界面，适合新手直观管理数据库，无需记忆命令。

### 3.3.1 操作步骤
1. 从Windows开始菜单启动pgAdmin，自动在浏览器打开管理页面
2. 左侧右键【Servers】→【Register】→【Server…】新建服务器连接
3. 【常规】标签填写自定义名称，例如`Local-Postgres`，切换到【连接】标签
4. 填写连接信息：
   - Hostname：`127.0.0.1`
   - Port：`5432`
   - Username：`postgres`
   - Password：安装时设置的数据库密码
5. 点击【Save】保存连接
6. 展开新建的服务器，默认可见系统库`postgres`
7. 顶部菜单【Tools】→【Query Tool】打开SQL编辑器
8. 在编辑器输入SQL，点击执行按钮，下方【Data Output】展示查询结果

## 4.0 从外部的.tar文件加载数据表到数据库中

此教程在linux安装时已经有讲解，此处讲解Windows上的操作

### 4.1 前置准备
1. 本地 PostgreSQL 服务正常运行，已配置好 `psql`、`pg_restore` 命令环境变量；
2. 下载 `dvdrental.zip` 压缩包，解压得到 `dvdrental.tar` 备份文件（**必须是tar文件，不能直接用zip**）；
>dvdrental是模拟DVD租赁业务的PostgreSQL练习库，内含15张关联表及各类数据库对象，下载解压为tar文件后可通过psql或pgAdmin导入本地库用于SQL练习。下载地址为`https://neon.com/postgresqltutorial/dvdrental.zip`。

### 4.2 方式1：命令行 psql + pg_restore（Windows/Linux通用）
#### 4.2.1 登录数据库，创建空库 dvdrental
1. 打开终端执行登录：
```cmd
psql -U postgres
```
输入安装时设置的postgres密码，提示符变为 `postgres=#`；
2. 新建数据库：
```sql
CREATE DATABASE dvdrental;
```
3. 校验库是否创建成功：`\l` 查看数据库列表，出现dvdrental即成功；
4. 退出psql：`exit`。

#### 4.2.2 执行数据恢复导入

```cmd
pg_restore -U postgres -d dvdrental 你的tar文件完整路径
```
参数说明：
- `-U postgres`：使用超级用户postgres连接；
- `-d dvdrental`：指定导入目标数据库；
执行后输入密码，等待几秒自动建表、插入全部测试数据。

#### 4.2.3 校验导入结果
1. 重新登录 `psql -U postgres`；
2. 切换至练习库：`\c dvdrental`；
3. 查看全部数据表：`\dt`，输出15张业务表代表导入完成。

### 4.3 方式2：图形化 pgAdmin 导入（新手友好）
1. 打开pgAdmin并连接本地PostgreSQL服务器；
2. 左侧右键【Databases】→【Create】→【Database】，名称填 `dvdrental`，保存；
3. 右键新建的dvdrental库 → 选择【Restore】；
4. 弹窗设置：格式选`Custom or tar`，Filename选中本地`dvdrental.tar`；
5. 点击Restore等待完成；
6. 展开dvdrental → Schemas → public → Tables，即可看到全部数据表。

### 4.4 关键注意事项
1. 必须**先创建空数据库**，再执行恢复，不存在库会直接报错；
2. tar文件路径不要包含中文、空格，避免读取失败；
3. 导入完成后，`dvdrental.zip`、`dvdrental.tar` 源文件可直接删除，数据已完整存入PostgreSQL的data目录；
4. 命令行操作前提：PostgreSQL的bin目录已加入系统PATH，否则需写完整pg_restore程序路径执行。

### 4.5 用途
dvdrental 具备完整主外键关联、真实业务数据，适合零基础练习各类SQL语法、多表联查、统计分析，是PostgreSQL官方推荐标准练习数据集。
