`FileContent`表示可附加到[`ChatMessage`](https://docs.haystack.deepset.ai/docs/chatmessage)上的文件负载。当聊天模型接受PDF或其他文档等文件输入以及用户的文本提示时，请使用它。

### 属性

```python
@dataclass
class FileContent:
    base64_data: str
    mime_type: str | None = None
    filename: str | None = None
    extra: dict[str, Any] = field(default_factory=dict)
    validation: bool = True
```



- base64_data 将文件内容以 base64 编码字符串的形式存储。
- `mime_type` 用于标识文件类型，例如 `application/pdf`。建议明确提供该类型，因为许多模型提供商都要求提供。
- `filename`为可选参数，但部分提供方在处理上传文件时会使用该参数。
- `extra` 可存储特定于提供程序的元数据。值应可进行 JSON 序列化。
- `validation`会检查`base64_data`是否有效，并在未提供 MIME 类型时尝试推断其类型。


### 从文件路径创建

使用`from_file_path`读取本地文件，对其进行 Base64 编码，从路径推断 MIME 类型并填充文件名。


```python
from haystack.dataclasses import ChatMessage, FileContent

file_content = FileContent.from_file_path("data/attention-is-all-you-need.pdf")

message = ChatMessage.from_user(
    content_parts=[
        file_content,
        "Summarize the key ideas in this paper.",
    ]
)
```

当提供程序需要特定文件名或提供程序特定选项时，请传递`filename`或`extra`：

```python
file_content = FileContent.from_file_path(
    "data/report.pdf",
    filename="quarterly-report.pdf",
    extra={"source": "finance"},
)
```

### 从URL中创建

使用`from_url`下载文件并将其转换为`FileContent`实例。

```python
from haystack.dataclasses import FileContent

file_content = FileContent.from_url(
    "https://example.com/reports/quarterly-report.pdf",
    timeout=30,
)
```

如果未提供文件名，Haystack 会使用 URL 的最后一个路径段。


### 基于Base64数据创建

如果你已经有文件字节，请对其进行编码并明确传递 MIME 类型。

```python
import base64
from pathlib import Path

from haystack.dataclasses import FileContent

data = Path("data/manual.pdf").read_bytes()
file_content = FileContent(
    base64_data=base64.b64encode(data).decode("utf-8"),
    mime_type="application/pdf",
    filename="manual.pdf",
)
```
仅当 base64 数据和 MIME 类型已受信任，且你希望跳过验证时，才设置 ``validation=False``。

## 检查ChatMessage文件

将 `FileContent` 添加到 `ChatMessage` 后，使用 `file` 和 `files` 属性访问文件负载。
```python
from haystack.dataclasses import ChatMessage, FileContent

file_content = FileContent.from_file_path("data/invoice.pdf")
message = ChatMessage.from_user(
    content_parts=[file_content, "Extract the invoice total."]
)

print(message.file)
print(message.files)
```
`message.file` 返回第一个文件负载，若无文件则返回 `None`。`message.files` 返回所有文件负载。


## 序列化

使用`to_dict`和`from_dict`来序列化和恢复文件内容。
```python
payload = file_content.to_dict()  

restored = FileContent.from_dict(payload)
```
在进行追踪时，Haystack 会将完整的 base64 负载替换为占位符，因此大型文件不会被发送到追踪后端。
