# 创建自定义组件

你可以创建独属的组件，并可以使用Pipeline进行串联。

借助 Haystack，你可以轻松为各类任务创建任意自定义组件，从筛选结果到与外部软件集成都不在话下。随后你可以在 Haystack 内部插入、复用和分享这些组件，甚至还能将它们打包后提交至Haystack 集成平台，供外部用户使用！

## 自定义的要求


以下是所有自定义组件的要求：
- @component：该装饰器将一个类标记为组件，使其能够在管道中使用
- run():这是每个组件必须要实现的方法

**组件就是通过@component装饰器修饰后的有输入和输出可以被Pipeline连接的类的封装**

注意：
*在构建自定义组件时，请勿直接修改组件的输入。相反，应处理输入的副本或新版本，对其进行修改后再返回。原因在于原始输入值可能会被其他组件或后续的流水线步骤重复使用。直接修改输入会导致流水线中出现意外的副作用和错误，因为其他组件可能依赖于原始输入值。*

当仅需修改输入的一个或少数几个字段时（例如 meta 位于 Document 上），可使用 dataclasses.replace() 创建包含更新后字段的新实例。这比深度复制整个对象更简单、更高效：
```python
from dataclasses import replace


def run(self, documents):
    updated = [replace(doc, meta={**doc.meta, "processed": True}) for doc in documents]
    return {"documents": updated}
```
当你需要修改嵌套的可变结构（例如 list 或 dict 属性），或更新数据类实例的多个字段时，请使用完整的深拷贝：
```python

import copy


def run(self, documents):
    documents_copy = copy.deepcopy(documents)
    # mutate documents_copy safely here
    return {"documents": documents_copy}
    
```


## 输入和输出

*输入和输出是组件最重要能力，无论使用Pipeline与否，都需要又明确定义的输入和输出*

### 输入

你可以在三种输入选项中选择：
- set_input_type：此方法定义或更新组件实例的单个输入套接字。**非常适合在运行时添加或修改特定输入而不影响其他输入。当你需要根据特定条件动态设置或修改单个输入时，可使用此方法。**
- set_input_types：此方法允许你一次性定义多个输入接口，替换所有现有输入。**当你明确组件所需的全部输入并希望批量配置时，该方法非常实用。请在初始化期间需要定义多个输入时使用它。**
- 直接在 run() 方法中声明参数。**当组件的输入在类定义时即为静态且已知时，可使用此方法。**

### 输出

你可以在两种输出选项中进行选择：

- @component.output_types：该装饰器在类定义时指定输出类型和名称。输出名称和类型必须与 dict 由 run() 方法返回的内容相匹配。**当输出类型为静态且预先已知时，可使用此装饰器。对于静态组件，该装饰器更简洁且可读性更强。**
- set_output_types：此方法在运行时为组件实例定义或更新多个输出套接字。**当你需要灵活地动态配置输出时，此方法非常有用。当需要在运行时设置输出类型以获得更高灵活性时，可使用此方法。**


### 简单示例

```python
from haystack import component


@component
class WelcomeTextGenerator:
    """
    A component generating personal welcome message and making it upper case
    """

    @component.output_types(welcome_text=str, note=str)
    def run(self, name: str):
        return {
            "welcome_text": f"Hello {name}, welcome to Haystack!".upper(),
            "note": "welcome message is ready",
        }

```

这里,**自定义组件接收的输入：name:str，并定义有两个输出welcome_text&note,是正常的组件定义的方法**


### 扩展示例

这个示例展示了如何自定义组件，并将其通过pipeline连接：

```python
# import necessary dependencies
from haystack import component, Pipeline


# Create two custom components. Note the mandatory @component decorator and @component.output_types, as well as the mandatory run method.
@component
class WelcomeTextGenerator:
    """
    A component generating personal welcome message and making it upper case
    """

    @component.output_types(welcome_text=str, note=str)
    def run(self, name: str):
        return {
            "welcome_text": (
                "Hello {name}, welcome to Haystack!".format(name=name)
            ).upper(),
            "note": "welcome message is ready",
        }


@component
class WhitespaceSplitter:
    """
    A component for splitting the text by whitespace
    """

    @component.output_types(split_text=list[str])
    def run(self, text: str):
        return {"split_text": text.split()}


# create a pipeline and add the custom components to it
text_pipeline = Pipeline()
text_pipeline.add_component(
    name="welcome_text_generator",
    instance=WelcomeTextGenerator(),
)
text_pipeline.add_component(name="splitter", instance=WhitespaceSplitter())

# connect the components
text_pipeline.connect(
    sender="welcome_text_generator.welcome_text",
    receiver="splitter.text",
)

# define the result and run the pipeline
result = text_pipeline.run({"welcome_text_generator": {"name": "Bilge"}})

print(result["splitter"]["split_text"])
```

##### 无论多少组件相连都需要手动connect

**为了数据可控，并且每个组件都是数据的输入/输出源**
A → B
pipeline.connect("A.out1", "B.input")

A → C
pipeline.connect("A.out1", "C.input")

A → D
pipeline.connect("A.out1", "D.input")
