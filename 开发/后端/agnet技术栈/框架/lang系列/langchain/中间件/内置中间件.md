# LangChain 内置中间件（Prebuilt Middleware）

LangChain 和 Deep Agents 为常见智能体用例提供了预构建的中间件。每个中间件都是生产级可用的，并可根据你的具体需求进行配置。

以下中间件适用于任何 LLM 供应商：

| 中间件 | 描述 |
|---|---|
| 工具错误（Tool error） | 捕获工具执行异常并将其转换为模型可读的错误消息 |
| 工具重试（Tool retry） | 自动以指数退避重试失败的工具调用 |
| 模型重试（Model retry） | 自动以指数退避重试失败的模型调用 |
| 模型回退（Model fallback） | 主模型失败时自动回退到备用模型 |
| 摘要（Summarization） | 接近 Token 限制时自动总结对话历史 |
| 人工介入（Human-in-the-loop） | 暂停执行，等待人工批准工具调用 |
| 模型调用限制（Model call limit） | 限制模型调用次数以防止过度开销 |
| 工具调用限制（Tool call limit） | 通过限制调用次数来控制工具执行 |
| PII 检测（PII detection） | 检测并处理个人身份信息 |
| 待办事项列表（To-do list） | 为智能体提供任务规划与跟踪能力 |
| LLM 工具选择器（LLM tool selector） | 在主模型调用前使用 LLM 筛选相关工具 |
| 供应商工具搜索（Provider tool search） | 将工具延迟到供应商的服务器端工具搜索，按需呈现 |
| Shell 工具（Shell tool） | 为智能体暴露持久化 Shell 会话以执行命令 |
| 文件系统（Filesystem） | 为智能体提供文件系统，用于存储上下文和长期记忆 |
| 子智能体（Subagent） | 添加生成子智能体的能力 |
| 评分标准（Rubric grading，Beta） | 应用 LLM-as-a-judge 评分，使智能体自我评估并迭代直至满足标准 |
| 文件搜索（File search） | 提供对文件系统文件的 Glob 和 Grep 搜索工具 |
| 上下文编辑（Context editing） | 通过裁剪或清除工具使用记录来管理对话上下文 |
| LLM 工具模拟器（LLM tool emulator） | 使用 LLM 模拟工具执行以用于测试 |

---

## 1. 工具错误（Tool error）

**对应装饰器：`@wrap_tool_call`（工具调用包装器）。**

捕获工具执行期间引发的异常，并将其转换为模型可见且可从中恢复的错误 `ToolMessage`，而不是中止智能体运行。

**适用场景**：
- 让模型使用修正后的参数重试失败的工具调用。
- 呈现受控的、经过清理的错误消息，而非原始异常详情。
- 防止意外的工具异常导致智能体崩溃。

**配置选项**：
- `on_error`：同步异常处理函数，返回字符串或内容块列表，将异常转换为 `ToolMessage(status="error")`。返回 `None` 则让异常传播。
- `aon_error`：可选的异步处理函数，未提供时回退到 `on_error`。
- `tools`：可选，指定要应用错误处理的工具列表或工具名称，`None` 表示应用于所有工具。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ToolErrorMiddleware

def on_tool_error(error: Exception) -> str:
    return f"Tool failed: {error}"

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ToolErrorMiddleware(
            on_error=on_tool_error,
            tools=["my_tool"],  # 可选；None 表示所有工具
        ),
    ],
)
```

## 2. 工具重试（Tool retry）

**对应装饰器：`@wrap_tool_call`（工具调用包装器）。**

自动以可配置的指数退避重试失败的工具调用。

**适用场景**：
- 处理外部 API 调用中的瞬时故障。
- 提高依赖网络的工具的可靠性。
- 构建能够优雅处理临时错误的弹性智能体。

**配置选项**：
- `max_retries`：初始调用后的最大重试次数（默认总共 3 次尝试）。
- `backoff_factor`：指数退避乘数，每次重试等待 `initial_delay * (backoff_factor ** retry_number)` 秒。
- `initial_delay`：首次重试前的初始延迟（秒）。
- `max_delay`：重试之间的最大延迟上限。
- `jitter`：是否添加随机抖动（±25%）以避免惊群效应。
- `on_failure`：重试耗尽后的行为。`'continue'`（默认）返回包含错误详情的 `ToolMessage`；`'error'` 重新抛出异常；自定义可调用对象返回字符串作为 `ToolMessage` 内容。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ToolRetryMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ToolRetryMiddleware(
            max_retries=3,
            backoff_factor=2.0,
            initial_delay=1.0,
            max_delay=60.0,
            jitter=True,
            on_failure="continue",
        ),
    ],
)
```

## 3. 模型重试（Model retry）

**对应装饰器：`@wrap_model_call`（模型调用包装器）。**

自动以可配置的指数退避重试失败的模型调用。

**适用场景**：
- 处理模型 API 调用中的瞬时故障。
- 提高依赖网络的模型请求的可靠性。
- 构建能够优雅处理临时模型错误的弹性智能体。

**配置选项**：
- `max_retries`：初始调用后的最大重试次数（默认总共 3 次尝试）。
- `retry_on`：要重试的异常类型元组，或接收异常并返回布尔值的可调用对象。从 `langchain>=1.3.16` 起，默认重试可重试的模型错误和所有未分类异常，不再重试标记为不可重试的模型错误。
- `on_failure`：重试耗尽后的行为。`'continue'`（默认）返回包含错误详情的 `AIMessage`；`'error'` 重新抛出异常；自定义可调用对象返回字符串作为 `AIMessage` 内容。
- `backoff_factor`：指数退避乘数。
- `initial_delay`：首次重试前的初始延迟（秒）。
- `max_delay`：重试之间的最大延迟上限。
- `jitter`：是否添加随机抖动（±25%）。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ModelRetryMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ModelRetryMiddleware(
            max_retries=3,
            retry_on=(Exception,),
            on_failure="continue",
            backoff_factor=2.0,
            initial_delay=1.0,
            max_delay=60.0,
            jitter=True,
        ),
    ],
)
```

## 4. 模型回退（Model fallback）

**对应装饰器：`@wrap_model_call`（模型调用包装器）。**

主模型失败时自动回退到备用模型。

**适用场景**：
- 构建能够处理模型服务中断的弹性智能体。
- 通过回退到更便宜的模型来优化成本。
- 跨 OpenAI、Anthropic 等供应商的冗余。

**配置选项**：
- 第一个回退模型：主模型失败时首先尝试的模型，可以是模型标识字符串（如 `'openai:gpt-5.4-mini'`）或 `BaseChatModel` 实例。
- 额外的回退模型：如果之前的模型失败，按顺序尝试的更多回退模型。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ModelFallbackMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ModelFallbackMiddleware(
            "openai:gpt-4o-mini",
            "anthropic:claude-3-5-sonnet",
        ),
    ],
)
```

## 5. 摘要（Summarization）

**对应装饰器：`@before_model`（模型调用前钩子）。**

接近 Token 限制时自动总结对话历史，保留最近消息，同时压缩较早的上下文。

**适用场景**：
- 超出上下文窗口的长时间运行对话。
- 具有大量历史记录的多轮对话。
- 需要保留完整对话上下文的应用。

**注意**：摘要中间件是面向文本的上下文压缩，不会调整图像/音频/视频负载的大小或进行下采样。被保留的最近消息仍包含其原始多模态块，而被摘要的较早多模态消息仅以生成的文本摘要形式表示。

**配置选项**：
- `model`：用于生成摘要的模型。
- `trigger`：触发摘要的条件。可以是单个 `ContextSize` 元组、单个 `TriggerClause` 字典（所有阈值必须满足）、或混合两者的列表（任一满足即可）。阈值类型包括：`fraction`（模型上下文大小的比例，0-1）、`tokens`（绝对 Token 数）、`messages`（消息数量）。
- `keep`：摘要后保留多少上下文。指定 `fraction`、`tokens` 或 `messages` 之一。
- `token_counter`：自定义 Token 计数函数，默认基于字符计数。
- `summary_prompt`：自定义摘要提示模板，应包含 `{messages}` 占位符。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        SummarizationMiddleware(
            model="openai:gpt-4o-mini",
            trigger={"tokens": 4000},
            keep={"messages": 20},
            token_counter=...,
            summary_prompt="...",
        ),
    ],
)
```

## 6. 人工介入（Human-in-the-loop）

**对应装饰器：`@wrap_tool_call`（工具调用包装器）。**

暂停智能体执行，等待人工对工具调用进行批准、编辑或拒绝后再执行。

**适用场景**：
- 需要人工批准的高风险操作（如数据库写入、金融交易）。
- 人工监督为强制要求的合规工作流。
- 人工反馈引导智能体的长时间对话。

**注意**：人工介入中间件需要 `checkpointer` 来在中断期间维护状态。

**配置选项**：
- `interrupt_on`：指定哪些工具需要中断以及允许的决策。例如 `{"your_send_email_tool": {"allowed_decisions": ["approve", "edit", "reject"]}, "your_read_email_tool": False}`。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import HumanInTheLoopMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[send_email, read_email],
    middleware=[
        HumanInTheLoopMiddleware(
            interrupt_on={
                "send_email": {"allowed_decisions": ["approve", "edit", "reject"]},
                "read_email": False,
            },
        ),
    ],
    checkpointer=...,
)
```

## 7. 模型调用限制（Model call limit）

**对应装饰器：`@before_model`（模型调用前钩子）。**

限制模型调用次数以防止过度开销。

**配置选项**：
- `thread_limit`：一个线程中所有运行的最大模型调用次数，默认无限制。
- `run_limit`：单次调用的最大模型调用次数，默认无限制。
- `exit_behavior`：达到限制时的行为。`'end'`（优雅终止）或 `'error'`（抛出异常）。

**注意**：线程限制需要 `checkpointer` 来维护状态。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ModelCallLimitMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ModelCallLimitMiddleware(
            thread_limit=10,
            run_limit=5,
            exit_behavior="end",
        ),
    ],
)
```

## 8. 工具调用限制（Tool call limit）

**对应装饰器：`@wrap_tool_call`（工具调用包装器）。**

通过限制工具调用次数来控制智能体执行，可以是全局所有工具或特定工具。

**适用场景**：
- 防止对昂贵外部 API 的过度调用。
- 限制网络搜索或数据库查询。
- 对特定工具使用强制执行速率限制。
- 防止智能体失控循环。

**配置选项**：
- `tool_name`：要限制的特定工具名称，未提供则全局应用于所有工具。
- `thread_limit`：一个线程（对话）中所有运行的最大工具调用次数，需要 `checkpointer`。
- `run_limit`：单次调用（一个用户消息→响应周期）的最大工具调用次数，每次新用户消息重置。
- `exit_behavior`：达到限制时的行为。`'continue'`（默认）阻止超限调用并返回错误消息，让其他工具和模型继续；`'error'` 抛出异常立即停止；`'end'` 立即停止执行（仅适用于限制单个工具）。

**注意**：`thread_limit` 和 `run_limit` 至少需要指定一个。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ToolCallLimitMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ToolCallLimitMiddleware(
            tool_name="search",
            thread_limit=20,
            run_limit=5,
            exit_behavior="continue",
        ),
    ],
)
```

## 9. PII 检测（PII detection）

**对应装饰器：`@before_model` 与 `@after_model`（模型调用前后钩子）。**

使用可配置策略检测和处理对话中的个人身份信息。

**适用场景**：
- 有合规要求的医疗和金融应用。
- 需要清理日志的客户服务智能体。
- 任何处理敏感用户数据的应用。

**注意**：使用 `apply_to_output=True` 时，PII 中间件还会通过注册的流转换器对流式输出进行脱敏，包括文本增量、工具调用参数、工具输出和状态快照。需要 `langchain>=1.3.2`。

**配置选项**：
- `type`：要检测的 PII 类型，可以是内置类型（`email`、`credit_card`、`ip`、`mac_address`、`url`）或自定义类型名称。
- `strategy`：处理检测到的 PII 的方式。`'block'` 检测到时抛出异常；`'redact'` 替换为 `[REDACTED_{PII_TYPE}]`；`'mask'` 掩码处理；`'hash'` 哈希处理。
- `detector`：自定义检测器，支持正则字符串、编译的正则对象或自定义检测函数。
- `apply_to_input`：是否应用于输入。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import PIIMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        PIIMiddleware(
            type="email",
            strategy="redact",
            detector=r"[\w\.-]+@[\w\.-]+",
            apply_to_input=True,
            apply_to_output=True,
        ),
    ],
)
```

## 10. 待办事项列表（To-do list）

**对应装饰器：`@before_agent`（智能体执行前钩子）。**

为智能体提供任务规划与跟踪能力，适用于复杂的多步骤任务。

**适用场景**：
- 需要跨多个工具协调的复杂多步骤任务。
- 进度可见性重要的长时间运行操作。

**注意**：该中间件自动为智能体提供 `write_todos` 工具和系统提示，以引导有效的任务规划。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import TodoListMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[TodoListMiddleware()],
)
```

## 11. LLM 工具选择器（LLM tool selector）

**对应装饰器：`@before_model`（模型调用前钩子）。**

在主模型调用前，使用 LLM 筛选出相关的工具。

当智能体有大量可用工具时，该中间件会将其过滤为仅与用户查询最相关的工具，从而减少 Token 使用量。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import LLMToolSelectorMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        LLMToolSelectorMiddleware(
            model="openai:gpt-4o-mini",
            max_tools=5,
        ),
    ],
)
```

## 12. 供应商工具搜索（Provider tool search）

**对应装饰器：`@before_model`（模型调用前钩子）。**

将选定的工具延迟到 OpenAI/Anthropic 供应商原生工具搜索之后，按需呈现。

该中间件将选定工具标记为延迟加载（通过 `extras["defer_loading"]`），并注入供应商的服务器端工具搜索工具，而不是在每一轮都发送所有工具的模式。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ProviderToolSearchMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ProviderToolSearchMiddleware(
            tools=["tool_a", "tool_b"],
        ),
    ],
)
```

## 13. Shell 工具（Shell tool）

**对应装饰器：`@before_agent`（智能体执行前钩子）。**

为智能体暴露持久化 Shell 会话以执行命令。

**注意**：`ShellToolMiddleware` 在 `before_agent` 钩子中创建资源，这些资源被标记为 `UntrackedValue` 而不会被检查点保存，因此在人工介入工作流暂停后恢复时会丢失。

**执行策略**：
- `HostExecutionPolicy`：完全主机访问权限。
- 可选只读根文件系统和用户重映射。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ShellToolMiddleware, HostExecutionPolicy

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ShellToolMiddleware(
            execution_policy=HostExecutionPolicy(),
        ),
    ],
)
```

## 14. 文件系统（Filesystem）

**对应装饰器：`@before_agent`（智能体执行前钩子）。**

为智能体提供文件系统，用于存储上下文和长期记忆。

该中间件为智能体添加以下文件系统工具：`ls`、`read_file`、`write_file`、`edit_file`、`glob`、`grep`。还会在工具结果超过 Token 阈值时自动将其驱逐到文件系统，防止上下文窗口饱和。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import FilesystemMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[FilesystemMiddleware()],
)
```

## 15. 子智能体（Subagent）

**对应装饰器：`@before_agent`（智能体执行前钩子）。**

添加生成子智能体的能力。

子智能体自动接收默认中间件栈（`todoListMiddleware`、`filesystemMiddleware`、`summarizationMiddleware` 等），然后才应用自定义中间件。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import SubAgentMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        SubAgentMiddleware(
            subagents=[...],
        ),
    ],
)
```

## 16. 评分标准（Rubric grading，Beta）

应用 LLM-as-a-judge 评分，使智能体自我评估并迭代，直到满足评分标准。

该中间件使智能体针对调用方提供的验收标准进行自我评估，并循环迭代直到满足条件。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import RubricMiddleware

agent = create_agent(

        RubricMiddleware(
```

## 17. 文件搜索（File search）

**对应装饰器：`@before_agent`（智能体执行前钩子）。**

提供对文件系统文件的 Glob 和 Grep 搜索工具。

该中间件添加两个搜索工具：
- **Glob**：按文件路径进行快速文件模式匹配。
- **Grep**：使用正则表达式进行快速内容搜索。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import FileSearchMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[FileSearchMiddleware()],
)
```

## 18. 上下文编辑（Context editing）

**对应装饰器：`@before_model`（模型调用前钩子）。**

通过裁剪或清除工具使用记录来管理对话上下文。

最常见的策略是 `ClearToolUsesEdit`，它在保留最近工具结果的同时清除较早的工具结果。

**配置选项**：
- `edits`：要应用的编辑策略序列，默认为单个 `ClearToolUsesEdit`。
- `clearAtLeast`：编辑运行时最少要回收的 Token 数，设为 0 则按需清除。
- `keep`：保留的最近工具结果数量，默认 3。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import ContextEditingMiddleware, ClearToolUsesEdit

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        ContextEditingMiddleware(
            edits=[ClearToolUsesEdit(clearAtLeast=1000, keep=3)],
        ),
    ],
)
```

## 19. LLM 工具模拟器（LLM tool emulator）

**对应装饰器：`@wrap_tool_call`（工具调用包装器）。**

使用 LLM 模拟工具执行以用于测试目的。

该中间件允许选择性地模拟工具。默认情况下（当 `tools=None` 时），所有工具都会被模拟。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import LLMToolEmulatorMiddleware

agent = create_agent(
    model="openai:gpt-4o",
    tools=[...],
    middleware=[
        LLMToolEmulatorMiddleware(
            tools=["tool_a"],  # 可选；None 表示模拟所有工具
        ),
    ],
)
```
