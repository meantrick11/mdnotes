# 多模态输入和输出

当你使用支持多模态输入和工具结果或返回多模态输出的大语言模型时，Deep Agents 支持多模态工作流。你可以为用户消息附加图片和其他媒体，通过内置的read_file工具读取非文本文件，并从自定义工具返回多模态内容。

## 多模态输入

可以在message中输入多模态输入的格式,可以直接传入字典列表，或者使用langchian内置的Message类实例化，但是都会涉及content的不同输入：
```python
result = agent.invoke({
    "messages": [{
        "role": "user",
        "content": [
            {"type": "text", "text": "What is in this screenshot?"},
            {"type": "image", "url": "https://example.com/screenshot.png"},
        ],
    }],
})
```

## 自定义工具输出

工具可以返回包含多模态的列表，会被转换为ToolMessage：

```python
from langchain.tools import tool


@tool
def capture_screenshot() -> list[dict]:
    """Capture a screenshot of the current page."""
    return [
        {"type": "text", "text": "Screenshot of the current page:"},
        {"type": "image", "url": "https://example.com/page.png"},
    ]
```

返回值会被转换为ToolMessage，供模型在下一轮读取。通过结果消息上的content_blocks访问标准化表示形式。然后可以作为下一轮的模型输入(当然还是针对于多模态模型)

## 上下文压缩和多模态内容

内置的分流与摘要功能针对文本和消息历史进行了优化：
1. Offloading仅针对文本标记进行处理。非文本块（包括图片）会保留在替换消息中，而非被压缩。仅包含图片的消息不会仅根据图片大小进行卸载。
2. Summarization会将较早的消息压缩为纯文本摘要。该范围内的图片、音频、视频和文件块不会被保留——模型只会看到摘要器对它们的描述内容。低于保留阈值的最新消息保持不变。
