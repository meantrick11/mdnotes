# Permissions

使用声明式权限规则控制智能体可读取或写入的文件和目录。将规则列表传递给permissions=，智能体的内置文件系统工具会遵守这些规则。

**权限仅适用于内置文件系统工具（ls、read_file、glob、grep、write_file、edit_file、delete）。**访问文件系统的自定义工具和 MCP 工具不在此范围内。权限也不适用于 沙箱后端，后者可通过 execute 工具支持任意命令执行。


## 基本用法

**create_deep_agent接收一个FilesystemPermission的类的列表，文件权限依次进行匹配**
将一组FilesystemPermission规则传递给create_deep_agent。规则将按声明顺序进行评估。**首个匹配的规则生效。若无规则匹配，则允许执行该操作。**

```python
from deepagents import FilesystemPermission, create_deep_agent


# Read-only agent: deny all writes
agent = create_deep_agent(
    model=model,
    backend=backend,
    permissions=[
        FilesystemPermission(
            operations=["write"],
            paths=["/**"],
            mode="deny",
        ),
    ],
)
```

## 规则结构

每个FilesystemPermission都有三个字段：

|Field|Type|Description|
|---|---|---|
|operations|list["read"|"write"]|"read" 包含 ls、read_file、glob、grep。"write" 包含 write_file、edit_file、delete。|
|paths|list[sre]|用于匹配文件路径的 Glob 模式（例如，["/workspace/**"]）。支持 ** 进行递归匹配，以及 {a,b} 进行匹配项选择。|
|mode|"allow" | "deny" | "interrupt"|是否允许、拒绝或暂停以等待人工审批匹配操作。默认为"allow"。请参阅暂停以等待人工审批。|

**规则采用首次匹配优先的评估机制：第一个operations和paths与当前调用匹配的规则将决定结果。如果没有规则匹配，则调用被允许（默认允许）。**

## 文件系统的设置

## 1. 独立的工作空间目录

由于上述的文件系统可以依次进行匹配，那么我们明显可以针对不同的文件进行不同文件权限的设置，即独立设置工作空间目录

```python
agent = create_deep_agent(
    model=model,
    backend=backend,
    permissions=[
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/workspace/**"],
            mode="allow",
        ),
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/**"],
            mode="deny",
        ),
    ],
)
```

### 2. 保护特定的文件

即对某些特殊的文件进行deny设置达到保护的效果

```python
agent = create_deep_agent(
    model=model,
    backend=backend,
    permissions=[
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/workspace/.env", "/workspace/examples/**"],
            mode="deny",
        ),
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/workspace/**"],
            mode="allow",
        ),
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/**"],
            mode="deny",
        ),
    ],
)
```

### 3. 只读模式


```python
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend

agent = create_deep_agent(
    model=model,
    backend=CompositeBackend(
        default=StateBackend(),
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: (rt.server_info.user.identity,),
            ),
            "/policies/": StoreBackend(
                namespace=lambda rt: (rt.context.org_id,),
            ),
        },
    ),
    permissions=[
        FilesystemPermission(
            operations=["write"],
            paths=["/memories/**", "/policies/**"],
            mode="deny",
        ),
    ],
)
```

### 5. 顺序之上

由于是第一个匹配执行对应规则，自然可以设计层级关系，比如同一个文件夹下的子文件夹不同的权限问题

```python
# Correct: deny .env, allow workspace, deny everything else
correct_permissions = [
    FilesystemPermission(
        operations=["read", "write"],
        paths=["/workspace/.env"],
        mode="deny",
    ),
    FilesystemPermission(
        operations=["read", "write"],
        paths=["/workspace/**"],
        mode="allow",
    ),
    FilesystemPermission(
        operations=["read", "write"],
        paths=["/**"],
        mode="deny",
    ),
]

# Bug: /workspace/** matches .env first, so the deny never triggers
incorrect_permissions = [
    FilesystemPermission(
        operations=["read", "write"],
        paths=["/workspace/**"],
        mode="allow",
    ),
    FilesystemPermission(
        operations=["read", "write"],
        paths=["/workspace/.env"],
        mode="deny",  # never reached
    ),
    FilesystemPermission(
        operations=["read", "write"],
        paths=["/**"],
        mode="deny",
    ),
]
```

### 6. subagent权限

这里的subagent的权限也是对子agent的对文件的操作权限

```python
agent = create_deep_agent(
    model=model,
    backend=backend,
    permissions=[
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/workspace/**"],
            mode="allow",
        ),
        FilesystemPermission(
            operations=["read", "write"],
            paths=["/**"],
            mode="deny",
        ),
    ],
    subagents=[
        {
            "name": "auditor",
            "description": "Read-only code reviewer",
            "system_prompt": "Review the code for issues.",
            "permissions": [
                FilesystemPermission(
                    operations=["write"],
                    paths=["/**"],
                    mode="deny",
                ),
                FilesystemPermission(
                    operations=["read"],
                    paths=["/workspace/**"],
                    mode="allow",
                ),
                FilesystemPermission(
                    operations=["read"],
                    paths=["/**"],
                    mode="deny",
                ),
            ],
        }
    ],
)

```
