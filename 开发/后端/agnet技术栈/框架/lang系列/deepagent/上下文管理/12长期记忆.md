# 长期记忆

这里的memory讨论对时长期记忆，而不是checkpoint对状态的保存的单线程的短期记忆

Deep Agents 让记忆成为核心功能，它提供基于文件系统的记忆机制：智能体以文件形式读写记忆，你可以通过后端控制这些文件的存储位置**也是建立在langchain的长期记忆的指定不同命名空间实现的不同的长期记忆**。

## 记忆的工作原理

将智能体指向记忆文件。 创建智能体时，将文件路径传递给 memory=。你也可以通过 skills= 传递 技能 以用于程序性记忆（告知智能体 如何 执行任务的可复用指令）。后端 控制文件的存储位置以及访问权限。

智能体读取记忆。 智能体可在启动时将记忆文件加载到系统提示词中，也可在对话过程中按需读取。例如，技能采用按需加载方式：智能体在启动时仅读取技能描述，仅在匹配到任务时才读取完整的技能文件。这样可在需要某项能力之前保持简洁的上下文内容。

智能体更新记忆（可选）。 当智能体学习到新信息时，可使用其内置的edit_file工具更新记忆文件。更新可在对话过程中进行（默认方式），也可通过后台整合在对话之间的后台执行。所做更改会被持久化，并在下一次对话中生效。并非所有记忆都可写入：开发者定义的技能和组织策略通常为只读状态。详见只读与可写记忆了解详情。

## 作用域记忆

### agent级作用域

通过在banckend指定路由空间，也就是比如memories就是长期记忆，skills就是可复用的技能（某种程度上也是长期记忆），**这里的指定磁盘文件是映射到对应的store中，而不是直接操作电脑中的磁盘**

```python
from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend

agent = create_deep_agent(
    model="google_genai:gemini-3.6-flash",
    memory=["/memories/AGENTS.md"],
    skills=["/skills/"],
    backend=CompositeBackend(
        default=StateBackend(),
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: (
                    rt.server_info.assistant_id,
                ),
            ),
            "/skills/": StoreBackend(
                namespace=lambda rt: (
                    rt.server_info.assistant_id,
                ),
            ),
        },
    ),
)
```


### 用户级作用域

为每位用户创建专属的记忆文件。智能体将记住每位用户的偏好、背景信息和历史记录，而智能体的核心指令保持固定。如果将技能存储在用户范围的后端中，用户也可以拥有专属的技能。


该命名空间使用(user_id,)，因此每个用户都会获得一份独立的记忆文件副本。用户A的偏好绝不会泄露到用户B的对话中。

```python
from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend

agent = create_deep_agent(
    model="google_genai:gemini-3.6-flash",
    memory=["/memories/preferences.md"],
    skills=["/skills/"],
    backend=CompositeBackend(
        default=StateBackend(),
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: (rt.server_info.user.identity,),
            ),
            "/skills/": StoreBackend(
                namespace=lambda rt: (rt.server_info.user.identity,),
            ),
        },
    ),
)

```

### 情境记忆

### 组织级记忆

组织级内存遵循与用户作用域内存相同的模式，但其命名空间是全组织范围的，而非按用户划分。可将其用于适用于组织内所有用户和智能体的策略或知识库。

```python
from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend

agent = create_deep_agent(
    model="google_genai:gemini-3.6-flash",
    memory=[
        "/memories/preferences.md",
        "/policies/compliance.md",
    ],
    backend=CompositeBackend(
        default=StateBackend(),
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: (rt.server_info.user.identity,),
            ),
            "/policies/": StoreBackend(
                namespace=lambda rt: (rt.context.org_id,),
            ),
        },
    ),
)
```
