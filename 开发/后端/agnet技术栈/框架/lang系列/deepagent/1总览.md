# Deep Agents 概述


Deep Agent 基于langchain/graph构建的具有上层功能封装的上下文管理的文件系统、subagent-spawing,long-term memory以及task planning\skills\MCP等扩展功能，用来直接使用可用工具组件开发上层Agent。

底层可以使用具体代码定义langgraph节点或者langchain创造，但是更多上层agent常用功能封装，可以直接调用，而不用追究底层节点、边的实现等等。

**也就是基于langchain/graph创建的时候就定义了一些工具，需要指定后端，以及skills、memory，上层中间件、subagent的封装等等更加上层的内容**

## 核心能力

### 执行环境

工具、虚拟文件系统、沙箱、REPL（解释器(交互式编程环境)）

### 上下文管理

skill,memory,summarization,context,context offloading(上下文卸载),promopt caching(提示词缓存)

### 委托(Delegation)

subagent spawing&task planing

### 引导(steering)

Human-in-the-loop approval &interrupts 

审查+中断机制
