# 运行时、框架与执行外壳（Runtimes, frameworks, and harnesses）
理解 LangChain、LangGraph、Deep Agents 的差异以及各自适用场景

LangChain 维护了多款开源包，用于构建智能代理（Agent）。它们在代理开发技术栈中承担不同职责。搞懂**代理框架（agent frameworks）**、**代理运行时（agent runtimes）**、**代理执行外壳（agent harnesses）**三者的区别，可以帮助你选出贴合自身需求的工具。

| | 运行时 Runtime | 框架 Framework | 执行外壳 Harness |
|---|---|---|---|
| 核心增值能力 | - 持久化执行<br>- 流式输出<br>- 人工介入(HITL)<br>- 状态持久化 | - 各类抽象封装<br>- 多方集成能力 | - 预定义工具集<br>- 预置提示词<br>- 子代理能力 |
| 适用场景 | - 需要底层精细控制<br>- 长运行、带状态的工作流与智能代理 | - 快速上手开发<br>- 团队统一构建范式 | - 更高自主性的代理<br>- 处理复杂、非确定性任务的代理 |
| 同类产品 | - LangGraph<br>- Temporal<br>- Inngest | - LangChain<br>- Vercel AI SDK<br>- CrewAI<br>- OpenAI Agents SDK<br>- Google ADK<br>- LlamaIndex | - Deep Agents SDK<br>- Claude Agent SDK<br>- Manus |

## 代理框架（以 LangChain 为例）
代理框架提供各类抽象封装，降低基于大模型构建应用的上手门槛。

**LangChain** 就是一款代理框架，它提供结构化内容块、代理主循环、中间件等抽象。LangChain 的抽象设计兼顾上手简单与高级场景所需的灵活性。
虽然 LangChain 底层基于 LangGraph 构建，但你使用 LangChain 并不需要掌握 LangGraph。

其他代理框架：Vercel AI SDK、CrewAI、OpenAI Agents SDK、Google ADK、LlamaIndex 等。

### 什么时候选择 LangChain
满足以下场景可以选用 LangChain：
- 希望快速搭建智能代理与自主应用
- 需要一套标准化抽象，统一封装模型、工具、代理执行循环
- 需要简单易用，同时保留足够灵活度的开发框架
- 开发逻辑直白，无复杂编排需求的代理应用

## 代理运行时（以 LangGraph 为例）
代理运行时为代理的生产环境运行提供基础设施，包含的能力：
- **持久化执行（Durable execution）**：代理遇到故障不会中断，可以长时间运行，并且从上次中断位置恢复执行
- **流式输出（Streaming）**：支持工作流、模型响应的流式返回
- **人工介入（Human‑in‑the‑loop）**：允许人类查看、修改代理内部状态，实现人工监督
- **状态持久化（Persistence）**：单会话、跨会话的状态管理持久化
- **底层精细控制**：直接操控代理编排逻辑，不受高层抽象束缚

**LangGraph** 是一套底层编排框架兼运行时，专门用于构建、管理、部署长运行、带状态的智能代理。
代理框架一般层级更高，并且依托代理运行时来执行。例如 LangChain 1.0 就构建在 LangGraph 之上。

其他代理运行时：Temporal、Inngest 以及其他持久化执行引擎。

### 什么时候选择 LangGraph
满足以下场景可以选用 LangGraph：
- 需要对代理编排做细粒度、底层的控制
- 需要给长运行、带状态的代理提供故障恢复的持久化执行能力
- 构建混合确定性步骤与智能代理步骤的复杂工作流
- 需要可直接用于生产环境的代理部署底座

## 代理执行外壳（以 Deep Agents SDK 为例）
代理执行外壳是带有明确设计倾向、开箱即用的框架，内置丰富工具集，专门用于开发复杂、长时间运行的智能代理。具备能力：
- **任务规划能力**：通过待办列表跟踪多项任务
- **任务委派**：利用子代理委派任务，保持主上下文整洁
- **文件系统**：对接各类可插拔存储后端，提供文件读写能力
- **Token 管理**：会话历史摘要压缩、对过大工具返回结果做淘汰清理

**Deep Agents SDK** 基于 LangGraph 构建，额外增加任务规划、用于上下文管理的文件系统、子代理创建等能力。Deep Agents 面向需要规划、任务拆解的复杂多步任务，例如处理搜索结果、脚本以及其他保存在状态中的产物。

其他代理执行外壳：Claude Agent SDK、Manus 以及其他代码命令行工具。

### 什么时候选择 Deep Agents SDK
满足以下场景可以选用 Deep Agents SDK：
- 构建需要长时间持续运行的代理
- 处理复杂、多步骤的业务任务
- 希望直接使用预封装工具，例如文件系统操作、bash 执行、自动化上下文工程
- 直接复用预置提示词与子代理能力

## 功能对比
LangChain、LangGraph、Deep Agents 都可以实现很多同类功能，但三者的集成抽象层级不一样：

| 功能 | LangGraph | LangChain | Deep Agents |
|---|---|---|---|
| 短期记忆 | 短期记忆 | 短期记忆 | `StateBackend` |
| 长期记忆 | 长期记忆 | 长期记忆 | 长期记忆 |
| 技能 Skills | 无 | 多代理技能 | Skills（技能模块） |
| 子代理 | 子图 Subgraphs | 多代理子代理 | Subagents（子代理） |
| 人工介入 | Interrupts（中断机制） | 人工介入中间件 | `interrupt_on` 参数 |
| 流式输出 | Streaming | 代理流式输出 | Streaming |
