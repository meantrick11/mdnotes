
## 6 属性的高级用法
前面属性大多只是作为类表达式内部构件；本节介绍属性自身的公理与高级建模能力。

### 6.1 属性特征（Property Characteristics）
1. **InverseObjectProperties 逆属性**
hasParent定义为hasChild的逆：如果A hasChild B，则B hasParent A。

> 函数式语法
```
 InverseObjectProperties( :hasParent :hasChild ) 
```
> 曼彻斯特语法
```
 ObjectProperty: hasParent
 InverseOf: hasChild
```

类表达式内部也可以直接写匿名逆属性，不必专门命名。

2. **SymmetricObjectProperty 对称属性**
hasSpouse配偶是对称：A hasSpouse B → B hasSpouse A。

> 函数式语法
```
 SymmetricObjectProperty( :hasSpouse ) 
```
> 曼彻斯特语法
```
 ObjectProperty: hasSpouse
 Characteristics: Symmetric
```

3. **AsymmetricObjectProperty 非对称属性**
hasChild子女是非对称：A hasChild B，则B绝对不能hasChild A。
> 注意：“非对称(asymmetric)”强于“不是对称(not symmetric)”。

> 函数式语法
```
 AsymmetricObjectProperty( :hasChild ) 
```

4. **DisjointObjectProperties 属性不相交**
两个属性不能同时在同一对个体之间成立。示例：hasParent与hasSpouse互斥，一个人不能同时是另一个人的父母和配偶。

> 函数式语法
```
 DisjointObjectProperties( :hasParent :hasSpouse ) 
```

5. **ReflexiveObjectProperty 自反属性**
每个个体都和自己具备该属性。例如hasRelative亲属：每个人都是自己的亲属。

> 函数式语法
```
 ReflexiveObjectProperty( :hasRelative )
```

6. **IrreflexiveObjectProperty 反自反属性**
任何个体不能将该属性指向自身。parentOf，没有人是自己的父母。

> 函数式语法
```
 IrreflexiveObjectProperty( :parentOf ) 
```

7. **FunctionalObjectProperty 函数属性**
同一个源个体，该属性最多只能有一个目标个体。hasHusband：一个人最多一位丈夫。
> 不强制必须拥有丈夫，只是不能多个。如果Mary hasHusband James，同时Mary hasHusband Jim，推理机推出James sameAs Jim。

> 函数式语法
```
 FunctionalObjectProperty( :hasHusband ) 
```

8. **InverseFunctionalObjectProperty 逆函数属性**
属性的逆是函数属性。hasHusband标记InverseFunctional：一个男人最多只能是一个人的丈夫。

> 函数式语法
```
 InverseFunctionalObjectProperty( :hasHusband )
```

9. **TransitiveObjectProperty 传递属性**
hasAncestor祖先具备传递性。A hasAncestor B，B hasAncestor C → A hasAncestor C。

> 函数式语法
```
 TransitiveObjectProperty( :hasAncestor )
```

### 6.2 属性链公理 Property Chain Axiom（SubObjectPropertyOf + ObjectPropertyChain）
通过属性链条推导出新属性关系。示例：hasParent o hasParent → hasGrandparent。
> 含义：A hasParent B，B hasParent C，则A hasGrandparent C。也就是父母的父母是祖父母。
> 注意：属性链只匹配固定长度链条；和传递属性不同，传递属性会递归无限推导。

> 函数式语法
```
 SubObjectPropertyOf( 
 ObjectPropertyChain( :hasParent :hasParent ) 
 :hasGrandparent 
 )
```
> 曼彻斯特语法
```
 ObjectProperty: hasGrandparent
 SubPropertyChain: hasParent o hasParent
```

### 6.3 HasKey 键公理
给类指定一组属性作为键：类的每个命名实例，该属性（或属性集合）取值可以唯一标识该个体。类似数据库主键。
示例Person类，hasSSN社保号作为键：同一个社保号只能对应一个Person个体。

> 函数式语法
```
 HasKey( :Person () ( :hasSSN ) )
```
> 曼彻斯特语法
```
 Class: Person
 HasKey: hasSSN
```
