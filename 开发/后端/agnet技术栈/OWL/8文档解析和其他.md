## 8 文档信息与注解
下面介绍**不参与逻辑推理**的特性，用来描述本体、公理、实体本身元信息。

### 8.1 对公理与实体添加注解Annotation
注解属性记录元信息：注释、标签、作者。**注解不会被推理机用于逻辑推导**，主要供工具展示给人阅读。
给Person类添加rdfs:comment注释：

> 函数式语法
```
 AnnotationAssertion( rdfs:comment :Person "Represents the set of all people." )
```

也可以给某一条**公理本身**增加注解。例如给子类公理`Man subClassOf Person`写注释。

### 8.2 本体管理
1. 本体IRI：本体文档自身的标识符，一般就是本体文档网络地址。
> 函数式语法
```
 Ontology(<http://example.com/owl/families> ... )
```

2. 前缀(Prefix)：缩写长IRI。Turtle、函数式、曼彻斯特、OWL‑XML都有各自前缀写法。
```
 Prefix(:=<http://example.com/owl/families />)
 Prefix(xsd:=<http://www.w3.org/2001/XMLSchema#>)
```

3. Import导入本体：引入其他本体全部公理。
```
 Import( <http://example.org/otherOntologies/families.owl> )
```

4. 跨本体对齐：SameIndividual、EquivalentClasses、EquivalentObjectProperties、EquivalentDataProperties，用来映射导入本体与本地本体的同名概念。

### 8.3 实体声明 Declaration
显式声明IRI属于哪一类实体（类 / 对象属性 / 数据属性 / 个体）。
> 函数式语法
```
 Declaration( NamedIndividual( :John ) )
 Declaration( Class( :Person ) )
 Declaration( ObjectProperty( :hasWife ) )
 Declaration( DataProperty( :hasAge ) )
```

> 曼彻斯特语法中声明是隐式，写Class:XXX就自动完成声明。
> **Punning（双关）**：同一个IRI既当类，又当个体。例如`:Father`既作为类（父亲），又作为个体，属于SocialRole社会角色。OWL2 DL允许该语法；直接语义下二者逻辑上视作两个不同实体。

## 9 OWL 2 DL 与 OWL 2 Full
OWL 2两套语义：
1. **直接语义（Direct Semantics）**：适用于OWL2 DL本体，基于描述逻辑。
2. **基于RDF的语义(RDF‑Based Semantics)**：把本体当做RDF图处理；适用于OWL2 Full。

- OWL2 DL：施加语法限制，保证**可判定推理**，现有大量成熟推理机完整支持。
- OWL2 Full：去掉语法限制，完全兼容RDFS，但是**不可判定**，不存在完备推理机。

OWL2 DL本体同样可以用RDF‑Based语义解读。二者大部分推导结果一致；主要差异来自Punning双关处理。

## 10 OWL 2 Profiles（OWL2简行子集/轻量化子语言）
OWL2 DL表达能力很强，但推理计算代价高。W3C定义三个可处理的子语言：**OWL2 EL、OWL2 QL、OWL2 RL**。三个子集**互相之间谁也不是谁的子集**，各有设计目标，牺牲部分表达能力换取高效可扩展推理。共同特点：大多禁止否定、析取。

### 10.1 OWL 2 EL
- 来源：EL++描述逻辑；EL=Existential Logic，侧重存在量词some。
- 适用场景：大规模生物医学本体，例如SNOMED‑CT、NCI词典，类数量巨大，大量使用存在约束、属性链。
- 允许：ObjectIntersectionOf、someValuesFrom、hasSelf、属性链。
- **不允许**：全称量词only、属性逆、否定、析取union。
- 推理复杂度：多项式时间。

### 10.2 OWL 2 QL
- 来源：DL‑Lite；QL=Query Language查询语言。
- 核心特点：本体TBox重写SPARQL/SQL查询，不需要修改原始数据库数据，适合数据库模式、数据库集成。
- 限制：子类公理两边不对称；禁止部分存在量词，不支持属性链。

### 10.3 OWL 2 RL
- 来源：DLP描述逻辑程序；RL=Rule Language规则语言。
- 面向规则推理实现，适配RDF数据流处理，适合RDF数据增强。
- 限制：不允许“存在带来新个体”的公理；子类公理左右两边语法不对称。

> 工具兼容性：OWL2 DL推理机可以读取三个profile本体，但不会专门做性能优化；各个profile有专门轻量化推理工具。

## 11 OWL工具
两类核心工具：
1. **本体编辑器**：Protégé（最主流开源）、TopBraid Composer商业版，SWOOP、NeOn‑Toolkit。
2. **推理机 Reasoner**
    - OWL DL通用推理机：Fact++、Hermit、Pellet、RacerPro。
    - Profile专用推理：CEL(EL)、QuOnto(QL)、Oracle11g(RL)。
- **OWL‑API**：Java开发库，程序读写、操作OWL本体。
