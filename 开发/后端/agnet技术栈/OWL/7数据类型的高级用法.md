
## 7 数据类型的高级用法
4.8节介绍基础数据属性。数据类型也可以做复杂定义：通过facet约束已有数据类型、取交、取补、并集、枚举字面量。

1. DatatypeRestriction 面约束：定义personAge：整数，0‑150闭区间。
```
DatatypeDefinition(
 :personAge
 DatatypeRestriction( xsd:integer 
 xsd:minInclusive "0"^^xsd:integer
 xsd:maxInclusive "150"^^xsd:integer
 )
 ) 
```

2. DataIntersectionOf、DataComplementOf：数据类型交、补。majorAge = personAge 并且 not minorAge。

3. DataOneOf：枚举字面量。toddlerAge取值只能是1、2。
```
DatatypeDefinition(
 :toddlerAge
 DataOneOf( "1"^^xsd:integer "2"^^xsd:integer ) 
 ) 
```

4. FunctionalDataProperty：数据属性函数特性。hasAge：一个人最多一个年龄值。
```
 FunctionalDataProperty( :hasAge ) 
```

5. DataSomeValuesFrom数据属性约束：Teenager（青少年）：hasAge some integer(minExclusive 12, maxInclusive19)，年龄大于12、小于等于19。
