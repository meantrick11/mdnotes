## 5 高级类关系
前面章节处理的都是带名称的“不透明”类；通过子类、不相交描述类之间关系。接下来介绍如何把命名类、属性、个体当做构件，定义出新的复杂类。

### 5.1 复杂类
依靠前面基础构造只能完成简单本体建模。为表达更加复杂知识，OWL提供逻辑类构造子，对应集合论中的**交(intersection)、并(union)、补(complement)**，把原子命名类组合得到复杂类表达式。

**类的交集**：个体同时属于全部参与类。
示例定义Mother（母亲）等价于Woman和Parent（家长）的交集：一个母亲，既是女人，同时又是家长。

> 函数式语法
```
 EquivalentClasses(
 :Mother 
 ObjectIntersectionOf( :Woman :Parent )
 ) 
```
> RDF/XML语法
```
 <owl:Class rdf:about="Mother">
 <owl:equivalentClass>
 <owl:Class>
 <owl:intersectionOf rdf:parseType="Collection">
 <owl:Class rdf:about="Woman" />
 <owl:Class rdf:about="Parent" />
 </owl:intersectionOf>
 </owl:Class>
 </owl:equivalentClass>
 </owl:Class>
```
> Turtle语法
```
 :Mother owl:equivalentClass [
 rdf:type owl:Class ;
 owl:intersectionOf ( :Woman :Parent ) 
 ] .
```
> 曼彻斯特语法
```
 Class: Mother
 EquivalentTo: Woman and Parent
```
> OWL/XML语法
```
 <EquivalentClasses>
 <Class IRI="Mother" />
 <ObjectIntersectionOf>
 <Class IRI="Woman" />
 <Class IRI="Parent" />
 </ObjectIntersectionOf>
 </EquivalentClasses>
```

由此公理可以推导：所有Mother实例一定是Parent实例。

**类的并集**：个体至少属于其中一个参与类。
示例定义Parent等价于Mother或Father（父亲）：

> 函数式语法
```
 EquivalentClasses(
 :Parent 
 ObjectUnionOf( :Mother :Father )
 ) 
```
> RDF/XML语法
```
 <owl:Class rdf:about="Parent">
 <owl:equivalentClass>
 <owl:Class>
 <owl:unionOf rdf:parseType="Collection">
 <owl:Class rdf:about="Mother" />
 <owl:Class rdf:about="Father" />
 </owl:unionOf>
 </owl:Class>
 </owl:equivalentClass>
 </owl:Class>
```
> Turtle语法
```
 :Parent owl:equivalentClass [
 rdf:type owl:Class ;
 owl:unionOf ( :Mother :Father )
 ] .
```
> 曼彻斯特语法
```
 Class: Parent
 EquivalentTo: Mother or Father
```
> OWL/XML语法
```
 <EquivalentClasses>
 <Class IRI="Parent" />
 <ObjectUnionOf>
 <Class IRI="Mother" />
 <Class IRI="Father" />
 </ObjectUnionOf>
 </EquivalentClasses>
```

**类的补集**：逻辑否定，代表不属于该类的全部个体。
示例定义ChildlessPerson（无子女者）：是人，并且不是家长。演示构造子可以嵌套。

> 函数式语法
```
 EquivalentClasses(
 :ChildlessPerson 
 ObjectIntersectionOf(
 :Person 
 ObjectComplementOf( :Parent )
 )
 ) 
```
> RDF/XML语法
```
 <owl:Class rdf:about="ChildlessPerson">
 <owl:equivalentClass>
 <owl:Class>
 <owl:intersectionOf rdf:parseType="Collection">
 <owl:Class rdf:about="Person" />
 <owl:Class>
 <owl:complementOf rdf:resource="Parent" />
 </owl:Class>
 </owl:intersectionOf>
 </owl:Class>
 </owl:equivalentClass>
 </owl:Class>
```
> Turtle语法
```
 :ChildlessPerson owl:equivalentClass [
 rdf:type owl:Class ;
 owl:intersectionOf ( :Person 
 [ rdf:type owl:Class ;
 owl:complementOf :Parent ] ) 
 ] .
```
> 曼彻斯特语法
```
 Class: ChildlessPerson
 EquivalentTo: Person and not Parent
```
> OWL/XML语法
```
 <EquivalentClasses>
 <Class IRI="ChildlessPerson" />
 <ObjectIntersectionOf>
 <Class IRI="Person" />
 <ObjectComplementOf>
 <Class IRI="Parent" />
 </ObjectComplementOf>
 </ObjectIntersectionOf>
 </EquivalentClasses>
```

复杂类既可以写在EquivalentClasses（完整定义，充要条件），也可以写在SubClassOf，代表必要条件而非充分条件。
示例：所有祖父(Grandfather)都同时是男人和家长；但男人且家长不一定是祖父。

> 函数式语法
```
 SubClassOf( 
 :Grandfather 
 ObjectIntersectionOf( :Man :Parent )
 )
```
> RDF/XML语法
```
 <owl:Class rdf:about="Grandfather">
 <rdfs:subClassOf>
 <owl:Class>
 <owl:intersectionOf rdf:parseType="Collection">
 <owl:Class rdf:about="Man" />
 <owl:Class rdf:about="Parent" />
 </owl:intersectionOf>
 </owl:Class>
 </rdfs:subClassOf>
 </owl:Class>
```
> Turtle语法
```
 :Grandfather rdfs:subClassOf [
 rdf:type owl:Class ;
 owl:intersectionOf ( :Man :Parent )
 ] .
```
> 曼彻斯特语法
```
 Class: Grandfather
 SubClassOf: Man and Parent
```
> OWL/XML语法
```
 <SubClassOf>
 <Class IRI="Grandfather" />
 <ObjectIntersectionOf>
 <Class IRI="Man" />
 <Class IRI="Parent" />
 </ObjectIntersectionOf>
 </SubClassOf>
```

复杂类表达式可以直接用在原本写命名类的任何位置，包括ClassAssertion。示例断言Jack是人，并且不是家长。

> 函数式语法
```
 ClassAssertion(
 ObjectIntersectionOf(
 :Person 
 ObjectComplementOf( :Parent )
 ) 
 :Jack
 )
```
> RDF/XML语法
```
 <rdf:Description rdf:about="Jack">
 <rdf:type>
 <owl:Class>
 <owl:intersectionOf rdf:parseType="Collection">
 <owl:Class rdf:about="Person" />
 <owl:Class>
 <owl:complementOf rdf:resource="Parent" />
 </owl:Class>
 </owl:intersectionOf>
 </owl:Class>
 </rdf:type>
 </rdf:Description>
```
> Turtle语法
```
 :Jack rdf:type [
 rdf:type owl:Class ;
 owl:intersectionOf ( :Person 
 [ rdf:type owl:Class ;
 owl:complementOf :Parent ]
 )
 ] .
```
> 曼彻斯特语法
```
 Individual: Jack
 Types: Person and not Parent
```
> OWL/XML语法
```
 <ClassAssertion>
 <ObjectIntersectionOf>
 <Class IRI="Person" />
 <ObjectComplementOf>
 <Class IRI="Parent" />
 </ObjectComplementOf>
 </ObjectIntersectionOf>
 <NamedIndividual IRI="Jack" />
 </ClassAssertion>
```

### 5.2 属性约束
**属性约束(Property restrictions)**是另一大类类构造子，借助属性来定义复杂类。

1. **存在量词(ObjectSomeValuesFrom / some)**：定义类：该类每个个体，通过该属性**至少连接一个**属于目标类的个体。
示例：Parent等价于：存在hasChild属性指向Person。
> 含义：只要是家长，就**至少有一个孩子是人**。适合描述不完备知识：我们知道Bob是家长，但不知道孩子名字，推理机仍然推出Bob一定有至少一个孩子。自然语言关键词：“存在”、“某些”。

> 函数式语法
```
 EquivalentClasses(
 :Parent 
 ObjectSomeValuesFrom( :hasChild :Person )
 )
```
> RDF/XML语法
```
 <owl:Class rdf:about="Parent">
 <owl:equivalentClass>
 <owl:Restriction>
 <owl:onProperty rdf:resource="hasChild" />
 <owl:someValuesFrom rdf:resource="Person" />
 </owl:Restriction>
 </owl:equivalentClass>
 </owl:Class>
```
> Turtle语法
```
 :Parent owl:equivalentClass [
 rdf:type owl:Restriction ;
 owl:onProperty :hasChild ;
 owl:someValuesFrom :Person
 ] .
```
> 曼彻斯特语法
```
 Class: Parent
 EquivalentTo: hasChild some Person
```
> OWL/XML语法
```
 <EquivalentClasses>
 <Class IRI="Parent" />
 <ObjectSomeValuesFrom>
 <ObjectProperty IRI="hasChild" />
 <Class IRI="Person" />
 </ObjectSomeValuesFrom>
 </EquivalentClasses>
```

2. **全称量词(ObjectAllValuesFrom / only)**：描述一类个体：该属性连接出去的**所有个体都属于目标类**。
示例：HappyPerson等价于 hasChild only HappyPerson。

> 函数式语法
```
 EquivalentClasses(
 :HappyPerson 
 ObjectAllValuesFrom( :hasChild :HappyPerson )
 )
```
> RDF/XML语法
```
 <owl:Class>
 <owl:Class rdf:about="HappyPerson" />
 <owl:equivalentClass>
 <owl:Restriction>
 <owl:onProperty rdf:resource="hasChild" />
 <owl:allValuesFrom rdf:resource="HappyPerson" />
 </owl:Restriction>
 </owl:equivalentClass>
 </owl:Class>
```
> Turtle语法
```
 :HappyPerson rdf:type owl:Class ;
 owl:equivalentClass [
 rdf:type owl:Restriction ;
 owl:onProperty :hasChild ;
 owl:allValuesFrom :Happy
 ] .
```
> 曼彻斯特语法
```
 Class: HappyPerson
 EquivalentTo: hasChild only HappyPerson
```
> OWL/XML语法
```
 <EquivalentClasses>
 <Class IRI="HappyPerson" />
 <ObjectAllValuesFrom>
 <ObjectProperty IRI="hasChild" />
 <Class IRI="Happy" />
 </ObjectAllValuesFrom>
 </EquivalentClasses>
```

> ⚠️非常容易踩坑：`only`全称量词**不要求该属性一定存在取值**。**没有任何孩子的个体，自动满足 hasChild only X**。本例子：没有子女的人，会被判定为HappyPerson。
> 如果想要表达：“所有孩子都快乐，**并且至少有一个孩子**”，需要同时合并some和only。

> 函数式语法
```
 EquivalentClasses(
 :HappyPerson 
 ObjectIntersectionOf(
 ObjectAllValuesFrom( :hasChild :HappyPerson )
 ObjectSomeValuesFrom( :hasChild :HappyPerson )
 )
 )
```
> 曼彻斯特语法
```
 Class: HappyPerson
 EquivalentTo: hasChild only HappyPerson and hasChild some HappyPerson
```

自然语言关键词对应：`only`对应“全部、只、仅仅”；`some`对应“存在、有一些”。绝大多数自然语言句子翻译到OWL优先用some；only要谨慎使用。

3. **ObjectHasValue(value)**：属性指向某个**特定个体**。
示例JohnsChildren：所有以John为父/母的人，等价于 hasParent value John。

> 函数式语法
```
 EquivalentClasses( 
 :JohnsChildren 
 ObjectHasValue( :hasParent :John )
 )
```
> 曼彻斯特语法
```
 Class: JohnsChildren
 EquivalentTo: hasParent value John
```

4. **ObjectHasSelf(Self)**：个体把该属性指向自己。
自恋者NarcisticPerson等价于 loves Self，即自己爱自己。

> 函数式语法
```
 EquivalentClasses(
 :NarcisticPerson 
 ObjectHasSelf( :loves ) 
 )
```
> 曼彻斯特语法
```
 Class: NarcisticPerson
 EquivalentTo: loves Self
```

### 5.3 属性基数约束
存在量词描述“至少一个”；全称量词描述“全部”；**基数约束(Cardinality Restrictions)**用来限定属性关联个体的数量。分为最大max、最小min、精确exact；带限定类则称为**限定基数(Qualified Cardinality)**。

示例：John最多有4个属于Parent类的子女。
> 含义：允许John有更多子女，只是那些子女不属于Parent。

> 函数式语法
```
 ClassAssertion(
 ObjectMaxCardinality( 4 :hasChild :Parent ) 
 :John
 )
```
> 曼彻斯特语法
```
 Individual: John
 Types: hasChild max 4 Parent
```

最小基数：John至少2个属于Parent的子女
```
ClassAssertion( ObjectMinCardinality( 2 :hasChild :Parent ) :John )
```

精确限定基数：John恰好3个属于Parent的子女
```
ClassAssertion( ObjectExactCardinality( 3 :hasChild :Parent ) :John )
```

不限定目标类（非限定基数）：John一共恰好5个子女，不区分子女是什么类：
```
ClassAssertion( ObjectExactCardinality( 5 :hasChild ) :John )
```

### 5.4 个体枚举 ObjectOneOf
直接把全部实例枚举出来定义一个类。
示例MyBirthdayGuests生日宾客，只有Bill、John、Mary三个人。

> 函数式语法
```
 EquivalentClasses(
 :MyBirthdayGuests
 ObjectOneOf( :Bill :John :Mary)
 )
```
> 曼彻斯特语法
```
 Class: MyBirthdayGuests
 EquivalentTo: { Bill, John, Mary }
```

> 注意：ObjectOneOf不只是声明三个人属于这个类；它同时声明**这个类只有这三个人**。如果再断言Jeff属于MyBirthdayGuests，推理机会推出Jeff必须等价于Bill/John/Mary其中之一。这种类也叫封闭类。
