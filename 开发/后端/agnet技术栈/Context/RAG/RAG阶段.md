# RAG 系统架构

一个完整的RAG系统由3个核心组件构成：
┌─────────────────────────────────────────────────────────────┐
│                        RAG 系统架构                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────┐      ┌──────────────┐      ┌───────────┐ │
│  │   索引阶段    │ ───> │   检索阶段    │ ───> │  生成阶段  │ │
│  │  (Indexing)  │      │ (Retrieval)  │      │(Generation)│ │
│  └──────────────┘      └──────────────┘      └───────────┘ │
│        │                     │                      │       │
│        ▼                     ▼                      ▼       │
│  文档分块+向量化          语义搜索              基于上下文生成 │
│                                                              │
└─────────────────────────────────────────────────────────────┘

## 索引阶段(Indexing)--准备数据库

目标：将文档（需要嵌入向量数据库中的数据类型,不止文档一种形式，有可能还有音频、视频、图片等形式进行）做预处理
，这里以文档为例：

核心步骤：
1. 文档加载(Document Loading)

2. 数据清洗(Clearing)

3. 文档分块(Text Splitting)

4. 向量化(Vectorization)

5. 存储(Storage)


## 检索阶段(Retrieval)--找到相关信息

目标：根据用户查询找到最相关的文档(对应的内容片段)

核心步骤：
1. 查询向量化

2. 相似度计算

3. 结果排序

## 三、生成阶段(Generation)--生产答案

目标：基于检索到的信息生成新的提示词，然后发给大模型，提供参考依据，以便生成更准确答案

核心步骤：
1. 构建提示词

2. LLM生成

3. 答案返回
