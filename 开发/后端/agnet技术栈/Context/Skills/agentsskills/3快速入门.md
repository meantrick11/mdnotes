# Agent Skills 快速入门笔记
来源：https://agentskills.io/skill‑creation/quickstart

## 前置条件
- VS Code + GitHub Copilot
> Agent Skills是开放格式，同一套技能包也可以在Claude Code、OpenAI Codex等兼容智能体直接使用。

## 创建第一个技能
VS Code 默认读取项目下 `.agents/skills/` 目录中的技能包。
教程示例为掷骰子技能，文件路径：`.agents/skills/roll‑dice/SKILL.md`

文件各部分作用：
1. **name**：技能唯一标识，必须和外层文件夹同名
2. **description**：告诉智能体该在什么场景启用技能，是触发激活的核心
3. **正文**：技能激活后执行的任务指令；示例提供Shell/PowerShell随机数命令，替换骰子面数参数。

> 示例仅需单个文件，代码不足20行。

## 测试运行步骤
1. 在VS Code打开项目
2. 打开Copilot聊天面板
3. 切换至**Agent智能体模式**
4. 输入 `/skills`，确认列表出现`roll‑dice`，识别失败检查文件路径
5. 提问“Roll a d20”，允许终端执行权限，输出1‑20随机点数

> 提示：不同模型工具调用表现不一样。如果模型直接回答、不运行终端命令，更换模型再尝试。

## 底层执行流程（渐进式披露）
1. **发现**：会话启动扫描技能目录，仅读取技能名称、描述，用于任务匹配
2. **激活**：用户提问匹配技能描述，完整加载SKILL.md全部指令正文
3. **执行**：智能体按照正文指令，替换参数，运行命令完成任务

## 后续学习方向
- 技能编写最佳实践：编写范围合理、效果可靠的技能
- 优化技能描述：调试文本，保证技能可以被正确触发
- 查阅完整规范：SKILL.md完整格式文档
- 参考样例：浏览GitHub上的真实开源技能案例
