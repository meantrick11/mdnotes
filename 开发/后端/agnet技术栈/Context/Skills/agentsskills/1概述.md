# 概述

## 什么是 Agent Skills
Agent Skills 是一套轻量、开放的格式，用于为AI智能体扩展专业知识与业务流程能力。

技能包本质是一个文件夹，核心文件为 `SKILL.md`。该文件至少要填写名称、描述元数据，同时写入任务指令，告诉AI如何完成特定任务。技能包还可以附带脚本、参考资料、模板以及其他资源文件。

## 为什么需要 Agent Skills
AI智能体虽然能力越来越强，但往往缺少真实业务需要的上下文，难以稳定完成实际工作。

Agent Skills 将流程化知识，以及企业、团队、用户的专属业务上下文，打包成可移植、支持版本管理的文件夹，由智能体按需加载。
- **领域专业能力**：把法律审核、数据分析、演示文稿排版等专业知识封装成可复用的指令与资源。
- **可复现工作流**：将多步骤任务转化为输出稳定、可审计追溯的标准化流程。
- **跨产品复用**：技能包只需要编写一次，就能在所有兼容该规范的AI智能体上使用。

## 工作原理
AI智能体通过**渐进式披露**分为三个阶段加载技能。

## 适用场景
Agent Skills 可以在任意支持该规范的AI智能体产品中运行。

## 开放开发
项目采用开放开发模式，规范公开，任何人都可以创建、分享技能包。

## 快速上手
可以直接编写技能包的核心文件 `SKILL.md`，按照规范定义元数据和任务指令，即可给到兼容的AI智能体使用。
