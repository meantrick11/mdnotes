# 应用部署与交付全景

## 解决的问题与位置

本目录回答“从本地代码到用户可持续使用的服务，中间发生了什么”。它是各能力领域的共同入口，不替代 Docker、Jenkins 或 Nginx 等技术专题的操作教程。

## 核心概念与技术关系

源码经过测试和构建成为制品；制品与环境配置组合，在服务器、容器或集群中运行；DNS、TLS 与代理提供访问入口；日志、指标和健康检查支持运维与后续版本更新。CI/CD 使这些步骤更可重复，SOP 把跨领域动作连成实际交付流程。

## 推荐顺序与掌握程度

先理解生命周期与交付本质，再看技术体系和职责边界，最后按学习路线选择 P0、P1、P2 深度。开发工程师应能达到“解释完整链路并独立交付单机服务”的 L2 水平；大规模平台治理按实际项目学习。
