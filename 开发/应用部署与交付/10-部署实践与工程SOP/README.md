# 部署实践与工程 SOP

## 解决的问题与位置

将多个能力领域串成可执行的交付流程。它位于从源码到可持续服务的交付链中，与「应用部署与交付全景」直接衔接。

## 概念与技术边界

关键概念：前置条件、发布步骤、验证、回滚、复盘。

Python-FastAPI 是单服务实操；多服务实践覆盖依赖联调；AI 应用实践补充推理资源与模型版本。

## 推荐学习顺序与掌握程度

首次部署 → 迭代更新 → 多服务联调 → 故障回滚。开发工程师的建议目标：P0：单服务部署到 L2；P1：多服务和回滚到 L2/L3。
