# 基础设施自动化

## 解决的问题与位置

用可审查、可重复的声明管理环境和基础设施。它位于从源码到可持续服务的交付链中，与「基础设施与服务器」直接衔接。

## 概念与技术边界

关键概念：期望状态、变更审查、幂等、漂移。

Ansible 偏主机配置与任务自动化；Terraform 偏基础设施资源声明与状态管理。

## 推荐学习顺序与掌握程度

IaC 原理 → Ansible/Terraform 按项目需求选择。开发工程师的建议目标：P2：先 L1；有环境治理需求时到 L2。
