# Ansible 学习索引

## 定位与场景

主机配置与任务自动化工具。典型场景：重复配置多台主机。

## 知识地图

Inventory；Playbook；Task；Role。

建议优先级：**P2 / L1，使用时 L2**。本索引只规划学习路径，表中的 TODO 不是已完成教程。
