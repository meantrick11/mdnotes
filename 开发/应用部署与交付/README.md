# 应用部署与交付

面向 AI 应用开发与后端工程师的部署知识地图。学习主线是：**源码 → 测试与构建 → 制品 → 部署 → 对外服务 → 观测与更新**。本库保留完整能力范围，但按 P0、P1、P2 逐步深入。
