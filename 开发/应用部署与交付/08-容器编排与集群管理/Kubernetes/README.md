# Kubernetes 学习索引

## 定位与场景

容器编排平台。典型场景：跨节点调度、自愈和声明式管理需求。

## 知识地图

Cluster；Node；Pod；Controller；Service。

建议优先级：**P2 / L1，项目需要时 L2**。本索引只规划学习路径，表中的 TODO 不是已完成教程。
