# 服务器远程访问与堡垒机

远程访问是把人的操作安全地送到目标主机。SSH 提供加密连接和身份认证；堡垒机通常作为统一访问入口，增加授权、审计与会话管理。堡垒机不是 SSH 协议本身，也不替应用提供发布版本管理。

```mermaid
flowchart LR
  A[工程师] -->|身份认证与授权| B[堡垒机]
  B -->|受控 SSH 会话| C[目标服务器]
  C --> D[应用进程与日志]
```

访问前确认目标环境、主机名、账号、授权期限和操作目的。首次连接时核对主机密钥指纹，避免在未确认身份的主机上输入凭据。使用个人账号与最小权限；私钥保存在受保护位置，不放入知识库、脚本或制品。通过堡垒机访问时遵循团队审批与审计要求，不绕过入口直连。

进入主机后先做只读确认：主机与环境、当前服务版本、进程状态、监听端口、磁盘和日志。部署变更应按发布 SOP 记录版本、验证与回滚点；从个人终端手工修改线上代码会破坏可追溯性。

最小练习：在获授权的实验机上验证 SSH 主机指纹、用个人密钥登录、查看应用状态和日志，再退出并检查访问审计记录。堡垒机的具体连接方式由组织产品和策略决定，这里不假设某个厂商的命令格式。
