# 基础设施与服务器

## 解决的问题与位置

使应用拥有可访问、可管理的运行主机。它位于从源码到可持续服务的交付链中，与「应用部署与运行管理」直接衔接。

## 概念与技术边界

关键概念：主机、账号、权限、网络连通性、远程会话。

Linux 处理系统与进程；SSH 建立加密连接；堡垒机管理访问授权和审计。

## 推荐学习顺序与掌握程度

Linux → SSH → 堡垒机。开发工程师的建议目标：P0：Linux/SSH 到 L2；堡垒机按组织要求到 L1/L2。
