# SSH 学习索引

## 定位与场景

安全远程连接协议与工具。典型场景：远程登录、文件传输、受控自动化。

## 知识地图

主机身份；用户认证；密钥；会话与转发。

建议优先级：**P0 / L2**。本索引只规划学习路径，表中的 TODO 不是已完成教程。
