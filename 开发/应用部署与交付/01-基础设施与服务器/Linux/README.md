# Linux 学习索引

## 定位与场景

操作系统和主机运行基础。典型场景：准备运行目录、账号权限、进程端口与日志。

## 知识地图

文件权限；进程与信号；systemd；磁盘与网络排障。

建议优先级：**P0 / L2**。本索引只规划学习路径，表中的 TODO 不是已完成教程。
