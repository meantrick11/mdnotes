# 应用构建与制品管理

## 解决的问题与位置

把源码转换为可验证、可追踪、可分发的发布对象。它位于从源码到可持续服务的交付链中，与「CI-CD持续集成与交付」直接衔接。

## 概念与技术边界

关键概念：源码、依赖、构建、制品、版本、仓库。

Python/Java/Go 各有构建方式；Harbor 侧重容器镜像，Nexus 可管理多种包格式。

## 推荐学习顺序与掌握程度

构建原理 → Python 依赖 → 版本 → 制品仓库；其他语言按项目需要。开发工程师的建议目标：P0：Python 构建到 L2；P1：版本与仓库到 L2；其他语言先 L1。
