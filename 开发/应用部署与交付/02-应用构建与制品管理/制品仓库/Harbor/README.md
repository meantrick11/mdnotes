# Harbor 学习索引

## 定位与场景

容器镜像仓库与治理平台。典型场景：团队需要私有镜像分发和访问控制。

## 知识地图

项目；镜像；标签；访问控制；保留策略。

建议优先级：**P1 / L1，使用时 L2**。本索引只规划学习路径，表中的 TODO 不是已完成教程。
