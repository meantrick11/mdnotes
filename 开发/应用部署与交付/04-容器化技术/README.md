# 容器化技术

## 解决的问题与位置

统一应用运行单元并隔离进程，支持镜像分发。它位于从源码到可持续服务的交付链中，与「容器编排与集群管理」直接衔接。

## 概念与技术边界

关键概念：镜像、容器、仓库、卷、网络、服务。

Docker 管理镜像与容器；Docker Compose 用声明文件定义多服务应用。

## 推荐学习顺序与掌握程度

容器化原理 → Docker → Docker Compose。开发工程师的建议目标：P0：Docker 和 Compose 到 L2。
