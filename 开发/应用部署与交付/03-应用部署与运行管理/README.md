# 应用部署与运行管理

## 解决的问题与位置

将选定制品和配置变成持续运行的服务。它位于从源码到可持续服务的交付链中，与「容器化技术」直接衔接。

## 概念与技术边界

关键概念：运行环境、配置、进程、生命周期、健康检查、回滚。

systemd 是 Linux 服务管理器；Supervisor 是进程管理工具；容器部署时由容器平台管理运行实例。

## 推荐学习顺序与掌握程度

部署方式 → 配置 → 进程生命周期 → systemd → 更新回滚。开发工程师的建议目标：P0：单机 Python/systemd 到 L2；P1：更新与回滚到 L3。
