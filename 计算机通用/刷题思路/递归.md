# 递归

## 原理

递归是指当前问题拆

递归模板：
def recursive(参数):
    # 1. 终止条件：最简单的情况，直接返回
    if 满足终止条件:
        return 基础值

    # 2. 分解：将当前问题拆成更小的子问题
    子问题1 = 参数的一部分
    子问题2 = 参数的另一部分

    # 3. 信任并调用：递归解决子问题
    结果1 = recursive(子问题1)
    结果2 = recursive(子问题2)

    # 4. 合并：根据当前层的信息，组合子问题的结果
    当前层结果 = 合并(当前层数据, 结果1, 结果2)

    # 5. 返回
    return 当前层结果
