## 一、滑动窗口（Sliding Window）

### 1. 基本定义

滑动窗口是一种**双指针技巧**，用于解决**连续子数组或子串**的优化问题。它维护一个左右边界 `[left, right]` 的动态窗口，通过**同向移动**两个指针来遍历所有可能的连续区间，将暴力枚举的 O(n²) 优化到 O(n)。

- **双指针关系**：滑动窗口属于双指针类的**同向指针**子类（快慢指针的一种特殊形式）。
- **常见别名**：虫取法、追逐指针。

### 2. 适用场景（关键词）

- 子数组 / 子串 **连续**
- 求 **最大/最小长度**
- 满足某个条件（和 ≥ target、包含所有字符、最多 k 个不同字符等）
- 数组元素通常为正数（若含负数需结合前缀和+哈希）
- 固定长度窗口 or 可变长度窗口

### 3. 核心思想

1. 右指针 `right` 不断右移，**扩大窗口**，加入新元素。
2. 当窗口满足条件后，尝试**收缩左边界** `left`，寻找更优解。
3. 每次收缩前更新答案（如最小长度）。
4. 收缩到条件不再满足时，继续移动右指针。

> 关键：每个元素最多进、出窗口各一次，总复杂度 O(n)。

### 4. 通用模板（可变长度，求最小窗口）

```python
def min_window(nums, condition):
    left = 0
    cur_state = 0          # 窗口和、计数、频率表等
    ans = len(nums) + 1    # 初始化为不可能的大值

    for right in range(len(nums)):
        # 1. 扩展窗口：加入 nums[right]
        cur_state += nums[right]   # 或其他更新逻辑

        # 2. 收缩窗口：当条件满足时，尝试缩小
        while cur_state >= target:   # 条件视题目而定
            ans = min(ans, right - left + 1)   # 更新答案
            cur_state -= nums[left]            # 移除左边界元素
            left += 1

    return ans if ans <= len(nums) else 0
```

**不同题型模板变形**：
- **求最大窗口**：通常在 while 不满足条件时收缩，在循环外更新答案。
- **固定长度窗口**：先建窗口，然后整体滑动（无需 while 收缩）。

### 5. 典型例题：LeetCode 209. 长度最小的子数组

**题目**：给定正整数数组 `nums` 和目标值 `target`，找出和 ≥ target 的最短连续子数组长度。  
**输入**：`target = 11, nums = [1,2,3,4,5]`  
**输出**：`3`（子数组 `[3,4,5]` 或 `[2,3,4,5]`）

#### 手写模拟

| right | 操作 | 窗口 | 当前和 | 是否 ≥11 | 收缩动作 | 更新长度 |
|-------|------|------|--------|----------|----------|----------|
| 0 | 加1 | [0,0] | 1 | 否 | 无 | - |
| 1 | 加2 | [0,1] | 3 | 否 | 无 | - |
| 2 | 加3 | [0,2] | 6 | 否 | 无 | - |
| 3 | 加4 | [0,3] | 10 | 否 | 无 | - |
| 4 | 加5 | [0,4] | 15 | 是 | 移出1 → 和14，窗口[1,4]；移出2 → 和12，窗口[2,4]；移出3 → 和9，停止 | 长度5→4→3，最小=3 |

最终返回 `3`。

#### 正确代码

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        n = len(nums)
        ans = n + 1
        left = 0
        cur_sum = 0
        for right in range(n):
            cur_sum += nums[right]
            while cur_sum >= target:
                ans = min(ans, right - left + 1)
                cur_sum -= nums[left]
                left += 1
        return ans if ans <= n else 0
```

### 6. 常见错误（结合你的原始代码总结）

| 错误操作 | 后果 | 正确做法 |
|---------|------|----------|
| 收缩条件使用 `(sum - nums[left]) > target` | 窗口未充分收缩，可能遗漏更优解 | 使用 `while sum >= target` |
| 更新答案时用 `right - left` | 少计1，答案偏小 | 用 `right - left + 1` |
| 错误覆盖累加和 `sum = nums[left]` | 窗口状态错乱 | 使用 `sum -= nums[left]` |
| 将答案更新放在收缩循环外面 | 只能记录某个特定时刻的长度 | 在收缩循环内部（每次移除前）更新 |
| 忘记处理无解情况 | 返回不合理值 | 最后判断 `ans` 是否被更新 |

### 7. 滑动窗口 vs 其他双指针

| 类型 | 指针移动方向 | 典型例题 |
|------|-------------|----------|
| **滑动窗口** | 同向（右快左慢） | 最小覆盖子串、最长无重复子串 |
| **快慢指针** | 同向（不同速度） | 环形链表、删除有序数组重复项 |
| **对撞指针** | 相向（两端向中间） | 两数之和 II、回文判断 |

### 8. 复杂度分析

- **时间复杂度**：O(n) —— 每个元素最多被 `left` 和 `right` 各访问一次。
- **空间复杂度**：O(1) 或 O(k)（k 为字符集大小，如哈希表存储频率）。

### 9. 实战提醒

- 窗口条件必须**单调**（如和、长度等），否则双指针失效（负值场景需特殊处理）。
- 当数组元素**全为正数**时，滑动窗口求“和 ≥ target 的最短子数组”正确性有保障。
- 对于“最长无重复子串”问题，收缩条件变为 `while 窗口内有重复字符`，需配合哈希表。

**最后一句记忆口诀**：
> 右指针扩张进元素，左指针收缩找最短；  
> 条件一满足即更新，每个元素只走一遍。

# 对撞指针（Two Pointers）


## 一、对撞指针


### 1. 基本定义


对撞指针是一种**双指针技巧**，通常用于**有序数组**的搜索问题。它维护左右两个指针 `left` 和 `right`，初始分别指向数组的**首尾**，通过**相向移动**逐步缩小搜索范围，将暴力枚举的 O(n²) 优化到 O(n)。


- **双指针关系**：对撞指针属于双指针类的**相向指针**子类（与滑动窗口的同向移动相反）。
- **常见别名**：左右指针、首尾指针、夹逼法。


### 2. 适用场景（关键词）


- 数组 **有序**（或可排序后求解）
- 寻找 **两数之和 / 三数之和** 等组合
- 判断 **回文串**
- 盛水容器、接雨水等面积/体积问题
- 二分查找的变形（与二分不同，一次移动一步）
- 要求 **O(n)** 时间 + **O(1)** 空间


### 3. 核心思想


1. 初始化 `left = 0`, `right = n - 1`。
2. 计算当前指针对应元素的和（或其他条件）。
3. 根据条件与目标值的关系，**移动一个指针**：
   - 若当前和 **小于** target → `left++`（需要更大值）
   - 若当前和 **大于** target → `right--`（需要更小值）
   - 若 **等于** target → 找到答案，返回。
4. 循环终止条件：`left >= right`（指针相遇，无解）。


> 关键：每次比较都能排除一个边界元素，总比较次数最多 n-1 次，复杂度 O(n)。


### 4. 通用模板（两数之和问题）


```python
def two_sum(numbers, target):
    left, right = 0, len(numbers) - 1

    while left < right:
        cur_sum = numbers[left] + numbers[right]

        if cur_sum == target:
            return [left + 1, right + 1]   # 题目要求 1-based 索引
        elif cur_sum < target:
            left += 1      # 和太小，增加左边界
        else:
            right -= 1     # 和太大，减小右边界

    return [-1, -1]   # 无解，视题目而定
```


**不同题型模板变形**：
- **三数之和**：外层固定一数，内层对撞指针求两数之和。
- **回文判断**：左右指针比较字符是否相等，不等则 `return False`。
- **接雨水/盛水容器**：移动较矮的一侧，维护当前最大水量。


### 5. 典型例题：LeetCode 167. 两数之和 II - 输入有序数组


**题目**：给定一个已按 **非递减顺序排列** 的整数数组 `numbers`，找出两个数之和等于目标数 `target`，返回两数的 **1-based 索引**。  
**输入**：`numbers = [2,7,11,15], target = 9`  
**输出**：`[1,2]`（因为 2 + 7 = 9）


#### 手写模拟


**初始**：`left = 0 (值2)`, `right = 3 (值15)`


| 步骤 | left | right | 值对 | 当前和 | 与 target(9) 比较 | 动作 | 结果 |
|------|------|-------|------|--------|-------------------|------|------|
| 1 | 0(2) | 3(15) | (2,15) | 17 | 17 > 9 | right-- | → right=2 |
| 2 | 0(2) | 2(11) | (2,11) | 13 | 13 > 9 | right-- | → right=1 |
| 3 | 0(2) | 1(7) | (2,7) | 9 | 9 == 9 | 找到！返回 [1,2] | 结束 |


**正确性解释**：
- 当 `cur_sum < target` 时，`numbers[left]` 与右侧任意元素的和只会更小，因此左边界可永久排除。
- 当 `cur_sum > target` 时，`numbers[right]` 与左侧任意元素的和只会更大，因此右边界可永久排除。
- 每一步都在缩小搜索范围，且不会遗漏解。


#### 正确代码


```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        left, right = 0, len(numbers) - 1
        while left < right:
            s = numbers[left] + numbers[right]
            if s == target:
                return [left + 1, right + 1]
            elif s < target:
                left += 1
            else:
                right -= 1
        return []  # 题目保证有解，此行仅为代码完整性
```


### 6. 常见错误


| 错误操作 | 后果 | 正确做法 |
|---------|------|----------|
| 未利用有序性，暴力双层循环 | 超时 O(n²) | 使用对撞指针 O(n) |
| 循环条件写成 `left <= right` | 可能重复使用同一元素，违反题目要求 | 必须 `left < right`（两数不同下标） |
| 两数之和小于 target 时移动 `right` | 和会越变越小，永远找不到解 | 小于 target 应 `left++` |
| 大于 target 时移动 `left` | 和会越变越大，方向错误 | 大于 target 应 `right--` |
| 返回 `[left, right]` | 索引为 0-based，不符合题目要求 | 返回 `[left+1, right+1]`（若要求 1-based） |
| 找到解后未立即返回 | 画蛇添足，可能被后续移动覆盖 | 直接 return |


### 7. 对撞指针 vs 其他双指针


| 类型 | 指针移动方向 | 特点 | 典型例题 |
|------|-------------|------|----------|
| **对撞指针** | 相向（两端向中间） | 每次排除一端，依赖有序性 | 两数之和 II、三数之和、盛水容器 |
| **滑动窗口** | 同向（右快左慢） | 维护连续区间，依赖单调性 | 最小覆盖子串、最长无重复子串 |
| **快慢指针** | 同向（不同速度） | 常用于链表判环、去重 | 环形链表、删除有序数组重复项 |


### 8. 复杂度分析


- **时间复杂度**：O(n) —— 每次比较移动一个指针，最多移动 n 次。
- **空间复杂度**：O(1) —— 只使用了常数个变量，无额外数据结构。


### 9. 实战提醒


- **有序是前提**：数组必须有序（或可以 O(n log n) 先排序，但注意排序后会丢失原始索引，两数之和 II 本身有序，三数之和需预先排序）。
- **移动方向不能反**：和太小 → 增大左指针；和太大 → 减小右指针。这是有序数组单调性的直接应用。
- **跳过重复值（进阶）**：在三数之和、四数之和等问题中，找到解后需要跳过重复元素，避免结果集重复。
- **终止条件**：`left < right` 保证不会使用同一个元素，符合题目“不同下标”的要求。
- **溢出注意**：如果 `numbers[left] + numbers[right]` 可能超出 int 范围（如 C++ 中），可用 `long long` 或使用减法比较：`target - numbers[left] < numbers[right]` 等技巧。


**最后一句记忆口诀**：
> 首尾指针相向行，和大于目标右减一；  
> 和小于目标左加一，有序数组 O(n) 解两数。
