# 416. 分割等和子集

## 题目

给你一个 只包含正整数 的 非空 数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

 

示例 1：

输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11] 。
示例 2：

输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。


## 思路(dp)

等价于在0->total//2的背包中，是否能够最大化的装价值总和=total的数?当然这里的数字，空间=价值=nums[i]


```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        #sum/2个背包空间，如果在dp的最后的结果dp[sum/2]== sum/2，那么就可以装满sum/2的背包
        #使用滚动数组的方式
        ### 数字=重量=价值
        total = sum(nums)
        if total%2 != 0:    #注意，如果1/2为小数，那么肯定没有整数可以
            return False
        target = total//2
        dp = [0]*(target+1)    #初始化一维数组，这里的正整数，所以可以初始化为0，如果包含负数，就应该初始化为-inf了
        
        #第一个物品进行初始化
        for i in range(target+1):
            if nums[0] <= i:    #如果当前数字<total，那么就装进背包里面
                dp[i] = nums[0]

        #进行dp
        for i in range(1,len(nums)):
            for j in range(target,0,-1):  #滚动数组，需要从后往前进行遍历，避免被多算多次    
                if nums[i] > j: #如果当前的数字>背包容量，肯定不能装入，那么dp[j] = dp[j],不变
                    dp[j] = dp[j]
                else:   #<，那么进行不装nums[j]或者装nums[j]的比较
                    dp[j] = max(dp[j],dp[j-nums[i]]+nums[i])    
            
        return dp[-1] == target
```
