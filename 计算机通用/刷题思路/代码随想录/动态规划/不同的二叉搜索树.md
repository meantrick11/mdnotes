# 96. 不同的二叉搜索树

## 题目

给你一个整数 n ，求恰由 n 个节点组成且节点值从 1 到 n 互不相同的 二叉搜索树 有多少种？返回满足题意的二叉搜索树的种数。

 

示例 1：


输入：n = 3
输出：5
示例 2：

输入：n = 1
输出：1
 

## 思路（dp）

**主要是以某一个树为根节点，然后左右剩余数字的个数，然后左右不同的子树的个数相乘**
**根为i时总方案 = 左方案数 × 右方案数（乘法原理）**

dp五部曲：

1. dp[i]含义：当n=i时，n个树构成的二叉树的个数，比如dp[1]=1,dp[2]=2,dp[3]=5
2. dp递推公式：1-n，以所有数字为头节点的二叉搜索树的个数,比如dp[3],需要以1，2，3分别为头节点的二叉搜索树的个数,dp[i] = 求和dp[i-j]*dp[j-1] j=1~i,
3. dp初始化：dp[0] = 1 空树
4. 遍历顺序，数字越大，越依赖左侧的数字从左向右1-n进行遍历
5. 举例，n=3 ,dp[3] = dp[0][2]+dp[1]dp[1]+dp[2]dp[0]，分别以1，2，3为头节点


```python
class Solution:
    def numTrees(self, n: int) -> int:
        #创建dp数组
        dp = [0] * (n+1)

        dp[0] = 1   
        dp[1] = 1

        for i in range(2,n+1,1):
            #计算dp[i],要分别以1~i，作为根节点然后求总和，才是dp[i]的方案数
            for j in range(1,i+1,1):    
                dp[i] += dp[j-1]*dp[i-j]    #以i为根节点，左侧的数字个数的不同排列的个数*右侧剩余数字的不同排列的个数

        return dp[n]    #返回最后的结果
```
