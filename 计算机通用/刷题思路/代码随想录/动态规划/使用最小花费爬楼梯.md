# 746. 使用最小花费爬楼梯

## 题目

给你一个整数数组 cost ，其中 cost[i] 是从楼梯第 i 个台阶向上爬需要支付的费用。一旦你支付此费用，即可选择向上爬一个或者两个台阶。

你可以选择从下标为 0 或下标为 1 的台阶开始爬楼梯。

请你计算并返回达到楼梯顶部的最低花费。

 

示例 1：

输入：cost = [10,15,20]
输出：15
解释：你将从下标为 1 的台阶开始。
- 支付 15 ，向上爬两个台阶，到达楼梯顶部。
总花费为 15 。
示例 2：

输入：cost = [1,100,1,1,1,100,1,1,100,1]
输出：6
解释：你将从下标为 0 的台阶开始。
- 支付 1 ，向上爬两个台阶，到达下标为 2 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 4 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 6 的台阶。
- 支付 1 ，向上爬一个台阶，到达下标为 7 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 9 的台阶。
- 支付 1 ，向上爬一个台阶，到达楼梯顶部。
总花费为 6 。

## 思路（动态规划）

爬到当前阶梯的最小花费应该是和dp[i-1]+cost[i-1]和dp[i-2]+cost[i-2]进行对比

dp五部曲：

1. dp数组含义：dp[i]表示到达i所需要的最小的体力消耗
2. 确定递推公式：dp[i] = min(dp[i-2]+cost[i-2],dp[i-1]+cost[i-1])
3. dp数组初始化：dp[0]=0,dp[1]=0,爬到0或1都不需要消耗体力
4. 遍历顺序：因为后续的dp[i]和前面的dp[i-1]&dp[i-2]有关系，所以应该是正序
5. 自行模拟dp数组，如示例1，最后dp数组应该是[0,0,10,15]，只有到n+1，才是爬到顶层

```python
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:

        n = len(cost)
        dp = [0]*(n+1)  #因为0-n,应该有n+1个位置，dp[0]&dp[1]已经初始化了

        for i in range(2,n+1,1):    #由于爬到顶层，满足最后dp应该是n，也就是下标指向n，下标初始化应该为*(n+1)
            dp[i] = min(dp[i-1]+cost[i-1],dp[i-2]+cost[i-2])

        return dp[-1]
        
```
