# 343. 整数拆分

### 题目重述
给定一个正整数 `n`，将其拆分为 **至少两个正整数** 的和，并使这些整数的乘积最大化。返回最大乘积。

---

### 第一步：确定 dp 数组及下标的含义

- **`dp[i]`**：表示将正整数 `i` 拆分成**至少两个正整数**的和时，这些正整数的**最大乘积**。
- 下标 `i` 就是我们要拆分的那个整数。
- 注意：`dp[0]` 和 `dp[1]` 没有实际意义（无法拆分），我们只从 `i = 2` 开始使用。

---

### 第二步：确定递推公式

对于 `i >= 2`，我们遍历可能的第一个因子 `j`（`1 <= j < i`），考虑两种拆分方式：

1. **拆成两个数**：`j * (i - j)`  
   —— 即把 `i` 直接拆成 `j` 和 `i - j` 两个部分，不再继续拆分。

2. **拆成多个数**：`j * dp[i - j]`  
   —— 即把 `i` 拆成 `j` 和 `(i - j)`，但 `(i - j)` 继续拆分，其最大乘积由 `dp[i - j]` 给出。这样一共拆成了 **3 个或更多** 个数。

因此对于每个 `j`，候选值为：
```
max( j * (i - j), j * dp[i - j] )
```
我们需要对所有 `j` 取最大值，同时不断更新 `dp[i]`，所以递推公式为：
```
dp[i] = max( dp[i], j * (i - j), j * dp[i - j] )   (j 从 1 遍历到 i-1)
```

> **为什么不用考虑拆分 `j`？**  
> 因为拆分 `j` 的情况已经在遍历更小的 `j` 时被包含了。例如，如果 `j` 本身被拆成 `a + b`，那么在遍历 `j' = a` 时，`a * dp[i - a]` 会涵盖这种结构。我们只需固定一个因子作为“不拆分”部分，剩余部分交给 `dp` 处理即可，这样不会遗漏。
例如 i= 10，j = 5，i-j = 5，如果把j拆分为 2 和 3，其实在j = 2 的时候，i-j= 8 ，拆分i-j的时候就可以拆出来一个3了。

或者也可以理解j是拆分i的第一个整数。
---

### 第三步：dp 数组的初始化

- `dp[2] = 1`，因为 `2` 只能拆成 `1 + 1`，乘积为 `1`。
- `dp[0]` 和 `dp[1]` 无意义，可设为 `0`，但不会被用到（因为遍历时 `i - j >= 2` 才需要 `dp`，但 `j` 从1开始，`i - j` 可能为1，此时不取 `dp[1]`，只取 `j*(i-j)` 即可）。
- 实际代码中，我们通常将 `dp` 数组长度设为 `n+1`，并全部初始化为 `0`，然后单独设置 `dp[2] = 1`。

---

### 第四步：确定遍历顺序

- 从 `i = 3` 到 `n` **从小到大**遍历，因为计算 `dp[i]` 时需要用到 `dp[i - j]`，而 `i - j < i`，所以 `dp[i - j]` 已经在前面的迭代中计算好了。
- 对于每个 `i`，内层循环 `j` 从 `1` 遍历到 `i-1`（或更高效地，只到 `i/2`，但为了理解清晰，可以遍历到 `i-1`）。

---

### 第五步：举例推导 dp 数组（以 n = 6 为例）

我们手动推导 `dp[2]` 到 `dp[6]`：

- **dp[2] = 1**
- **dp[3]**：
  - j=1：`1*2=2`，`1*dp[2]=1` → 取 2
  - j=2：`2*1=2`，`2*dp[1]`（忽略）→ 取 2
  - 最终 `dp[3] = 2`（实际拆分：1+2）
- **dp[4]**：
  - j=1：`1*3=3`，`1*dp[3]=2` → 取 3
  - j=2：`2*2=4`，`2*dp[2]=2` → 取 4
  - j=3：`3*1=3`，`3*dp[1]`忽略 → 取 3
  - 最终 `dp[4] = 4`（拆分：2+2）
- **dp[5]**：
  - j=1：`1*4=4`，`1*dp[4]=4` → 4
  - j=2：`2*3=6`，`2*dp[3]=4` → 6
  - j=3：`3*2=6`，`3*dp[2]=3` → 6
  - j=4：`4*1=4`，`4*dp[1]`忽略 → 4
  - 最终 `dp[5] = 6`（拆分：2+3）
- **dp[6]**：
  - j=1：`1*5=5`，`1*dp[5]=6` → 6
  - j=2：`2*4=8`，`2*dp[4]=8` → 8
  - j=3：`3*3=9`，`3*dp[3]=6` → 9
  - j=4：`4*2=8`，`4*dp[2]=4` → 8
  - j=5：`5*1=5`，`5*dp[1]`忽略 → 5
  - 最终 `dp[6] = 9`（拆分：3+3，乘积 9）

所以，`n=6` 时最大乘积为 `9`，符合预期。

---

### 补充：时间复杂度与空间复杂度

- 时间复杂度：双重循环，`O(n^2)`
- 空间复杂度：一维数组，`O(n)`

---

### 代码实现（C++）

```python
class Solution:
         # 假设对正整数 i 拆分出的第一个正整数是 j（1 <= j < i），则有以下两种方案：
        # 1) 将 i 拆分成 j 和 i−j 的和，且 i−j 不再拆分成多个正整数，此时的乘积是 j * (i-j)
        # 2) 将 i 拆分成 j 和 i−j 的和，且 i−j 继续拆分成多个正整数，此时的乘积是 j * dp[i-j]
    def integerBreak(self, n):
        dp = [0] * (n + 1)   # 创建一个大小为n+1的数组来存储计算结果
        dp[2] = 1  # 初始化dp[2]为1，因为当n=2时，只有一个切割方式1+1=2，乘积为1
       
        # 从3开始计算，直到n
        for i in range(3, n + 1):
            # 遍历所有可能的切割点
            for j in range(1, i // 2 + 1):#遍历1~i//2+1,如果j>i//2+1,之前已经遍历过了，比如i=10，只需要遍历到5即可

                # 计算切割点j和剩余部分(i-j)的乘积，并与之前的结果进行比较取较大值
                ## 注意j是内层循环，当i=10的时候，需要持续记录获得的最大值，所以不能只比较从当前分割
                dp[i] = max(dp[i], (i - j) * j, dp[i - j] * j)
        
        return dp[n]  # 返回最终的计算结果

```
