# 63. 不同路径Ⅱ

## 题目

给定一个 m x n 的整数数组 grid。一个机器人初始位于 左上角（即 grid[0][0]）。机器人尝试移动到 右下角（即 grid[m - 1][n - 1]）。机器人每次只能向下或者向右移动一步。

网格中的障碍物和空位置分别用 1 和 0 来表示。机器人的移动路径中不能包含 任何 有障碍物的方格。

返回机器人能够到达右下角的不同路径数量。

测试用例保证答案小于等于 2 * 109。

 

示例 1：


输入：obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
输出：2
解释：3x3 网格的正中间有一个障碍物。
从左上角到右下角一共有 2 条不同的路径：
1. 向右 -> 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右 -> 向右
示例 2：


输入：obstacleGrid = [[0,1],[0,0]]
输出：1


## 思路（dp）

dp五部曲

**根据不同路径的思路，只不过，这里它已经初始化了数组，我们需要其他的计量单位，比如-0.1,遇到左侧为1的那么只添加上面的路径走法，如果上边为1的，那么只添加左侧的路径走法**
1. dp数组含义：走到当前非障碍格子的路径条数
2. dp递推公式：分为四种情况：1.左侧和上侧都是障碍，那么dp[i][j]=0 2.只有左侧或者只有上侧有障碍，那么dp[i][j]等于非障碍的那一方的路径 3. 左侧和上侧都没有障碍，那么应该是dp[i][j] = dp[i-1][j]+dp[i][j-1] 4. 当前格子为障碍，跳过
3. dp数组初始化：由于题目初始化的障碍表示为1，那么就不能使用同为正数的标记法，这里使用-0.1表示一种路径的标记法,也就是先将首行和首列初始化为-0.1,当然遇到障碍需要跳过
4. 遍历顺序，需要知道左侧和上侧的路径情况，所以从左向右行优先或者从上到下列优先都是可以的
5. 举例枚举dp数组结果：...


**极其巧妙的方法是在遇到障碍物的时候将其置零，初始化的时候同样，那么就可以直接套用不同路径的直接左+上的路径数了**

最开始置-0.1的想法十分需要考虑很多其他情况，比如只有一行或者只有一列、最后一个格子本身就为障碍等等可能，所以遇到障碍物就将其置0的思路要好很多

```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:


        ## 数组已经初始化
        ## 对首行和首列进行初始化

        m, n = len(obstacleGrid), len(obstacleGrid[0])
        # 处理起点
        if obstacleGrid[0][0] == 1:
            return 0
        obstacleGrid[0][0] = 1

        # 初始化首行
        for j in range(1, n):
            obstacleGrid[0][j] = 0 if obstacleGrid[0][j] == 1 else obstacleGrid[0][j-1] #将障碍物改为0，相加逻辑就可以实现了
        # 初始化首列
        for i in range(1, m):
            obstacleGrid[i][0] = 0 if obstacleGrid[i][0] == 1 else obstacleGrid[i-1][0]

        # 填充其余格子
        for i in range(1, m):
            for j in range(1, n):
                if obstacleGrid[i][j] == 1:
                    obstacleGrid[i][j] = 0
                else:
                    obstacleGrid[i][j] = obstacleGrid[i-1][j] + obstacleGrid[i][j-1]

        return obstacleGrid[m-1][n-1]
                   
```
