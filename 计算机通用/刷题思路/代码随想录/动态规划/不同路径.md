# 62. 不同路径


## 题目

一个机器人位于一个 m x n 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

 

示例 1：

输入：m = 3, n = 7
输出：28
示例 2：

输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
示例 3：

输入：m = 7, n = 3
输出：28
示例 4：

输入：m = 3, n = 3
输出：6

## 思路（dp）

**每到一个格子，都可以看作从起点开始走到当前格子的路径，也就是子问题**

dp五部曲：

1. dp数组含义,dp[i][j]表示从起点到dp[i][j]的不同路径
2. dp的递推公式：由于dp[i][j]只能从dp[i-1][j]或者dp[i][j-1]走到，所以，dp[i][j]=dp[i-1][j]+dp[i][j-1]
3. dp数组初始化，首行和首列只能有一种走法，因为只能向下或者向右走，初始化dp[i][0]&dp[0][j]
4. 遍历顺序：由于dp[i][j]由左和上格子确定，那么应该从左向右依次遍历每行，或者从上到下，从左向右依次遍历每列，只要确保当前格子的左边和上边的路径已经被计算过了。
5. 模拟dp数组:...


```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:

        
        ## 创建dp数组，dp[i][j]，第i行，第j列
        dp = [[0]*n for _ in range(m)]  ## 如果是写[0]*n*m，则m列都是对第一行的引用

        ## 初始化首行&首列

        for i in range(n):  #对首行初始化
            dp[0][i] = 1
        for j in range(m):  #对首列初始化
            dp[j][0] = 1

        for k in range(1,m):    #选择行优先，那么应该是
            
            for l in range(1,n):
                dp[k][l] = dp[k-1][l] + dp[k][l-1]  #上+左

        
        return dp[m-1][n-1]
```
