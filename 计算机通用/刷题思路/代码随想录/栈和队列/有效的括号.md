# 20. 有效的括号

## 题目
给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

左括号必须用相同类型的右括号闭合。
左括号必须以正确的顺序闭合。
每个右括号都有一个对应的相同类型的左括号

示例 1：

输入：s = "()"

输出：true

示例 2：

输入：s = "()[]{}"

输出：true

## 思路

**本题是匹配相邻元素，最后都是做消除的操作。**
此题可以很好地实操栈，将由于必须是有效地括号，首先使用hashmap建立一一对应的匹配关系。那么先进栈的后以和前一个进栈的对比，如果匹配上了，那么就从栈中移除，遍历到最后，检查栈是否为空？如果不为空，那么返回False

```python
class Solution:
    def isValid(self, s: str) -> bool:
        if not s:
            return True
        hashmap = {
            "}":"{",
            "]":"[",
            ")":"(",
        }

        stack = []
        for i in range(len(s)):
            if stack and stack[-1] == hashmap.get(s[i],""):#如果当前的字符能和栈中最后一个字符匹配，那么删除栈中的最后一个元素
                stack.pop()
            else:
                stack.append(s[i])  #如果不匹配，填入栈中

        if not stack:#如果为空栈，那么所有字符都已经匹配
            return True
        return False    #如果不为空，那么返回False
```
