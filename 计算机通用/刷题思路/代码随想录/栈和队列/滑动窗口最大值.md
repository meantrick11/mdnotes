# 滑动窗口最大值
**单调队列**
## 题目

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

 

示例 1：

输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
示例 2：

输入：nums = [1], k = 1
输出：[1]

## 思路一

采用双指针法左右维护一个固定窗口，然后获取窗口中的最大值

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        res = []
        left = 0
        right = left + k

        while right < len(nums)+1:
            res.append(max(nums[left:right]))
            right += 1
            left += 1
        
        return res
```

但是上述方法的数组切片会占用额外的空间，且使用max()函数，底层的时间复杂度为O(n),所以总的时间复杂度为O(n^2),遇到k太大的情况，会超时。

## 思路二(单调队列)
单调队列不存窗口里所有数字，只保留「有可能成为未来窗口最大值」的候选人；队列维持：队头→队尾，数值严格递减；✅ 队头永远是当前窗口最大值⚠️ 队列里面存下标，不是数值（用来判断元素有没有滑出窗口）
通俗比喻：一群人排队，要求从前往后身高越来越矮；新来一个高个子，所有排在他身后、比他矮的人永久失去出头机会，直接赶出队伍。原因：新人更高、位置更靠后，只要新人还在窗口里，矮个子永远当不了最大值。
```python
from collections import deque
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq = deque()#记录的是可能成为最大值的下标
        res = []
        for idx, val in enumerate(nums):

            # 维护单调递减：剔除尾部更小元素
            # 对于每个遍历的元素，如果当前元素>=dq中的第一个下标的元素的，那么不断将res下标移除队列，比如当前是[3,-1]
            while dq and nums[dq[-1]] <= val:
                dq.pop()
            dq.append(idx)
            # 队首超出窗口范围，移除
            while dq[0] <= idx - k:
                dq.popleft()
            # 形成完整窗口后记录答案,>=k-1之后才满足k个元素的窗口，前面不满足的不记录答案
            if idx >= k - 1:
                res.append(nums[dq[0]])
        return res
```
