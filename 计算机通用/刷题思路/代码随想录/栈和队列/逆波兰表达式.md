# 逆波兰表达式

## 题目

给你一个字符串数组 tokens ，表示一个根据 逆波兰表示法 表示的算术表达式。

请你计算该表达式。返回一个表示表达式值的整数。

注意：

有效的算符为 '+'、'-'、'*' 和 '/' 。
每个操作数（运算对象）都可以是一个整数或者另一个表达式。
两个整数之间的除法总是 向零截断 。
表达式中不含除零运算。
输入是一个根据逆波兰表示法表示的算术表达式。
答案及所有中间计算结果可以用 32 位 整数表示。

## 思路

思考一下，逆波兰表达式是加减乘除法写在操作数的后边，考虑到后进的操作数遇到操作的时候，应该获取之前的操作数并进行操作，所以应该考虑用栈，那么每当遇到一个操作数，那么就给他放进栈，而遇到操作符时，从stack中获取操作数并完成相应的操作，并将结果作为新的操作数放入栈中，方便下一次操作

```python
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:

        stack = []
        operate = ['+','-',"*","/"]
        for i in range(len(tokens)):
            if tokens[i] not in operate:
                stack.append(int(tokens[i]))
            else:
                #获取操作数
                num1 = stack.pop(-2)
                num2 = stack.pop(-1)
                #逻辑判断执行操作
                if tokens[i] == "/":
                    res = int(num1 / num2) 
                elif tokens[i] == "*":
                    res = num1 * num2
                elif tokens[i] == "+":
                    res = num1 + num2
                else:#-
                    res = num1 - num2
                #重新添加到stack中
                stack.append(res)
        #返回结果
        return stack[0]

                
```

这里需要做一个说明，当为"/"时，完成的是浮点数除法，无论结果是否整除与否，返回的都是浮点数float，然"//"表示向下除法取整，如果为浮点数，则向下取整，整数为原数，但是都是int，如果想要"/"结果向着0取整，那么应该对结果采取int().
