# 90. 子集Ⅱ

## 题目

给你一个整数数组 nums ，其中可能包含重复元素，请你返回该数组所有可能的 子集（幂集）。

解集 不能 包含重复的子集。返回的解集中，子集可以按 任意顺序 排列。

 

示例 1：

输入：nums = [1,2,2]
输出：[[],[1],[1,2],[1,2,2],[2],[2,2]]
示例 2：

输入：nums = [0]
输出：[[],[0]]

## 思路（回溯递归法）

**注意：这里的子集Ⅱ题目，nums可能是无序的，且包含重复元素，但是题目要求不要返回重复的子集，那么就需要我们先对nums进行排序，并在每层遍历的时候，需要数层去重**

1. 递归输入：当前层的备选元素起始索引startindex 递归输出：每层每次遍历的时候都将结果添加到result数组中，所以无需向上return

2. 递归终止条件：当前层的备选元素起始索引startindex == n时，说明上层递归已经把nums中的元素遍历完了，也无num可供下层递归了，直接return

3. 每次递归操作：检查是否达到递归终止条件？对于当前层的的后续元素，将可能的元素依次添加进curpath中，将curpath添加到result中，(**路径收集问题**)向后进行深度递归，递归完成之后将当前遍历的元素pop()，进行回溯

```python
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        result = [[]] #结果收集数组,必有[]为集合的子集
        
        nums.sort() #必须要排序，因为后续需要连续去重，否则，for递归中的去重逻辑失效，出现大量重复元素
        curpath = []    #当前"回溯"路径

        n = len(nums)   

        def findsubsets(startindex:int):#递归输入时当前及后续需要遍历的数字
            nonlocal result 
            nonlocal curpath
            nonlocal n
            if startindex == n: 
                return 

            for i in range(startindex,n): 
                if i>startindex and nums[i] == nums[i-1]:   #同层去重，因为如果元素相等，那么前一次的同层递归已经将当前需要的后续递归完了，无需重复。
                    continue
                curpath.append(nums[i]) #将当前需要递归的元素添加到curpath中
                result.append(curpath.copy())   #路径收集，将每个子集添加到result中
                findsubsets(i+1)   #每个元素下层不能重复递归，
                curpath.pop()   #回溯当前操作

        findsubsets(0)  #调用for递归函数

        return result   #返回结果

```
