# 77. 组合

## 题目
**回溯经典题目**

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

你可以按 任何顺序 返回答案。

 

示例 1：

输入：n = 4, k = 2
输出：
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]
示例 2：

输入：n = 1, k = 1
输出：[[1]]

## 思路（递归回溯法）

**集合求组合问题，需要传入startindex以获取当前以及后续递归的索引起始值**
**如果是互不影响的list或str等等，那么就不用传入startindex，用其他来确定需要for递归的具体的值就可以了**


如果k = 2,那么两次for循环就可以解决，如果k = 3，那么三次for循环就可以解决，但是如果k=50，那么需要50层for循环，且每次的for循环根据输入不一样还不一样，所以，最好采用回溯法，就是递归到某些程度，然后向上回溯，撤销某些操作。

1. 递归输入：当前递归深度(对应k)，当前递归起始位置startindex 递归输出：由于在递归结束的时候将结果添加到了result中，所以，整体上不用return，只需要在递归结束时return，终止一下就可以了

2. 递归终止条件：由于只需要组合问题，那么也就是必须遵循k的大小限制，那么就是递归(回溯)数的深度等于k，那么就将结果添加到result，并return

3. 每次递归操作：遍历当前层没有被递归的剩下数字，并将当前数字添加到curpath中，然后向下层递归，每次返回之后都将curpath.pop()，因为要删除当前遍历的数字，比如，上层取1，中层取2，那么向下递归深度已经达到2了，这时候将[1,2]添加到result中之后，向上回溯，这时需要将共享的curpath.pop()，也就是curpath=[1],然后当前层的for循环，然后将3添加进curpath中，进行下一次递归，，**这里的pop()就是撤销上一次递归的操作，也就是回溯**。

*由于通过nonlocal获取上层函数的局部变量，而不用将result，curpath单独作为参数传入递归函数中。单独传入也可以，不过递归函数参数显得冗杂。*

```python
class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        result = []
        curpath = []
        
        def dfs(depth:int,startindex:int):
            nonlocal result #获取上层函数的局部变量
            nonlocal curpath    #同上
            if depth == 0:  #终止条件，如果层数已经是最后一层了，那么应该是将结果添加到result中
                result.append(curpath.copy())   #注意，Python中的数组等可变对象传入的是指针，那么保存的也是指针引用，如果要记录当前数组的具体状态，应该使用copy()方法或者curpath[:],进行拷贝，如果不拷贝，最后result中保存的是curpath的引用，到最后curpath为空，最后返回的是n个[]组成的二维数组。
                return 
                
        ## 每层递归操作

            for i in range(startindex,n+1):
                curpath.append(i)   #将当前要遍历的数字添加到curpath中，
                dfs(depth-1,i+1)    #向下深层递归
                curpath.pop()   #当前层某次递归操作完成之后的回溯
 

        dfs(k,1)    #调用递归函数

        return result
```
**#注意，Python中的数组等可变对象传入的是指针引用，那么保存的也是指针引用，如果要记录当前数组的具体状态，应该使用copy()方法或者curpath[:],进行拷贝，如果不拷贝，最后result中保存的是curpath的引用，到最后curpath为空，最后返回的是n个[]组成的二维数组。**
