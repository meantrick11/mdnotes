# 78. 子集

## 题目

给你一个整数数组 nums ，数组中的元素 互不相同 。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

 

示例 1：

输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
示例 2：

输入：nums = [0]
输出：[[],[0]]

## 思路（递归回溯法）

**子集问题不是像组合、分割等叶子节点收集问题，而是全路程收集问题**

同样是递归回溯，只不过在每次for递归之前就将curpath添加到result中，

1. 递归输入：startindex：当前起始索引 递归输出：每次for递归都将curpath添加到result中，而不需要向上返回值

2. 递归终止条件：如果startindex==n，也就是子集划分完成，那么就return

3. 每次递归操作：for递归当前层，将当前遍历元素添加到curpath中，将当前的curpath添加到result中(路径收集)，然后进行深层递归，递归结束之后将当前元素pop()，进行回溯


```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        result = [[]] #结果记录数组,由于[]是每个集合的子集，那么直接初始化添加了

        curpath = []    #当前遍历路径
        n = len(nums)

        def findsubsets(startindex:int):
            #从上层变量命名空间中获取变量
            nonlocal result
            nonlocal curpath
            nonlocal n

            
            if startindex == n: #当前需要递归的索引起始位n，也就是n-1也被处理了，那么整个数组都被处理了，直接退出
                return 

            for i in range(startindex,n):
                curpath.append(nums[i]) #将当前需要遍历的元素添加到curpath中
                result.append(curpath.copy())  #将每次递归的值添加到result中，路径收集
                findsubsets(i+1)    #向下层递归，没有重复
                curpath.pop()   #进行回溯

        findsubsets(0)#调用函数

        return result   #返回结果
```
