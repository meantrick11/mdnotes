# 非递减子序列

## 题目

给你一个整数数组 nums ，找出并返回所有该数组中不同的递增子序列，递增子序列中 至少有两个元素 。你可以按 任意顺序 返回答案。

数组中可能含有重复元素，如出现两个整数相等，也可以视作递增序列的一种特殊情况。

 

示例 1：

输入：nums = [4,6,7,7]
输出：[[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]
示例 2：

输入：nums = [4,4,3,2,1]
输出：[[4,4]]

## 思路(递归回溯法)

不定的多重for循环，使用递归回溯法

**注意：这里是路径收集问题,收集条件是curpath至少2个元素，并且递增（curpath添加条件是not curpath or (curpath and nums[i] >= curpath[-1]）；并且原数组不能排序，所以涉及树层去重需要使用额外的set或者list进行记录去重；同样是向后递归的逻辑，每次向下递归都是i+1;**

1. 递归输入：当前层的起始遍历索引startindex 递归输出：每层根据条件进行是否添加到result中进行筛选，无需return

2. 递归终止条件：当前层起始索引startindex==n，也就是所有元素已经被递归完成了，那么return

3. 每次递归操作：
    1. 检查是否startindex==n，是则return
    2. 对于当前层的遍历数字，进行依次尝试添加到curpath(去重判断+递增判断添加+满足len(curpath)>=2添加到result中)
    3. 深层递归
    4. 递归结束之后进行回溯


```python
class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        ##题目条件必须递增，那么说明>=curpath[-1]才能添加到元素数组当中去
        ##路径收集问题，当收集之前要判断len(curpath)>=2?才能添加到result中
        result = [] #结果记录数组
        # nums.sort() #方便后续同层去重，需要数组先排序.这种方式对于那种可排序的数组题目可用
        curpath = []    #当前递归路径
        
        n = len(nums)   #获取当前的curpath

        def findquence(startindex:int): #依旧传入后续可能的遍历的候选数字
            nonlocal result
            nonlocal curpath
            nonlocal n
            if startindex == n: #索引到最后，无候选数字添加，遍历到数组最后了
                return 
            used = set()   #记录当前已经使用了的元素，而不是通过排序的去重方式，因为本题要求在原来的数组不变的基础上进行子集的遍历，那么需要去重就应该使用一个set或者list等记录已经使用了的元素

            for i in range(startindex,n):

                if nums[i] in used: #同层之间需要去重，由于是无序且有同层去重要求，那么使用一个set进行记录即可，为不是使用先排序在前一个元素比较
                    continue
                
                if not curpath or (curpath and nums[i] >= curpath[-1]): #只有在curpath为空或者不为空，那么组递增条件的时候将当前候选数字添加到curpath中
                    curpath.append(nums[i]) #将当前元素添加到curpath中
                    used.add(nums[i])    #记录当前层已经遍历过了的元素进行去重
                    if len(curpath) >= 2 :  #路径收集问题，递增子序列至少有两个元素，才能添加到result中
                        result.append(curpath.copy())
                    findquence(i+1) #向下层递归
                    curpath.pop()   #递归之后进行回溯
                
                
                    
        findquence(0)   #调用递归函数

        return result   #返回结果

```
