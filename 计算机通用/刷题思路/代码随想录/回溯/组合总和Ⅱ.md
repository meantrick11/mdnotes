# 40. 组合总和Ⅱ

## 题目

给定一个候选人编号的集合 candidates 和一个目标数 target ，找出 candidates 中所有可以使数字和为 target 的组合。

candidates 中的每个数字在每个组合中只能使用 一次 。

注意：解集不能包含重复的组合。 

 

示例 1:

输入: candidates = [10,1,2,7,6,1,5], target = 8,
输出:
[
[1,1,6],
[1,2,5],
[1,7],
[2,6]
]
示例 2:

输入: candidates = [2,5,2,1,2], target = 5,
输出:
[
[1,2,2],
[5]
]

## 思路（递归回溯法）

这里介绍一下去重的三大条件；
输入数组包含重复元素（比如 [1, 2, 2] 里有俩 2）。

每个元素在组合中只能使用一次（即递归传参是 idx+1，不能重复取自己）。

题目要求返回的结果集是唯一的（即 [1,2] 不管选哪个位置的 2，都只能算一个）。

只要满足这三点，就必须在同一层循环（即 for 循环）中，跳过值相同的后续元素。


思路：由于让我们满足组合总和=target的子数组，那么仿照`数组总和`的思路，我们直接进行for递归的方式，这里由于每个数只能使用一次，那么向下传递应该是i+1，其次，我们需要在同层遍历的过程中，遇到相同的元素continue，进行结果去重，不必对相同元素的数组进行向下递归，因为相同的元素在同层上次遍历的过程中已经递归了

首先需要将候选数组排序

1. 递归输入：**递归索引**(候选元素)，当前路径curpath，目标target 递归输出：由于在递归结束的时候将候选结果添加到result中，所以无需返回值

2. 递归终止条件：由于是有序数组，那么只要curpath的和大于等于target，那么就return(等于需要额外判断是否添加到result中，如果大于等于，由于是有序数组，那么后续的元素添加到curpath，之和也会大于target，所以直接return就行了)

3. 每次递归操作：检查当前元素是否和i-1相等，相等则跳过，将当前要遍历的元素添加到curpath中，然后向下递归i+1，递归完成后curpath.pop()，进行回溯，以便同层的下一个元素的递归

```python
class Solution:
    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:
        n = len(candidates) #候选数组的长度
        candidates.sort()   #需要将候选数组排序
        result = [] #结果记录数组
        
        curpath = []    #当前路径数组
        
        def find(startindex:int):
            #加载外层变量定义
            nonlocal n
            nonlocal result
            nonlocal curpath
            nonlocal candidates

            cursum = sum(curpath)   #获取当前curpath的总和

            if cursum >= target:    #递归终止条件：结果>=target
                if cursum == target :
                    result.append(curpath.copy())   #如果结果==target，那么将拷贝数组添加到result中
                return  #终止递归

            for idx in range(startindex,n):
                # 跳过当前层中重复的数字（第一个相同数字会执行，后面的跳过），及其重要，因为在每次递归的过程中遇到重复的数字直接continue，因为前一个已经递归完成了查找目标数组，他俩相同。

                ##这样还是会有很多的重复比如传入[1,2,2,2,2,5]...这样会出现很多个[1,2,5].
                if idx > startindex and candidates[idx] == candidates[idx-1]:
                    continue
                    
                curpath.append(candidates[idx])   #将备选数字添加到curpath中，以便后续向下递归
                find(idx+1)   #当前数字也不能重复，所以需要传入i+1
                curpath.pop()   #递归结束，将curpath尾部删除，也就是回溯，以便下一个同层元素的递归

        find(0) #调用函数，从索引0开始寻找
        return result
```
