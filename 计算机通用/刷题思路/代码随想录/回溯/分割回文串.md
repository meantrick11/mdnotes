# 131. 分割回文串

## 题目

给你一个字符串 s，请你将 s 分割成一些 子串，使每个子串都是 回文串 。返回 s 所有可能的分割方案。

 

示例 1：

输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
示例 2：

输入：s = "a"
输出：[["a"]]
 

## 思路（递归回溯法）

思路：主要也是子字符串分割回溯的问题

1. 递归输入：当前的起始startindex 递归输出：由于最后将可能的结果添加到result中，所以不需要返回值

2. 递归终止条件：由于是将字符串分割，如果startindex==n,那么表示上次递归已经将字符串分割并添加到了curpath中，所以，递归条件应该是==n，如果==n-1，那么会留最后一个字符没有处理

3. 每次递归操作：将后续的字符按照当前遍历索引分割，然后判断是否是回文（也可以分割之后到最后返回条件的时候进行判断），如果是，将分割字符串添加到curpath中，然后向下层递归(i+1),不能重复，每次递归结束，那么需要curpath.pop()，进行回溯。

```python
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        result = []

        curpath = []
        n = len(s)

        def splitto(startindex:int):
            nonlocal result
            nonlocal n
            nonlocal curpath
            if startindex == n:
                #如果能够遍历到starindex == n,由于上层递归已经判断了是否是回文，那么这时候就只需要将curpath添加到result中
                result.append(curpath.copy())
                return 
            for i in range(startindex,n):
                curstr = s[startindex:i+1]
                if self.check(curstr):  #只有在当前添加进curpath的字符串是回文才进行深层次递归，相当于剪枝
                    curpath.append(curstr)#将str中的子字符串依次添加进curpath中
                    splitto(i+1)   #向下递归后续的字符串
                    curpath.pop()   #回溯
                else:
                    continue    
        splitto(0)#从0开始分割，然后找回文子字符串

        return result

##这里的判断是否为回文使用双指针的方式，其实也可以直接str[::-1]=str?进行判断
    def check(slef,s:str)->bool:
        """判断是否是回文"""
        flag = True
        left = 0
        right = len(s)-1
        while left < right :
            if s[left] != s[right]:
                flag = False
            left += 1
            right -= 1

        return flag
```                 
