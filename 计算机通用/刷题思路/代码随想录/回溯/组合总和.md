# 39. 组合总和

## 题目

给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。 

对于给定的输入，保证和为 target 的不同组合数少于 150 个。
示例 1：

输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。
示例 2：

输入: candidates = [2,3,5], target = 8
输出: [[2,2,2,2],[2,3,3],[3,5]]

## 思路

首先想到多重for循环，枚举进行查找，但是由于能够组合为target的数量不确定，不能够确定的for循环层数，也就是可变的for循环次数，遇到这种题目，首先考虑回溯算法。
题目要求的是不能够重复，也就是每次向下递归的时候只能是i以及i后面索引的元素，而不是每次都从0开始遍历，否则会出现大量重复。

1. 递归输入：**当前递归的索引起始**，全局candidates，result，curpath，n（candidates的长度） 递归输出：由于如果在递归的过程中满足了条件，那么直接将结果数组添加到result中，所以无需返回值

2. 递归终止条件；当curpath的sum>=target的时候，那么就应该终止继续递归了，因为后续的candidate都是正数，并且如果不终止，curpath将持续递增，且没有其他条件判断终止，也起到一个剪枝的作用

3. 每次递归操作：对于当前的后选数字及其后续的candidates进行添加到curpath中，并向下深层递归，递归完成之后需要pop()以回溯以便后续的递归遍历

```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:

        n = len(candidates) #记录候选数字长度
        result = [] #结果记录数组   
        curpath = []    #全局总curpath，也就是当前递归路径

        def find(startindex:int):
            #加载上层递归变量
            nonlocal candidates
            nonlocal n
            nonlocal result 
            nonlocal curpath
            #获取当前curpath的和
            cursum = sum(curpath)
            if cursum >= target:#终止条件：如果cursum>=target,检查，是否相等？如果等，那么添加到result中，否，则后续的sum也不会=target了,终止条件如此，有点剪枝的味道
                if cursum == target:    #如果当前和==target，那么添加到result中，无论是curpath中有几个元素[7],[2,5]...
                    result.append(curpath.copy())   #注意：应该添加数组拷贝，而不是指针，否则最后都为[]空列表了
                return 
            
            for i in range(startindex,n):   #每层操作；对于当前数字及其后续的候选元素进行递归
                curpath.append(candidates[i])   #添加到curpath中,以便下层递归
                find(i) #从当前元素以及后续元素进行递归，如果是0，则会有大量重复数组,比如[2,2,3],[3,2,2]...所以应该传入i
                curpath.pop()   #回溯删除当前遍历的数字

        find(0) #调用函数，从索引0开始寻找
        return result   #返回结果
```
