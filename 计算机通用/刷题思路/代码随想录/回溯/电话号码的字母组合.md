# 17. 电话号码的字母组合

## 题目

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按 任意顺序 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

示例 1：

输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
示例 2：

输入：digits = "2"
输出：["a","b","c"]

## 思路

**组合问题，由于要组合和撤销组合问题，首先考虑回溯**

1. 递归输入：传入当前的的数字->str的映射，也就是当前要处理的字母str，这里通过传入digit进行从上层函数中获取，之前走过的路径，也就是curpath，用于组合具体的结果（可以使用str，但是回溯的时候需要切片，使用数组可以达到一样的效果。），同样通过从上层函数获取的方式
    递归输出：由于递归到底层，直接将对应的结果添加到result中，所以整体上不需要返回值

2. 递归终止条件：当递归深度达到最深，也就是k==0时，那么将当前结果添加到result中，并return

3. 每次递归的操作：将当前层也就是数字->str的映射使用for循环添加到curpath中，然后向下进行递归，每个字符向下递归结束后进行pop()回溯。


```python
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        hashmap = ["abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"]
        
        digits = int(digits[::-1])  #由于遍历逻辑是从后向前，但是由于数字的位置不同，最后的结果也不同，所以需要反转一下以符合题意，比如，如果传入“29”且不反转，那么返回的结果是按照9，2的顺序进行递归遍历，显然这是错误的。
        result = [] #结果记录数组
        curpath = []    #记录当前遍历的路径，后续通过join()添加到result中
        def backtracking(left:int): #递归输入：当前剩余的没有便利的数字（递归深度），以及数字对应的字母组合
            nonlocal hashmap    #获取外层的hash映射
            nonlocal result     #获取外层的result结果数组
            nonlocal curpath    #获取外层的当前路径
            if left == 0:
                result.append("".join(curpath)) #如果当前层是最后一层，那么将上层的curpath组合成str添加到结果result数组中去
                return
            curnum = left%10    #当前层的遍历的数组
            left = left // 10
            curstr = hashmap[curnum-2]  #获取到对应的映射str

            for char in curstr:
                curpath.append(char)    #将结果添加到curpath中
                backtracking(left)  #向下层继续寻找递归
                curpath.pop()   #撤销当前层当前递归的char的添加
        
        backtracking(digits)    #调用函数

        return result   #返回结果
```
