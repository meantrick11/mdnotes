# 组合总和Ⅲ

## 题目

找出所有相加之和为 n 的 k 个数的组合，且满足下列条件：

只使用数字1到9
每个数字 最多使用一次 
返回 所有可能的有效组合的列表 。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

 

示例 1:

输入: k = 3, n = 7
输出: [[1,2,4]]
解释:
1 + 2 + 4 = 7
没有其他符合的组合了。
示例 2:

输入: k = 3, n = 9
输出: [[1,2,6], [1,3,5], [2,3,4]]
解释:
1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
没有其他符合的组合了。
示例 3:

输入: k = 4, n = 1
输出: []
解释: 不存在有效的组合。
在[1,9]范围内使用4个不同的数字，我们可以得到的最小和是1+2+3+4 = 10，因为10 > 1，没有有效的组合。

## 思路（递归回溯法）

1. 递归输入：当前还需向下递归的深度，当前起始值的startindex，距离目标target还差多少(target为向下传递的差值) 递归输出：由于在递归结束的时候检查是否深度刚好==k，且target==0，那么将结果添加到result中，所以不需要每层递归返回值

2. 递归终止条件，当递归所需深度==0，也就是无需向下递归时，那么检查是否target==0,并停止递归

3. 每次递归操作：将当前层后续可能的值进行递归遍历，将当前层的值添加到curpath中，并且向下传递新的k-1,i+1,target-i等参数，如果当前层递归结束，那么需要回溯，将cuapath中的最近添加的结果pop()删除。

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> List[List[int]]:
        result = [] #记录数组

        curpath = []    #当前的数组组合

        def backtracing(k:int,startindex:int,target:int):
            nonlocal curpath
            nonlocal result

            if k == 0:  #终止条件，递归深度为k
                if target == 0: #如果target == 0，那么将当前结果添加到result中
                    result.append(curpath.copy())
                return



            for i in range(startindex,10):  #由于需要从1-9数字中选择可能的组合元素，那么循环条件应该是startindex-10
                # if target - i < 0:    #可选剪枝，如果当前target-i<0,那么后续比它大的元素相减也<0,无需再递归
                #     return 
                curpath.append(i)
                backtracing(k-1,i+1,target-i)   #进行深层递归，将当前层的target-i，也就是通过减去i，进行向下匹配。
                curpath.pop()   #同样进行回溯，删除当前遍历过的curpath中的数值，方便同层的下层递归
            
        backtracing(k,1,n)
    
        return result
                
```
