# 反转链表

>题目：给你单链表的头节点 head ，请你反转链表，并返回反转后的链表。

思路一：使用一个dummy节点作为结果链表的head节点，然后遍历当前链表，不断将当前节点拼接到dummy后继节点中。

```python

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        #使用一个dummy节点链接反转后的节点


        dummy = ListNode()
        cur = head

        while cur:
            last = cur.next #记录原来没有被遍历的节点

            temp = dummy.next   #记录结果链表的后继节点

            dummy.next = cur    #更新链表指向
            cur.next = temp
            
            cur= last

        return dummy.next

```


思路二：使用快慢指针的方式fast记录下一个节点，slow记录已经更新的节点，循环条件是while fast :，那么退出的时候，fast指向None，slow指向尾节点，且slow和fast直接没有next相连：
```python

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        #使用快慢指针的方式
        slow = None
        fast = head

        while fast :#循环条件是fast != None,所以退出循环的时候，slow指向尾节点，fast指向None
            temp = fast.next
            fast.next = slow


            slow = fast 
            fast = temp

        return slow

```
