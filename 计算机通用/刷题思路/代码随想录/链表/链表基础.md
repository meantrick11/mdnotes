# 链表

## 定义

**链表**是一种通过指串联在一起的线性结构，每一个节点由两部分组成一个是数据域一个是指针域，最后一个指针域指向None(空指针)。
链表的入口节点称为链表的头头节点，也就是head。

## 链表的类型

### 单链表

如链表的定义

```python
class ListNode:
    def __init__(self,val=0,next=None):
        self.val = val
        self.next = next

```

### 双链表

单链表的指针域只能指向节点的下一个节点。
**双链表**：每一个节点由两个指针域，一个指向上一个节点，一个指向下一个节点，所以双链表可以做到双向查询。

```python
class DoublyListNode:
    def __init__(self,val=0,pre=None,next=None):
        self.val = val
        self.pre = pre
        self.next = next
```

### 循环链表

循环链表表示首尾相连的链表，任何节点都可以作为head节点，且可以遍历任何节点。

## 链表的存储方式

由于数组是连续的，所以需要分配连续的地址空间，但是链表没有此限制，其内存分布可以不连续，因为通过指针相连，所以链表的节点在内存中的分布不是连续的，而是散乱分布在内存的某地址上，分配机制取决于操作系统的内存管理。


## 链表的操作

### 删除操作

需要定位到所要删除的节点的前一个节点，然后将前一个节点的next指针，指向所删除节点的next节点。

如果所用编程语言没有自动回收内存的机制，那么需要手动release，比如C或者CPP，但是Java、Python这类语言是由自动内存回收机制，所以就不用手动释放。

### 添加节点

1. 如果添加头节点，那么需要将新的节点的next指针指向原来的head节点

2. 如果要添加中间节点，那么需要先保存原来节点的next节点，并将前一个节点的指针指向新节点，新节点的next指针指向原来保存的next节点

3. 如果在尾部添加节点，如中间节点类似，不过不需要第三步

## 性能分析

|      | 插入/删除（时间复杂度） | 查询（时间复杂度） | 适用场景                         |
| ---- | ------------------------ | ------------------ | -------------------------------- |
| 数组 | O(n)                     | O(1)               | 数据量固定，频繁查询，较少增删    |
| 链表 | O(1)                     | O(n)               | 数据量不固定，频繁增删，较少查询  |

数组在定义的时候，长度就是固定的，如果想改动数组的长度，就需要重新定义一个新的数组。

链表的长度可以是不固定的，并且可以动态增删，适合数据量不固定，频繁增删，较少查询的场景。
