# 两两交换链表中的节点

>给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

思路：由于要两两交换节点，那么头节点肯定会动，此时引入dummy节点，避免单独处理头节点的情况。那么循环条件是后续有两个节点才能交换(while cur.next and cur.next.next),每次循环记录交换节点node1&node2,以及后继节点，然后更新指针指向，移动两次cur节点(cur=node1)，以便下一次循环，最后return dummy.next



```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        #由于需要交换head节点，所以需要dummy节点辅助
        dummy = ListNode(0,head)

        cur = dummy
        
        if not dummy.next:
            return 


        while cur.next and cur.next.next:#循环条件是至少由两个节点，那么如何有两个节点呢？就是cur.next and cur.next.next,如果只写cur.next.next,那么只有一个节点没有遍历的情况下，那么会报错
            node1 = cur.next  #当前轮的第一个节点
            node2 = node1.next  #当前轮的第二个节点
            after = node2.next #后继节点

            #更新指针指向
            cur.next = node2
            node2.next = node1
            node1.next = after

            cur = node1#此时node1=cur.next.next

        return dummy.next
```
