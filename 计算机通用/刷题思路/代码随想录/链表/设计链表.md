## 707. 设计链表

>你可以选择使用单链表或者双链表，设计并实现自己的链表。

>单链表中的节点应该具备两个属性：val 和 next 。val 是当前节点的值，next 是指向下一个节点的指针/引用。

>如果是双向链表，则还需要属性 prev 以指示链表中的上一个节点。假设链表中的所有节点下标从 0 开始。

>实现 MyLinkedList 类：

>MyLinkedList() 初始化 MyLinkedList 对象。
>int get(int index) 获取链表中下标为 index 的节点的值。如果下标无效，则返回 -1 。
>void addAtHead(int val) 将一个值为 val 的节点插入到链表中第一个元素之前。在插入完成后，新节点会成为链表的第一个节点。
>void addAtTail(int val) 将一个值为 val 的节点追加到链表中作为链表的最后一个元素。
>void addAtIndex(int index, int val) 将一个值为 val 的节点插入到链表中下标为 index 的节点之前。如果 index 等于链表的长度，那么该节点会被追加到链表的末尾。如果 index 比长度更大，该节点将 不会插入 到链表中。
>void deleteAtIndex(int index) 如果下标有效，则删除链表中下标为 index 的节点。


```python
class ListNode:
    def __init__(self,val=0,next=None):
        self.val = val
        self.next = next

class MyLinkedList:

    def __init__(self):
        self.dummy_node = ListNode()
        self.size = 0#链表应该是0->size-1

#阐明一下index和size的关系index属于[0->size-1]
        
        
        

    def get(self, index: int) -> int:
        '''获取链表的索引'''
        if index < 0 or index > self.size-1:
            return -1

        cur = self.dummy_node
        while index >= 0:#循环次数如何确定？当前是dummy_node,如果index=3,那么应该是(0,1,2,3),所以应该是循环四次
            cur= cur.next 
            index -= 1

        return cur.val
            

        

    def addAtHead(self, val: int) -> None:
        
        oldhead = self.dummy_node.next
        newhead = ListNode(val,oldhead)

        self.dummy_node.next = newhead  #跟新新节点作为dummy_node的后继节点
        self.size += 1
        
        

    def addAtTail(self, val: int) -> None:
        newtail = ListNode(val)#创造新的尾部节点

        cur = self.dummy_node

        for i in range(self.size):#移动到old尾部节点
            cur = cur.next
        cur.next = newtail#更新指针，尾部节点串联
        self.size += 1


    def addAtIndex(self, index: int, val: int) -> None:
        
        #找到所要更换的节点的前一个节点，比如index=3(0,1,2,3),那么应该定位到index=2的节点，那么需要循环n次
        if index > self.size:#如果index比链表长度更大，那么节点不会被插入到链表中
            return 
        if index == 0:
            self.addAtHead(val)
        elif index == self.size:
            self.addAtTail(val)
        else:
            cur = self.dummy_node
            for i in range(index):
                cur = cur.next
            temp = cur.next #记录原来的index的位置的后继链表
            newnode = ListNode(val,temp)#创造新节点，并添加到链表中
            cur.next = newnode
            self.size += 1

        

    def deleteAtIndex(self, index: int) -> None:
        if index < 0 or index >= self.size:
            return
        cur = self.dummy_node

        for i in range(index):
            cur = cur.next
        cur.next = cur.next.next

        self.size -= 1

```

值得注意的是，添加时候self.size 需要+=1，而删除的时候self.size需要-=1。
