# 160. 链表相交

面试题 02.07. 链表相交

>给你两个单链表的头节点 headA 和 headB ，请你找出并返回两个单链表相交的起始节点。如果两个链表没有交点，返回 null 。

思路：由于没有子链表的情况，并且如果相交，那么后续节点一定是同一段链表，持续到末尾，考虑到相交节点可能是初始节点的情况，所以，需要分别引入dummy节点，然后分别记录链表A(lengthA)&链表B的长度(lengthB),然后让根据谁更长移动先走，使得两个链表起始位置到最后节点的长度相等(因为如果相交的话，一定是在长度较小的那个节点上)，然后循环对比startA.next ?== startB.next,如果相等，那么返回相交的节点(即startA/startB.next)，否则，遍历结束，然后返回None

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        #如果链表相交，那么后继节点一定持续到末尾，然后相交
        dummyA = ListNode(0)
        dummyA.next = headA
        dummyB = ListNode(0)
        dummyB.next = headB
        lengthA = 0
        lengthB = 0

        curA = dummyA
        curB = dummyB

        while curA:
            lengthA += 1
            curA = curA.next
            
        while curB:
            lengthB += 1
            curB = curB.next

        if lengthA > lengthB:
            startA = dummyA
            for i in range(lengthA-lengthB):
                startA = startA.next
            startB = dummyB
        else:
            startB = dummyB
            for i in range(lengthB-lengthA):
                startB = startB.next
            startA = dummyA

        while startA :
            if startA.next == startB.next :
                return startA.next
            else:# !=
                startA = startA.next
                startB = startB.next
        return None
```
