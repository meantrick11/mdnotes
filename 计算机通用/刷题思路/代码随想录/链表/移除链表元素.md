# 移除链表元素

## 203. 移除链表元素

>题目：给你一个链表的头节点 head 和一个整数 val ，请你删除链表中所有满足 Node.val == val 的节点，并返回 新的头节点 。

思路：由于是移除元素，那么有可能移除的是头节点，那么此时边界处理会很麻烦，所以选择添加一个dummy节点，每次定位到前一个节点，然后更新指针指向，实现移除元素的目的。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
class Solution:
    def removeElements(self, head: Optional[ListNode], val: int) -> Optional[ListNode]:
        dummy = ListNode()

        dummy.next = head


        cur = dummy#cur为targetNode的前一个节点

        while cur.next :#循环条件应该是cur.next不为None
            if cur.next.val == val:#如果cur.next=val,那么更新节点的next指向下下一个节点
                cur.next = cur.next.next

            else:# 如果不是的话，更新节点为下一个节点
                cur = cur.next

        return dummy.next
```
