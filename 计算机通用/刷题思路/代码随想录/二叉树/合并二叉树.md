# 合并二叉树

## 题目

给你两棵二叉树： root1 和 root2 。

想象一下，当你将其中一棵覆盖到另一棵之上时，两棵树上的一些节点将会重叠（而另一些不会）。你需要将这两棵树合并成一棵新二叉树。合并的规则是：如果两个节点重叠，那么将这两个节点的值相加作为合并后节点的新值；否则，不为 null 的节点将直接作为新二叉树的节点。

返回合并后的二叉树。

注意: 合并过程必须从两个树的根节点开始。


## 思路

### 前序遍历

区分前序后序遍历的条件是对于节点的处理是在左右之后还是在左右之前，这里介绍前序遍历的方式

1. 递归输入：左树当前节点 递归输出：当前构造的节点(TreeNode)

2. 递归终止条件：
    1. 如果左树当前节点是None且右树当前节点也是None，那么return None
    2. 如果左树当前节点是None，但右树当前节点不为空，那么说明只需要将右树以及其下层节点全部添加到新树，也就是return rightnode即可
    3. 如果左树当前节点不为空，但右树当前节点是None，那么说明只需要将左树以及其下层节点全部添加到新树，也就是return leftnode即可

3. 每次递归操作，创建当前节点，然后左右递归子树获取其左右left&right树，然后return


这里的python实现是遍历到当前节点，直接计算root1.val+root2.val，创造节点，然后再递归其左右子树，虽然return 在递归函数最后，但是对于节点的操作是刚进入就创造节点的，所以是前序遍历

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        #递归终止条件“
        if not root1 and not root2: #左右树都不存在，return None
            return None
        if not root1 and root2: #递归最后的情况，情况一，左树不存在，右树存在
            return root2
        if root1 and not root2: #情况二：左树存在，右树不存在
            return root1

        curnode = TreeNode()
        curnode.val = root1.val + root2.val#将左右节点的值相加
        curnode.left = self.mergeTrees(root1.left,root2.left)
        curnode.right = self.mergeTrees(root1.right,root2.right)

        return curnode
        
```

上述代码的情况判断有些冗余，比如如果not root1,直接return root2，无需判断是否为None，root2为None同理。即退出条件可以变为：
```python
if not root1 :
    return root2
if not root2:
    return root1
```

### 后续遍历

和前序遍历的思路一样，但是对于节点的创建是在其左右递归遍历之后：

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        #递归终止条件“
        if not root1 and not root2: #左右树都不存在，return None
            return None
        if not root1 and root2: #递归最后的情况，情况一，左树不存在，右树存在
            return root2
        if root1 and not root2: #情况二：左树存在，右树不存在
            return root1


        left = self.mergeTrees(root1.left,root2.left)
        right = self.mergeTrees(root1.right,root2.right)

        curnode = TreeNode()
        curnode.val = root1.val + root2.val#将左右节点的值相加
        curnode.left = left
        curnode.right = right
        
        return curnode
        
```
