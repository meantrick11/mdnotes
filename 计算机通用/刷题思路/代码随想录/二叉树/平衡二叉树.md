# 110. 平衡二叉树

## 题目

给定一个二叉树，判断它是否是 平衡二叉树  

## 思路(后续递归法)

1. 递归输入：当前节点，递归输出：左右子树的高度差是否小于1

2. 递归终止条件：当节点为空

3. 每次递归操作：获取左右子树的高度，判断左右子树的高度是否超过1？如果返回结果是-1表示某侧子树已经不是平衡二叉树，那么不断向上传递-1，最后进行对整个遍历结果进行判断。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:

        def height(root:TreeNode)->int:
            if not root :
                return 0

            leftheight = height(root.left)
            rightheight = height(root.right)

            if leftheight == -1:
                return -1
            if rightheight == -1:
                return -1
            if abs(leftheight-rightheight) > 1:
                return -1
            else:
                return 1+max(leftheight,rightheight)
        
        result = height(root)
        if result == -1:
            return False
        else:
            return True
            
```
