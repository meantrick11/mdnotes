# 111. 二叉树的最小深度

## 题目

给定一个二叉树，找出其最小深度。

最小深度是从根节点到最近叶子节点的最短路径上的节点数量。

说明：叶子节点是指没有子节点的节点

## 思路一（队列迭代法）


仿照二叉树的层序遍历，初始化队列q，然后将root添加进队列q中，循环条件是while
q不为空，然后获取当前层的size，然后for循环size次数，对于每个节点curnode，然后将curnode.left,curnode.right添加进队列中，退出条件是如果遇到第一个叶子节点if not curnode.left and if not curnode.right.返回maxdepth+1。在每次遍历每一层的时候maxdepth+=1。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root :
            return 0
        
        maxdepth = 0    

        q = deque()
        q.append(root)

        while q :
            size = len(q)

            for _ in range(size):
                curnode = q.popleft()
                
                if not curnode.left and not curnode.right:
                    return maxdepth+1
                if curnode.left :
                    q.append(curnode.left)
                
                if curnode.right :
                    q.append(curnode.right)
                
            maxdepth += 1
```

## 思路二（递归法）

1. 递归输入：当前遍历的节点，递归输出：左右子树的最小深度+1

2. 递归终止条件：当节点的节点为None时，return 0 #必须要是叶子节点

3. 每次递归的操作：
    - 如果只有左子树，那么返回左子树的最小深度+1
    - 如果只有右子树，那么返回右子树最小深度+1
    - 如果左右子树都存在，返回将左右子树的最小深度+1
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right



class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        ##只有左子树
        if not root.left:
            return self.minDepth(root.right)+1
        ##只有右子树
        if not root.right:
            return self.minDepth(root.left)+1
        ## 左右子树都存在
        else:
            minleft = self.minDepth(root.left) 
            minright = self.minDepth(root.right)

            return min(minleft,minright) + 1
```
