# 235. 二叉搜索树的最近公共祖先

## 题目

给定一个二叉搜索树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：“对于有根树 T 的两个结点 p、q，最近公共祖先表示为一个结点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

例如，给定如下二叉搜索树:  root = [6,2,8,0,4,7,9,null,null,3,5]

## 思路

思路同二叉树的最近公共祖先一样，使用递归方式

1. 递归输入：每次递归的节点，目标节点p&q， 递归输入：遍历到的目标节点

2. 递归终止条件：如果遍历到空结点None，或者目标节点p或q，那就返回空结点或者目标节点

3. 每次递归的操作：将左右子树的递归结果？是否找到p，q？或者已经是公共祖先了？如果在左右各自找到一个节点，那么当前的节点就是公共祖先，将当前节点向上传递，如果只存在一个节点，那么向上传递对应节点。


```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root or root == p or root == q:
            return root
        findinleft = self.lowestCommonAncestor(root.left,p,q)
        findinright = self.lowestCommonAncestor(root.right,p,q)
        if findinleft and findinright:  #find q & p
            return root
        elif findinleft and not findinright:    #find one of the node ?or the father
            return findinleft
        elif not findinleft and findinright:    #same as the prior
            return findinright
        else:   #not find any ,None and None
            return None


```
