# 701.二叉搜索树中的插入操作

## 题目

给定二叉搜索树（BST）的根节点 root 和要插入树中的值 value ，将值插入二叉搜索树。 返回插入后二叉搜索树的根节点。 输入数据 保证 ，新值和原始二叉搜索树中的任意节点值都不同。

注意，可能存在多种有效的插入方式，只要树在插入后仍保持为二叉搜索树即可。 你可以返回 任意有效的结果 。

输入：root = [4,2,7,1,3], val = 5
输出：[4,2,7,1,3,5]

## 思路

最好的方式是直接找到对应的插入节点位置，然后进行插入逻辑，而不是改变二叉搜索树的原有节点的位置，此方法是**路径递归，而不是全树遍历**

1. 递归输入：当前要判断（是否是插入的位置）的节点 递归输出：不需要输出，只需要在具体的插入位置完成插入逻辑之后，return根节点

2. 递归终止条件：如果找到对应的插入位置(root==None)，此时需要引入一个条件Node去记录其父节点，然后执行插入操作，所以在class的方法中定义了一个三值输入的内置函数。
3. 每次递归操作：由于是路径递归，所以，只需要在进行下一次递归之前对于当前值进行判断，然后选择下一次递归的路径（左/右子树）

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def insertIntoBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:

        ## 如果不变动节点顺序的情况下，只需要找到对应的空结点即可
        if not root:    #空树则直接构造return
            return TreeNode(val)

        def insertnode(root:TreeNode,val:int,father:TreeNode=None):
            if root == None:    #如果说当前节点为空，那么说明当前就是对应的插入位置
                #节点构造+插入逻辑：
                if val > father.val:
                    father.right = TreeNode(val=val)
                else:#val<father.val
                    father.left = TreeNode(val=val)
                return  #成功插入之后退出return
            
            if val > root.val:
                insertnode(root.right,val,root) #在右子树寻找插入节点
            else:
                insertnode(root.left,val,root)  #在左子树寻找插入节点
            

        insertnode(root=root,val=val) #调用函数

        return root
                
        
```
