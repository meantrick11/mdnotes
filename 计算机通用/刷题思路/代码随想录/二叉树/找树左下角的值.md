# 513. 找树左下角的值

## 题目

给定一个二叉树的 根节点 root，请找出该二叉树的 最底层 最左边 节点的值。

假设二叉树中至少有一个节点。

## 思路(层序遍历法)

由于需要找出左下角的，递归思路需要遍历所有节点，而层序遍历的迭代算法，可以使用list记录最后一层的所有数值，所以使用层序遍历最好解决此法。初始化队列q以及result=[]，然后将root添加进队列，由于题目保证至少有一个节点，所以不需要判断if not root,循环条件是队列存在节点，，然后初始化当前层的result=[]，记录当前曾的size，对size进行for循环(遍历当前层中的节点)，然后取出队头节点popleft(),将curnode.val添加进result中，然后判断有没有左节点，右节点，依次添加进q中，方便下一层的遍历，循环结束result中记录的是最后一层的节点的值，然后return result[0]就可以了。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        
        q = deque()

        q.append(root)

        while q:
            size = len(q)
            result = []   #重置全局记录
            for _ in range(size):
                curnode = q.popleft()
                result.append(curnode.val)
                if curnode.left :
                    q.append(curnode.left)
                if curnode.right:
                    q.append(curnode.right)
            
        return result[0]

```
