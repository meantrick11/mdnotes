# 112. 路径总和

## 题目

给你二叉树的根节点 root 和一个表示目标和的整数 targetSum 。判断该树中是否存在 根节点到叶子节点 的路径，这条路径上所有节点值相加等于目标和 targetSum 。如果存在，返回 true ；否则，返回 false 。

叶子节点 是指没有子节点的节点。

## 思路一（后序递归法）

1. 递归输入：当前节点，到当前节点的总和，targetSum， 递归输出：是否满足路径之和为targetSum的布尔值
2. 递归终止条件：当节点为空，return False
3. 每次递归操作：检查是否是叶子节点？如果是检查cursum==targetSum？，如果不是非叶子节点则传递左右子树的布尔值

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        
        def find(root:TreeNode,cursum:int,targetSum:int)->True:
            ##递归退出条件：遍历到空节点
            if not root:    
                return False
            #将当前cursum += root.val,以便下一层递归
            cursum += root.val  
            leftcheck = find(root.left,cursum,targetSum)  #左递归
            rightcheck = find(root.right,cursum,targetSum)  #右递归

            ## 每次递归操作：1.是否是叶子节点，且满足当前路径为targetSum,

            if not root.left and not root.right and cursum == targetSum:   
                return True
            ##2.非叶子节点则向上传递左右子树的判断
            return leftcheck or rightcheck
        
        return find(root,0,targetSum)   #调用函数

```     

## 思路二

答题思路同上，不过通过传递targetSum - root.val进行判断

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        
        def find(root:TreeNode,cursum:int,targetSum:int)->True:
            if not root:
                return False

            cursum += root.val  
            leftcheck = find(root.left,cursum,targetSum)  #
            rightcheck = find(root.right,cursum,targetSum)
            if not root.left and not root.right and cursum == targetSum:
                return True

            return leftcheck or rightcheck
        
        return find(root,0,targetSum)
```
