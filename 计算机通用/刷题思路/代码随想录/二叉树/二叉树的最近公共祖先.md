# 236. 二叉树的最近公共祖先

## 题目

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。

## 思路（递归法）

1. 递归输入：当前节点，目标节点p&q，递归输出：是否右节点符合当前节点==p,q,None or已经是公共节点？
2. 递归终止条件：当节点为空，也就是该树没有找到匹配的节点，return None，如果找到某个节点p or q？return 对应找到的节点
3. 每次递归操作：判断当前节点是否有左子树和右子树的返回值，如果左右子树都有返回值，（由于二叉树没有重复节点，），那么该节点就是最近的公共祖先，其后的递归回溯则是依次向上传递结果

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        #终止条件：当递归到空节点|或者碰到某一个节点的时候
        if not root:
            return None
        if root == p:
            return root
        if root == q:
            return root 
        
        #先左后右进行递归
        left = self.lowestCommonAncestor(root.left,p,q)
        right = self.lowestCommonAncestor(root.right,p,q)

        #对于左右子树返回的值进行比较
        if not left and not right:#左右子树都没找到节点
            return None
        elif not left and right:    #在左子树或者右子树找到其中一个节点，那么就将找到的对应节点返回，p or q
            return right    

        elif left and not right:    
            return left
        else:
            return root ##如果在左右子树各找到一个节点，那么当前节点就是公共节点
```
