# 538.把二叉搜索树转换为累加树

## 题目

给出二叉 搜索 树的根节点 root，该树的节点值各不相同，请你将其转换为累加树（Greater Sum Tree），将其转换为一个更大的树，使得原始二叉搜索树中的每个节点值都变为原本值加上原本二叉搜索树中所有比该节点值大的节点值的总和。

提醒一下，二叉搜索树满足下列约束条件：

节点的左子树仅包含键 小于 节点键的节点。
节点的右子树仅包含键 大于 节点键的节点。
左右子树也必须是二叉搜索树。
注意：本题和 1038: https://leetcode.cn/problems/binary-search-tree-to-greater-sum-tree/ 相同

## 思路（逆序中序遍历）

1. 本题想到首先中序遍历，然后通过数组求累加，然后重新根据构造二叉搜索树进行构造，这样子的时间复杂度和空间复杂度太高了

2. 然后想到逆序中序遍历，
    1. 首先声明一个局部变量s用于统计二叉搜索树比当前大于等于的总和，递归输入：当前遍历的节点 递归输出：没有输出，在递归的时候就已经更改了二叉树的值了
    2. 递归终止条件：当遇到空结点的时候，return 
    3. 每次递归操作，将当前节点的值相加到s中，然后更新当前节点的值
    ```python
    # Definition for a binary tree node.
    # class TreeNode:
    #     def __init__(self, val=0, left=None, right=None):
    #         self.val = val
    #         self.left = left
    #         self.right = right
    class Solution:
        def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
            s = 0
            def dfs(root:TreeNode)->int:
                if not root:
                    return 
                
                right_sum = dfs(root.right)
                nonlocal s
                s += root.val   #将节点的值添加到s中
                root.val = s
                left_sum =  dfs(root.left)
            
            dfs(root)
            return root
    ```
3. 和逆序中序遍历差不多，但是每次递归函数有返回值，为比当前节点小于等于的值的总和，也就是进行累加值的传递，遍历右子树之后将结果和与root节点相加，然后将结果和作为遍历左子树的cursum，其实就是思路二的一个变种，只不过值传递通过递归方式，而不是直接从上层嵌套函数获取，最终目的是一样的。

```python
class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        def dfs(node: TreeNode, cur_sum: int) -> int:
            if not node:
                return cur_sum  # 空节点不改变累加值，原封不动返回
            
            # 1. 先去右子树，把当前的累加值传进去
            #    返回的是：处理完右子树所有节点后的最新累加值
            cur_sum = dfs(node.right, cur_sum)
            
            # 2. 处理当前节点（累加值已经包含了所有比它大的数）
            cur_sum += node.val
            node.val = cur_sum
            
            # 3. 去左子树！此时 cur_sum 已经加上了“右子树 + 根节点”的值
            #    这正是你想要的：把 cursum 传入左子树
            cur_sum = dfs(node.left, cur_sum)
            
            # 4. 返回处理完这整棵树（左+根+右）后的最新累加值，给上层调用者
            return cur_sum
        
        dfs(root, 0)
        return root
```
