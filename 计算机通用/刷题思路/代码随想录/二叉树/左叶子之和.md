# 左叶子之和

## 题目

给定二叉树的根节点 root ，返回所有左叶子之和。

## 思路(递归法)

**使用后序遍历，因为需要将左右子树的左叶子节点的之和相加，应该放在递归遍历左右子树之后**

1. 递归输入：当前节点，递归输出：当前节点以下的左右子树的左节点数值之和

2. 终止条件：将所有节点递归完，也就是节点不为空（可以稍微剪枝，比如到叶子节点就可以退出了）

3. 每次递归操作：判断当前节点的左节点是不是左叶子节点？将左右子树的左叶子节点之和相加return


```python
class Solution:
    def sumOfLeftLeaves(self, root):
        if root is None:
            return 0
        # if root.left is None and root.right is None:
        #     return 0
        
        leftValue = self.sumOfLeftLeaves(root.left)  # 左子树
        rightValue = self.sumOfLeftLeaves(root.right)  # 右

        ##每次递归操作，检查当前节点的左节点是否为左叶子+将左右子树的左叶子节点之后相加return
        if root.left and not root.left.left and not root.left.right:  # 左子树是左叶子的情况
            leftValue = root.left.val

        sum_val = leftValue + rightValue  # 中
        return sum_val
```
