# 二叉树的所有路径

## 题目

给你一个二叉树的根节点 root ，按 任意顺序 ，返回所有从根节点到叶子节点的路径。

叶子节点 是指没有子节点的节点。

## 思路(递归法)

1. 递归输入：节点不为空， 递归输出：到叶子节点之后将结果添加到result中

2. 递归条件：节点不是叶子节点

3. 每次递归处理，将当前节点添加到curpath中，然后判断如果存在左子树，则继续递归左子树，如果存在右子树，则继续递归右子树

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def binaryTreePaths(self, root: Optional[TreeNode]) -> List[str]:
        if not root:
            return []
            
        result = []
        
        def findpath(root:TreeNode,curpath:str)->None:#递归输入，当前节点+曾经的path
            ##终止条件，遍历到了叶子节点,左右子树都没有
            if root.left==None and root.right==None:
                result.append(curpath[2:])
                return 
            ##每次递归操作
            curpath += f"->{root.val}"
            elif root.left:#没有右节点,则只遍历左子树
                findpath(root.left,curpath)
            elif root.rihgt: #没有左节点，则只遍历右子树
                findpath(root.right,curpath)
            
        #调用递归函数
        findpath(root,curpath="")

        return result
```
