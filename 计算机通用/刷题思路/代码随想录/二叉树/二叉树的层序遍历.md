# 二叉树的层序遍历

## 思路

层序遍历一个二叉树。就是从左到右一层一层的去遍历二叉树。这种遍历的方式和我们之前讲过的都不太一样。

需要借用一个辅助数据结构即队列来实现，队列先进先出，符合一层一层遍历的逻辑，而用栈先进后出适合模拟深度优先遍历也就是递归的逻辑。

而这种层序遍历方式就是图论中的广度优先遍历，只不过我们应用在二叉树上。


## 题目

### 102. 二叉树的层序遍历

#### 题目
给你二叉树的根节点 root ，返回其节点值的 层序遍历 。 （即逐层地，从左到右访问所有节点）。


#### 思路

直接使用deque的队列的写法实现层序遍历。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        q = deque()
        q.append(root)

        res = []

        while q:
            size = len(q)   #当前层的节点个数
            cur = []    #记录每一层的list
            for _ in range(size):
                node = q.popleft()  #出队
                cur.append(node.val)

                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            
            res.append(cur)
                
        return res
```    
            
### 119. 二叉树的右视图

#### 题目
给定一个二叉树的 根节点 root，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

 

示例 1：

输入：root = [1,2,3,null,5,null,4]

输出：[1,3,4]


#### 思路

本题直接复用二叉树的层序遍历，只是在每层操作不一样，只记录每一层的最右侧的数字即可，循环条件时队列不为空，每次循环将每一层的最右侧节点值放入结果当中。然后同时将下一层节点放入队列当中。


```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        result = []    #记录结果
        q = deque()
        q.append(root)

        while q:
            size = len(q)   #记录每一层长度

            for i in range(size):
                node = q.popleft()  #取出对头，并将子节点放入队列中
                if i == size - 1:
                    result.append(node.val)
                if node.left:   #保证添加进队列的不是空节点
                    q.append(node.left)
                if node.right:
                    q.append(node.right)

        return result

```

### 107. 二叉树的层序遍历

#### 题目

给你二叉树的根节点 root ，返回其节点值 自底向上的层序遍历 。 （即按从叶子节点所在层到根节点所在的层，逐层从左向右遍历）

#### 思路

由于每一层还是从左到右没有改变，那么只需要正常的层序遍历之后，将最终结果list翻转一下即可


```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
class Solution:
    def levelOrderBottom(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        result = []

        q = deque() #初始化队列

        q. append(root)

        while q :
            size = len(q)    #获取当前层的元素的大小
            
            cur = []    #当前层的记录数组

            for _ in range(size):   #开始遍历当前层
                node = q.popleft()  #获取队头
                cur.append(node.val)    #将队头的值放到当前层记录数组里

                if node.left:   #如果有左节点，那么添加进队列中
                    q.append(node.left)
                if node.right:  #如果有右节点，添加进队列中
                    q.append(node.right)

            result.append(cur)

        result.reverse()    #翻转正常的层序遍历，以满足题意

        return result
        
```

### 637. 二叉树的层平均值

#### 题目

给定一个非空二叉树的根节点 root , 以数组的形式返回每一层节点的平均值。与实际答案相差 10-5 以内的答案可以被接受。

#### 思路

直接二叉树的层序遍历，只是每层记录总和，然后将总和/size，添加到result中


```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
class Solution:
    def averageOfLevels(self, root: Optional[TreeNode]) -> List[float]:
        if not root:
            return []

        result = []
        q = deque()
        q.append(root)

        while q :
            cursum = 0
            size = len(q)
            for _ in range(size):
                node = q.popleft()
                cursum += node.val

                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            result.append(cursum/size)

        return result
```            

### 429. N 叉树的层序遍历

#### 题目
给定一个 N 叉树，返回其节点值的层序遍历。（即从左到右，逐层遍历）。

树的序列化输入是用层序遍历，每组子节点都由 null 值分隔（参见示例）。

#### 思路

仿照二叉树的层序遍历，先创建一个队列q，一个结果数组result，然后将root添加进q，循环条件是q不为空，然后定义每一层有一个记录数组cur然后记录每一层的size(节点数量)，依次遍历节点q.popleft()，将节点的值添加进cur中，如果节点有children，那么使用一个for循环遍历children节点，并添加到队列中,每一层遍历完后将cur添加到result数组，最后返回result数组即可

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: Optional[int] = None, children: Optional[List['Node']] = None):
        self.val = val
        self.children = children
"""
from collections import deque
class Solution:
    def levelOrder(self, root: 'Node') -> List[List[int]]:
        if not root :
            return []

        result = []

        q = deque()
        q.append(root)

        while q :
            cur = []    #当前层的记录数组

            size = len(q)   #记录当前层的节点个数

            for _ in range(size):   #循环size次将当前层的节点的值依次添加进cur数组中
                node = q.popleft()
                cur.append(node.val)

                curnode_children = node.children    #记录当前遍历的节点的children

                if curnode_children:    #如果有children=List[node]，那么依次将node添加进队列中
                    for i in range(len(curnode_children)):
                        q.append(curnode_children[i])

            result.append(cur)  #将每层的结果添加进result中

        return result
```

### 515. 在每个树行中找最大值

给定一棵二叉树的根节点 root ，请找出该二叉树中每一层的最大值。

#### 思路

显而易见，是二叉树的层序遍历，不过每次循环要记录的值应该是每一层的最大值，那么就声明一个maxnum去对比记录每一层的最大值：首先声明一个result记录最后结果，然后声明一个队列q，将root添加进q中，循环条件是队列q不为空，然后记录每一层的节点个数size，并声明一个当前层的“最大数”，因为节点可能为负数，所以这个“最大数”尽可能地小(**由于python中int是通过数组对象存储的每一个对象依次占用(2^0,2^30,2^60...)，如果需要表示很大的数字，那么依次增大数组长度，可以说说，底层通过C语言实现的数组存储定义的对象，不断增大数组长度，可以表示无限大的数字)**，遍历每一个节点q.popleft()，

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque

class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        q = deque()
        q.append(root)

        result = []

        while q:
            size = len(q)
            maxnum = -9e18

            for _ in range(size):
                curnode = q.popleft()
                maxnum = curnode.val if curnode.val > maxnum else maxnum
            
                if curnode.left:
                    q.append(curnode.left)
                if curnode.right:
                    q.append(curnode.right)
            
            result.append(maxnum)
        
        return result
```


### 116. 填充每一个节点的下一个右侧节点

#### 题目

给定一个 完美二叉树 ，其所有叶子节点都在同一层，每个父节点都有两个子节点。二叉树定义如下：

struct Node {
  int val;
  Node *left;
  Node *right;
  Node *next;
}
填充它的每个 next 指针，让这个指针指向其下一个右侧节点。如果找不到下一个右侧节点，则将 next 指针设置为 NULL。

初始状态下，所有 next 指针都被设置为 NULL。

#### 思路

同样是二叉树的层序遍历，首先初始化队列q，然后将root添加进q中，循环条件是q不为空，记录q的当前层的大小size，然后对于size进行for循环，记录curnode=q.popleft()，如果i==size-1,当前层的最右侧节点，那么curnode.next = None，其他则的情况则是curnode.next = q[0],(为什么是q[0]呢，因为上面的q经过popleft()长度缩小了，而不能是curnode.next = q[i+1],否则容易out of index错误)，依次遍历然后返回root即可

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: int = 0, left: 'Node' = None, right: 'Node' = None, next: 'Node' = None):
        self.val = val
        self.left = left
        self.right = right
        self.next = next
"""
from collections import deque
class Solution:
    def connect(self, root: 'Optional[Node]') -> 'Optional[Node]':
        if not root :
            return None

        q = deque()
        q.append(root)

        while q:
            size = len(q)

            for i in range(size):
                curnode = q.popleft()

                if i == size - 1:
                    curnode.next = None
                else:
                    curnode.next = q[0]
                if curnode.left:
                    q.append(curnode.left)
                if curnode.right:
                    q.append(curnode.right)


        return root
```


### 117. 填充每一个节点的下一个节点Ⅱ

#### 题目

给定一个二叉树：

struct Node {
  int val;
  Node *left;
  Node *right;
  Node *next;
}
填充它的每个 next 指针，让这个指针指向其下一个右侧节点。如果找不到下一个右侧节点，则将 next 指针设置为 NULL 。

初始状态下，所有 next 指针都被设置为 NULL 。

#### 思路

和116题的思路和代码几乎没有变化，但是以下给出我之前写的比较不是很规范的解答代码,大致思路虽然一样，但是取节点的方式略有不同。如果用116题的代码，同样能够通过。

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val: int = 0, left: 'Node' = None, right: 'Node' = None, next: 'Node' = None):
        self.val = val
        self.left = left
        self.right = right
        self.next = next
"""
from collections import deque
class Solution:
    def connect(self, root: 'Node') -> 'Node':
        if not root:
            return 
        q = deque()#队列

        q.append(root)#将头节点添加到队列当中

        while q:#循环条件是队列不为空
            cur_len = len(q)#获取当前层的节点个数
            i = 0
            while i < cur_len:
                if i == cur_len-1:
                    q[0].next = None#当前层没有右侧节点，修改next指针为None
                else:#其他情况,,
                #q取q[1]这种很慢
                    q[0].next = q[1]#指向当前层的下一个节点
                if q[0].left:#如果左侧节点存在则添加
                    q.append(q[0].left)
                if q[0].right:#如果右侧节点存在则添加
                    q.append(q[0].right)
                q.popleft()
                i += 1#移动节点指针

        
        return root

```

### 104. 二叉树的最大深度

#### 题目

给定一个二叉树 root ，返回其最大深度。

二叉树的 最大深度 是指从根节点到最远叶子节点的最长路径上的节点数。

#### 思路

###### 递归遍历

1. 递归输入：当前节点，递归输出:当前节点及其以下的深度

2. 递归条件：if not root:return 如果当前节点为空结点，那么返回

3. 每次递归的处理，取左右子树的最大深度+1，因为要返回当前节点及其以下的深度，算上当前节点，那么就应该+1

```python
class TreeNode:
    def __init__(self,val=0,left=None,right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:

        if not root:
            return 0
        
        leftmax = self.maxDepth(root.left)
        rightmax = self.maxDepth(root.right)

        return max(leftmax,rightmax) + 1
        
        
```

###### 层序遍历思路

由于递归需要遍历所有节点，然后层序遍历也可以起到同样的作用，只不过在每层结束遍历的时候将全局的count+=1就可以了。


```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root :
            return 0
        
        maxdepth = 0
        q = deque()
        q.append(root)

        while q :

            size = len(q)

            for _ in range(size):
                curnode = q.popleft()
                
                if curnode.left:
                    q.append(curnode.left)
                if curnode.right:
                    q.append(curnode.right)
                
            maxdepth += 1
        
        return maxdepth
```

### 111. 二叉树的最小深度

#### 题目

给定一个二叉树，找出其最小深度。

最小深度是从根节点到最近叶子节点的最短路径上的节点数量。

说明：叶子节点是指没有子节点的节点。


#### 思路

仿照二叉树的层序遍历，初始化队列q，然后将root添加进队列q中，循环条件是while
q不为空，然后获取当前层的size，然后for循环size次数，对于每个节点curnode，然后将curnode.left,curnode.right添加进队列中，退出条件是如果遇到第一个叶子节点if not curnode.left and if not curnode.right.返回maxdepth+1。在每次遍历每一层的时候maxdepth+=1。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root :
            return 0
        
        maxdepth = 0    

        q = deque()
        q.append(root)

        while q :
            size = len(q)

            for _ in range(size):
                curnode = q.popleft()
                
                if not curnode.left and not curnode.right:
                    return maxdepth+1
                if curnode.left :
                    q.append(curnode.left)
                
                if curnode.right :
                    q.append(curnode.right)
                
            maxdepth += 1
```
