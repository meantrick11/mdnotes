# 108.将有序数据转换为二叉搜索树

## 题目

给你一个整数数组 nums ，其中元素已经按 升序 排列，请你将其转换为一棵 平衡 二叉搜索树。

## 思路(递归法)

### 方法一：输入整体数组

1. 递归输入条件：需要构建的数组   2. 递归输出条件：当前构造的节点

2. 递归终止条件，当数组为空时，return None

3. 每次递归操作：取数组中间节点值，然后塑造节点，左右节点分别进行左右递归塑造左右子树

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
    left = 0
    right = len(nums)-1
    mid = (left+right)//2
    root = TreeNode(nums[mid])#创造根节点
    # 塑造左右节点,切片传入有额外内存开销，可以通过内定义函数，只传入参数进行  def build(l, r)，对应比较
    root.left = self.sortedArrayToBST(nums[0:mid])#数组前半部分切片
    root.right = self.sortedArrayToBST(nums[mid+1:])#数组后半部分切片
    return root

```

### 方法二：传递指针法

方法一每次需要传入一整个数组切片，需要额外的数组空间，如果优化一下，将数组指针传入，那么将减少空间开销：

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:

        def buildBST(nums:List[int],left:int,right:int)->TreeNode:  #循环不变量为左闭右开
            if left >= right:
                return None
            mid = (left+right)//2
            root = TreeNode(nums[mid])
            root.left = buildBST(nums,left,mid)
            root.right = buildBST(nums,mid+1,right)
            return root

        left = 0
        right = len(nums)
        root = buildBST(nums,left,right)    #调用函数
        return root #返回根节点
```
