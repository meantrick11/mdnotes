# 106. 从中序和后序遍历中构造二叉树
**中后序遍历的索引关系**
+**数组分割元素的循环不变量的使用**

## 题目

给定两个整数数组 inorder 和 postorder ，其中 inorder 是二叉树的中序遍历， postorder 是同一棵树的后序遍历，请你构造并返回这颗 二叉树 。
输入：inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
输出：[3,9,20,null,null,15,7]

**注意，本题默认没有值相等的节点**


## 思路(递归法)

思考，二叉树的后续遍历一定是右侧头节点root节点，那么每次pop()就应该是最后遍历的节点，并且中序遍历并承**左(子树)中(节点)右(子树)**，而后序遍历并承**左(子树)中(节点)右(子树)**,所以，根据pop后续遍历的最后一个节点，然后在中序遍历中去index，进而分割后续遍历的左子树和右子树，**两者index有联系,将两者遍历的数组对照写入可观察出**，然后这里有和二分查找一样的**循环不变量**的引用，以为要按照某个位置分割数组，然后进行右左递归，并判断分割位置是左开右闭还是左闭右开分割。首先将postorder中最后一个元素pop，然后找inorder中的索引位置，获取右子树的后续遍历的索引，这里采用左闭右开的方式，也就是当left_inoder >= right_inorder时(可以换为==)，那么这个元素已经被遍历过了，那么直接返回None，相应的递归也应该是如下：

```python
class Solution:
    def buildTree(self, inorder: List[int], postorder: List[int]) -> TreeNode:
        def helper(left_inorder:int,right_inorder:int):
            if left_inorder == right_inorder:   #区间为左闭右开，最后退出递归的时候，应该时左右指针指向同一个元素，但是已经被上层遍历了，那么条件可以改为>=,但是实际上在==时，就已经return了
                return None
            
            val = postorder.pop()   #获取后序遍历的中节点
            root = TreeNode(val)    #创造当前根节点

            sp = hashmap[val]   #找出左右子树的分割
            
            root.right = helper(sp+1,right_inorder) #由于是左闭右开，所以，应该时sp+1->right_inorder,
            root.left = helper(left_inorder,sp) #由于是左闭右开，所以应该是left_inorder->sp

            return root
        hashmap = {val:key for key,val in enumerate(inorder)}   #创造数值->索引的映射
        root = helper(0,len(postorder))
        return root #左闭右开，不包含最右侧索引，所以直接传入len(postorder)

```

以下是左闭右闭的写法

```python
class Solution:
    def buildTree(self, inorder: List[int], postorder: List[int]) -> TreeNode:
        
        
        def helper(left_inorder:int,right_inorder:int):
            if left_inorder > right_inorder:    #左闭右闭写法，退出条件应该是left_inorder跑到right_inorder的右侧了，也就是当left_inorder==right_inorder的时候，该元素还没有被创建节点
                return None

            val = postorder.pop()       #获取后续遍历的节点的值
            root = TreeNode(val)    #创造当前根节点

            sp = hashmap[val]   #找出左右子树的分割
            
            root.right = helper(sp+1,right_inorder)     #左闭右闭，那么应该是sp+1->right_inorder的元素没有被遍历
            root.left = helper(left_inorder,sp-1)   #左闭右闭，那么应该是left_inorder->sp-1没有被遍历过

            return root
        hashmap = {val:key for key,val in enumerate(inorder)}   #创造数值->索引的映射

        root = helper(0,len(postorder)-1)
        return root    #左闭右闭，传入应该是len(postorder)-1
```
