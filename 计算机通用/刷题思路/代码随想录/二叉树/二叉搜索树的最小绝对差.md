# 530. 二叉搜索树的最小绝对差

## 题目

给你一个二叉搜索树的根节点 root ，返回 树中任意两不同节点值之间的最小差值 。

差值是一个正数，其数值等于两值之差的绝对值。

## 思路

**二叉搜索树的中序遍历的结果是有序数组**

同样根据上述定理进行遍历二叉搜索树，然后对结果数组进行遍历记录最小值，最后return即可


```python

import math
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def getMinimumDifference(self, root: TreeNode) -> int:
        vals = []   #数值记录数组

        def preorder(node,res:List)->None:
            if not node:
                return#如果遇到空结点，直接返回，退出递归

            preorder(node.left,res)
            res.append(node.val)
            preorder(node.right,res)

        preorder(root,vals)#调用递归函数，进行中序遍历

        mi = math.inf   #定义一个最大值，也就是初始化一个不可能的差值
        for i in range(1,len(vals)):    #遍历获取最小差值
            cur =vals[i]-vals[i-1]
            if cur <= mi:
                mi = cur

        return mi
```
