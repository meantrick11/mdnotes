# 101. 对称二叉树

## 题目

给你一个二叉树的根节点 root ， 检查它是否轴对称。


## 遍历到最后的几种情况

1. leftnode ==None &leftnode != None    --> return False
2. leftnode != None & rightnode == None     --> return False
3. leftnode == None & rightnode == None     --> return True|pass
4. leftnode.val != rightnode.val        --> return False
5. leftnode.val == rightnode.val        --> pass



## 思路一（递归法）

1. 递归输入：由于是对比左右两侧节点的对称位置的节点value是否相同，那么对于递归函数输入应该是左右两侧同方位节点，递归输出：判断是否为对称，那么应该对比两侧同方位节点之后的判断是否为True|False，所以输出应该是Bool值

2. 终止条件，考虑最终的终止条件的可能情况
    1. 如果递归到某一处发现左右同方位节点的val不相等，那么return False，如果相等，那么继续向下递归，不进行操作
    2. 如果递归到某一处发现左右同方位节点，左侧为空+右侧不为空，或者左侧不为空+右侧为空，那么应该return False
    3. 如果递归到某一处发现左右同方为节点，左右侧都为空，那么应该return True，因为下面已经没有其他节点可以递归了，（已经递归到头了）
3. 每次递归需要左什么操作呢？应该对比外侧递归和内测递归的Bool值，并向上传递。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True #空树也是对称的
        
        def check(q:TreeNode,p:TreeNode):   #确定输入是左右需要比较的节点
            ##终止条件：
            ## 两种为True的情况
            if q == None and p == None:
                return True
            # elif q.val == p.val :
            #     return True
            elif q != None and p == None:
                return False
            elif q == None and p != None:
                return False
            elif q.val != p.val:
                return False

            outside = check(q.left,p.right)
            inside = check(q.right,p.left)

            return outside and inside

        return check(root.left,root.right)
```

## 思路二(栈迭代法)

从第二层开始，初始化一个栈stack，然后将第二层节点依次加入栈中，循环条件是stack不为空，每次循环中依次取出leftnode，和rightnode
1. 左为空，右不为空，return False
2. 左不为空，右为空，return False
3. 左为空，右为空，continue #跳过执行，表示当前节点的对比是对称的，然后跳过后续添加节点，如果不跳过，那么后续添加空结点的左右节点会报错，如果return True，那么可能判断太过决断，比如某一层添加到栈之后为[4,1,None,None],如果此时return True，显然是不正确的
4. 左右值不相等，return False

然后将leftnode.left,rightnode.right,leftnode.right,rightnode.left添加进stack中，方便后续两两取出对比元素。
如果遍历完所有的节点都没有返回Flase，则表示整个二叉树对称，return True

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True #空树也是对称的
        stack = []

        stack.append(root.left)
        stack.append(root.right)

        ##两两取出进行对比
        while stack:
            # 将stack中的当前需要对比的两个节点取出
            rightnode = stack.pop()
            leftnode = stack.pop()
            #空结点的情况
            if not rightnode and leftnode:
                return False
            elif rightnode and not leftnode:
                return False
            elif not rightnode and not leftnode:
                continue
            #值不相等的情况
            elif rightnode.val != leftnode.val:
                return False
            
            ### 外部节点（将左节点的left，右节点的right）添加进stack中，
            stack.append(leftnode.left)
            stack.append(rightnode.right)

            ### 内部节点添加进stck
            stack.append(leftnode.right)
            stack.append(rightnode.left)

        ###如果整个过程都没有
        return True
```

## 思路三（队列迭代法）

同样是两两取出队列中的元素进行对比,判断根节点是否为None，是，则return True，然后初始化队列q，将root的左右节点分别加入队列当中，循环条件是q不为空，然后将q中的前两个节点取出leftnode,rightnode，进行上面5中情况的对比，不过可以调整if，elif的顺序和条件减少判断次数，然后将外层(leftnode.left,rightnode.right)节点添加进队列q中，将内层节点(leftnode.right,rightnode.left)添加进队列q中，如果将整个二叉树遍历完之后都没有return False，那么return True(为对称二叉树)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True #空树也是对称的
        
        q = deque()

        q.append(root.left)
        q.append(root.right)

        while q:
            leftnode = q.popleft()
            rightnode = q.popleft()

            ###其实就几种情况：
            

            if not leftnode and not rightnode:
                continue
            elif not leftnode or not rightnode:
                return False
            elif leftnode.val != rightnode.val:
                return False
            
            ##将外层节点入队

            q.append(leftnode.left)
            q.append(rightnode.right)

            ## 将内层节点入队
            q.append(leftnode.right)
            q.append(rightnode.left)

        return True     #遍历完整个Tree都没有return False，则表示是对称树
```
