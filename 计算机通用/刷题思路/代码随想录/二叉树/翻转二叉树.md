# 翻转二叉树

## 题目

给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

 
## 思路

对于二叉树的操作，绝大多数都需要针对遍历，所以一定要掌握对于二叉树遍历的四种方式(前中后序遍历(递归方式/栈实现方式)，层序遍历(队列实现方式))


本题要求交换二叉树，此处只写递归的三种遍历方式以及层序遍历的交换实现

### 前/后序遍历

本题要求翻转二叉树，那么就需要对每一个节点交换左右子树，如果是前序遍历，在每次向下递归之前，先实现交换左右节点，然后分别向下递归，则上层节点已经被交换，后续依次向左向右递归，则不会混乱没有交换的子树。
如果是后序遍历，那么也同理，从底向上遍历，只有左右子树分别被交换之后，当前节点才会被交换左右节点，则依次的顺序没有改变。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

### 前序遍历
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        def reverse(node:TreeNode):
            if not node:
                return 

            #交换逻辑
            temp = node.left
            node.left = node.right
            node.right = temp

            reverse(node.left)#交换左右
            reverse(node.right)

        reverse(root)

        return root 

        


###后序遍历
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        def reverse(node:TreeNode):
            if not node:
                return 


            reverse(node.left)#交换左右
            reverse(node.right)
            #交换逻辑
            temp = node.left
            node.left = node.right
            node.right = temp

        reverse(root)

        return root 
```

### 中序遍历

由于中序遍历，当需要交换当前节点的左右子树的时候，那么左子树已经是翻转过后的结果，但是右子树却没有翻转，如果此时交换当前节点的左右子树，那么后面就不应该是和前/后遍历一样遍历右子树，而是遍历左子树，因为左边是之前没有被遍历的右子树。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        def reverse(node:TreeNode):
            if not node:
                return 

            reverse(node.left)#交换左右

            #交换逻辑
            node.left,node.right = node.right,node.left

            reverse(node.left)

        reverse(root)

        return root 
```

### 层序遍历


初始化队列，将头节点添加进队列，然后对于当前层进行计数，对于每个节点都进行左右子树的交换，并且交换过后将节点的子节点添加到队列中，以进行下一层的遍历，此方法，也是从顶到底的遍历，但是和前序遍历的从顶到底略有区别，前序是交换之后进入左子树，把左子树交换完毕后进入右子树，但是层序遍历真正意义上的从顶到底每一层每一层地交换。

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:

        if not root :
            return 
        
        q = deque()
        q.append(root)

        while q:
            size = len(q)#获取当前层的节点个数

            for _ in range(size):
                node = q.popleft()#获取到当前队列的头节点
                #交换左右节点
                node.left,node.right = node.right,node.left
                #将下一层的节点添加到队列
                if node.left:#如果没有这个判断，那么
                    q.append(node.left)
                if node.right:
                    q.append(node.right)


        return root 
```
