# 134. 加油站

## 题目

在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 gas[i] 升。

你有一辆油箱容量无限的的汽车，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 gas 和 cost ，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 -1 。如果存在解，则 保证 它是 唯一 的。

 

示例 1:

输入: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出: 3
解释:
从 3 号加油站(索引为 3 处)出发，可获得 4 升汽油。此时油箱有 = 0 + 4 = 4 升汽油
开往 4 号加油站，此时油箱有 4 - 1 + 5 = 8 升汽油
开往 0 号加油站，此时油箱有 8 - 2 + 1 = 7 升汽油
开往 1 号加油站，此时油箱有 7 - 3 + 2 = 6 升汽油
开往 2 号加油站，此时油箱有 6 - 4 + 3 = 5 升汽油
开往 3 号加油站，你需要消耗 5 升汽油，正好足够你返回到 3 号加油站。
因此，3 可为起始索引。
示例 2:

输入: gas = [2,3,4], cost = [3,4,3]
输出: -1
解释:
你不能从 0 号或 1 号加油站出发，因为没有足够的汽油可以让你行驶到下一个加油站。
我们从 2 号加油站出发，可以获得 4 升汽油。 此时油箱有 = 0 + 4 = 4 升汽油
开往 0 号加油站，此时油箱有 4 - 3 + 2 = 3 升汽油
开往 1 号加油站，此时油箱有 3 - 3 + 3 = 3 升汽油
你无法返回 2 号加油站，因为返程需要消耗 4 升汽油，但是你的油箱只有 3 升汽油。
因此，无论怎样，你都不可能绕环路行驶一周。


## 思路一(暴力枚举)


从0->n-1进行枚举遍历作为起始点，然后依次记录向后能否绕行一圈：

```python
class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        ## 暴力做法，每次以i作为起点模拟开始，然后更新起始位置
        n = len(gas)

        start = 0

        while start < n:
            total_gas = 0
            total_cost = 0
            step = 0
            while step < n:#以start开始循环遍历后续是否满足能够遍历的条件？
                cur = (start+step)%n#循环
                total_gas += gas[cur]
                total_cost += cost[cur]

                if total_gas < total_cost:
                    break
                step += 1
            
            if step == n:#如果刚好能遍历，则返回起始站台
                return start
            start += max(1,step)#,

        return -1
```

## 思路二(贪心算法)


局部最优：
**当前这一小段区间的最优选择**
遍历累加curleft，一旦curSum < 0，直接把候选起点更新为i+1，重置 curleft=0。从旧起点 start，一直走到 i 这个位置，油不够了，走不到 i+1。

全局最优：
**可以完整绕环路跑完整一圈**


```python
class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        ## 暴力做法，每次以i作为起点模拟开始，然后更新起始位置
        totalleft = 0
        curleft = 0
        start = 0   #默认从0号汽油站可以走完全程
        for i in range(len(gas)):
            curleft += gas[i] - cost[i] #记录当前到下一个车站的"剩余油量"
            totalleft += gas[i] - cost[i]   #记录全程，为后面判断是否够一圈做准备

            if curleft < 0: #当前油箱不够到达下一站，那么更新起始位置为start=i+1,并更新油箱的初始值
                curleft = 0
                start = i+1 #局部最优

        if totalleft < 0:   #全程油量不足
            return -1
        
        return start #最终的start为全局最优
```
