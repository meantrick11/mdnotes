# 135. 分发糖果

## 题目

n 个孩子站成一排。给你一个整数数组 ratings 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

每个孩子至少分配到 1 个糖果。
相邻两个孩子中，评分更高的那个会获得更多的糖果。
请你给每个孩子分发糖果，计算并返回需要准备的 最少糖果数目 。

 

示例 1：

输入：ratings = [1,0,2]
输出：5
解释：你可以分别给第一个、第二个、第三个孩子分发 2、1、2 颗糖果。
示例 2：

输入：ratings = [1,2,2]
输出：4
解释：你可以分别给第一个、第二个、第三个孩子分发 1、2、1 颗糖果。
     第三个孩子只得到 1 颗糖果，这满足题面中的两个条件。
 

## 思路

贪心一：比较相较于左侧,左孩子<右孩子,则糖果选择max(candies[i-1]+1,(candies[i])1),初始化都至少为1，则如果左< 右，则右孩子应该选择更大的糖果
贪心二：比较相较于右侧,左>右，则当前糖果应该选择max(candies[j]+1,candies[j]),当前的糖果和如果相较于右侧糖果+1，谁更大

两次贪心，分别选出相较于左侧和相较于右侧都符合的糖果数量

```python
class Solution:
    def candy(self, ratings: List[int]) -> int:
        n = len(ratings)

        candies = [1]*n

        for i in range(1,n):
            #从前往后遍历，找到右孩子>左孩子的情况
            #贪心为max[i]+1

            if ratings[i] >ratings[i-1]:#当前的右孩子>左孩子
                candies[i] = max(candies[i-1]+1,1)  #去左孩子的糖果的个数，和1做比较
        
        for j in range(n-1,0,-1):
            #从后往遍历，将左孩子>有孩子的情况，则选取相较于candies[i]更大的糖果数，也就是贪心，进而全局最优解决
            if ratings[j] < ratings[j-1]:    #左孩子>右孩子
                candies[j-1] = max(candies[j]+1,candies[j-1])


        return sum(candies)

```
