# 55. 跳跃游戏

## 题目

给你一个非负整数数组 nums ，你最初位于数组的 第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true ；否则，返回 false 。

 

示例 1：

输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。
示例 2：

输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0 ， 所以永远不可能到达最后一个下标。

## 思路(贪心算法)

贪心：当前能够到达的区间内能否找到能到达的更远点?,进而找到全局能够到达的位置

首先声明一个maxmeet，保存遍历过的节点能够到达的最远点，然后依次遍历当前能够到达的最远点的过程中是否还有能到达的更远的点？，如果遍历到当前点，maxmeet< i,那么表示当前点不能到达，由于是一遍遍历，那么表示当前点不能被到达(即不能到达最后一个下标),return False,整个遍历过程中都没有return False，那么就说明能够到达最后一个下标，return True

大体思路：遍历整个数组，遍历过程中判断i<=maxmeet?(保证在i+1->i+nums[i]+1的过程中尝试更新maxmeet)，如果不小于，那么说明整个遍历过程中不能到达当前位置，那么return，尝试更新maxmeet的大小，

终止条件：当当前位置不能被到达或者已经将整个数组遍历完的时候退出，

特殊情况：由于是遍历整个数组不存在特殊情况

```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        ## 贪心，贪的就是当前能到的最远的距离是否有能到达更远的起点?，并且如果当前索引下标+当前能到的长度的总和之前有其他索引+步数更大的，那么就更新最大的距离

        maxmeet = 0
        start = 0
        for i in range(len(nums)):
            if maxmeet < i: #每次需要判断，曾经的maxmeet能不能到达i,如果不能到达，因为i<=n-1,则说明不能到达最后一个下标
                return False
            curmeet = i+nums[i] #当前索引+步数能到的位置
            if curmeet > maxmeet:   #记录当前能够在maxmeet的步数范围内能到达的最远的maxmeet
                maxmeet = curmeet
                
        return True #整个过程中都没有return False，则能够到达最后一个下标n-1，则return True，也可以在for循环中添加一个if判断，可以稍微减少循环次数
```
