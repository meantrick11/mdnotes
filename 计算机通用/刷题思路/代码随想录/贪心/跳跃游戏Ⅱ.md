# 45. 跳跃游戏Ⅱ

## 题目

给定一个长度为 n 的 0 索引整数数组 nums。初始位置在下标 0。

每个元素 nums[i] 表示从索引 i 向后跳转的最大长度。换句话说，如果你在索引 i 处，你可以跳转到任意 (i + j) 处：

0 <= j <= nums[i] 且
i + j < n
返回到达 n - 1 的最小跳跃次数。测试用例保证可以到达 n - 1。

## 思路(贪心算法)

**贪心的思路，局部最优：当前可移动距离尽可能多走，如果还没到终点，步数再加一。整体最优：一步尽可能多走，从而达到最少步数。**

大体思路：以当前位置i+1->i+nums[i]+1，尝试找下一个能够跳最远的跳跃点，使用for循环遍历，如果期间的cur_reach>max_reach，那么更新下一个best_j(也就是下一个起始跳跃点，当前要跳到的下一个节点)

终止条件:循环条件是i< n-1,所以，需要在每次循环进入的时候判断当前节点能够到达n-1?(i+nums[i]>=n-1)，如果能，则return count+1,还需要再跳一步才到n-1

特殊情况：传入的数组只有一个数，那么循环进不了，则直接return 0

```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)   #数组长度
        if n == 1:  #特殊情况
            return 0
        count = 0
        i = 0
        while i < n - 1:
            # 终止条件：如果当前点能直接跳到终点，返回跳跃次数+1
            if i + nums[i] >= n - 1:
                return count + 1
            # 否则在 i+1 到 i+nums[i] 范围内寻找能到达最远的点
            max_reach = 0
            best_j = i
            # 注意：寻找下一个跳跃点的索引应该是 i+1->i+nums[i]+1
            for j in range(i + 1, i + nums[i] + 1):
                cur_reach = j + nums[j]
                if cur_reach > max_reach:
                    max_reach = cur_reach
                    best_j = j
            # 跳跃一步到 best_j。count+1,更新i作为下一个起始点。
            count += 1
            i = best_j
        return count
```
