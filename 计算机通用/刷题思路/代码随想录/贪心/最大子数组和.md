# 最大子数组和

## 题目

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

 

示例 1：

输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
示例 2：

输入：nums = [1]
输出：1
示例 3：

输入：nums = [5,4,-1,7,8]
输出：23

## 思路
**贪心的思路为局部最优：当前“连续和”为负数的时候立刻放弃，从下一个元素重新计算“连续和”，因为负数加上下一个元素 “连续和”只会越来越小。从而推出全局最优：选取最大“连续和”**

贪心算法:每一个子数组必然会以某个数为结尾，遍历过程中，如果以当前数结尾的子数组之和>0,,那么就可能让下一个数之和更大，但是如果当前cursum之和<0,那么就是以这个数结尾的子数组之和只能让以后续数结尾的子数组的和变小，那么当前子数组就不能要，需要重新以下一个数字开始尝试寻找最大的子数组和。

**以当前数字结尾的子数组和的最大情况->全局子数组和最大的情况**

需要用一个全局的maxsum记录遍历过程中的最大的子数组和，如果cursum>maxsum,那么才更新maxsum。并每次对以当前元素结尾的子数组和进行判断：是否能添加到下一个子数组中，如果<=0,那么就尝试以下一个数字为子数组起始索引：

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_sum = float('-inf') #全局记录最大的子数组和，实时更新
        cursum = 0  #以当前数字结尾的子数组和cursum(当然，起始索引为使cursum>=0的那个数字)
        for i in range(len(nums)):#全局遍历
            cursum += nums[i]   #尝试将当前的数字添加到cursum中，并考究是否能够使得cusum比max_sum更大？
            if cursum > max_sum:    #如果以当前数字结尾的数组的和>max_sum，那么更新全局最大子数组和
                max_sum = cursum
            if cursum <= 0: #如果以当前的数字为结尾的和<=0,那么应该尝试以后面的数字为新的子数组的起始位置，摒弃当前数字为结尾的子数组
                cursum = 0

        return max_sum
```
