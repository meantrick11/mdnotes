# 763. 划分字母区间

## 题目

给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。

返回一个表示每个字符串片段的长度的列表。

 

示例 1：
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。 
示例 2：

输入：s = "eccbbbbdec"
输出：[10]

## 思路（贪心算法）

每次只找能够最小化区间长度，并且包括剩余的字符串中没有当前区间的任意字符，也就是找到当前区间中的所有字符的最远的索引分割为一个子字符串，->全局最大字符串个数

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        ## 贪心算法，将当前字符添加进当前切片中向后贪心地将相同的字符拿进当前字符串中，并记录当前更新的字符，同理
        res = []    #记录的是下一个字符串的分割位置，第一个元素刚好就是第一个子字符串的长度，最后一个就是字符串的长度

        curmax = 0
        ###记录索引分割：
        for i in range(len(s)):
            cur = s.rfind(s[i])  #找到当前字符在字符串中最后一个下标的位置
            if i <= curmax and cur > curmax:    #如果当前字符在当前子字符串的区间内，且出现的最后位置>当前子字符串的
                curmax = cur    
            if i == curmax : #如果当前等于curmax，并且cur没有>curmax，那只能等于curmax了，那么就将结果添加到res中，
                curmax = i+1
                res.append(i+1) 
        ##每一个元素记录的就是下一个字符串开始的索引位置，但是第一个元素就是题目所需的数量，然后只需要后续的元素依次减去前一个字符串的开始的索引
        for j in range(len(res)-1,0,-1):
            res[j] = res[j]-res[j-1]
                

        return res
```
