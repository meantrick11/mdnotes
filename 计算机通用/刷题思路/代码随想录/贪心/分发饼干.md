假设你是一位很棒的家长，想要给你的孩子们一些小饼干。但是，每个孩子最多只能给一块饼干。

对每个孩子 i，都有一个胃口值 g[i]，这是能让孩子们满足胃口的饼干的最小尺寸；并且每块饼干 j，都有一个尺寸 s[j] 。如果 s[j] >= g[i]，我们可以将这个饼干 j 分配给孩子 i ，这个孩子会得到满足。你的目标是满足尽可能多的孩子，并输出这个最大数值。

 
示例 1:

输入: g = [1,2,3], s = [1,1]
输出: 1
解释: 
你有三个孩子和两块小饼干，3 个孩子的胃口值分别是：1,2,3。
虽然你有两块小饼干，由于他们的尺寸都是 1，你只能让胃口值是 1 的孩子满足。
所以你应该输出 1。
示例 2:

输入: g = [1,2], s = [1,2,3]
输出: 2
解释: 
你有两个孩子和三块小饼干，2 个孩子的胃口值分别是 1,2。
你拥有的饼干数量和尺寸都足以让所有孩子满足。
所以你应该输出 2。

## 思路(倒序cookiefor循环)
**大饼干优先喂给大胃口**
为了满足更多的小孩，就不要造成饼干尺寸的浪费。

大尺寸的饼干既可以满足胃口大的孩子也可以满足胃口小的孩子，那么就应该优先满足胃口大的。

这里的局部最优就是**大饼干喂给胃口大的，充分利用饼干尺寸喂饱一个，全局最优就是喂饱尽可能多的小孩。**

对于饼干为循环基础，从后往前进行遍历，使用child记录当前孩子的胃口，同样是从后往前进行对比(**主要目的为了匹配尽可能使用最大饼干满足较大胃口的孩子**)，那么外层循环就是当前没有被匹配到的最大的饼干，内层进行对当前较大胃口孩子进行匹配，如果当前孩子的胃口比当前最大的饼干s[i]都还大，那么使用while循环进行child -= 1，如果能够匹配上，那么将child-=的同时count+=1。**注意：这里需要小心while循环或下次循环的时候child已经超过索引，所以需要while和if匹配之前先进行索引大小的判断child>-1**

```python
class Solution:
    def findContentChildren(self, g: List[int], s: List[int]) -> int:
        glen = len(g)   #孩子和饼干总数
        slen = len(s)

        g.sort()    #将胃口和饼干大小排序
        s.sort()

        count = 0   #能够被满足的孩子的数量，结果
        child = glen - 1    

        for i in range(slen-1,-1,-1):          
            while child > -1 and g[child] > s[i]:  #当前孩子的胃口>最大的饼干，那么孩子-=1
                child -= 1
            
            if child > -1 and g[child] <= s[i]:#当前饼干能够满足当前孩子的胃口
                count += 1  #记录结果
                child -= 1  #当前的孩子也要减去
        return count
```   

## 思路(正序child为for循环)
**小饼干优先喂给小胃口**

**贪心思路不变：就是尽可能使用较小(大)的cookie满足较小(大)孩子的胃口**

循环条件是当前还有孩子或者还有cookie剩余没有被匹配，那么就继续while循环。如果curchild的胃口<=curcookie，那么count+=1，curchild+=1，curcookie+=1，如果当前的cookie不足以匹配curchild的胃口，由于curchild已经是较小的胃口了，所以应该找更大的cookie尝试匹配curchild的胃口，即curcookie+=1


```python
class Solution:
    def findContentChildren(self, g: List[int], s: List[int]) -> int:
        glen = len(g)
        slen = len(s)

        g.sort()    #将胃口和饼干大小排序
        s.sort()
##尽可能用剩余较小的饼干满足较小的孩子，->全局最多的小孩被满足，以child为主的遍历
        count = 0
        curcookie = 0
        curchild = 0
        while curcookie < slen and curchild < glen:
            if s[curcookie] >= g[curchild]:#当前的cookie能够满足当前孩子的胃口
                count += 1
                curcookie += 1  #移动到下一个cookie
                curchild += 1  #移动到下一个孩子
            else:       #当前的cookie都不能满足当前的孩子
                curcookie += 1  #向后找更大的cookie，匹配当前较小孩子的胃口,##由于每次匹配或者不匹配都要移动curcookie，所以可以合并cookie始终+=1
        return count 
```
