# 454. 四数相加

>题目：给定四个包含整数的数组列表 A , B , C , D ,计算有多少个元组 (i, j, k, l) ，使得 A[i] + B[j] + C[k] + D[l] = 0。

>为了使问题简单化，所有的 A, B, C, D 具有相同的长度 N，且 0 ≤ N ≤ 500 。所有整数的范围在 -2^28 到 2^28 - 1 之间，最终结果不会超过 2^31 - 1 。


思路一：首先想到暴力解法，那就是直接四重循环，对每个nums进行遍历zhi满足A[i] + B[j] + C[k] + D[l] = 0。那么count+=1,显然，暴力解法时间复杂度太高为O(n^4)

思路二：可以考虑使用hash法记录一部分和，然后遍历，查看是否有target(0)-当前和在hash记录中，由于需要记录次数，那么应该选用dict()，键为A[i]+B[j],值为count个数，然后对寻找是否有target-(C[k]+D[l])在dict中，此法，可以将时间复杂度将为O(n^2)，最多降为n/2


```python
class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int], nums3: List[int], nums4: List[int]) -> int:
        
        n = len(nums1)
        hashmap = {}
        
        
        for i in range(n):
            for j in range(n):
                curtwosum = nums1[i]+nums2[j]
                if curtwosum in hashmap:
                    hashmap[curtwosum] += 1
                else:
                    hashmap[curtwosum] = 1
        res = 0
        for k in range(n):
            for l in range(n):
                curtwosum = nums3[k]+nums4[l]
                if -curtwosum in hashmap:
                    res += hashmap[-curtwosum]
                
        return res

```
