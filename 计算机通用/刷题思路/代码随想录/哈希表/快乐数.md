# 202. 快乐数

>编写一个算法来判断一个数 n 是不是快乐数。

>「快乐数」定义为：对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和，然后重复这个过程直到这个数变为 1，也可能是 无限循环 但始终变不到 1。如果 可以变为  1，那么这个数就是快乐数。

>如果 n 是快乐数就返回 True ；不是，则返回 False 。

题目说可能会无限循环，也就是求和过程中，sum会重复出现，以此，应该**考虑将每次结果都记录**，然后判断是否已经出现过，如果出现过，那么表示已经是下一个循环的开始，所以需要return False

思路一：使用dict实现记录

```python
from collections import defaultdict
class Solution:
    def isHappy(self, n: int) -> bool:
        hashmap = defaultdict(int)#记录已经遍历有的值

        hashmap[n] = 1

        def com(n):
            res = 0
            while n > 0:
                temp = n%10
                res += temp**2
                n //= 10
            return res
        
        aftercom = com(n)#获取第一个结果

        while aftercom != 1 and not hashmap[aftercom]:#退出条件是，字典中有对应的值，那么陷入了循环，条件二是aftercom==n
            hashmap[aftercom] = 1
            aftercom = com(aftercom)
            

        return aftercom == 1
```

思路二：使用set()的hash映射

```python
from collections import defaultdict
class Solution:
    def isHappy(self, n: int) -> bool:
        res = set()#创建一个记录结果的hash映射

        while True:
            cursum = self.getcom(n)
            if cursum in res or cursum == 1:
                break
            res.add(cursum)
            n = cursum

        return cursum == 1

    
    def getcom(self,n:int)->int:
        res = 0

        while n >0:
            res += (n%10)**2
            n //= 10
        return res
```
