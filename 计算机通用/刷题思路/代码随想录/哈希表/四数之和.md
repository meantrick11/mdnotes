# 18. 四数之和

>给你一个由 n 个整数组成的数组 nums ，和一个目标值 target 。请你找出并返回满足下述全部条件且不重复的四元组 [nums[a], nums[b], nums[c], nums[d]] （若两个四元组元素一一对应，则认为两个四元组重复）：

>0 <= a, b, c, d < n
>a、b、c 和 d 互不相同
>nums[a] + nums[b] + nums[c] + nums[d] == target
>你可以按 任意顺序 返回答案 。


思路：参考三数之和，那么此题只需要外层两次循环，然后确定target-(nums[i]+nums[j]),然后内层使用双指针，实现查找，注意去重，时间复杂度为O(n^3)，使用双指针法可以使时间复杂度降一个数量级。

```python
class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums = sorted(nums)

        n = len(nums)

        res = []

        for i in range(n):
            if i > 0 and nums[i] ==nums[i-1]:
                continue
            for j in range(i+1,n):
                if j > i+1 and nums[j] == nums[j-1]:
                    continue 
                curtarget = target -(nums[i]+nums[j])

                left = j + 1
                right = n-1

                while left < right:
                    cursum = nums[left] +nums[right]

                    if cursum == curtarget:
                        res.append([nums[i],nums[j],nums[left],nums[right]])
                        left += 1
                        right -= 1

                        while left < right and nums[left] == nums[left-1]:
                            left += 1
                        while left < right and nums[right] == nums[right+1]:
                            right -= 1
                    elif cursum <curtarget:
                        left += 1
                    else:
                        right -= 1
        return res
```

然后可以做适当剪枝，比如i循环到n-4，也就是for i in range(n-3):以及j循环到n-3,也就是for j in range(n-2),以及如果遇到if nums[i] > target and nums[i] > 0 and target > 0,或者if nums[i] + nums[j] > target and target > 0，那么可以直接break，所以可以做到以下优化代码：

```python
class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        n = len(nums)
        result = []
        for i in range(n):
            if nums[i] > target and nums[i] > 0 and target > 0:# 剪枝（可省）
                break
            if i > 0 and nums[i] == nums[i-1]:# 去重
                continue
            for j in range(i+1, n):
                if nums[i] + nums[j] > target and target > 0: #剪枝（可省）
                    break
                if j > i+1 and nums[j] == nums[j-1]: # 去重
                    continue
                left, right = j+1, n-1
                while left < right:
                    s = nums[i] + nums[j] + nums[left] + nums[right]
                    if s == target:
                        result.append([nums[i], nums[j], nums[left], nums[right]])
                        while left < right and nums[left] == nums[left+1]:
                            left += 1
                        while left < right and nums[right] == nums[right-1]:
                            right -= 1
                        left += 1
                        right -= 1
                    elif s < target:
                        left += 1
                    else:
                        right -= 1
        return result
```
