# 三数之和

>题目:给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

>注意：答案中不可以包含重复的三元组。


思路一：使用hash法，但是难度很高，就记住三数之和使用双指针法吧！

```python
def threeSum(nums):
    res = []
    nums.sort()
    n = len(nums)
    
    for i in range(n):
        # a 大于0直接退出，后面全正数不可能和为0
        if nums[i] > 0:
            break
        # 去重 a：和上一轮i相同则跳过
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        
        seen = set()
        # k 对应原代码第二层循环变量，从 i+1 开始
        for k in range(i + 1, n):
            # 去重 b、c：连续三个相同数字去重逻辑
            if k > i + 2 and nums[k] == nums[k - 1] and nums[k - 1] == nums[k - 2]:
                continue
            
            target = -(nums[i] + nums[k])
            if target in seen:
                res.append([nums[i], target, nums[k]])
                seen.remove(target)
            else:
                seen.add(nums[k])
    return res
```


思路二：使用双指针法，对于数组中的每个元素，然后内层遍历后续的left&right是否能够满足==-nums[i]的程度，每次对外层和内层都需要注重去重处理：
```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums = sorted(nums)
        
        res = []
        
        for i in range(len(nums)):
            left = i + 1
            right = len(nums) - 1
            #外层去重
            if i >0 and nums[i] == nums[i-1]:
                continue

            target = - nums[i]

            while left < right:
                cursum = nums[left] + nums[right]
                if cursum == target:
                    res.append([nums[i],nums[left],nums[right]])
                    left += 1
                    right -= 1
                    #内部去重
                    while left < right and nums[left] == nums[left-1]:
                        left += 1
                    while left < right and nums[right] == nums[right+1]:
                        right -= 1
                    
                elif cursum < -nums[i]:
                    left += 1
                else:
                    right -= 1

        
        return res

```
