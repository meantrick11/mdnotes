# 242. 有效的字母异位词

>题目：给定两个字符串 s 和 t ，编写一个函数来判断 t 是否是 s 的 字母异位词。

思路一：直接使用python内置的sorted()方法，这个方法的时间复杂度是O(nlogn),因为它需要不断比较+找位置，每一次新的character都需要和原来的元素进行比较，所以说总的时间复杂度为O(nlogn+mlogm),空间复杂度为O(n+m)，因为它需要排序后重新构造一个原来一样但顺序不一的字符串

```python

class Solution:
    def isAnagram(self,s:str,t:str)->bool:
        return sorted(s)==sorted(t)
```


思路二：使用collections的Counter()方法，这个方法将目标str或者list使用hash表统计元素出现的次数，它只需要一次遍历，那么总的时间复杂度为O(n+m)->O(n),空间复杂度只有有限个字符(最多不超过26个字符，因为题目说的是只有小写字母),所以说总的空间复杂度为O(26+26)->O(1)，这里取最大的情况
```python
from collections import Counter

class Solution:
    def isAnagram(self,s:str,t:str)->bool:
        return Counter(s)==Counter(t)

```


思路三：类似思路二的hash记录法，声明一个0-25的数组或者其他hash类(dict),然后遍历第一个字符串，对应字符的下标依次+1，然后遍历第二个字符串，对应字符下标依次-1，然后遍历最终结果，如果遇到非0的下标，则表示两个字符串有差值，return False，总的时间复杂的O(n+m+26)->O(n),空间复杂度O(26)->O(1)

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        cnt = [0] * 26
        for c in s:
            cnt[ord(c)-ord('a')] += 1
        for c in t:
            cnt[ord(c)-ord('a')] -= 1
            if cnt[ord(c)-ord('a')] < 0:
                return False
        return True
```
