# 349. 两个数组的交集

>题目：题意：给定两个数组，编写一个函数来计算它们的交集。

>说明： 输出结果中的每个元素一定是唯一的。 我们可以不考虑输出结果的顺序。

思路一：使用双循环，主循环为nums1，然后针对每个外循环，内循环嵌套nums2，对比，如果两个个数字相等，那么添加到结果，时间复杂度为O(n^2)

思路二：使用hash表记录nums1的出现的数字，然后用set()记录结果，随后遍历nums2，如果出现在hashmap中，那么set.add(num)，最后返回

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        hashmap = {}

        for num in nums1:
            hashmap[num] = hashmap.get(num,0) + 1   #构造索引hashmap，避免索引报错，同样，可以使用defaultDict()

        res = set()
        
        for num in nums2:
            if hashmap.get(num,0) != 0:#如果在nums1记录的hashmap中存在
                res.add(num)
                
        
        return list(res)
```

思路三：同样是记录+对比，这里直接使用set()自动去重+&的自动求交的运算返回结果

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        return list(set(nums1)&set(nums2))
```
