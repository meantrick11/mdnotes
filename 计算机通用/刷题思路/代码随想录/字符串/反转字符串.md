# 344. 反转字符串

>编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 char[] 的形式给出。

>不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

>你可以假设数组中的所有字符都是 ASCII 码表中的可打印字符。

>示例 1：
>输入：["h","e","l","l","o"]
>输出：["o","l","l","e","h"]

>示例 2：
>输入：["H","a","n","n","a","h"]
>输出：["h","a","n","n","a","H"]

思路一：反转字符串，首先想到的就是list的自带方法reverse()

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        s.reverse()

        return s
        
```

分析其底层，起始也是双向双指针，然后遍历的时候交换位置数值。时间复杂度为O(n)


思路二：不使用python找的list自带的库，手动实现双向双指针的交换

```python
class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        left = 0
        right = len(s) - 1

        while left < right :
            s[left],s[right] = s[right],s[left]# 实现交换

            left += 1
            right -= 1
```
