# 459. 重复的子字符串

>题目：给定一个非空的字符串 s ，检查是否可以通过由它的一个子串重复多次构成。

思路一：直接遍历每一个字符，然后获取子字符串，尝试是否能够构成s，时间和空间复杂度都太高了，因为s的切片需要大量的额外空间和时间

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:

        n = len(s)
        for i in range(1,n):
            if s[:i]*(n//i) == s:
                return True
            
        return False
```
