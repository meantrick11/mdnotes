# 反转字符串里的单词


>给定一个字符串，逐个翻转字符串中的每个单词。

>示例 1：
>输入: "the sky is blue"
>输出: "blue is sky the"


思路一:直接使用字符串自带的split，然后反转([::-1]或者reverse())，最后.join()即可，这里的split遍历字符串，时间复杂度为O(n)，reverse()需要遍历一般的字典，时间复杂度为O(n/2),字符串的.join()也需要O(n),三者线性，所以总的时间复杂度为O(n)

```python
class Solution:
    def reverseWords(self,s:str)->str:
        s = s.split()#根据空格分割
        s.reverse()#翻转
        return " ".join(s)
```

思路二：双指针反转手动实现reverse()

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        # 将字符串拆分为单词，即转换成列表类型
        words = s.split()

        # 反转单词
        left, right = 0, len(words) - 1
        while left < right:
            words[left], words[right] = words[right], words[left]
            left += 1
            right -= 1

        # 将列表转换成字符串
        return " ".join(words)
```
