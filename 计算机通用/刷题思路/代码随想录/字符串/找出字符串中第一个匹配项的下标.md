# 28. 找出字符串中第一个匹配项的下标

>题目：给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回  -1 。


思路一：双重循环，对于每个haystack中的字符进行遍历，对于每一个字符为起始点，然后分别对比是否后续满足haystack[i:i+n]==needle?,如果满足，则返回，时间复杂度为O(n+m)
```python
class Solution(object):
    def strStr(self, haystack, needle):
        """
        :type haystack: str
        :type needle: str
        :rtype: int
        """
        m, n = len(haystack), len(needle)
        for i in range(m):
            if haystack[i:i+n] == needle:
                return i
        return -1    
```

思路二：先记录可能的起点，然后以每个起点进行和思路一的对比
```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n = len(needle)
        potential = []#记录首字母相同可能的起点
        for i in range(len(haystack)):
            if needle[0] == haystack[i]:
                potential.append(i)

        for j in range(len(potential)):
            cur = haystack[potential[j]:potential[j]+n]
            if cur == needle:
                return potential[j]

        return -1
        
```


思路三：使用内置方法字符串的内置方法index()、find()

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        return haystack.find(needle)

class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        try:
            return haystack.index(needle)
        except ValueError:
            return -1
```
思路三(KMP算法)：使用前缀表的方法，进行快速遍历和回退。
[https://programmercarl.com/0028.%E5%AE%9E%E7%8E%B0strStr.html#%E6%80%9D%E8%B7%AF]

```python
class Solution:
    def getNext(self, next: List[int], s: str) -> None:
        j = 0
        next[0] = 0
        for i in range(1, len(s)):
            while j > 0 and s[i] != s[j]:
                j = next[j - 1]
            if s[i] == s[j]:
                j += 1
            next[i] = j
    
    def strStr(self, haystack: str, needle: str) -> int:
        if len(needle) == 0:
            return 0
        next = [0] * len(needle)
        self.getNext(next, needle)
        j = 0
        for i in range(len(haystack)):
            while j > 0 and haystack[i] != needle[j]:
                j = next[j - 1]
            if haystack[i] == needle[j]:
                j += 1
            if j == len(needle):
                return i - len(needle) + 1
        return -1
```
