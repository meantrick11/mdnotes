### 209.长度最小的子数组

>给定一个含有 n 个正整数的数组和一个正整数 s ，找出该数组中满足其和 ≥ s 的长度最小的 连续 子数组，并返回其长度。如果不存在符合条件的子数组，返回 0。

>示例：

>输入：s = 7, nums = [2,3,1,2,4,3]
>输出：2
>解释：子数组 [4,3] 是该条件下的长度最小的子数组。
>提示：

>1 <= target <= 10^9
>1 <= nums.length <= 10^5
>1 <= nums[i] <= 10^5

思路一：暴力枚举，使用双重遍历，针对每个数为开始，查询cur>=target?，否则循环遍历右侧元素，并添加到cur中

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        #暴力枚举

        res = len(nums)+1

        for i in range(len(nums)):
            cur = nums[i]
            
            if cur >= target:#排除单数直接>=target的值
                return 1

            for j in range(i+1,len(nums),1):
                
                if cur < target:
                    cur += nums[j]
                
                if cur >= target and (j-i+1) < res :#如果不是单数，则需要j-i+1
                    res = j-i+1
                    break

        return res if res != len(nums)+1 else 0
```
