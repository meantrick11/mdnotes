# 插入元素

**由于数组中的元素只能被覆盖而不能直接删除，无论是手动移动还是使用del list[i]，底层都是覆盖，del是移动覆盖之后再释放末尾空间**

但是底层的2\*n空间不会立即释放n空间，底层依旧是2*n空间的CPython内存

### 27.移除元素
>题目：给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素，并返回移除后数组的新长度。

>不要使用额外的数组空间，你必须仅使用 O(1) 额外空间并原地修改输入数组。

>元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

>示例 1: 给定 nums = [3,2,2,3], val = 3, 函数应该返回新的长度 2, 并且 nums 中的前两个元素均为 2。 你不需要考虑数组中超出新长度后面的元素。

>示例 2: 给定 nums = [0,1,2,2,3,0,4,2], val = 2, 函数应该返回新的长度 5, 并且 nums 中的前五个元素为 0, 1, 3, 0, 4。

**你不需要考虑数组中超出新长度后面的元素。**

思路一：遍历元素，如果等于target，那么左移后续元素覆盖
```python
class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        size = len(nums)
        i = 0
        while i < size:
            if nums[i] == val:
                # 后面元素全部向前移动一位
                for j in range(i + 1, size):
                    nums[j - 1] = nums[j]
                i -= 1
                size -= 1
            i += 1
        return size
```

思路二：使用快慢指针的方式（**slow表示当前需要被覆盖的索引**）
    首先找到第一个等于val的元素，然后将slow和fast都置为下标，然后循环让fast指向没有遍历过的元素，然后遇到nums[fast] != val，覆盖原来slow位置的元素，并slow+=1，每次循环都要fast+=1,边界条件是fast==len(nums),

```python
class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        slow = fast = 0
        for i in range(len(nums)):#定位第一个要插入的元素的位置
            if nums[i] ==val:
                slow = fast = i
                break

        while fast < len(nums):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
            fast += 1
        
        return slow#最后退出的索引是slow，比如原本是[3,2,2,3]，那么最后的结果是slow指向倒数第一个2，但是它的索引是2，因为在他之前有两个元素[2,2,2,3]，所以直接返回slow就可以了
```

思路三：同思路二的覆盖思路，那么可以直接从0元素开始遍历，nums[fast] != val,覆盖之后slow+=1,持续遍历到末尾，也就是终止条件是fast==len(nums)
```python
class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
            
        return slow

```

### 26.删除有序数组中的重复项

>题目：给你一个 非严格递增排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。然后返回 nums 中唯一元素的个数。

>考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。

>nums 的前 k 个元素应包含 排序后 的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

仿照27题的思路三，但是判断条件应该是nums[fast]是否和nums[slow-1]，如果等那么跳过(已经存在了),如果不等，那么移动覆盖nums[slow]，然后slow+=1

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        n = len(nums)

        if n <=1:#如果数组为空或者一个元素
            return n

        slow = fast = 1#如果要判断，至少有两个元素，slow指向当前要被覆盖的元素，fast表示遍历的元素

        while fast < n:
            if nums[fast] != nums[slow-1]:
                nums[slow] = nums[fast]
                slow += 1
            
            fast += 1

        return slow
```

### 283.移动零

>题目：给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

>请注意 ，必须在不复制数组的情况下原地对数组进行操作

仿照思路三：使用快慢指针覆盖，判断条件是fast<\len(nums),如果nums[fast] != 0,左右交换元素，而不是直接赋值后元素为0，因为有可能数组中没有0元素：
```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
            

        slow = 0    #指向0元素下标
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow],nums[fast] = nums[fast],nums[slow]#移动非0元素到slow,不能直接nums[slow],nums[slow] = nums[fast],0,因为这样如果nums=[2,1],返回结果为[2,0]，显然不符合题意
                slow += 1   #更新slow

```

### 844.比较含退格的字符串

>题目：给定 s 和 t 两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回 true 。# 代表退格字符。

>注意：如果对空文本输入退格字符，文本继续为空

这道题可以思考不用原来的移动覆盖思路,改为栈的后进先出原则，如果i=="#",则删除栈顶，否则则将i加入栈中
```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        def build(s:str):
            res = list()

            for i in s:
                if i != "#":
                    res.append(i)
                else:
                    if res:
                        res.pop()
            return "".join(res)

        return build(s) == build(t)
```

### 977.有序数组的平方

>题目：给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

思路一：不知为何将这题放到插入元素的例题当中，明显是使用list的内置方法就可以了，但是要经过遍历+排序，所以时间复杂度为O(n+logn)
```python
class Solution:
    def sortedSquares(self,nums:List[int]) -> List[int]:
        res = [num**2 for num in nums]
        res.sort()
        return res

```

思路二：如果使用双向指针一遍遍历，然后直接记录结果，那么时间复杂度为O(n),大大提高

```python
class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
    
        n = len(nums)
        i = 0
        j = n - 1
        k = n - 1
        result = [0] * n
        
        while i <= j:
            if nums[i] * nums[i] < nums[j] * nums[j]:
                result[k] = nums[j] * nums[j]
                j -= 1
            else:
                result[k] = nums[i] * nums[i]
                i += 1
            k -= 1
        return result
```
