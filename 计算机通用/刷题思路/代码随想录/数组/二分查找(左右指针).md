### 704.二分查找

>题目：给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target  ，写一个函数搜索 nums 中的 target，如果目标值存在返回下标，否则返回 -1。

使用条件：有序数组的快速查找方式

注意边界比较问题，推荐使用[)方式，循环条件是`while left < right`,因为左闭右开，当left==right的时候，这个元素已经被上一轮判断过了，后续也只需要移动也是left=mid+1,or right=mid
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums)
        
        while left < right:     #边界条件是左指针<右指针
            mid = (left+right)//2   #中点指针

            if nums[mid] == target:     #比较并移动指针
                return mid
            elif nums[mid] < target:
                left = mid+1
            else:
                right = mid
        
        return -1            #没找到
```

使用[]也是可以的，不过，每次都要严格的遵循最开始的定义，且循环条件是`while left <= right`,因为是全闭区间，那么当left==right的时候，当前元素没有被判断过。left=mid+1,or right=mid-1,才满足[]的定义，其中区间表示没有被排查的数！

**循环不变量，整个过程都要遵循的准则，比如左闭右开，左闭右闭**

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums)-1
        
        while left <= right:     #边界条件是左指针<右指针
            mid = (left+right)//2   #中点指针

            if nums[mid] == target:     #比较并移动指针
                return mid
            elif nums[mid] < target:
                left = mid+1
            else:
                right = mid-1
        
        return -1            #没找到
```

时间复杂度为O(logn)，空间复杂度为O(1)

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums)#选择左闭右开

        while left<right:
            mid = (left+right)//2

            if nums[mid] == target:
                return mid
            elif nums[mid] > target:
                right = mid
            else:#<
                left = mid+1
            
        return left #如果有序数组中没找到，返回它的左侧下标，此时left已经是目标值了

```
同理使用双闭区间也是可以的
这里梳理一下思路（在有序且target唯一存在或者不存的的情况下）：

如果循环不变量是左闭右开区间，那么循环条件应该是left<\right,因为如果遍历到最后left==right,区间里面元素为空，没有元素可以检查，那么直接退出就可以了，除了循环条件，那么就是分情况讨论最后退出时的left和right的指针指向，由于循环条件确认，
1. 如果在遍历过程中，刚好nums[mid]==target，那么遇到循环内部逻辑直接return退出
2. 如果一直移动左右指针，直到最后才刚好找到nums[mid]等于target，那么此时left始终指向的是>=target的第一个大于等于target索引，由于循环条件是left<\right，那么right就不会移动到left的左侧，也就是和left共同指向第一个大于等于target的元素的索引(如果数组中有target，left=right指向的是target的下标,否则指向第一个大于target的元素下标)，此时left=right

如果循环不变量是左闭右闭区间，那么循环条件应该是left<=right,因为如果遍历到最后left=right的时候，那么双闭区间里面是有元素没有被判断的，所以需要多一次，而不能是left < right，讨论最后退出情况：
1. 如果在遍历的过程中，刚好nums[mid]==target,那么遇到循环内部逻辑直接return退出
2. 如果一直移动左右指针，直到最后才刚好找到nums[mid]等于target，那么此时的left始终指向第一个大于等于target的索引，由于循环条件是left<=right,那么最后退出的时候，right会移动到left的左侧，也就是left指向第一个大于等于target的元素的索引()，而right始终指向第一个小于target的索引，此时，left = right+1.

如果循环不变量是左开右开区间 (left, right)，那么循环条件应该是 left < right - 1，因为如果遍历到最后 left==right-1，区间里面元素为空，没有元素可以检查，那么直接退出就可以了，除了循环条件，那么就是分情况讨论最后退出时的 left 和 right 的指针指向，由于循环条件确认：
- 如果在遍历过程中，刚好nums[mid]==target，那么遇到循环内部逻辑直接 return 退出
- 如果一直移动左右指针，直到循环终止条件触发，此时left == right - 1，left始终指向数组中最后一个小于 target 的元素下标，right指向第一个大于 target 的元素下标（如果数组中有 target，target 的下标一定落在 left 和 right 中间；否则 left 指向最大的小于 target 的元素下标，right 指向第一个大于 target 的元素下标），此时left == right - 1

### 34. 在排序数组中查找元素的第一个和最后一个位置

>题目：给定一个按照升序排列的整数数组 nums，和一个目标值 target。找出给定目标值在数组中的开始位置和结束位置。

>如果数组中不存在目标值 target，返回 [-1, -1]。

>进阶：你可以设计并实现时间复杂度为 $O(\log n)$ 的算法解决此问题吗？

>示例 1：

>输入：nums = [5,7,7,8,8,10], target = 8
>输出：[3,4]

思考，原本的二分查找是在有序的只存在一次的元素数组中查找，所以最终退出条件是`left<right或者找到元素然后return mid`,这里需要我们找到左右边界，那么有两个思路

1. 思路一：使用两次二分查找(左闭右开方式)，分别寻找左右边界，左边界：只要`nums[mid]>=target`,更新`right=mid`,最后的条件退出时`return right`,同理，右边界，`nums[mid]<=target`,更新`left=mid+1`,最后退出条件是`return left`，然后返回[right,left]
```python
def searchRange(nums, target):
    def get_left_bound():#由于左闭右开，所以获取的元素应该直接是target的第一个元素
        # 左闭右开 [0, len(nums))
        left = 0
        right = len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] >= target:
                right = mid
            else:
                left = mid + 1
        return right
    
    def get_right_bound():#由于左闭右开，获取的元素应该是第一个大于target的下标
        left = 0
        right = len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] <= target:
                left = mid + 1
            else:
                right = mid
        return left
    
    l_bound = get_left_bound()
    r_bound = get_right_bound()
    # 情况1：target不在数组里
    if l_bound >= len(nums) or nums[l_bound] != target:
        return [-1, -1]
    # 右边界返回的left是最后一个target的下一位，所以真实末尾是 r_bound - 1
    return [l_bound, r_bound - 1]
```

2. 思路二，由于思路的边界处理稍微麻烦，起始可以写同一函数，分别找target的起始位置和target+1的起始位置，那么合起来就是所求下标

```python
class Solution:
    # lower_bound 返回最小的满足 nums[i] >= target 的下标 i
    # 如果数组为空，或者所有数都 < target，则返回 len(nums)
    # 要求 nums 是非递减的，即 nums[i] <= nums[i + 1]
    def lower_bound(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1  # 闭区间 [left, right]
        while left <= right:  # 区间不为空
            # 循环不变量：
            # nums[left-1] < target
            # nums[right+1] >= target
            mid = (left + right) // 2
            if nums[mid] >= target:
                right = mid - 1  # 范围缩小到 [left, mid-1]
            else:
                left = mid + 1  # 范围缩小到 [mid+1, right]
        # 循环结束后 left = right+1
        # 此时 nums[left-1] < target 而 nums[left] = nums[right+1] >= target
        # 所以 left 就是第一个 >= target 的元素下标
        return left

    def searchRange(self, nums: List[int], target: int) -> List[int]:
        start = self.lower_bound(nums, target)
        if start == len(nums) or nums[start] != target:#num全比target小，或者找到了但是不存在num==target
            return [-1, -1]  # nums 中没有 target
        # 如果 start 存在，那么 end 必定存在
        end = self.lower_bound(nums, target + 1) - 1
        return [start, end]

```

2. 思路二：采用一次二分查找的方式，然后以此为点分别向左右两端延申寻找起始和末尾
```python
class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        #二分查找到第一个为target的数值

        left = 0
        right = len(nums)
        first = last = -1#记录第一个和最后一个的索引位置,起始值不应该为0，如果[1],target=1,
        while left < right:
            mid = (left+right)//2#中间索引
            if nums[mid] == target:
                first = last = mid
                break
            elif nums[mid] > target:#在左边
                right = mid
            else:#<target,在右边
                left = mid+1
        
        if first==-1 and last == -1 :
            return [-1,-1]#如果二分查找之后没有找到，则直接返回
        while (first-1)>=0 and nums[first-1] == target:
            first -= 1
        while (last+1)<len(nums) and nums[last+1] == target:
            last += 1
        
        return [first,last]
```
