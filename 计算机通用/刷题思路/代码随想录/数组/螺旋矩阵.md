# 螺旋矩阵

## 题目
>给你一个正整数 n ，生成一个包含 1 到 n2 所有元素，且元素按顺时针顺序螺旋排列的 n x n 正方形矩阵 matrix 

## 思路

如果n=3，那么矩阵为
[
 [1, 2, 3],
 [8, 9, 4],
 [7, 6, 5]
]
如果n=4，那么矩阵为
[
 [ 1,  2,  3,  4],
 [12, 13, 14,  5],
 [11, 16, 15,  6],
 [10,  9,  8,  7]
]

分奇偶情况，如果n为偶，那么回环次数为n//2次，如果n为奇数，那么回环次数若为n//2次，显然最中间res[mid][mid]没有填入数字，那么此时需要额外处理

讨论完整体的奇偶分，那么统一思路为：
单次回环：
每次回环遍历都是从左上到右上，从右上到右下，从右下到左下，从左下到坐上的循环，这里需要建立**循环不变量**，如果是[]，那么从左上到右上符合逻辑，但
1. 首先从左上到右上，for j in range(starty,n-offset,1),此时x轴不变(x=startx)，变换y轴(y=j=starty->n-offset-1)，修改res[startx][j],遍历最后j=n-offset-1;
2. 下一次确定从右上到右下，for i in range(startx,n-offset,1),此时y轴不变(y=j+1),变换x轴(x=i=startx->n-offset-1),修改res[i][j+1]，最后i=n-offset-1;
3. 然后是从右下到左下，for k in range(j+1,starty,-1)，此时x轴不变(x=i+1)，变换y轴(y=k=j+1->starty+1)，然后修改res[i+1][k],最后k=starty+1;
4. 最后是从左下到左上，for l in range(i+1,startx,-1)，此时y轴不变(y=starty),变换x轴(x=k-1->startx+1),最后 l=startx+1;

单次循环之后startx+=1,starty+=1,offset+=1，因为要内缩一个单位

完整代码：
```python
class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        #模拟循环过程
        
        res = [[0]*n for _ in range(n)] #创建结果矩阵
        mid = n//2
        # 每次回环遍历的起始位置
        startx = 0
        starty = 0
        offset = 1
        count = 1
        #循环不变量,左闭右开，[)，
        for time in range(n//2):

            for j in range(starty,n-offset,1):#每次循环次数都是n-offset,正方形上边
                res[startx][j] = count
                count += 1

            for i in range(startx,n-offset,1):#正方形右边，x变换，y=j不变
                res[i][j+1] = count
                count += 1

            for k in range(j+1,starty,-1):
                res[i+1][k] = count
                count += 1
            
            for l in range(i+1,startx,-1):#正方形左边，
                res[l][starty] = count
                count += 1
            
            startx += 1
            starty += 1
            offset += 1
            

        if n%2 == 1:
            
            res[mid][mid] = n**2

        return res
```
