# 替换数字

## 题目

给定一个字符串 s，它包含小写字母和数字字符，请编写一个函数，将字符串中的字母字符保持不变，而将每个数字字符替换为number。

例如，对于输入字符串 "a1b2c3"，函数应该将其转换为 "anumberbnumbercnumber"。

对于输入字符串 "a5b"，函数应该将其转换为 "anumberb"

输入：一个字符串 s,s 仅包含小写字母和数字字符。

输出：打印一个新的字符串，其中每个数字字符都被替换为了number

样例输入：a1b2c3

样例输出：anumberbnumbercnumber

数据范围：1 <= s.length < 10000。

## 思路一

使用一个res记录字符串，遍历原始字符串，每次遇到数字，那么就添加number，否则则添加原字母，这里的时间复杂度为O(n),空间复杂度为O(n)，因为要用到额外的记录辅助空间，python的字符串为不可变类型，所以必然用到额外空间

```python
import sys


def main():
    getin = sys.stdin.readline().strip("\n")#获取输入，并去除\n

    res:str = ""

    for i in range(len(getin)):
        if getin[i].isdigit():
            res += "number"
        else:
            res += getin[i]

    sys.stdout.write(res)


if __name__ == "__main__":
    main()
```

## 思路二

如果想不用额外的辅助空间，那么需要语言支持可变，比如C语言存储的"a5b"变为"anumberb",这里需要将原数组长度从3->8,如此可以使用双指针，大致思路为，填充指针指向当前要填充的末尾(7->0),而原指针则是指向原来的数组的末尾向前延申(2->0),如果遇到number，那么循环六次，一次填充rebmun,然后再进行下一次大循环。
