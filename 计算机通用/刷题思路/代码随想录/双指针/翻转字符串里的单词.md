# 反转字符串里的单词

## 题目

给定一个字符串，逐个翻转字符串中的每个单词。

示例 1：
输入: "the sky is blue"
输出: "blue is sky the"

示例 2：
输入: "  hello world!  "
输出: "world! hello"
解释: 输入字符串可以在前面或者后面包含多余的空格，但是反转后的字符不能包括。

示例 3：
输入: "a good   example"
输出: "example good a"
解释: 如果两个单词间有多余的空格，将反转后单词间的空格减少到只含一个。

## 思路

首先需要将字符串中的单词分割，然后就是反转了，通翻转字符串一个道理，那么使用列表的reverse()方法或者手动实现双指针翻转

**reverse()方法：**
```python
class Solution:
    def reverseWords(self, s: str) -> str:
        s = s.split()
        s.reverse()

        return " ".join(s)
```

**分割后双指针：**
```python
class Solution:
    def reverseWords(self, s: str) -> str:
        s = s.split()
        left = 0
        right = len(s) - 1

        while left < right:
            s[left],s[right] = s[right],s[left]
            left += 1
            right -= 1

        return " ".join(s)        
```
