# 206. 翻转链表

## 题目

给你单链表的头节点 head ，请你反转链表，并返回反转后的链表。
 

## 思路一

引入**头节点**，依次将当前遍历的节点放置到头节点的末尾，然后更新节点指向

```python

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()
        
        cur = head
        while cur :
            temp = cur.next
            cur.next = dummy.next
            dummy.next = cur
            cur = temp

        return dummy.next
```

## 思路二

使用快慢指针的方式，fast比slow快一个节点，slow表示当前已经改变指针指向的节点，fast表示后续没有改变指向的节点，循环条件是while fast,使用temp记录后继节点，然后slow = fast，fast =temp，持续移动

```python

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = None
        fast = head

        while fast :
            temp = fast.next 
            fast.next = slow
            
            #update the nodes
            slow = fast 
            fast = temp

        return slow
```
