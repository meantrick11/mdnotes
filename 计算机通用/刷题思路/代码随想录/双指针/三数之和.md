# 15. 三数之和

## 题目
给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

 

 

示例 1：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。


## 思路一

对于每一个都进行遍历，然后参考两数之和的hashmap记录方式，但是去重不好考虑，这里当作扩展思路,首先将数组排序，对于每个数遍历，以及对后面的数进行hash记录，如果target-nums[k]-nums[i],那么返回添加的结果,时间复杂度为O(n^2),空间复杂度为seen,O(n)：
```python
class Solution:
    def threeSum(self,nums:List[int]):
        res = []
        nums.sort()
        n = len(nums)
        
        for i in range(n):
            # a 大于0直接退出，后面全正数不可能和为0
            if nums[i] > 0:
                break
            # 去重 a：和上一轮i相同则跳过
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            seen = set()
            # k 对应原代码第二层循环变量，从 i+1 开始
            for k in range(i + 1, n):
                # 去重 b、c：连续三个相同数字去重逻辑
                if k > i + 2 and nums[k] == nums[k - 1] and nums[k - 1] == nums[k - 2]:
                    continue
                
                target = -(nums[i] + nums[k])
                if target in seen:
                    res.append([nums[i], target, nums[k]])
                    seen.remove(target)
                else:
                    seen.add(nums[k])
        return res


```

## 思路二

使用双向指针的操作，首先将数组排序，然后对于后续数值，采用双向指针的策略，target=0-nums[i],如果nums[left]+nums[right]小于target，那么移动右移左指针，如果大于，左移右指针,注意去重，因为只有当当前数组被记录的时候，才需要考虑去重问题：

```python
class Solution:
    def threeSum(self,nums:List[int]):
        nums.sort()
        res = []
        for i in range(len(nums)):
            
            if i > 0 and nums[i] == nums[i-1]:
                continue
            target = 0-nums[i]

            left = i+1
            right = len(nums) - 1

            while left < right:
                cursum = nums[left]+nums[right] 
                if cursum== target:
                    res.append([nums[i],nums[left],nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left-1]:
                        left += 1
                    while left < right  and nums[right] == nums[right+1]:
                        right -= 1

                elif cursum > target:
                    right -= 1
                else:
                    left += 1

        return res
```
