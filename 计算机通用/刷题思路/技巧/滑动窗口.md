# 滑动窗口

## 思想：

滑动窗口表示使用两个指针维持一个窗口，如果这个窗口满足一定条件，那么选择是否扩大还是缩减窗口。


## 经典题目

> 209. 长度最小的子数组

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        
        cursum = 0  #窗口当前的和
        minlen = len(nums) + 1  #初始化一个不可能的结果

        slow = fast = 0 #初始化窗口

        while fast < len(nums):
            cursum += nums[fast]

            while cursum >= target :    #[slow,fast]这个窗口的和是否满足>=target，如果满足，考虑缩小窗口
                cursum -= nums[slow]
                minlen = min(minlen,fast-slow+1)
                slow += 1
            fast += 1

        return minlen if minlen != len(nums)+1 else 0
                
```
