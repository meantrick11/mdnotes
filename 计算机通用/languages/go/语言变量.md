# Go语言变量

## 先声明再赋值

```
var id1,id2 type //默认声明的时候不赋值为零值，比如0,"",false

id1 = ?
id2 = ?

```

## 声明即赋值

```
var id3 string = "hello"
```

可以省略类型，编译器自行判断类型

```
var id3 = "hello"
```
## 函数内部独有的声明

```
id4 := "hello"
```

函数内部独有的声明方式,**在声明的时候就根据右侧的值自行判断类型**
如果id4已经被声明过，则会产生编译报错

**如果在相同的代码块中，我们不可以再次对于相同名称的变量使用初始化声明，例如：a := 20 就是不被允许的，编译器会提示错误 no new variables on left side of :=，但是 a = 20 是可以的，因为这是给相同的变量赋予一个新的值。**

**Go中不能对已经声明了的变量重复声明**
