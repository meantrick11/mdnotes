# Go 语言数组

Go 语言提供了数组类型的数据结构。**一旦定义，不可修改**

数组是具有相同唯一类型的一组已编号且长度固定的数据项序列，这种类型可以是任意的原始类型例如整型、字符串或者自定义类型。

相对于去声明 number0, number1, ..., number99 的变量，使用数组形式 numbers[0], numbers[1] ..., numbers[99] 更加方便且易于扩展。

数组元素可以通过索引（位置）来读取（或者修改），索引从 0 开始，第一个元素索引为 0，第二个索引为 1，以此类推。

## 声明数组
**注意：在 Go 语言中，数组的大小是类型的一部分，因此不同大小的数组是不兼容的，也就是说 [5]int 和 [10]int 是不同的类型。**
Go语言数组声明需要指定元素类型以及个数，格式：
`var arrayName [size]dataType`

## 初始化数组

### 声明+初始化

```go
// 写法1：指定长度 + 赋值
var arr1 [3]int = [3]int{1, 2, 3}

// 写法2：自动推导类型（推荐）
arr2 := [3]int{1, 2, 3}

// 写法3：不写长度，用 ... ,编译器自动推断并计算（最方便）
arr3 := [...]int{10, 20, 30, 40} // 长度自动变成4
```
### 部分初始化

`a := [5]int{1,2}`//[1,2,0,0,0]

### 指定初始化

`a := [5]int{0:1,3:50}`//[1,0,50,0,0]

## 访问数组

```go
1. 访问元素（下标从 0 开始）
arr := [3]int{10, 20, 30}

fmt.Println(arr[0])  // 10
fmt.Println(arr[2])  // 30
2. 修改元素

arr[1] = 999 // arr 变成 [10 999 30]
3. 获取数组长度

fmt.Println(len(arr)) // 3
4. 遍历数组

// 方式1：for 循环
for i := 0; i < len(arr); i++ {
    fmt.Println(arr[i])
}

// 方式2：for range（最常用）
for index, value := range arr {
    fmt.Println(index, value)
}

```

## 多维数组

Go 语言支持多维数组，以下为常用的多维数组声明方式：

```var variable_name [SIZE1][SIZE2]...[SIZEN]variable_type```

### 二维数组
#### 声明
`var arrayName [x][y]dataType`
#### 初始化
```go
a := [3][4]int{  
 {0, 1, 2, 3} ,   /*  第一行索引为 0 */
 {4, 5, 6, 7} ,   /*  第二行索引为 1 */
 {8, 9, 10, 11},   /* 第三行索引为 2 */
}
```
同理，也是变量，按照声明那一节的三种方式:①声明+赋值，②声明省略类型直接赋值，③函数内部:=直接声明赋值
