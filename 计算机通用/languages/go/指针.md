# 指针

**Go语言中的指针不像C语言中直接对地址+-运算**

## 基础概念

*dataType :表示指向某一类型的指针

&var :取地址草走

*指针 : 解引用，获取指针指向的对应地址的值

## 指针的声明

指针是Go语言中的一种变量类型，只不过只能指向一个值的内存地址，所以，声明和普通变量一样

```go
var i var_type = data//声明并赋值给一个变量
var var_name *var_type//声明指针，此时指向的是nil，空指针
var_name = &i//获取地址并保存到变量中
```

`var var_name *var_type = &i`

使用new函数创建指针
`p := new(int)`声明了一个指向int类型的指针，后续可赋值等操作

## 指针数组

指针作为Go语言中的一种类型，那么可以直接作为数组的声明类型
`var var_name [5]*int`声明了一个内含可以指向五个int的指针，同理，可以直接使用数组的索引访问方式访问数组元素，获取对应数组指针指向的地址

## 指向指针的指针

顾名思义，表示当前指针指向的是一个指针，而这个指针指向另外的变量地址

`var var_name **int = &i`,其中i是一个指向变量的地址的指针，然后将这个指针取地址，存入到双重指针当中

## 指针作为函数参数

一般的值传递都是赋值传递，即是将真值赋值，然后传递给函数。但是由于指针指向的是变量的地址，所以**一旦函数中对变量进行修改，则直接更改的是变量对应的值**
