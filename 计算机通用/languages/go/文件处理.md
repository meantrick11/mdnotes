# Go 语言文件处理
核心包由os，能够创建、读写、删除、权限等作用
标准流程:`os.Open()->bufio.Scanner->处理数据->defer.Close()

## 1. 文件创建

os.Create()创建一个新文件，如果已经存在，则会被截断(清空内存)，返回的文件队形必须关闭以释放系统资源。

```go
package main

import (
        "log"
        "os"
)

func main() {
        // os.Create 创建文件（已存在则清空）
        file, err := os.Create("test.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close() // defer 确保函数结束时关闭文件

        // 写入内容验证创建成功
        file.WriteString("文件创建成功\n")
        log.Println("文件创建成功")
}
```

**defer file.Close()是go文件的操作的最佳实践，defer确保后面即使代码出现panic，文件也会被正确关闭，避免文件描述符泄露。**

*defer的特性：
1. 延迟执行：只有等到函数返回或者结束的时候才执行
2. 一定执行：无论遇panic，函数退出或者正常执行到结尾，defer语句都执行
3. 倒序执行：最后的defer最先跑
4. 参数早算：声明时候参数就定死了
## 2. 文件的打开与关闭

os 包提供三种打开文件的方式，适用于不同场景：

| 函数 | 模式 | 说明 |
| ---- | ---- | ---- |
| os.Open(name) | 只读 | 最简单的方式，只读打开 |
| os.Create(name) | 读写 + 创建/截断 | 创建新文件或清空已有文件 |
| os.OpenFile(name, flag, perm) | 自定义 | 可指定读写、追加、创建等标志 |

**os.Create()底层相当于`os.OpenFile(name, os.O_RDWR|os.O_CREATE|os.O_TRUNC, 0666)`**

```go
package main

import (
        "fmt"
        "os"
)

func main() {
        // 方式1：只读打开
        file, err := os.Open("example.txt")
        if err != nil {
                fmt.Println("打开失败:", err)
                return
        }
        defer file.Close()
        fmt.Println("文件打开成功")

        // 方式2：OpenFile 自定义模式
        // os.O_WRONLY  只写
        // os.O_CREATE  不存在则创建
        // os.O_APPEND  追加模式
        // os.O_TRUNC   存在则截断
        f, err := os.OpenFile("log.txt",
                os.O_WRONLY|os.O_CREATE|os.O_APPEND, 0644)
        if err != nil {
                fmt.Println("打开失败:", err)
                return
        }
        defer f.Close()
        f.WriteString("追加一行日志\n")
}
```

## 3. 文件读取

### 3.1 一次性读取

适合小文件，不会占用过多内存，且自动打开、读取、关闭文件，一步到位。

```go
package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        // 一次性读取整个文件（Go 1.16+）
        data, err := os.ReadFile("config.json")
        if err != nil {
                log.Fatal(err)
        }

        fmt.Println(string(data))
}

```

### 3.2 逐行读取(大文件推荐)

对于大文件，使用bufio.Scanner()逐行处理，避免一次性加载到内存。但是要配合os.Open()&defer file.Close()使用。

```go
package main

import (
        "bufio"
        "fmt"
        "log"
        "os"
)

func main() {
        file, err := os.Open("large-file.log")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 逐行扫描
        scanner := bufio.NewScanner(file)
        lineNum := 0
        for scanner.Scan() {
                lineNum++
                line := scanner.Text() // 获取当前行内容
                fmt.Printf("第 %d 行: %s\n", lineNum, line)
        }

        // 检查扫描过程中是否出错
        if err := scanner.Err(); err != nil {
                log.Fatal("读取错误:", err)
        }
}
```
**注意：bufio.Scanner默认最大行长度为64KB，如果文件中有超长行，需要在调用Scan()前设置scanner.Buffer(make([]byte,0),maxSize)来增大缓冲区**

### 3.3 使用io.ReadAll读取

当你已经有一个打开的io.Reader（如网络响应，已打开的文件），可以使用io.ReadAll:

```go
package main

import (
        "fmt"
        "io"
        "log"
        "os"
)

func main() {
        file, err := os.Open("example.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 从 Reader 读取所有数据
        data, err := io.ReadAll(file)
        if err != nil {
                log.Fatal(err)
        }

        fmt.Println(string(data))
}
```

## 4. 文件写入

### 4.1 一次性写入

os.WriteFile将数据一次性写入文件(覆盖原有的内容)：
其中等效代码为：
```go
func WriteFile(name string, data []byte, perm FileMode) error {
    // 打开标志固定：O_WRONLY | O_CREATE | O_TRUNC
    f, err := OpenFile(name, O_WRONLY|O_CREATE|O_TRUNC, perm)
    if err != nil {
        return err
    }
    // 一次性把data全部写入
    _, err = f.Write(data)
    f.Close()
    return err
}
```
以覆盖方式打开，所以直接覆盖性写入。

示例如下：

```go
package main

import (
        "log"
        "os"
)

func main() {
        content := []byte("Hello, Go!\n这是第二行\n")

        // 0644: 所有者读写，其他用户只读
        err := os.WriteFile("output.txt", content, 0644)
        if err != nil {
                log.Fatal(err)
        }
        log.Println("写入成功")
}
```


### 4.2 使用File对象写入

根据你的文件打开方式，执行不同的写入行为，比如覆盖、追加等等。

通过文件对象写入，可以分多次写入内容：
```go
package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        file, err := os.Create("output.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 方式1：写入字符串
        file.WriteString("直接写入字符串\n")

        // 方式2：写入字节切片
        data := []byte("写入字节切片\n")
        file.Write(data)

        // 方式3：格式化写入
        fmt.Fprintf(file, "格式化写入: %d + %d = %d\n", 3, 4, 7)
}
```

## 5. 文件追加

底层通过使用os.O_APPEND标志在文件末尾追加内容，而不是覆盖内容

```go
package main

import (
        "log"
        "os"
        "time"
)

func main() {
        // O_APPEND: 追加模式
        // O_CREATE: 不存在则创建
        // O_WRONLY: 只写
        file, err := os.OpenFile("app.log",
                os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
        if err != nil {
                log.Fatal(err)
        }
        defer file.Close()

        // 每次运行都会追加，不会覆盖
        timestamp := time.Now().Format("2006-01-02 15:04:05")
        file.WriteString("[" + timestamp + "] 应用启动\n")
}
```

## 6. 文件删除与重命名

`os.Rename(old_name,new_name),os.remove(file_name)`

```go
package main

import (
        "log"
        "os"
)

func main() {
        // 重命名 / 移动文件
        err := os.Rename("old.txt", "new.txt")
        if err != nil {
                log.Fatal("重命名失败:", err)
        }
        log.Println("重命名成功")

        // 删除文件
        err = os.Remove("temp.txt")
        if err != nil {
                log.Fatal("删除失败:", err)
        }
        log.Println("删除成功")
}

```

## 7. 文件信息和检查

### 7.1 获取文件信息

**os.Stat(file_name)获取文件信息**

```go
package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        info, err := os.Stat("test.txt")
        if err != nil {
                log.Fatal(err)
        }

        fmt.Println("文件名:    ", info.Name())
        fmt.Println("大小:      ", info.Size(), "字节")
        fmt.Println("权限:      ", info.Mode())
        fmt.Println("修改时间:  ", info.ModTime())
        fmt.Println("是目录吗:  ", info.IsDir())
}
```

### 7.2 检查文件是否存在

Go中没有专门检查文件是否存在的函数，通过os.Stat()+os.IsNotExist判断：

```go
package main

import (
        "fmt"
        "os"
)

// fileExists 检查文件是否存在
func fileExists(path string) bool {
        _, err := os.Stat(path)
        return !os.IsNotExist(err)
}

func main() {
        if fileExists("test.txt") {
                fmt.Println("文件存在")
        } else {
                fmt.Println("文件不存在")
        }
}
```

## 8. 目录操作

使用`os.Mkdir(dir_name,1033)`创建单个目录，`os.MkdirAll(recursive_dir,0744)`创建递归目录，`os.ReadDir(dir_name)`读取目录内容，`os.Remove(dir_name)`删除空目录，`os.RemoveAll(path)`,递归删除目录以及所有内容.

```go
package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        // 创建单个目录
        err := os.Mkdir("newdir", 0755)
        if err != nil {
                log.Fatal(err)
        }

        // 递归创建多级目录（父目录不存在也会自动创建）
        err = os.MkdirAll("path/to/deep/dir", 0755)
        if err != nil {
                log.Fatal(err)
        }

        // 读取目录内容
        entries, err := os.ReadDir(".")
        if err != nil {
                log.Fatal(err)
        }
        for _, entry := range entries {
                mark := "&#x1f4c4;"
                if entry.IsDir() {
                        mark = "&#x1f4c1;"
                }
                fmt.Printf("%s %s\n", mark, entry.Name())
        }

        // 删除空目录
        os.Remove("newdir")

        // 递归删除目录及其所有内容（&#x26a0; 谨慎使用）
        os.RemoveAll("path")
}
```
## 9. 高级操作

### 9.1 文件复制

`io.Copy()`在两个文件之间高效复制数据

```go
package main

import (
        "io"
        "log"
        "os"
)

// copyFile 复制文件的通用函数
func copyFile(src, dst string) (int64, error) {
        srcFile, err := os.Open(src)
        if err != nil {
                return 0, err
        }
        defer srcFile.Close()

        dstFile, err := os.Create(dst)
        if err != nil {
                return 0, err
        }
        defer dstFile.Close()

        // io.Copy 自动管理缓冲区，高效复制
        return io.Copy(dstFile, srcFile)
}

func main() {
        n, err := copyFile("source.txt", "destination.txt")
        if err != nil {
                log.Fatal(err)
        }
        log.Printf("复制完成，共 %d 字节", n)
}
```

### 9.2 临时文件和目录

`os.CreateTemp("","app-*.txt")`系统自动命名

```go
package main

import (
        "fmt"
        "log"
        "os"
)

func main() {
        // 创建临时文件（自动命名，前缀为 "app-"）
        tmpFile, err := os.CreateTemp("", "app-*.txt")
        if err != nil {
                log.Fatal(err)
        }
        defer os.Remove(tmpFile.Name()) // 用完后清理
        fmt.Println("临时文件:", tmpFile.Name())

        // 创建临时目录
        tmpDir, err := os.MkdirTemp("", "app-*")
        if err != nil {
                log.Fatal(err)
        }
        defer os.RemoveAll(tmpDir) // 用完后清理
        fmt.Println("临时目录:", tmpDir)
}
```

### 9.4 跨平台路径拼接

永远不要用字符串拼接路径（如 dir + "/" + file），使用 filepath.Join 确保跨平台兼容：
```go
// 错误：Windows 上路径分隔符是 \
path := "dir" + "/" + "file.txt"

// 正确：自动适配当前操作系统
path := filepath.Join("dir", "file.txt")
```
