## Go基础语法

### 行分隔符

go程序中，每行代表一个语句结束，然后由编译器自行完成
如果要同一行写多个语句，必须得使用;分隔区分（不鼓励）

### 注释

注释不会被编译，单行注释//,多行注释/* */

### 标识符

用来命名变量、类型的等程序实体，一个标识符实际上就是一个或是多个字母(A~Z和a~z)数字(0~9)、下划线_组成的序列，但是第一个字符必须是字母或下划线而不能是数字。

### 字符串连接

使用`+`可直接连接，如`"Goole"+"Play"`

### go语言中的空格

1. 在 Go 语言中，空格通常用于分隔标识符、关键字、运算符和表达式，以提高代码的可读性：
`const Pi float64 = 3.14159265358979323846 `
2. 在运算符和操作数之间留空格
`fruit = apples + oranges; `
3. 在关键字和表达式之间要使用空格。
```
if x > 0 {

}
```
4. 在函数调用时，函数名和左边等号之间要使用空格，参数之间也要使用空格。
`result := add(2, 3)`

### go格式化字符串
Go 语言中使用 fmt.Sprintf 或 fmt.Printf 格式化字符串并赋值给新串：

Sprintf 根据格式化参数生成格式化的字符串并**返回该字符串。**
Printf 根据格式化参数生成格式化的字符串并**写入标准输出**。
