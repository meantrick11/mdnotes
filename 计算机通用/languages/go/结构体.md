# Go 语言结构体

Go语言中数组可以存储同一类型的数据，但在结构体中我们可以定义不同类型的数据类型。

## 定义结构体

结构体的定义需要使用type&struct。struct语句定义一个新的数据类型，结构体中有一个或多个成员，type语句设定了结构体的名称，街头提的格式如下：
```go
type struct_variable_type struct {
   member definition
   member definition
   ...
   member definition
}
```

一旦有了结构体类型，它就能用与变量的声明，语法格式如下；

```go
variable_name := structure_variable_type {value1, value2...valuen}
或
variable_name := structure_variable_type { key1: value1, key2: value2..., keyn: valuen}
```
举例：
```go
package main

import "fmt"

type Books struct {
   title string
   author string
   subject string
   book_id int
}


func main() {

    // 创建一个新的结构体
    fmt.Println(Books{"Go 语言", "www.runoob.com", "Go 语言教程", 6495407})

    // 也可以使用 key => value 格式
    fmt.Println(Books{title: "Go 语言", author: "www.runoob.com", subject: "Go 语言教程", book_id: 6495407})

    // 忽略的字段为 0 或 空
   fmt.Println(Books{title: "Go 语言", author: "www.runoob.com"})
}
```

## 访问结构体成员

如果要访问结构体成员，需要用点号.操作符，格式如:`结构体.成员名`

**举例**：
```go
package main

import "fmt"

type Books struct {
   title string
   author string
   subject string
   book_id int
}

func main() {
   var Book1 Books        /* 声明 Book1 为 Books 类型 */
   var Book2 Books        /* 声明 Book2 为 Books 类型 */

   /* book 1 描述 */
   Book1.title = "Go 语言"
   Book1.author = "www.runoob.com"
   Book1.subject = "Go 语言教程"
   Book1.book_id = 6495407

   /* book 2 描述 */
   Book2.title = "Python 教程"
   Book2.author = "www.runoob.com"
   Book2.subject = "Python 语言教程"
   Book2.book_id = 6495700

   /* 打印 Book1 信息 */
   fmt.Printf( "Book 1 title : %s\n", Book1.title)
   fmt.Printf( "Book 1 author : %s\n", Book1.author)
   fmt.Printf( "Book 1 subject : %s\n", Book1.subject)
   fmt.Printf( "Book 1 book_id : %d\n", Book1.book_id)

   /* 打印 Book2 信息 */
   fmt.Printf( "Book 2 title : %s\n", Book2.title)
   fmt.Printf( "Book 2 author : %s\n", Book2.author)
   fmt.Printf( "Book 2 subject : %s\n", Book2.subject)
   fmt.Printf( "Book 2 book_id : %d\n", Book2.book_id)
}
```

## 结构体作为函数参数

由于结构体定义之后，相当于一种新的数据类型，所以同样可以作文参数传递给函数

```go
package main

import "fmt"

type Books struct {
   title string
   author string
   subject string
   book_id int
}

func main() {
   var Book1 Books        /* 声明 Book1 为 Books 类型 */
   var Book2 Books        /* 声明 Book2 为 Books 类型 */

   /* book 1 描述 */
   Book1.title = "Go 语言"
   Book1.author = "www.runoob.com"
   Book1.subject = "Go 语言教程"
   Book1.book_id = 6495407

   /* book 2 描述 */
   Book2.title = "Python 教程"
   Book2.author = "www.runoob.com"
   Book2.subject = "Python 语言教程"
   Book2.book_id = 6495700

   /* 打印 Book1 信息 */
   printBook(Book1)

   /* 打印 Book2 信息 */
   printBook(Book2)
}

func printBook( book Books ) {
   fmt.Printf( "Book title : %s\n", book.title)
   fmt.Printf( "Book author : %s\n", book.author)
   fmt.Printf( "Book subject : %s\n", book.subject)
   fmt.Printf( "Book book_id : %d\n", book.book_id)
}
```

## 结构体指针

由于结构体定义之后作为新的一种数据类型，所以同样可以定义其对应的指针

```go
//声明结构体指针
var struct_point *Books
//将结构体实例的地址存储到结构体指针中
```

### 结构体的方法和函数体的方法

<!-- 如果是结构体含有的方法，编译器的语法糖，无论你传入的是结构体指针还是结构体实例，底层会自动帮你转换，就算是传入结构体指针，也可以通过book.name直接访问属性，底层语法糖会(*pi).name,其中pi=&book,与传入实例，通过book.name访问结构一样，区别就是，前者如果限制了需要传入指针， -->

#### 一、结构体方法（自带编译器语法糖）
##### 1. 访问结构体字段（`.` 自动解引用）
不管变量是实例 `T` 还是指针 `*T`，统一用 `.字段`，不用手动写 `*`：
- 指针变量 `pi := &book`：`pi.name` → 底层自动转为 `(*pi).name`
- 实例变量 `book`：`book.name`，直接访问无转换

##### 2. 调用方法（双向自动适配类型）
1. 方法接收者为指针 `(b *Book)`：
   - 传实例 `book.Func()` → 编译器自动转 `(&book).Func()`，无需手动加 `&`
2. 方法接收者为值 `(b Book)`：
   - 传指针 `pi.Func()` → 编译器自动转 `(*pi).Func()`，无需手动解引用 `*`
3. 核心特性：**写法统一，不用手动转换 &/***
4. 底层差异：
   - 指针接收者：传递原对象地址，方法内修改字段会作用于外部原变量，无结构体拷贝
   - 值接收者：完整拷贝结构体副本，方法内修改仅生效在副本，外部原数据不变

#### 二、普通函数（无任何语法糖，类型必须严格匹配）
普通函数参数不会自动做取地址/解引用转换，传参类型必须和形参完全一致：
1. 函数形参为指针 `func f(b *Book)`：
   - `f(book)` 直接报错，必须手动取地址 `f(&book)`
2. 函数形参为实例 `func f(b Book)`：
   - `f(pi)` 直接报错，必须手动解引用 `f(*pi)`

#### 三、什么时候必须手动写 `&` / `*`
1. 给变量赋值：`pi := &book`、`copyBook := *pi`
2. 调用普通函数传参，类型不匹配时
3. 只有结构体的 `.字段`、`.方法()` 操作会自动转换，其余场景无语法糖

#### 四、一句话区分记忆
1. 结构体方法：点操作万能，实例、指针随便调用，编译器自动转换；指针接收者可修改原数据，值接收者仅只读副本。
2. 普通函数：类型严格一对一，要指针必须传 `&实例`，要实例必须传 `*指针`，不会自动适配。
