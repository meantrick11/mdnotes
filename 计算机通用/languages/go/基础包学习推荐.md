### 🧱 核心基础包 (几乎所有程序都会用到)
这些是 Go 语言的基石，提供了最基础的输入输出、字符串和系统交互能力。

*   **`fmt`**：格式化输入输出，最常用的是 `Println`、`Printf` 打印信息，以及 `Sprintf` 生成格式化字符串。
*   **`os`**：提供操作系统接口，用于文件操作（创建、打开、读写、删除）、环境变量、命令行参数 (`os.Args`) 等。
*   **`io`**：定义了 `io.Reader` 和 `io.Writer` 等核心接口，是数据流读写（如文件、网络）的抽象基础。
*   **`strings`**：提供丰富的字符串操作函数，如分割、连接、查找、替换、大小写转换等。
*   **`strconv`**：实现字符串与基础数据类型（整型、浮点型、布尔型等）之间的相互转换。
*   **`time`**：提供时间的显示、测量、格式化、解析以及定时器（`Timer`、`Ticker`）等功能。

### 🌐 常用功能包 (处理特定任务)
这些包是日常开发特定功能时的“主力军”，非常实用。

*   **`encoding/json`**：处理 JSON 数据的编解码（序列化与反序列化），是开发 Web 服务时最常用的包之一。
*   **`net/http`**：提供 HTTP 客户端和服务端的完整实现，几行代码就能启动一个 Web 服务或发送 HTTP 请求。
*   **`sync`**：提供并发控制的基础原语，如互斥锁（`Mutex`）、等待组（`WaitGroup`）等，用于安全地操作共享资源。
*   **`flag`**：用于解析命令行参数，是开发命令行工具（CLI）的必备包。
*   **`log`**：提供简单的日志记录功能，可以设置日志前缀、输出目标等。

### 📚 按功能分类的其他重要包
为了更系统地了解，这里按功能领域划分了更多重要的包。

*   **输入输出**：**`bufio`** - 提供带缓冲的 I/O，能提高读写效率。
*   **文本处理**：**`bytes`** - 操作字节切片；**`regexp`** - 正则表达式引擎。
*   **网络编程**：**`net`** - 提供网络套接字、IP 和端口解析等底层网络操作。
*   **系统相关**：**`time`**（计时与休眠）、**`unsafe`**（提供绕过 Go 类型安全的能力，需谨慎使用）。
*   **数据结构与算法**：**`sort`** - 切片和自定义集合的排序；**`container/heap`** - 堆操作；**`math`** - 数学常数和函数。
*   **编码与加密**：**`encoding`** 下的子包如 `encoding/base64`、`encoding/xml`；**`crypto`** 下的子包提供哈希（`md5`、`sha256`）及加解密功能。
*   **运行时与反射**：**`runtime`** - 与 Go 运行时交互（如控制协程、获取栈信息）；**`reflect`** - 提供运行时反射能力，在特定框架或序列化库中常用。

### 🚀 如何高效学习和使用？

1.  **首选官方文档**：最权威、最详细的资料永远是 [Go 官方标准库文档](https://pkg.go.dev/std)。你也可以在命令行使用 `go doc` 快速查看文档，例如 `go doc fmt.Printf`。
2.  **“Just-in-Time”学习**：不需要一次性记住所有包。最好的方式是**在需要实现某个功能时，再去查阅标准库是否提供了现成的解决方案**。这种方式记忆更深刻。
3.  **从源码中学习**：Go 标准库的源码就在你的 Go 安装目录下，且代码质量极高，并附有详尽的示例和注释，是学习 Go 语言设计理念的最佳材料。
