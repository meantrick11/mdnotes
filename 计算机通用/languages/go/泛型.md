## Go 语言泛型

分类：
- 类型参数：允许你在函数或类型定义中使用一个或多个类型作为参数

- 类型约束：指定类型参数必须要满足的条件，确保函数内部能够安全地操作这些类型
### 概念对照表
| 概念 | 作用 | 示例 |
| ---- | ---- | ---- |
| 类型参数 | 在函数/类型名后声明，代表待定的类型 | `[T any]` |
| 类型约束 | 规定类型参数必须满足的条件（支持的运算符、方法等） | `int`、`float64`、`comparable`、`constraints.Ordered`、`any` |
| any | 约束类型参数可接收任意类型 | `[T any]` |
| comparable | 约束类型参数为支持==/!=比较的类型 | `[K comparable]` |

**泛型核心说明**
1. 泛型（Generics）作用：编写不绑定特定数据类型的通用代码；
2. **无泛型时代码痛点：处理多种类型数据时，要为每种类型重复编写几乎一样的函数。**

### 类型参数声明

```go
// 基本语法结构
func 函数名[T 约束](参数 T) 返回值类型 {
    // 函数体
}

type 类型名[T 约束] struct {
    // 结构体字段
}
```
类型参数命名约定
通常使用大写字母：T、K、V、E 等
- T：表示 Type（类型）
- K：表示 Key（键）
- V：表示 Value（值）
- E：表示 Element（元素）

### 约束

约束定义了类型参数必须满足地条件，是泛型地核心概念

2. comparable约束

comparable 表示类型支持 == 和 != 操作符。
**支持比较的类型，如：数字类：int系列，float32，float64,bool,string,*T,chan T,[N]T,结构体，接口**
```go
实例
func FindIndex[T comparable](slice []T, target T) int {
    for i, v := range slice {
        if v == target {
            return i
        }
    }
    return -1
}

// 使用示例
numbers := []int{1, 2, 3, 4, 5}
fmt.Println(FindIndex(numbers, 3))  // 输出: 2

names := []string{"Alice", "Bob", "Charlie"}
fmt.Println(FindIndex(names, "Bob"))  // 输出: 1
```
3. 联合约束

使用 | 运算符组合多个类型

```go
// 数字类型约束
type Number interface {
    int | int8 | int16 | int32 | int64 | 
    uint | uint8 | uint16 | uint32 | uint64 | 
    float32 | float64
}

func Add[T Number](a, b T) T {
    return a + b
}

// 使用示例
fmt.Println(Add(10, 20))        // 输出: 30
fmt.Println(Add(3.14, 2.71))    // 输出: 5.85
```

#### 自定义约束

1. 方法约束
定义需要特定的方法约束

```go
// 定义 Stringer 约束
type Stringer interface {
    String() string
}

func PrintString[T Stringer](value T) {
    fmt.Println(value.String())
}


// 实现自定义类型
type Person struct {
    Name string
    Age  int
}

func (p Person) String() string {
    return fmt.Sprintf("%s (%d years old)", p.Name, p.Age)
}

// 使用示例
person := Person{Name: "Alice", Age: 25}
PrintString(person)  // 输出: Alice (25 years old)
```

上述类型的约束表示，只有支持接口的接口体才能调用PrintString这个函数，实现通过自定义接口约束。

#### 复杂约束

结合类型和方法要求：
```go
// 要求类型是数字且实现 String() 方法
type NumericStringer interface {
    Number
    String() string
}
```
要求实现了Number接口类并且有String这个内置方法的结构体。

### 类型判断
Go编译器能够自行推断类型参数，让代码更简洁
```go

// 无需显式指定类型
func main() {
    // 类型推断示例
    fmt.Println(Max([]int{1, 2, 3}))        // 编译器推断 T 为 int
    fmt.Println(Max([]float64{1.1, 2.2}))   // 编译器推断 T 为 float64
    
    // 显式指定类型（有时需要）
    var result int = Max[int]([]int{1, 2, 3})
    fmt.Println(result)
}
```

### Go泛型常见问题与注意事项
#### 1. 性能考虑
泛型在编译时进行类型特化，运行时性能与手写特定类型代码相当。

#### 2. 类型约束的选择
- 使用 `any`：灵活性最高，但可执行的操作功能受限
- 使用 `comparable`：允许使用 `==`、`!=` 做相等比较
- 使用联合约束：限定只能使用指定范围内的具体类型

#### 3. 错误处理（实例）
```go
// 良好的错误处理实践
func SafeMax[T Number](slice []T) (T, error) {
	if len(slice) == 0 {
		var zero T
		return zero, errors.New("slice is empty")
	}
	return Max(slice), nil
}
```
逻辑说明：
切片为空时，通过 `var zero T` 获取类型T的零值，搭配错误返回；切片非空则返回最大值与 `nil`。
