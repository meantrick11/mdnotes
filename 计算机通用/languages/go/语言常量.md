# Go语言常量

## const 关键字

```
const identifier [type] = value
```

## 枚举效果

```
const (
    Unknown = 0
    Female = 1
    Male = 2
)
```

## 内置函数在常量中的应用

```
package main

import (
    "fmt"
    "unsafe"
)

const (
    a = "abc"
    b = len(a)
    c = unsafe.Sizeof(a)//获取变量的内存占用，16bit
)
```

## iota 常量计数器
iota 是 Go 语言的特殊常量，也称为常量计数器。它可以在 const 声明块中自动生成递增的序列值。

重要特性：

- iota 在 const 关键字出现时将被重置为 0。
- const 中每新增一行常量声明，iota 自动计数加 1。
- 可以理解为 const 语句块中的行索引（从 0 开始）。

```
package main

import "fmt"

func main() {
    const (
        a = iota   // 0
        b          // 1
        c          // 2
        d = "ha"   // 独立值，iota += 1
        e          // "ha"，iota += 1
        f = 100    // 独立值，iota += 1
        g          // 100，iota += 1
        h = iota   // 7，恢复使用 iota 值
        i          // 8
    )
    fmt.Printf("a=%d, b=%d, c=%d, d=%s, e=%s, f=%d, g=%d, h=%d, i=%d\n", a, b, c, d, e, f, g, h, i)
}
```
