# Go 错误处理

Go 语言通过内置的错误接口提供了非常简单的错误处理机制。

Go 语言的错误处理采用显式返回错误的方式，而非传统的异常处理机制。这种设计使代码逻辑更清晰，便于开发者在编译时或运行时明确处理错误。

Go 的错误处理主要围绕以下机制展开：

- error 接口：标准的错误表示。
- 显式返回值：通过函数的返回值返回错误。
- 自定义错误：可以通过标准库或自定义的方式创建错误。
- panic 和 recover：处理不可恢复的严重错误。

## error 接口

Go标准库定义了一个error接口，表示一个错误的抽象，error类型是一个接口类型，定义：
```go
type error interface {
    Error() string
}
```
- 实现error接口：任何实现了Error()方法的类型都可以作为错误

- Error()方法返回了一个错误的字符串

### 使用errors包创建错误

```go
package main

import (
    "errors"
    "fmt"
)

func main() {
    err := errors.New("this is an error")
    fmt.Println(err) // 输出：this is an error
}
```

## 显式返回错误
Go中，错误通常作为函数的返回值返回，开发者需要显示检查并处理

```go
package main

import (
        "errors"
        "fmt"
)

func divide(a, b int) (int, error) {
        if b == 0 {
                return 0, errors.New("division by zero")
                //使用error.New()函数创建一个错误
        }
        return a / b, nil
}

func main() {
        result, err := divide(10, 0)
        if err != nil {
                fmt.Println("Error:", err)
        } else {
                fmt.Println("Result:", result)
        }
}
```

## 自定义错误

通过定义自定义类型，可以扩展error接口

```go
package main

import (
        "fmt"
)
//定义结构体
type DivideError struct {
        Dividend int
        Divisor  int
}
//实现结构体的Error接口，，使用指针定义实现，也可以具体的DivideError类
//实现具体的error接口
func (e *DivideError) Error() string {
        return fmt.Sprintf("cannot divide %d by %d", e.Dividend, e.Divisor)
}

func divide(a, b int) (int, error) {
        if b == 0 {
                //返回&DivideError，用error接收
                return 0, &DivideError{Dividend: a, Divisor: b}//返回具体的错误
        }
        return a / b, nil
}

func main() {
        _, err := divide(10, 0)
        //触发接收error错误
        if err != nil {
                //Println发现err是一个错误，调用err.Error()方法，然后就输出了cannot divide 10 by 0\
                fmt.Println(err) // 输出：cannot divide 10 by 0
        }
}
```

## 使用errors.ls和errors.As

检查某个错误是否特定错误或由该错误包装而成
```go
package main

import (
        "errors"
        "fmt"
)

var ErrNotFound = errors.New("not found")

func findItem(id int) error {
        return fmt.Errorf("database error: %w", ErrNotFound)
}

func main() {
        err := findItem(1)
        if errors.Is(err, ErrNotFound) {
                fmt.Println("Item not found")
        } else {
                fmt.Println("Other error:", err)
        }
}
```

## panic 和recover


Go 的 panic 用于处理不可恢复的错误，recover 用于从 panic 中恢复。

panic:

- 导致程序崩溃并输出堆栈信息。
- 常用于程序无法继续运行的情况。
recover:

- 捕获 panic，避免程序崩溃。

```go
package main

import "fmt"

func safeFunction() {
        defer func() {//延迟执行函数，用于捕捉函数中的panic
                if r := recover(); r != nil {
                        fmt.Println("Recovered from panic:", r)
                }
        }()
        //故意制造一个panic，被上述延迟函数捕捉
        panic("something went wrong")
}

func main() {
        fmt.Println("Starting program...")
        safeFunction()
        fmt.Println("Program continued after panic")
}
```
