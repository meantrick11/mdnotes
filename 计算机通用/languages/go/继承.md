# 菜鸟Go继承页面精简笔记（两种嵌入=两种伪继承）
## 核心前提
Go **没有真正类继承**，页面标题的“继承”只是**匿名结构体嵌入（组合）**，靠语法糖模拟，本质是「包含」不是「父子is-a」。
两种嵌入方式：**嵌入值结构体**、**嵌入结构体指针**。
**继承的实现都是通过结构体中嵌入其他结构体，然后进而通过语法糖的转换，类似外层结构体实现了内层结构体的方法，实际上是伪继承**
## 一、方式1：嵌入值 `Vehicle`
```go
type Car struct {
    Vehicle // 直接写结构体类型（值嵌入）
    Model string
}
```
### 语法糖
1. 字段简写：`car.Brand` = `car.Vehicle.Brand`
2. 方法简写：`car.Start()` = `(&car.Vehicle).Start()`
编译器自动对内部值取地址，匹配指针接收者方法。
### 特点
1. Car内部完整存一份Vehicle副本，数据独立；
2. 调用父方法时编译器自动`&`；
3. 赋值必须显式写`Vehicle: Vehicle{}`。

## 二、方式2：嵌入指针 `*Vehicle`
```go
type Car struct {
    *Vehicle // 嵌入结构体指针
    Model string
}
```
### 语法糖
1. 同样简写字段：`car.Brand` = `(*car.Vehicle).Brand`
2. 方法简写：`car.Start()` = `car.Vehicle.Start()`，无需额外取地址。
### 特点
1. Car只存Vehicle内存地址，不拷贝数据；多结构嵌入可共享同一份Vehicle；
2. 赋值必须传地址`Vehicle: &Vehicle{}`。

## 三、通用关键区分（和真实继承划清界限）
1. **类型完全独立**
Car/Vehicle是两个无关类型，`&Car`不能直接传给`*Vehicle`形参，必须手动`&car.Vehicle`，无父子转换。
2. **同名方法是屏蔽，不是重写**
Car写同名Start后，`car.Start()`优先走Car自身；想调用内嵌方法要手动`car.Vehicle.Start()`，无OOP多态。
3. 语法糖仅作用于`.字段`、`.方法调用`，普通函数传参不自动转换。

## 极简总结
1. 嵌入值：内部存完整副本，调用父方法自动`&`；
2. 嵌入指针：内部存地址，共享数据，无需自动取地址；
3. 二者都只是语法糖简写，不是真正继承，类型不互通。
