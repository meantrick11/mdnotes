## Go语言结构

组成：
1. 包声明（指明该文件属于哪一个具体的包，以便后续包引入）--同一个文件夹下的所有.go文件，必须用同一个包名声明
```
your-project/
├── folder1/        # 文件夹1
│   ├── a.go        # package folder1
│   G── b.go        # package folder1
│   └── c.go        # package folder1
└── folder2/        # 文件夹2
    ├── x.go        # package folder2
    └── y.go        # package folder2
```
2. 引入包,从标准库或者自定义文件中引入包，引入语句：
```go
import (
    "fmt"
    "math"
    "mydemo/utils"
)
```
引入自己的包：
```
mydemo/
├── go.mod          ← 必须有
├── main.go         ← package main 每个项目只有一个主运行文件
└── utils/          ← 文件夹 = 包名
    ├── tool1.go    ← package utils
    └── tool2.go    ← package utils
```
**包中的函数、变量、常量想要被引用需要首字母大写**
然后执行`go mod init mydemo(创建go.mod)`
在main中引入：
    - 正常引入：`import "mydemo/utils"`
    - 别名引入: `import u(别名) "mydemo/utils"`
    - 点引入(后续使用不用写包名): `import . "mydemo/utils"`，直接使用Add()
    - 匿名引用: `import _ "database/sql"`，只执行初始化，不调用函数
3. 函数,使用`func main(){
    语句
}`定义，其中"{"不能单独放为一行。
4. 变量
5. 语句&表达式
6. 注释：//或者/**/

### 执行go程序

1. 使用`go run hello.go`直接执行
2. 编译为二进制文件执行`go build hello.go`，然后找到并双击或者cmd-./hello.exe直接执行
