# 过滤和排序

## Filtering

将查询结果结果去重返回

```sql
SELECT DISTINCT column, another_column, …
FROM mytable
WHERE condition(s);

```

## Ordering

ORDER BY colume ASC/DESC
表示升序或降序排序筛选结果
```sql
SELECT column, another_column, …
FROM mytable
WHERE condition(s)
ORDER BY column ASC/DESC;
```
## Limiting

Limit number OFFSET number_offset;
从筛选结果中选择前多少条返回，OFFSET表示偏移量

```sql
SELECT column, another_column, …
FROM mytable
WHERE condition(s)
ORDER BY column ASC/DESC
LIMIT num_limit OFFSET num_offset;
```
