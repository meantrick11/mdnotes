## 🔴 核心必学（占日常开发 80% 场景，务必吃透）

**Section 1-2：查询与过滤**
Select / Where / Order By / Limit / In / Between / Like / Is Null
→ 这是每天都在写的东西，CRUD 里的 R 全靠它

**Section 3：多表连接**
Joins / Inner Join / Left Join
→ 全栈开发数据关联查询的核心，Self-join / Full Outer / Cross / Natural Join 可以先略读，知道概念即可，用到再查

**Section 4：分组统计**
Group By / Having
→ 做统计报表、聚合数据（比如"每个用户的订单数"）必用

**Section 9：数据增删改**
Insert / Insert multiple rows / Update / Delete / Upsert
→ CRUD 的 C/U/D，Upsert 在写"存在则更新，不存在则插入"逻辑时非常实用（对应 ORM 里的 `upsert`）

**Section 12：建表与管理**
Data types / Create table / Alter table / Add column / Drop column
→ 设计 schema、写 migration 文件必备

**Section 13：约束**
Primary key / Foreign key / Unique / Not Null / Default / Delete Cascade
→ 保证数据完整性，设计数据库关系时天天用

**Section 14（挑重点）：常用数据类型**
CHAR/VARCHAR/TEXT、Integer、Boolean、Timestamp、UUID、**JSON/JSONB**、Array
→ JSON/JSONB 对全栈开发者尤其重要（存半结构化数据），UUID 常用作主键

## 🟡 进阶必学（当项目变复杂时会用到，建议学但不用死记）

- **Section 7：子查询** — Subquery、EXISTS 用得较多，ANY/ALL 了解即可
- **Section 8：CTE**（`WITH` 语句）— 写复杂查询时让 SQL 可读性大幅提升，推荐掌握，递归 CTE 可以先跳过
- **Section 10：事务**（Transaction）— 涉及多步操作要保证原子性时（比如转账、下单扣库存）必须掌握 BEGIN/COMMIT/ROLLBACK
- **Section 16：psql 常用命令** — 用命令行调试数据库时有用，但如果你主要用 GUI 工具（TablePlus/DBeaver）或 ORM，可以先跳过

## 🟢 按需查阅，不必现在学（先扫一眼知道存在即可）

- Section 5-6：集合操作（Union/Intersect/Except）、Grouping Sets/Cube/Rollup — 报表分析场景才用
- Section 11：CSV 导入导出 — 需要时再查
- Section 15：CASE/COALESCE/NULLIF/CAST — 用到时现查很快，不必专门背
- Section 17：Recipes（去重、随机数、EXPLAIN）— **EXPLAIN 例外，建议了解**，做性能优化时会用
- Section 14 剩余类型：hstore、XML、BYTEA、Composite Types、Enum、自定义类型 — 特定场景才需要

## ⚪ Advanced Tutorial（暂缓，等你独立负责数据库设计/优化时再学）

PL/pgSQL、Triggers、Views、Indexes、Administration
→ 这些偏 DBA 向。**唯一例外是 Indexes**，如果你的应用查询变慢了，理解索引原理会直接影响你能不能优化好，建议提前预习一下基础概念（B-tree 索引、何时该加索引）。

### 给你的学习路线建议

1. 先花 1-2 周把 🔴 核心必学 部分全部动手敲一遍（用 Neon 建个免费库直接练）
2. 做一个小项目（比如一个 Todo App 或博客后端），强制自己在真实场景里用到 Join、事务、约束
3. 遇到卡壳的地方，再回来查 🟡 或 🟢 部分对应章节
4. 索引和性能优化留到项目跑起来变慢之后再学——那时候你会更有体感
