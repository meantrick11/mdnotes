# 类型注释

使用类型注释，编辑器会自动匹配对应类型的方法

## 变量注释

a = str

def full_name(first:str,last:str)->str:
    pass

Python中的基础注释类型有：
1. int
2. float
3. str
4. bool
6. list
7. dict
8. tuple
9. set
10. callable
11. object

## Union

def process(item:str | List |None...):
    pass

使用联合注释的方法指定某一个item有多个类型可选

## 带有元数据注释的类型
Python中的typing库有Annotated这个函数，可以放置一个类型的元数据。

Python还有一个特性，允许使用 Annotated 在类型提示中放置额外的 元数据。
