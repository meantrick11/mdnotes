# 1. 获取**当前运行脚本所在目录**（最常用）
```python
import os

# 当前脚本的完整路径
script_path = __file__

# 当前脚本所在的目录
script_dir = os.path.dirname(script_path)

print("脚本目录：", script_dir)
```

---

# 2. 获取**当前工作目录**（你在哪里运行的 Python）
```python
import os

current_dir = os.getcwd()
print("当前工作目录：", current_dir)
```

---

# 3. 获取**上级目录**
```python
import os

current_dir = os.getcwd()
parent_dir = os.path.dirname(current_dir)

print("上级目录：", parent_dir)
```

---

# 4. 拼接路径（最安全）
不要手动拼 `/` 或 `\`，用 `os.path.join()` 跨平台兼容：
```python
import os

dir_path = os.path.dirname(__file__)
file_path = os.path.join(dir_path, "data.txt")

print("完整文件路径：", file_path)
```

---

# 5. 现代写法：pathlib（Python 3.4+ 推荐）
更简洁、更面向对象：
```python
from pathlib import Path

# 当前脚本目录
script_dir = Path(__file__).parent

# 拼接路径
file_path = script_dir / "data.txt"

print(script_dir)
print(file_path)
```

---

# 6. 获取**文件所在的绝对路径**
```python
import os

abs_path = os.path.abspath(__file__)
abs_dir = os.path.dirname(abs_path)

print("绝对路径：", abs_path)
print("绝对目录：", abs_dir)
```

---

# 最常用总结（你直接背这两句）
```python
# 1. 获取当前脚本所在目录（最常用）
import os
dir_path = os.path.dirname(os.path.abspath(__file__))

# 2. 现代写法（推荐）
from pathlib import Path
dir_path = Path(__file__).parent
```

---

### 总结
- **`__file__`** = 当前脚本路径
- **`os.path.dirname()`** = 取目录
- **`os.getcwd()`** = 取工作目录
- **`Path(__file__).parent`** = 现代最简洁写法
