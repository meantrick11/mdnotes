# Python math模块函数总表（常用优先，同你截图两栏表格格式）

abs(x)
min(x1,...)
max(x1,...)
round(x,[n])
为全局函数，皆可直接使用
## 一、基础数值运算（最高频常用）
| 函数 | 描述 |
| ---- | ---- |
| fabs(x) | 返回浮点数x的绝对值 |
| ceil(x) | 向上取整，返回大于等于x的最小整数 |
| floor(x) | 向下取整，返回小于等于x的最大整数 |
| round() | 内置函数，math无，附：四舍五入保留指定小数位 |
| sqrt(x) | 返回x的平方根，x≥0 |
| pow(x, y) | 返回x的y次幂，等价x**y，浮点精度更优 |
| fmod(x, y) | 返回x除以y的浮点余数 |
| modf(x) | 返回二元组(小数部分,整数部分)，拆分浮点数 |
| factorial(x) | 返回非负整数x的阶乘，负数/小数报错 |
| gcd(a, b) | 返回两个整数的最大公约数 |
| fsum(iterable) | 精确求和可迭代对象，避免浮点累加误差 |

## 二、幂、指数、对数（高频）
| 函数 | 描述 |
| ---- | ---- |
| exp(x) | 返回自然常数e的x次幂 e^x |
| expm1(x) | 返回 e^x - 1，极小x时精度更高 |
| log(x[, base]) | 默认求自然对数ln(x)；传base则求log₍base₎x |
| log10(x) | 返回以10为底的对数 lg(x) |
| log2(x) | 返回以2为底的对数 log₂(x) |

## 三、三角函数（你截图原有，常用）
| 函数 | 描述 |
| ---- | ---- |
| sin(x) | 返回x弧度的正弦值 |
| cos(x) | 返回x弧度的余弦值 |
| tan(x) | 返回x弧度的正切值 |
| asin(x) | 返回x的反正弦弧度值，x范围[-1,1] |
| acos(x) | 返回x的反余弦弧度值，x范围[-1,1] |
| atan(x) | 返回x的反正切弧度值，值域(-π/2, π/2) |
| atan2(y, x) | 根据坐标(y,x)返回反正切弧度，覆盖完整象限 |
| hypot(x, y) | 返回欧几里得范数 sqrt(x*x + y*y)，原点到(x,y)距离 |
| dist(p, q) | 返回两个同维度点p、q之间的欧氏距离 |

## 四、角度弧度转换（高频配套三角运算）
| 函数 | 描述 |
| ---- | ---- |
| radians(x) | 将角度数值转换为弧度 |
| degrees(x) | 将弧度数值转换为角度，如degrees(math.pi/2)返回90.0 |

## 五、双曲函数（次常用）
| 函数 | 描述 |
| ---- | ---- |
| sinh(x) | 返回x弧度的双曲正弦 |
| cosh(x) | 返回x弧度的双曲余弦 |
| tanh(x) | 返回x弧度的双曲正切 |
| asinh(x) | 返回x的反双曲正弦 |
| acosh(x) | 返回x的反双曲余弦，x≥1 |
| atanh(x) | 返回x的反双曲正切，x∈(-1,1) |

## 六、常数（模块内置常量，常配合函数使用）
| 常量 | 描述 |
| ---- | ---- |
| math.pi | 圆周率 π，约3.141592653589793 |
| math.e | 自然常数 e，约2.718281828459045 |
| math.tau | 2π，圆周常数τ |
| math.inf | 正无穷大浮点数，-math.inf为负无穷 |
| math.nan | 非数字（无效浮点数） |

## 七、冷门辅助函数（极少用到，放最后）
| 函数 | 描述 |
| ---- | ---- |
| copysign(x, y) | 返回x的绝对值，符号与y保持一致 |
| trunc(x) | 截断取整，直接去掉小数部分，不四舍五入 |
| isclose(a, b) | 判断两个浮点数是否近似相等，消除浮点误差 |
| isfinite(x) | 判断x是否为有限数字，非无穷、非nan返回True |
| isinf(x) | 判断x是否为无穷大 |
| isnan(x) | 判断x是否为nan无效数值 |
| ldexp(x, i) | 返回 x * (2 ** i)，浮点移位运算 |
| nextafter(x, y) | 返回x向y方向偏移后的最小浮点数 |
| ulp(x) | 返回x最小精度单位，浮点误差计算用 |
| gamma(x) | Γ伽马函数，阶乘泛化，Γ(n)=(n-1)! |
| lgamma(x) | 返回Γ函数绝对值的自然对数 |

### 使用前置说明
所有函数使用前必须导入模块：
```python
import math
# 示例
print(math.sqrt(16))
print(math.sin(math.radians(30)))
```
