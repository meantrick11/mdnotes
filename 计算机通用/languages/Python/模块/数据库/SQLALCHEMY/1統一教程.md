# SQLAIchemy統一教程

SQLAlchemy 统一教程整合了 SQLAlchemy 的核心组件与 ORM 组件，是对 SQLAlchemy 整体的统一入门指南。对于 1.x 系列的 SQLAlchemy 用户，在2.0 风格的使用方式下，ORM 采用核心风格的查询语法搭配select()构造，且核心连接与 ORM 会话之间的事务语义保持一致。请注意各章节的蓝色边框样式，它会告诉你特定主题与 ORM 的关联程度！

SQLAlchemy 被呈现为两个不同的 API，一个建立在另一个之上。这些 API 被称为 Core 和 ORM。


SQLAlchemy core是 SQLAlchemy 作为“数据库工具包”的基础架构。该库提供了用于管理数据库连接、处理数据库查询和结果以及以编程方式构建 SQL 语句的工具。

**SQLAlchemy ORM 基于 Core 构建，提供可选的对象关系映射功能。ORM 提供了额外的配置层，允许用户定义的 Python 类被映射到数据库表和其他结构，还提供了名为会话（Session）的对象持久化机制。随后，它扩展了 Core 级别的 SQL 表达式语言，使 SQL 查询能够基于用户定义的对象进行编写和调用。**

仅ORM相关的章节应在标题中包含“ORM”一词，以便明确这是与ORM相关的主题。这些章节中使用的SQLAlchemy构造将从sqlalchemy.orm命名空间导入。最后，作为主题分类的额外标识，这些章节还会在左侧添加浅蓝色边框。仅使用核心功能的用户可以跳过这些内容。
