## 使用地图

初始化engine，必备，无论是通过上层ORM还是底层的core

from sqlalchemy import create_engine

engine = create_engine("sqlite+pysqlite:///:memory:")    #创建engine,需要输入对应的url  


## core

### 建立连接

1. `with engine.connect() as conn`,创建连接，with在退出的时候会进行连接资源释放,**注意，需要手动commit**

2. `with engine.begin() as conn`,同样创建连接，在with退出之前自动commit+资源释放

### 执行语句

`conn.excute(SQL语句)`,执行初始化的SQL语句，纯底层就用text("SQL")进行，或者上层通过高阶封装比如insert，update等也可以直接用作执行，只要是初始化之后的SQL语句

### 创建表的映射

通过声明元数据MetaData进行映射的绑定

```python
from sqlalchemy import MetaData,String,Table,Column,Integer
#声明MetaDat对象
metada_obj = MetaData

## 通过Table、Column创建映射

user_table = Table(
    "user_account", #数据库表名
    metadata_obj,   #这个元数据，可以看成对数据的连接映射
    Column("id",Integer,Primary_key=True),  #具体的列名
    Column("name",String(30),)
)

from sqlalchemy import ForeignKey   #外键
address_table = Table(
    "address",
    metadata_obj,
    Column("id", Integer, primary_key=True),
    Column("user_id", ForeignKey("user_account.id"), nullable=False),
    Column("email_address", String, nullable=False),
)

向数据库生成DDL，Data Define Language

metadat_obj.create_all(engine)  #将Python的类字段进行映射到DDL，即类似转为SQL语句并执行

```

### 创建表映射
```python

from sqlalchemy.orm import DeclarativeBase
#声明基类，有点类似初始化MetaData
class Base(DeclarativeBase):
    pass
##通过基类创建python class->Table的映射


from typing import List
from typing import Optional
from sqlalchemy.orm import Mapped
from sqlalchemy.orm import mapped_column
from sqlalchemy.orm import relationship

class User(Base):
    __tablename__ = "user_account"
    id: Mapped[int] = mapped_column(primary_key=True)   #显示映射column
    name: Mapped[str] = mapped_column(String(30))
    fullname: Mapped[Optional[str]] #隐式映射column，自动调用mapped_column函数进行映射
    addresses: Mapped[List["Address"]] = relationship(back_populates="user")
    def __repr__(self) -> str:
        return f"User(id={self.id!r}, name={self.name!r}, fullname={self.fullname!r})"

class Address(Base):
    __tablename__ = "address"
    id: Mapped[int] = mapped_column(primary_key=True)
    email_address: Mapped[str]
    user_id = mapped_column(ForeignKey("user_account.id"))
    user: Mapped[User] = relationship(back_populates="addresses")
    def __repr__(self) -> str:
        return f"Address(id={self.id!r}, email_address={self.email_address!r})"


##地基还是MetaData，所以同样使用create_all(engine)进行对数据库的操作

Base.metadata.create_all(engine)

#等价于stmt=INSERT INTO user_account (name, fullname) VALUES (:name, :fullname)

```

### select语句


对于 Core 和 ORM 而言，select() 函数会生成一个Select 结构，该结构用于所有 SELECT 查询。将其传递给 Core 中的Connection.execute() 以及 ORM 中的Session.execute() 等方法后，一条 SELECT 语句会在当前事务中被发出，并且结果行可通过返回的Result 对象获取。



```python
from sqlalchemy import select

stmt = select(user_table).where(user_table.c.name="spongbob")   #这里使用select函数，where即筛选条件，其次user_table为映射表，.c表示列,如果是ORM进行的映射，那么对应的应该是User.name="spongbob"
```

### GROUP BY/HAVING

SQLAlchemy 通过一个名为 func 的命名空间，以开放式的方式支持 SQL 函数。这是一个特殊的构造器对象，当传入特定 SQL 函数的名称时，它会创建新的 Function 实例；函数名可以是任意名称，同时也可传入零个或多个参数（与其他所有情况一样，这些参数都是 SQL 表达式结构）。例如，要针对 user_account.id 列生成 SQL 的 COUNT() 函数，我们调用 count() 这个名称即可：
```python
from sqlalchemy import func
count_fn = func.count(user_table.c.id)
print(count_fn)
```

```python
with engine.connect() as conn:
    result = conn.execute(
        select(User.name, func.count(Address.id).label("count"))
        .join(Address)
        .group_by(User.name)
        .having(func.count(Address.id) > 1)
    )
    print(result.all())

```

### UPDATE & DELETE


#### UPDATE 进行对数据库中的值进行更新

#### 单元素更新

```python
from sqlalchemy import update
stmt = (
    update(user_table)
    .where(user_table.c.name == "patrick")
    .values(fullname="Patrick the Star")
)
print(stmt)
UPDATE user_account SET fullname=:fullname WHERE user_account.name = :name_1
```

其中.values()控制的是SET子句元素的内容

#### 多元素更新

使用bindparam进行元素绑定，有点像excutemany()

```python
from sqlalchemy import bindparam
stmt = (
    update(user_table)
    .where(user_table.c.name == bindparam("oldname"))
    .values(name=bindparam("newname"))
)
with engine.begin() as conn:
    conn.execute(
        stmt,
        [
            {"oldname": "jack", "newname": "ed"},
            {"oldname": "wendy", "newname": "mary"},
            {"oldname": "jim", "newname": "jake"},
        ],
    )
```

### DELETE SQL表达式构造
从 API 的角度来看，delete() 语句与 update() 结构非常相似，传统上它不返回任何行，但在某些数据库后端中支持带有 RETURNING 子句的变体。
```python
from sqlalchemy import delete

stmt = delete(User).where(User.name=="patrick")


delete_stmt = (
    delete(user_table)
    .where(user_table.c.id == address_table.c.user_id)
    .where(address_table.c.email_address == "patrick@aol.com")
)
from sqlalchemy.dialects import mysql
print(delete_stmt.compile(dialect=mysql.dialect()))
```
