# 使用ORM进行数据操作

上一节 数据操作 从核心（Core）的角度重点讲解了 SQL 表达式语言，以确保在各类主要 SQL 语句结构之间保持连贯性。本节将进一步展开 Session 的生命周期，以及它与这些结构的交互方式。

## 使用ORM进行插入操作

使用 ORM 时，Session 对象负责构建 Insert 构造，并在正在进行的事务中将其作为 INSERT 语句执行。我们指示 Session 执行此操作的方式是向其 添加 对象条目；随后 Session 会通过一个名为 刷新 的过程，确保这些新条目在需要时会被执行写入数据库。Session 用于持久化对象的整体过程被称为 工作单元 模式。
