## 使用INSERT语句
在使用 Core 以及使用 ORM 进行批量操作时，会直接通过insert()函数生成一条 SQL INSERT 语句——该函数会生成一个Insert的新实例，这个实例代表了 SQL 中的 INSERT 语句，用于向表中添加新数据。

### INSERT() SQL表达式构造

一个 Insert 的简单示例，同时展示了目标表和 VALUES 子句：
```python
from sqlalchemy import insert
stmt = insert(user_table).values(name="spongebob", fullname="Spongebob Squarepants")
```
上述 stmt 变量是 Insert 的一个实例。大多数 SQL 表达式可以就地进行字符串化，以此查看所生成内容的大致形式：
```python
print(stmt)
INSERT INTO user_account (name, fullname) VALUES (:name, :fullname)
```
字符串化形式是通过生成对象的Compiled形式创建的，该形式包含语句的数据库特定字符串 SQL 表示；我们可以直接使用ClauseElement.compile()方法获取该对象：
`print(stmt)`
我们的Insert构造是“参数化”构造的一个示例，之前在发送参数中有过说明；要查看name和fullname这两个绑定参数，它们也可以从Compiled构造中获取：
`compiled.params`

### 执行INSERT语句

调用该语句，我们可以向user_table中插入一行数据。INSERT SQL 语句以及捆绑的参数都可以在 SQL 日志中看到：
```python
>>> with engine.connect() as conn:
...     result = conn.execute(stmt)
...     conn.commit()
BEGIN (implicit)
INSERT INTO user_account (name, fullname) VALUES (?, ?)
[...] ('spongebob', 'Spongebob Squarepants')
COMMIT

```

在上面的简单形式中，INSERT 语句不会返回任何行；如果仅插入单行，它通常会支持返回在该行插入期间生成的列级默认值信息，最常见的是整数主键值。在上述情况下，SQLite 数据库中的第一行通常会为第一个整数主键值返回 1，我们可以通过 CursorResult.inserted_primary_key 访问器来获取该值。

*CursorResult.inserted_primary_key 返回一个元组，因为主键可能包含多个列。这被称为复合主键。CursorResult.inserted_primary_key 旨在始终包含刚插入记录的完整主键，而不仅仅是“cursor.lastrowid”这类值，并且无论是否使用了“自增”功能，该属性都会被填充，因此为了表示完整的主键，它是一个元组。*

### INSERT 通常会自动生成“值”子句

上面的示例使用了Insert.values()方法来显式创建SQL INSERT语句的VALUES子句。如果我们实际上不使用Insert.values()，只是打印出一条“空”语句，就会得到针对表中每一列的INSERT：
`print(insert(user_table))`

如果我们拿一个尚未调用过Insert.values()的Insert构造体，执行它而非打印它，该语句会根据我们传递给Connection.execute()方法的参数编译成字符串，且仅包含与所传递参数相关的列。这实际上是Insert用于插入行的常用方式，无需写出显式的 VALUES 子句。以下示例展示了如何一次性通过参数列表执行一个两列的 INSERT 语句：
```python
with engine.connect() as conn:
    result = conn.execute(
        insert(user_table),
        [
            {"name": "sandy", "fullname": "Sandy Cheeks"},
            {"name": "patrick", "fullname": "Patrick Star"},
        ],
    )
    conn.commit()
```

## 使用SELECT语句
**对于 Core 和 ORM 而言，select() 函数都会生成一个Select 结构，该结构用于所有 SELECT 查询。将 SELECT 语句传递给 Core 中的Connection.execute() 以及 ORM 中的Session.execute() 等方法后，该语句会在当前事务中被执行，结果行可通过返回的Result 对象获取.**

#### SELECT() SQL表达式的构造

select() 构造函数与 insert() 的构建方式相同，采用 生成式方法，其中每个方法都会为对象构建更多状态。与其他 SQL 构造函数一样，它可以就地转换为字符串：
```python
from sqlalchemy import select
stmt = select(user_table).where(user_table.c.name == "spongebob")
print(stmt)
```

结果：
```sql
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
WHERE user_account.name = :name_1
```
与所有其他语句级 SQL 构造一样，要实际运行该语句，我们将其传递给执行方法。由于 SELECT 语句会返回行，因此我们始终可以遍历结果对象以取回Row对象：

```python
with engine.connect() as conn:
    for row in conn.execute(stmt):
        print(row)
```

使用 ORM 时，尤其是针对 ORM 实体构建的 select() 结构时，我们需要通过 Session 上的 Session.execute() 方法来执行它；使用这种方式，我们仍会从结果中获取 Row 对象，但这些行现在可以包含完整的实体（例如 User 类的实例）作为每行中的单个元素：

```python
stmt = select(User).where(User.name == "spongebob")
with Session(engine) as session:
    for row in session.execute(stmt):
        print(row)
```


#### 设置COLUMNS&FROM子句
select() 函数接受位置参数，这些参数可表示任意数量的 Column 和/或 Table 表达式，同时也接受多种兼容对象。这些参数会被解析为一组 SQL 表达式，用于执行 SELECT 操作，最终会作为结果集中的列返回。在更简单的场景下，这些参数还会用于生成 FROM 子句，该子句可根据传入的列和类表表达式自动推导得出。
```python
>>> print(select(user_table))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
```

要使用核心方法从单个列进行查询，需从Column访问器获取Column对象并可直接传入；FROM 子句将被推断为所有Table对象以及由这些列表示的其他FromClause对象的集合：

```python
>>> print(select(user_table.c.name, user_table.c.fullname))
SELECT user_account.name, user_account.fullname
FROM user_account
```

或者，在使用任何FromClause（如Table）的FromClause.c集合时，可通过传入字符串名称元组，为select()指定多个列：

```python
>>> print(select(user_table.c["name", "fullname"]))
SELECT user_account.name, user_account.fullname
FROM user_account
```

#### 选择ORM实体和列

ORM 实体（例如我们的 User 类以及其上的列映射属性，如 User.name）也参与表示表和列的 SQL 表达式语言系统。下面展示一个从 User 实体进行查询的示例，其最终呈现的效果与我们直接使用 user_table 完全相同：
```python
>>> print(select(User))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
```

当使用 ORM 的 Session.execute() 方法执行上述语句时，与选择 `user_table` 表相比，从 `User` 这类完整实体中选择数据时有一个重要区别，即 实体本身会作为每行中的单个元素返回。也就是说，当我们从上述语句中获取行时，由于要获取的列表中只有 `User` 实体，因此会得到只包含一个元素的 Row 对象，这些对象中包含 User 类的实例。
```python
>>> row = session.execute(select(User)).first()
BEGIN...
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
[...] ()
```

**一种强烈推荐的便捷方法，可实现与上述相同的结果，即直接使用 Session.scalars() 方法执行语句；该方法会返回一个 ScalarResult 对象，该对象会一次性提供每一行的第一“列”数据，在本例中即为 User 类的实例：**

```python
>> user = session.scalars(select(User)).first()
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
[...] ()
```

或者，我们可以通过使用类绑定属性，将 ORM 实体的单个列选作结果行中的不同元素；当将这些属性传递给 select() 之类的构造时，它们会被解析为每个属性所对应的 Column 或其他 SQL 表达式：
```python
>>> print(select(User.name, User.fullname))
SELECT user_account.name, user_account.fullname
FROM user_account
```


当我们使用Session.execute()调用此语句时，现在会收到每行每个值都有单独元素的行，每个元素对应一个单独的列或其他 SQL 表达式：
```python
>>> row = session.execute(select(User.name, User.fullname)).first()
SELECT user_account.name, user_account.fullname
FROM user_account
[...] ()
```

#### 从带标签的 SQL 表达式中查询


ColumnElement.label() 方法以及 ORM 属性上同名的方法会提供列或表达式的 SQL 标签，使其在结果集中拥有特定名称。这在通过名称引用结果行中的任意 SQL 表达式时会很有帮助：
```python
>>> from sqlalchemy import func, cast
>>> stmt = select(
...     ("Username: " + user_table.c.name).label("username"),
... ).order_by(user_table.c.name)
>>> with engine.connect() as conn:
...     for row in conn.execute(stmt):
...         print(f"{row.username}")
BEGIN (implicit)
SELECT ? || user_account.name AS username
FROM user_account ORDER BY user_account.name
[...] ('Username: ',)
Username: patrick
Username: sandy
Username: spongebob
```

#### 使用文本列表达式进行查询

当我们使用select()函数构造一个Select对象时，通常会向其传入一系列基于表元数据定义的Table和Column对象；而在使用ORM（对象关系映射）时，也可能传入代表表列的ORM映射属性。不过，有时还需要在语句中构造任意的SQL片段，比如常量字符串表达式，或是仅编写一些字面形式更快捷的任意SQL语句。

```python
在使用事务和 DBAPI 中介绍的 text() 构造实际上可以直接嵌入到 Select 构造中，例如下面的示例，我们构造了一个硬编码的字符串字面量 'some phrase' 并将其嵌入到 SELECT 语句中：

>>> from sqlalchemy import text
>>> stmt = select(text("'some phrase'"), user_table.c.name).order_by(user_table.c.name)
>>> with engine.connect() as conn:
...     print(conn.execute(stmt).all())
BEGIN (implicit)
SELECT 'some phrase', user_account.name
FROM user_account ORDER BY user_account.name
[generated in ...] ()
[('some phrase', 'patrick'), ('some phrase', 'sandy'), ('some phrase', 'spongebob')]
ROLLBACK
```
虽然 text() 构造可在大多数场景中用于注入字面 SQL 短语，但我们实际处理的往往是各自代表单个列表达式的文本单元。在这种常见情况下，改用 literal_column() 构造能让我们的文本片段实现更多功能。该对象与 text() 类似，不同之处在于它不代表任意形式的任意 SQL，而是显式表示单个“列”，随后可在子查询及其他表达式中对其进行标记和引用：

```python
>>> from sqlalchemy import literal_column
>>> stmt = select(literal_column("'some phrase'").label("p"), user_table.c.name).order_by(
...     user_table.c.name
... )
>>> with engine.connect() as conn:
...     for row in conn.execute(stmt):
...         print(f"{row.p}, {row.name}")
BEGIN (implicit)
SELECT 'some phrase' AS p, user_account.name
FROM user_account ORDER BY user_account.name
[generated in ...] ()
some phrase, patrick
some phrase, sandy
some phrase, spongebob
ROLLBACK
```

**请注意，在这两种情况下，无论是使用text()还是literal_column()，我们编写的都是语法层面的SQL表达式，而非字面量值。因此，我们必须包含让SQL按预期呈现所需的所有引号或语法。**

### 使用WHERE 子句
SQLAlchemy 允许我们通过将标准 Python 运算符与Column及类似对象结合使用，来组合 SQL 表达式，例如name = 'squidward'或user_id > 10。对于布尔表达式，大多数 Python 运算符（如==、!=、<、>=等）会生成新的 SQL 表达式对象，而非普通的布尔True/False值：

```python
print(user_table.c.name == "squidward")

print(address_table.c.user_id > 10)
```

我们可以通过将生成的对象传递给Select.where()方法，**使用类似这样的表达式来生成WHERE子句**：

```python
>>> print(select(user_table).where(user_table.c.name == "squidward"))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
WHERE user_account.name = :name_1
```

**要生成多个由 AND 连接的表达式，可任意次数调用Select.where()方法：**

```python
>>> print(
...     select(address_table.c.email_address)
...     .where(user_table.c.name == "squidward")
...     .where(address_table.c.user_id == user_table.c.id)
... )
SELECT address.email_address
FROM address, user_account
WHERE user_account.name = :name_1 AND address.user_id = user_account.id
```

**单次调用Select.where()也可接受多个表达式，效果相同：**
```python
>>> print(
...     select(address_table.c.email_address).where(
...         user_table.c.name == "squidward",
...         address_table.c.user_id == user_table.c.id,
...     )
... )
SELECT address.email_address
FROM address, user_account
WHERE user_account.name = :name_1 AND address.user_id = user_account.id
```
**“AND”和“OR”连接词均可直接通过and_()和or_()函数使用，以下通过ORM实体进行示例说明：**

```python
>>> from sqlalchemy import and_, or_
>>> print(
...     select(Address.email_address).where(
...         and_(
...             or_(User.name == "squidward", User.name == "sandy"),
...             Address.user_id == User.id,
...         )
...     )
... )
SELECT address.email_address
FROM address, user_account
WHERE (user_account.name = :name_1 OR user_account.name = :name_2)
AND address.user_id = user_account.id
```

### 显示FROM子句与JOIN连接

如前所述，FROM 子句通常是根据我们在列子句中设置的表达式以及 Select 的其他元素来 推断的。

如果我们要放入两个表的列，就会得到一个以逗号分隔的 FROM 子句：
```python
>>> print(select(user_table.c.name, address_table.c.email_address))
SELECT user_account.name, address.email_address
FROM user_account, address
```

**.join_from()**
要将这两个表**连接**起来，我们通常会在Select上使用两种方法之一。第一种是Select.join_from()方法，它让我们可以明确指定连接的左表和右表：
```python
>>> print(
...     select(user_table.c.name, address_table.c.email_address).join_from(
...         user_table, address_table
...     )
... )
SELECT user_account.name, address.email_address
FROM user_account JOIN address ON user_account.id = address.user_id
```

另一种是**Select.join()**方法，该方法仅表示 JOIN 的右侧，左侧是推断得出的：
```python
>>> print(select(user_table.c.name, address_table.c.email_address).join(address_table))
SELECT user_account.name, address.email_address
FROM user_account JOIN address ON user_account.id = address.user_id
```
### 设置ON子句
之前的 JOIN 示例表明，Select 构造可以在两个表之间进行连接并自动生成 ON 子句。在这些示例中会出现这种情况，是因为 user_table 和 address_tableTable 对象包含了单个 ForeignKeyConstraint 定义，该定义用于生成此 ON 子句。

如果连接的左右目标没有此类约束，或者存在多个约束，我们需要直接指定 ON 子句。Select.join() 和 Select.join_from() 都接受 ON 子句的额外参数，其表述方式与我们在 WHERE 子句 中了解到的 SQL 表达式机制相同：
```python
>>> print(
...     select(address_table.c.email_address)
...     .select_from(user_table)
...     .join(address_table, user_table.c.id == address_table.c.user_id)
... )
SELECT address.email_address
FROM user_account JOIN address ON user_account.id = address.user_id
```
### OUTERJOIN|FULL JOIN 外全连接

Select.join() 和 Select.join_from() 方法均接受关键字参数 Select.join.isouter 和 Select.join.full，分别用于生成左外连接（LEFT OUTER JOIN）和全外连接（FULL OUTER JOIN）：
```python
>>> print(select(user_table).join(address_table, isouter=True))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account LEFT OUTER JOIN address ON user_account.id = address.user_id
>>> print(select(user_table).join(address_table, full=True))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account FULL OUTER JOIN address ON user_account.id = address.user_id
```

还有一种方法 Select.outerjoin()，它等效于使用 .join(..., isouter=True)。

### ORDER BY\GROUP BY\HAVING

SELECT SQL 语句包含一个名为 ORDER BY 的子句，该子句用于按指定的排序方式返回选定的行。
GROUP BY 子句的构造方式与 ORDER BY 子句类似，其作用是将选定的行细分为特定的组，可在这些组上调用聚合函数。HAVING 子句通常与 GROUP BY 配合使用，其形式与 WHERE 子句相似，不同之处在于它作用于组内使用的聚合函数。

#### ORDER BY

ORDER BY 子句是根据通常基于Column或类似对象的 SQL 表达式构造来构建的。Select.order_by() 方法按位置接受一个或多个此类表达式：
```python
>>> print(select(user_table).order_by(user_table.c.name))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account ORDER BY user_account.name
```
可通过ColumnElement.asc()和ColumnElement.desc()修饰符实现升序/降序，ORM 绑定的属性也支持这两个修饰符：
```python
>>> print(select(User).order_by(User.fullname.desc()))
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account ORDER BY user_account.fullname DESC
```

#### 聚合函数&GROUP BY/HAVING

在SQL中，聚合函数可将多行的列表达式进行汇总，以生成单个结果。示例包括计数、计算平均值，以及定位一组值中的最大值或最小值。

SQLAlchemy 通过一个名为 **func**的命名空间以开放式方式支持 SQL 函数。这是一个特殊的构造器对象，当传入特定 SQL 函数的名称时，它会创建新的 Function 实例；该名称可以是任意名称，同时也可传入零个或多个要传递给函数的参数，与其他所有情况一样，这些参数都是 SQL 表达式结构。例如，要针对 user_account.id 列生成 SQL 的 COUNT() 函数，我们调用 count() 这个名称：

```python
>>> from sqlalchemy import func
>>> count_fn = func.count(user_table.c.id)
>>> print(count_fn)
count(user_account.id)

```

在 SQL 中使用聚合函数时，GROUP BY 子句至关重要，它能将行划分为多个分组，聚合函数会分别作用于每个分组。在 SELECT 语句的 COLUMNS 子句中查询非聚合列时，SQL 要求这些列要么直接受 GROUP BY 子句约束，要么基于主键关联间接受其约束。随后 HAVING 子句的使用方式与 WHERE 子句类似，不同的是它会根据聚合值而非行的直接内容筛选掉不符合条件的行。


```python
SQLAlchemy 通过 Select.group_by() 和 Select.having() 方法支持这两个子句。下面我们示例展示如何查询用户名字段以及地址数量，针对那些拥有多个地址的用户：

>>> with engine.connect() as conn:
...     result = conn.execute(
...         select(User.name, func.count(Address.id).label("count"))
...         .join(Address)
...         .group_by(User.name)
...         .having(func.count(Address.id) > 1)
...     )
...     print(result.all())
BEGIN (implicit)
SELECT user_account.name, count(address.id) AS count
FROM user_account JOIN address ON user_account.id = address.user_id GROUP BY user_account.name
HAVING count(address.id) > ?
[...] (1,)
[('sandy', 2)]
ROLLBACK
```

### 按标签排序或者分组

一种重要的技术（尤其在部分数据库后端中），是能够对 **SELECT** 子句中已声明的表达式进行 **ORDER BY** 或 **GROUP BY** 操作——无需在 **ORDER BY** 或 **GROUP BY** 子句中重复声明该表达式，而是直接使用 **COLUMNS** 子句中的列名或标签名。将名称的字符串形式传递给Select.order_by()或Select.group_by()方法，即可使用这种形式。传入的文本不会直接渲染；相反，系统会匹配在列子句中为表达式指定的、并在上下文中渲染为该表达式名称的名称，若未找到匹配项则会抛出错误。一元修饰符asc()和desc()也可用于此形式：
```python
>>> from sqlalchemy import func, desc
>>> stmt = (
...     select(Address.user_id, func.count(Address.id).label("num_addresses"))
...     .group_by("user_id")
...     .order_by("user_id", desc("num_addresses"))
... )
>>> print(stmt)
SELECT address.user_id, count(address.id) AS num_addresses
FROM address GROUP BY address.user_id ORDER BY address.user_id, num_addresse
```
### 使用别名
既然我们要从多个表中进行查询并使用连接，很快就会遇到需要在一条语句的 FROM 子句中多次引用同一个表的情况。我们通过 SQL 别名来实现这一点，这是一种为表或子查询提供替代名称的语法，后续就可以在语句中通过该替代名称来引用它们。

在 SQLAlchemy 表达式语言中，这些“名称”由被称为FromClause的对象（即Alias构造）表示，该构造通过核心库中的FromClause.alias()方法创建。Alias构造与Table构造类似，它在Alias.c集合中也拥有一组Column对象的命名空间。例如，下面的 SELECT 语句会返回所有不重复的用户名对：
```python
>>> user_alias_1 = user_table.alias()
>>> user_alias_2 = user_table.alias()
>>> print(
...     select(user_alias_1.c.name, user_alias_2.c.name).join_from(
...         user_alias_1, user_alias_2, user_alias_1.c.id > user_alias_2.c.id
...     )
... )
SELECT user_account_1.name, user_account_2.name AS name_1
FROM user_account AS user_account_1
JOIN user_account AS user_account_2 ON user_account_1.id > user_account_2.id
```

### ORM 实体别名

与FromClause.alias()方法等效的ORM是ORM的aliased()函数，该函数可应用于User和Address等实体。这会在内部生成一个Alias对象，该对象基于原始映射的Table对象，同时保留ORM功能。下面的SELECT语句会从User实体中查询出包含两个特定电子邮件地址的所有对象：
```python
>>> from sqlalchemy.orm import aliased
>>> address_alias_1 = aliased(Address)
>>> address_alias_2 = aliased(Address)
>>> print(
...     select(User)
...     .join_from(User, address_alias_1)
...     .where(address_alias_1.email_address == "patrick@aol.com")
...     .join_from(User, address_alias_2)
...     .where(address_alias_2.email_address == "patrick@gmail.com")
... )
SELECT user_account.id, user_account.name, user_account.fullname
FROM user_account
JOIN address AS address_1 ON user_account.id = address_1.user_id
JOIN address AS address_2 ON user_account.id = address_2.user_id
WHERE address_1.email_address = :email_address_1
AND address_2.email_address = :email_address_2
```

## 使用UPDATA&DELETE语句

到目前为止，我们已经介绍了Insert操作，以便将一些数据存入数据库；随后又花了大量时间讲解Select，它涵盖了从数据库中检索数据的各类使用场景。在本节中，我们将介绍Update和Delete这两种操作，它们分别用于修改现有数据行和删除现有数据行。本节将从以核心组件为核心的角度讲解这些操作。
*ORM 读取器 - 与在使用 INSERT 语句中提到的情况一样，与 ORM 一起使用时，Update和Delete操作通常作为工作单元流程的一部分，由Session对象内部调用。*
### UPDATE表达式的构造

与insert()结构类似，update()也存在一种“传统”形式，它会针对单个表执行 UPDATE 操作，且不返回任何行。不过部分数据库后端支持可同时修改多个表的 UPDATE 语句，同时该语句还支持 RETURNING 子句，以便将匹配行中包含的列返回到结果集中。
```python
一个基础的 UPDATE 语句如下所示：

>>> from sqlalchemy import update
>>> stmt = (
...     update(user_table)
...     .where(user_table.c.name == "patrick")
...     .values(fullname="Patrick the Star")
... )
>>> print(stmt)
UPDATE user_account SET fullname=:fullname WHERE user_account.name = :name_1
```
Update.values() 方法用于控制 UPDATE 语句中 SET 子句的内容。该方法与 Insert 构造函数共享。参数通常可以通过列名作为关键字参数来传递。

UPDATE 语句支持所有主要的 SQL 形式，包括对表达式的更新，我们可以在其中使用Column表达式：
```python
>>> stmt = update(user_table).values(fullname="Username: " + user_table.c.name)
>>> print(stmt)
UPDATE user_account SET fullname=(:name_1 || user_account.name)
```

为在“executemany”场景中支持 UPDATE 操作（针对同一语句调用多个参数集），可使用bindparam()构造来绑定参数；这些参数会替代通常放置字面量值的位置：
```python
>>> from sqlalchemy import bindparam
>>> stmt = (
...     update(user_table)
...     .where(user_table.c.name == bindparam("oldname"))
...     .values(name=bindparam("newname"))
... )
>>> with engine.begin() as conn:
...     conn.execute(
...         stmt,
...         [
...             {"oldname": "jack", "newname": "ed"},
...             {"oldname": "wendy", "newname": "mary"},
...             {"oldname": "jim", "newname": "jake"},
...         ],
...     )
BEGIN (implicit)
UPDATE user_account SET name=? WHERE user_account.name = ?
[...] [('ed', 'jack'), ('mary', 'wendy'), ('jake', 'jim')]
<sqlalchemy.engine.cursor.CursorResult object at 0x...>
COMMIT
```
#### 关联更新

```python
一条 UPDATE 语句可以通过使用相关子查询来引用其他表中的行。子查询可用于放置列表达式的任何位置：

>>> scalar_subq = (
...     select(address_table.c.email_address)
...     .where(address_table.c.user_id == user_table.c.id)
...     .order_by(address_table.c.id)
...     .limit(1)
...     .scalar_subquery()
... )
>>> update_stmt = update(user_table).values(fullname=scalar_subq)
>>> print(update_stmt)
UPDATE user_account SET fullname=(SELECT address.email_address
FROM address
WHERE address.user_id = user_account.id ORDER BY address.id
LIMIT :param_1)
```

#### UPDATE FROM

部分数据库（如 PostgreSQL、MSSQL 和 MySQL）支持 UPDATE...FROM 语法，可在专用的 FROM 子句中直接指定其他表。当语句的 WHERE 子句中涉及其他表时，系统会隐式生成该语法：
```python
>>> update_stmt = (
...     update(user_table)
...     .where(user_table.c.id == address_table.c.user_id)
...     .where(address_table.c.email_address == "patrick@aol.com")
...     .values(fullname="Pat")
... )
>>> print(update_stmt)
UPDATE user_account SET fullname=:fullname FROM address
WHERE user_account.id = address.user_id AND address.email_address = :email_address
```

### DELETE()SQL表达式的构造
delete() 函数会生成 Delete 的一个新实例，该实例表示 SQL 中的 DELETE 语句，将从表中删除行。

从 API 的角度来看，delete() 语句与 update() 结构非常相似，传统上它不返回任何行，但在某些数据库后端中支持带有 RETURNING 子句的变体。
```python
>>> from sqlalchemy import delete
>>> stmt = delete(user_table).where(user_table.c.name == "patrick")
>>> print(stmt)
DELETE FROM user_account WHERE user_account.name = :name_1
```
#### 多表删除
与Update操作类似，Delete操作支持在 WHERE 子句中使用关联子查询，同时也支持特定后端的多表语法，例如 MySQL 上的DELETE FROM..USING：
```python
>>> delete_stmt = (
...     delete(user_table)
...     .where(user_table.c.id == address_table.c.user_id)
...     .where(address_table.c.email_address == "patrick@aol.com")
... )
>>> from sqlalchemy.dialects import mysql
>>> print(delete_stmt.compile(dialect=mysql.dialect()))
DELETE FROM user_account USING user_account, address
WHERE user_account.id = address.user_id AND address.email_address = %s
```
### 从 UPDATE、DELETE 语句获取受影响的行数
Update和Delete操作均支持在语句执行后返回匹配的行数，适用于通过核心Connection（即Connection.execute()）调用的语句。根据下文提及的注意事项，该值可从CursorResult.rowcount属性获取：
```python
>>> with engine.begin() as conn:
...     result = conn.execute(
...         update(user_table)
...         .values(fullname="Patrick McStar")
...         .where(user_table.c.name == "patrick")
...     )
...     print(result.rowcount)
BEGIN (implicit)
UPDATE user_account SET fullname=? WHERE user_account.name = ?
[...] ('Patrick McStar', 'patrick')
1
COMMIT
```
