## 10.1 `for` 底层在干什么

```python
for element in [1, 2, 3]:
    print(element)
```

大致等价于：

```python
it = iter([1, 2, 3])
while True:
    try:
        element = next(it)
    except StopIteration:
        break
    print(element)
```

两套协议：

- **可迭代（iterable）**：实现 `__iter__()`，返回一个迭代器。列表、字符串、文件、字典（默认迭代键）都是。
- **迭代器（iterator）**：实现 `__next__()`，每次给下一个值；耗尽时抛 `StopIteration`。迭代器的 `__iter__` 通常返回 `self`。

所以迭代器是「一次性的游标」：走完不能回头，除非再 `iter(原对象)` 拿新游标。列表可以反复 `for`，因为每次 `iter(list)` 都新建迭代器；生成器函数返回的生成器本身就是迭代器，第二次 `for` 往往什么都不产出。

```python
g = (x for x in range(3))
print(list(g))  # [0, 1, 2]
print(list(g))  # []  已经耗尽
```

## 10.2 自己写一个迭代器

```python
class Reverse:
    """反向遍历一个序列。"""

    def __init__(self, data):
        self.data = data
        self.index = len(data)

    def __iter__(self):
        return self

    def __next__(self):
        if self.index == 0:
            raise StopIteration
        self.index -= 1
        return self.data[self.index]

for ch in Reverse("spam"):
    print(ch)
```

这就是官网的例子。能工作，但状态（`index`）要自己维护，写起来啰嗦。

## 10.3 生成器函数：`yield`

带 `yield` 的函数不返回一个普通值，而是返回**生成器对象**。每次 `next`，函数运行到下一个 `yield`，把值交出去并**暂停**；再 `next` 从暂停处继续，局部变量还在。

```python
def reverse(data):
    for index in range(len(data) - 1, -1, -1):
        yield data[index]

for ch in reverse("golf"):
    print(ch)
```

和 `Reverse` 类干同一件事，短得多。调用 `reverse("golf")` **不会马上执行函数体**，只是造出生成器；`for` 开始拉数据才执行。

```python
def countdown(n):
    print("开始")
    while n > 0:
        yield n
        n -= 1
    print("结束")

g = countdown(3)
print(next(g))  # 先打印「开始」，再得到 3
print(next(g))  # 2
print(next(g))  # 1
print(next(g))  # 打印「结束」，然后 StopIteration
```

### 原理：为什么省内存

`[x * x for x in range(10_000_000)]` 会在内存里摊开一千万个数。`(x * x for x in range(10_000_000))` 是生成器表达式，几乎不占内存，下游要一个才算一个。文件对象 `for line in f` 也是同一思路。

能放进列表再处理当然更方便（可切片、可 `len`）。数据量未知或极大时用生成器。

## 10.4 生成器表达式

圆括号推导式：

```python
sum(i * i for i in range(10))
max(line.strip() for line in open("workfile.txt", encoding="utf-8") if line.strip())
```

已经在函数调用的括号里时，外层圆括号可省。和列表推导式的取舍：只要走一遍、只求一个聚合结果 → 生成器；要反复用、要下标 → 列表。

## 10.5 和小工具的配合

```python
def read_n(path, n):
    with open(path, encoding="utf-8") as f:
        for i, line in enumerate(f):
            if i >= n:
                break
            yield line.rstrip("\n")

def parse_ints(lines):
    for line in lines:
        yield int(line)

# 管道：文件 → 前 10 行 → 转整数
# total = sum(parse_ints(read_n("nums.txt", 10)))
```

`zip`、`enumerate`、`map`、`filter` 返回的也是迭代器（Py3）。`list()` 可以物化。
