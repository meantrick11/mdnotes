# 4. 函数

对照官网：[4.8 Defining Functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions) 起，到 Coding Style。

函数把一段逻辑起个名字、可以反复调用，还可以接收参数、返回结果。Python 里函数也是对象，可以当参数传来传去。

---

## 4.1 第一次定义

官网斐波那契改写成函数：

```python
def fib(n):
    """打印小于 n 的斐波那契数列。"""
    a, b = 0, 1
    while a < n:
        print(a, end=" ")
        a, b = b, a + b
    print()

fib(2000)
```

- `def` 引入函数名和形参列表。
- 函数体必须缩进。
- 文档字符串（docstring）写在第一行，`help(fib)` 和 IDE 悬浮提示都会用它。养成习惯：公开函数都写一句「这个函数干什么」。

没有 `return` 时，函数返回 `None`。`print(fib(0))` 会先打印空行，再打印 `None`。

需要返回列表而不是打印：

```python
def fib2(n):
    """返回小于 n 的斐波那契列表。"""
    result = []
    a, b = 0, 1
    while a < n:
        result.append(a)
        a, b = b, a + b
    return result

f100 = fib2(100)
print(f100)
```

`return` 立刻结束函数。可以一次返回多个值，其实是打包成元组：

```python
def divmod_like(a, b):
    return a // b, a % b

q, r = divmod_like(17, 3)
```

## 4.2 默认参数值

```python
def ask_ok(prompt, retries=4, reminder="请输入 yes 或 no"):
    while True:
        reply = input(prompt)
        if reply in {"y", "ye", "yes"}:
            return True
        if reply in {"n", "no", "nop", "nope"}:
            return False
        retries = retries - 1
        if retries < 0:
            raise ValueError("用户拒绝输入")
        print(reminder)
```

可以这样调：

```python
ask_ok("要覆盖文件吗？")
ask_ok("要覆盖文件吗？", 2)
ask_ok("要覆盖文件吗？", 2, "只能 yes / no")
```

默认值在**定义函数时求值一次**，不是每次调用求一次。所以**可变对象绝不能当默认值**。

```python
# 错：所有调用共享同一个 list
def f(a, L=[]):
    L.append(a)
    return L

print(f(1))  # [1]
print(f(2))  # [1, 2]  意外

# 对
def f(a, L=None):
    if L is None:
        L = []
    L.append(a)
    return L
```

这是 Python 函数里第一名的坑。默认值是「函数对象上的一份属性」，不是「调用时的临时变量」。

## 4.3 关键字参数

调用时 `名字=值`，顺序可以和定义不一致；位置参数必须在关键字参数前面。

```python
def parrot(voltage, state="a stiff", action="voom"):
    print(f"This parrot wouldn't {action} if you put {voltage} volts through it.")
    print(f"It's {state}!")

parrot(1000)
parrot(voltage=1000)
parrot(action="VOOOOOM", voltage=1000000)
```

同一参数不能既按位置又按关键字给两次。不存在的关键字会 `TypeError`。

## 4.4 `/` 和 `*`：限定怎么传参

```python
def f(pos1, pos2, /, pos_or_kwd, *, kwd1, kwd2):
    pass
```

- `/` 前面的**只能按位置**（调用时不能写名字）。标准库里 `len`、`int` 很多是这样，避免参数名变成公开 API。
- `*` 后面的**只能按关键字**。

```python
def standard_arg(arg):
    print(arg)

def pos_only_arg(arg, /):
    print(arg)

def kwd_only_arg(*, arg):
    print(arg)

standard_arg(2)
standard_arg(arg=2)

pos_only_arg(1)
# pos_only_arg(arg=1)  # TypeError

kwd_only_arg(arg=3)
# kwd_only_arg(3)  # TypeError
```

入门阶段自己写函数，用「普通参数 + 偶尔 `*` 强制关键字」就够。例如不想让人搞混两个布尔开关：

```python
def connect(host, port, *, timeout=30, retry=True):
    ...
```

## 4.5 `*args` 和 `**kwargs`

任意数量的位置参数收进元组，任意关键字收进字典：

```python
def cheeseshop(kind, *arguments, **keywords):
    print("-- 要", kind, "吗？")
    for arg in arguments:
        print(arg)
    for kw in keywords:
        print(kw, ":", keywords[kw])

cheeseshop(
    "Limburger",
    "非常臭",
    "真的很臭",
    shopkeeper="Michael Palin",
    client="John Cleese",
)
```

反过来，调用时可以把列表/字典**拆开**传进去：

```python
def foo(a, b, c):
    print(a, b, c)

args = [1, 2, 3]
foo(*args)

d = {"a": 1, "b": 2, "c": 3}
foo(**d)
```

## 4.6 lambda

`lambda` 造一个只有**一个表达式**的匿名函数：

```python
add = lambda x, y: x + y
print(add(2, 3))
```

典型用途：排序的 `key`。

```python
pairs = [(1, "one"), (2, "two"), (3, "three"), (4, "four")]
pairs.sort(key=lambda pair: pair[1])
print(pairs)
```

lambda 和普通 `def` 一样，**会捕获外层变量的名字，而不是定义时的值**（晚绑定）：

```python
funcs = [lambda: i for i in range(3)]
print(funcs[0](), funcs[1](), funcs[2]())  # 3 3 3，三个都看到循环结束的 i

funcs = [lambda i=i: i for i in range(3)]  # 用默认参数把当前 i 钉死
print(funcs[0](), funcs[1](), funcs[2]())  # 0 1 2
```

逻辑超过一行，就写 `def`。装饰器见 [`基础语法/装饰器.md`](./基础语法/装饰器.md)，基础教程不强制先学。

## 4.7 文档字符串与标注

```python
def f(ham: str, eggs: str = "eggs") -> str:
    """做一份火腿蛋。

    第一行是摘要。空一行后写细节、参数、返回值。
    """
    return ham + " and " + eggs

print(f.__annotations__)
# {'ham': <class 'str'>, 'eggs': <class 'str'>, 'return': <class 'str'>}
```

标注**不强制检查类型**（除非你另外跑 mypy / Pydantic）。它是给人和工具看的。更系统的类型注释见 `../模块/内置模块/类型注释/`。

## 4.8 作用域：LEGB（够用版）

读一个名字时，Python 按这个顺序找：

1. **L**ocal：函数内部
2. **E**nclosing：外层函数（闭包）
3. **G**lobal：当前模块
4. **B**uiltin：`len`、`print` 那些

```python
x = "全局"

def outer():
    x = "外层"

    def inner():
        print(x)  # 找到 enclosing 的 x
    inner()

outer()
```

函数里**赋值**默认创建局部变量。要改全局变量必须 `global x`；要改外层函数的变量用 `nonlocal x`。能不改全局就不改，参数和返回值更清晰。

## 4.9 编码风格（PEP 8 入门）

官网插了一节 Intermezzo。记住这几条就比「能跑」更像 Python：

- 缩进 4 空格
- 一行不超过 79 字符（现在 88/100 也常见，团队统一即可）
- 函数、类之间空两行
- `snake_case` 函数和变量，`CapWords` 类名
- `name == None` 改成 `name is None`
- 不要用 `l` `O` `I` 当变量名

## 4.10 综合例子：统计词频

```python
def count_words(text, *, min_len=1):
    """返回单词 -> 次数。忽略大小写，丢掉短于 min_len 的词。"""
    freq = {}
    for raw in text.replace(",", " ").replace(".", " ").split():
        word = raw.lower()
        if len(word) < min_len:
            continue
        freq[word] = freq.get(word, 0) + 1
    return freq

sample = "Python is easy, python is fun. Easy!"
print(count_words(sample, min_len=3))
```
