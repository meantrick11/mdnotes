## 2.1 注释与「什么是对象」

`#` 后面到行尾都是注释，解释器直接忽略：

```python
# 这是注释
spam = 1  # 行尾也可以写注释
```

Python 里**一切都是对象**：数字 `3` 是对象，字符串 `"hi"` 是对象，后面的列表、函数、类也都是。变量名只是**贴在对象上的标签**，不是盒子里装了一份拷贝。

```python
a = 3
print(id(a))   # 这个整数对象在内存中的标识
b = a          # b 和 a 贴在同一个 3 上
print(a is b)  # True
```

这就是后面「改列表时另一个变量也变了」的根：赋值默认**不复制数据**，只是多贴一张标签。

## 2.2 数字

解释器可以直接当计算器。`+` `-` `*` `/` 和括号分组都和小学算术一样：

```python
>>> 2 + 2
4
>>> 50 - 5 * 6
20
>>> (50 - 5 * 6) / 4
5.0
>>> 8 / 5          # 除法永远得到 float
1.6
```

整数是 `int`，带小数的是 `float`。Python 的 `int` **没有溢出上限**（和 C 的 `int` 不同），算再大的整数也可以，只是更慢、更占内存。

### 除法三种脸

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `/` | 真除法，结果总是 `float` | `7 / 2` → `3.5` |
| `//` | 向下取整除法（地板除） | `7 // 2` → `3`，`-7 // 2` → `-4` |
| `%` | 余数 | `7 % 2` → `1` |
| `**` | 幂 | `2 ** 10` → `1024` |

```python
>>> 17 / 3
5.666666666666667
>>> 17 // 3
5
>>> 17 % 3
2
>>> 5 * 3 + 2          # 用 // 和 % 可以还原：商*除数 + 余数
17
>>> -3 ** 2            # ** 比一元负号更优先，等于 -(3**2)
-9
>>> (-3) ** 2
9
```

交互模式里，上一次表达式的结果会记在 `_` 里，适合连续计算：

```python
>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _
113.0625
```

不要在脚本里依赖 `_`，那是交互模式的便利功能。

### 原理：为什么 `0.1 + 0.2 != 0.3`

```python
>>> 0.1 + 0.2
0.30000000000000004
>>> 0.1 + 0.2 == 0.3
False
```

不是 Python 算错了。小数在机器里用**二进制浮点**存，很多十进制小数（包括 0.1）无法精确表示，只能存近似值。比较浮点时用误差范围，或用 `decimal` 模块做精确十进制（标准库一览再讲）。日常开发：钱用整数「分」或 `Decimal`，不要用 `float` 直接比相等。

复数用 `j` 后缀：`3 + 5j`。业务代码几乎用不到。

## 2.3 字符串

字符串用单引号或双引号都可以，本质一样。需要在串里写引号时，换一种引号，或用 `\` 转义：

```python
>>> 'spam eggs'
'spam eggs'
>>> "doesn't"
"doesn't"
>>> 'doesn\'t'
"doesn't"
>>> '"Yes," they said.'
'"Yes," they said.'
```

`print()` 会把转义「翻译」出来；交互模式直接回车，会显示**带转义的正式表示**（repr）。这是官网特意强调的区别：

```python
>>> s = 'First line.\nSecond line.'
>>> s                    # 看到的是 \n 这两个字符
'First line.\nSecond line.'
>>> print(s)             # print 才真正换行
First line.
Second line.
```

不想转义时用原始字符串 `r"..."`，Windows 路径很常用：

```python
>>> print('C:\some\name')      # \n 变成换行
C:\some
ame
>>> print(r'C:\some\name')
C:\some\name
```

多行字符串用三引号 `'''...'''` 或 `"""..."""`。行末加 `\` 可以避免开头多一个空行。

### 拼接、重复、索引、切片

```python
>>> 3 * 'un' + 'ium'
'unununium'
>>> 'Py' 'thon'          # 两个字面量紧挨着会自动拼接
'Python'
>>> prefix = 'Py'
>>> prefix + 'thon'      # 变量拼接必须用 +
'Python'
```

字符串是**序列**：有顺序，可以用下标。下标从 `0` 开始；负数从右边数，`-1` 是最后一个字符。

```python
>>> word = 'Python'
>>> word[0]
'P'
>>> word[5]
'n'
>>> word[-1]
'n'
>>> word[-2]
'o'
```

切片 `word[start:stop]` 是**左闭右开**：包含 `start`，不包含 `stop`。缺省时 `start=0`，`stop=长度`。

```python
>>> word[0:2]
'Py'
>>> word[2:5]
'tho'
>>> word[:2] + word[2:]
'Python'
>>> word[:2]
'Py'
>>> word[4:]
'on'
>>> word[-2:]
'on'
```

记切片的一个心智模型：下标写在字符**缝隙**上：

```text
 +---+---+---+---+---+---+
 | P | y | t | h | o | n |
 +---+---+---+---+---+---+
 0   1   2   3   4   5   6
-6  -5  -4  -3  -2  -1
```

`word[1:3]` 就是从缝 1 切到缝 3，得到 `yt`。越界索引会报错，但**越界切片会静默截断**，不会报错：

```python
>>> word[42]
# IndexError
>>> word[4:42]
'on'
```

### 原理：字符串不可变

不能给某个下标赋值：

```python
>>> word[0] = 'J'
# TypeError: 'str' object does not support item assignment
```

「改字符串」其实是**造一个新字符串**，再让变量名改贴标签：

```python
>>> word = 'Python'
>>> print(id(word))
>>> word = 'J' + word[1:]
>>> word
'Jython'
>>> print(id(word))      # 新对象，id 变了
```

所以 `s.replace(...)`、`s.strip()` 都**不会改原来的 s**，必须接住返回值：`s = s.strip()`。

`len(word)` 得到长度。常用方法（完整清单以后当手册查即可）：

```python
s = "  Hello, Python  "
print(s.strip())                       # 'Hello, Python'
print(s.lower())
print("a,b,c".split(","))              # ['a', 'b', 'c']
print("-".join(["2026", "09", "10"]))  # '2026-09-10'
print("Python".replace("P", "C"))
```

## 2.4 列表

列表用方括号，元素用逗号隔开。元素类型可以混，但通常会保持同质。

```python
>>> squares = [1, 4, 9, 16, 25]
>>> squares
[1, 4, 9, 16, 25]
```

列表也是序列：索引、切片、`+` 拼接、`len()` 都和字符串同一套规矩。

```python
>>> squares[0]
1
>>> squares[-1]
25
>>> squares[-3:]
[9, 16, 25]
>>> squares + [36, 49, 64]
[1, 4, 9, 16, 25, 36, 49, 64]
```

### 原理：列表可变；赋值不拷贝

和字符串不同，列表**可以原地改**：

```python
>>> cubes = [1, 8, 27, 65, 125]
>>> cubes[3] = 64          # 4^3 本来写错了
>>> cubes
[1, 8, 27, 64, 125]
>>> cubes.append(216)
>>> cubes.append(7 ** 3)
>>> cubes
[1, 8, 27, 64, 125, 216, 343]
```

切片赋值可以一次换掉一段，甚至改变长度：

```python
>>> letters = ['a', 'b', 'c', 'd', 'e', 'f', 'g']
>>> letters[2:5] = ['C', 'D', 'E']
>>> letters
['a', 'b', 'C', 'D', 'E', 'f', 'g']
>>> letters[2:5] = []      # 删掉这一段
>>> letters
['a', 'b', 'f', 'g']
>>> letters[:] = []        # 清空
>>> letters
[]
```

**赋值从不拷贝列表**，只是多一个名字指向同一块数据。这是第 2 章最重要的坑：

```python
>>> rgb = ['red', 'green', 'blue']
>>> rgba = rgb             # 不是复制，是第二个标签
>>> id(rgb) == id(rgba)
True
>>> rgba.append('alph')
>>> rgb                    # rgb 也变了
['red', 'green', 'blue', 'alph']
```

需要独立副本时，切片整份拷贝（浅拷贝）：

```python
>>> correct_rgba = rgba[:]
>>> correct_rgba[-1] = 'alpha'
>>> correct_rgba
['red', 'green', 'blue', 'alpha']
>>> rgba
['red', 'green', 'blue', 'alph']
```

浅拷贝只复制「外层列表」。如果元素本身还是列表，内外层仍共享内层对象。深拷贝用 `copy.deepcopy`，第 5 章和「深浅拷贝」笔记再展开。

列表可以嵌套：

```python
>>> a = ['a', 'b', 'c']
>>> n = [1, 2, 3]
>>> x = [a, n]
>>> x
[['a', 'b', 'c'], [1, 2, 3]]
>>> x[0]
['a', 'b', 'c']
>>> x[0][1]
'b'
```

## 2.5 可变 vs 不可变（够用的那一层）

| | 不可变 | 可变 |
| --- | --- | --- |
| 常见类型 | `int` `float` `str` `tuple` `bool` `None` | `list` `dict` `set` |
| 「修改」时 | 创建新对象，旧对象 id 不变 | 原地改，id 通常不变 |
| 作 dict 的键 | 可以（元素也得不可变） | 不行 |

用 `id()` 自己验证：

```python
x = 1
print(id(x))
x = x + 1          # 新的 int 对象，不是把 1 改成 2
print(id(x))

lst = [1]
print(id(lst))
lst.append(2)      # 还是同一个 list
print(id(lst))
```

小整数（CPython 里大约 -5～256）会缓存，所以 `a = 20; b = 20; a is b` 常常是 `True`。**不要靠这个写逻辑。** 比内容用 `==`，比是不是同一个对象用 `is`（主要拿来判断 `None`：`x is None`）。

## 2.6 第一个小程序：斐波那契

官网从这里开始离开「一行一行当计算器」，进入真正的语句。斐波那契：下一项等于前两项之和，`0, 1, 1, 2, 3, 5, 8, ...`

```python
a, b = 0, 1
while a < 10:
    print(a)
    a, b = b, a + b
```

跑出来：

```text
0
1
1
2
3
5
8
```

拆开看：

1. `a, b = 0, 1`：多重赋值。右边先算完，再同时赋给左边，所以后面 `a, b = b, a + b` 交换/递推时**不需要临时变量**。
2. `while a < 10:`：条件为真就重复缩进块。Python 用**缩进**表示代码块，同一块必须对齐。
3. `print(a)`：输出当前项。
4. `a, b = b, a + b`：下一步。右边的 `a + b` 用的是赋值前的旧值。

`print` 可以一次打多个值，默认空格分隔、末尾换行：

```python
a, b = 0, 1
while a < 1000:
    print(a, end=",")
    a, b = b, a + b
```

`end=","` 把默认换行换成逗号。关键字参数的完整规则在第 4 章。

## 2.7 顺手会用的几个运算符

算术已经见过。条件里还会用到：

```python
print(10 < 15 < 20)     # True，链式比较，等于 10 < 15 and 15 < 20
print(3 == 3.0)         # True，比的是值
print([1, 2] == [1, 2]) # True
print([1, 2] is [1, 2]) # False，两个不同列表对象

print("py" in "python")
print(2 in [1, 2, 3])

print(0 and 99)         # 0  —— and 遇到假值立刻返回（短路）
print(1 or 1 / 0)       # 1  —— or 遇到真值立刻返回，右边的 1/0 根本不执行
```

`and` / `or` 返回的是**最后一个被求值的操作数本身**，不一定是 `True`/`False`。利用这一点可以写 `name = user_name or "匿名"`。完整控制流见下一章。
