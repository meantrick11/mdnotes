# 类型拆解

太基础的底层不讲，但是
- python的所有高级类都是建立在底层的基础数据类型上的，比如class中的属性定义，底层就是dict的映射，所以可以将一个class的属性转为JSON格式

- python的基础数据结构包括值(int\float\double...,str)，list(动态数组)/tuple(静态不可变数组)，dict(哈希映射)，set(哈希映射)

- python是建立在C语言基础之上的，除了最基础的int\float\double等数据结构外，str是通过c语言的数组底层封装，并且上述类型都设置为只读类型，**不可变类型**，然，dict，set等都是手写的C语言结构体做的映射。
