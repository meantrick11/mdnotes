对照官网：[7. Input and Output](https://docs.python.org/3/tutorial/inputoutput.html)

两种输出：给人看的漂亮字符串，以及写到文件。输入用 `input()`（第 3 章猜数字已经用过）或读文件。

## 7.1 格式化字符串

### f-string（首选）

```python
year = 2016
event = "Referendum"
print(f"Results of the {year} {event}")

import math
print(f"π 大约 {math.pi:.3f}")   # 保留 3 位小数

table = {"Sjoerd": 4127, "Jack": 4098, "Dcab": 7678}
for name, phone in table.items():
    print(f"{name:10} ==> {phone:10d}")
```

`:` 后面是格式说明：宽度、对齐、小数位。`{value!r}` 用 `repr`，`{value!s}` 用 `str`。

```python
animals = "eels"
print(f"My hovercraft is full of {animals}.")
print(f"My hovercraft is full of {animals!r}.")
```

### `str.format`

```python
print("{0} and {1}".format("spam", "eggs"))
print("{food} between {0}".format("bread", food="ham"))
```

旧式 `%` 格式化还能在日志代码里见到：`"Hello %s" % name`。新代码优先 f-string。

`str.rjust` / `ljust` / `center` / `zfill` 是手动对齐：

```python
print("12".zfill(5))      # '00012'
print("Python".rjust(10))
```

`repr(obj)` 尽量给出能让人看清类型、甚至能 `eval` 回去的形式；`str(obj)` 给人读。交互模式默认用 `repr`。

## 7.2 读文件、写文件

```python
with open("workfile.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")

with open("workfile.txt", "r", encoding="utf-8") as f:
    data = f.read()
print(data)
```

**永远写 `encoding="utf-8"`**，除非你明确在处理别人指定的编码。Windows 默认编码经常不是 UTF-8，不写就会在中文上踩坑。

模式：

| 字符 | 含义 |
| --- | --- |
| `r` | 读（默认） |
| `w` | 写，文件已存在则清空 |
| `a` | 追加 |
| `x` | 创建，已存在则失败 |
| `b` | 二进制，读写 `bytes` |
| `+` | 读写都要 |

文本模式会帮你处理换行：写入 `\n`，磁盘上可能是 `\r\n`（Windows）。二进制模式原样进出，适合图片、压缩包。

## 7.3 文件对象常用方法

```python
with open("workfile.txt", encoding="utf-8") as f:
    print(f.read())       # 整个文件；大文件别这样
    f.seek(0)
    print(f.readline())   # 一行，含末尾 \n
    f.seek(0)
    for line in f:        # 逐行迭代，省内存
        print(line, end="")
```

`f.write(s)` 返回写入的字符数（文本）或字节数（二进制）。要读回刚才写的内容，注意先 `f.flush()` 或关掉文件，或者用 `r+` 并 `seek`。

`f.tell()` / `f.seek(offset, whence)` 移动文件指针。文本模式下 `seek` 有限制，入门阶段逐行迭代即可。

## 7.4 原理：为什么必须 `with`

`open` 会向操作系统要一个文件描述符。不用了必须 `close()`，否则可能丢缓冲数据、占着句柄。

```python
f = open("workfile.txt", encoding="utf-8")
try:
    data = f.read()
finally:
    f.close()
```

`with` 等价于上面的 `try/finally`，并且在块**无论正常结束还是异常**时都会调用对象的 `__exit__`。文件、锁、数据库连接都适用。专题见 [`基础语法/with.md`](./基础语法/with.md)。

多个上下文：

```python
with open("a.txt", encoding="utf-8") as src, open("b.txt", "w", encoding="utf-8") as dst:
    dst.write(src.read())
```

路径推荐 `pathlib`（见 `../模块/日常开发模块/pathlib.md`）：

```python
from pathlib import Path

p = Path("workfile.txt")
p.write_text("hello\n", encoding="utf-8")
print(p.read_text(encoding="utf-8"))
```

## 7.5 结构化数据：JSON

不要自己用字符串拼接来存字典。标准库 `json`：

```python
import json

x = [1, "simple", "list"]
json.dumps(x)                 # 得到字符串
with open("data.json", "w", encoding="utf-8") as f:
    json.dump({"name": "Ada", "year": 1815}, f, ensure_ascii=False, indent=2)

with open("data.json", encoding="utf-8") as f:
    obj = json.load(f)
```

`dump`/`load` 对文件；`dumps`/`loads` 对字符串。JSON 对应 Python 的 dict/list/str/int/float/bool/None，**不能直接存 tuple、set、自定义类**（tuple 会变成 list）。更多见 `../模块/日常开发模块/json.md`。

## 7.6 小例子：访问日志计数

```python
from collections import Counter
from pathlib import Path

def count_ips(path):
    counter = Counter()
    with Path(path).open(encoding="utf-8") as f:
        for line in f:
            ip = line.split()[0]
            counter[ip] += 1
    return counter.most_common(5)

# 假设 access.log 每行: 1.2.3.4 - - ...
```
