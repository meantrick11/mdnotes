# 6. 模块

对照官网：[6. Modules](https://docs.python.org/3/tutorial/modules.html)

再长的脚本也会需要拆文件。**模块**就是一个 `.py` 文件；**包**是带 `__init__.py`（命名空间包可以没有）的目录。更细的搜索路径、相对导入见 [`../import.md`](../import.md)。

## 6.1 写一个模块

`fibo.py`：

```python
"""斐波那契相关工具。"""

def fib(n):
    a, b = 0, 1
    while a < n:
        print(a, end=" ")
        a, b = b, a + b
    print()

def fib2(n):
    result = []
    a, b = 0, 1
    while a < n:
        result.append(a)
        a, b = b, a + b
    return result
```

在同一目录打开解释器或另一个脚本：

```python
import fibo

fibo.fib(1000)
from fibo import fib, fib2
fib(500)

import fibo as fb
fb.fib(10)

from fibo import *
# 把模块里不以下划线开头的名字全倒进当前命名空间，容易冲突，脚本里尽量别用
```

### 原理：import 实际做了什么

1. 在 `sys.path` 里找 `fibo.py`（或已编译的 `fibo.pyc`）
2. 执行该文件的**顶层代码**（定义函数、可能的副作用）
3. 把得到的模块对象绑到当前名字上：`fibo = <module 'fibo'>`

同一进程里同一模块只加载一次。改完源码要看到效果，需要重启解释器，或 `importlib.reload(fibo)`。

`sys.path` 大致包括：脚本所在目录、`PYTHONPATH`、标准库、site-packages。所以「和脚本放一起的 `fibo.py`」能直接 import。

## 6.2 当脚本运行 vs 被导入

模块顶层可以写：

```python
if __name__ == "__main__":
    import sys
    fib(int(sys.argv[1]))
```

- `python fibo.py 50`：解释器把该文件当**主程序**，`__name__` 是 `"__main__"`，会执行测试/命令行入口
- `import fibo`：`__name__` 是 `"fibo"`，入口不跑，只提供函数

这是项目里几乎每个文件都会写的习惯。详见 [`基础语法/__name__.md`](./基础语法/__name__.md)。

命令行参数在 `sys.argv` 里：`argv[0]` 是脚本名，后面才是你传的参数。

## 6.3 `.pyc` 和 `__pycache__`

第一次 import 后，目录里可能出现 `__pycache__/fibo.cpython-314.pyc`。那是字节码缓存，让下次 import 跳过解析源码。一般不要手改、也不用提交进 git（可在 `.gitignore` 里忽略）。源码改了之后，解释器会按时间戳决定要不要重编。

## 6.4 标准库模块与 `dir()`

```python
import sys
print(sys.ps1)          # 交互模式主提示符，默认 '>>> '

import builtins
print(dir(builtins)[:10])
```

`dir(fibo)` 列出模块里的名字。`dir()` 不带参数列出当前命名空间。内置函数在 `builtins` 里。

常用标准库点名（不展开，后面 `../模块/` 再写）：`sys`、`os`、`math`、`json`、`pathlib`、`datetime`、`random`、`re`。

## 6.5 包（直觉版）

```text
sound/
    __init__.py
    formats/
        __init__.py
        wavread.py
    effects/
        __init__.py
        echo.py
```

```python
import sound.effects.echo
sound.effects.echo.func()

from sound.effects import echo
```

`from package import *` 依赖 `__all__` 列表，否则行为含糊，不推荐。包内部互引优先相对导入：`from . import echo`、`from ..formats import wavread`。相对导入只能在包内使用，直接 `python echo.py` 当脚本跑会失败——要用 `python -m sound.effects.echo`。

## 6.6 小例子：把第 5 章成绩表拆文件

`grades.py`：

```python
def averages(scores):
    return {name: sum(xs) / len(xs) for name, xs in scores.items()}

def top_student(scores):
    avg = averages(scores)
    name = max(avg, key=avg.get)
    return name, avg[name]

if __name__ == "__main__":
    demo = {"Alice": [90, 85], "Bob": [70, 88]}
    print(top_student(demo))
```

另一个文件 `main.py`：`from grades import top_student`。
