# 9. 类

对照官网：[9. Classes](https://docs.python.org/3/tutorial/classes.html)

Python 的类很「动态」：属性可以事后添加，方法和普通函数差别不大。先建立两张图：**名字 → 对象**（命名空间），以及 **实例 / 类 / 基类** 的查找顺序。

---

## 9.1 名字和对象

赋值从不复制对象，只是让名字指向对象（第 2 章列表那个坑）。多个名字可以指向同一对象。函数传参也是传引用：函数里如果**改可变对象的内容**，外面看得到；如果**给形参重新赋值**，外面的名字不受影响。

```python
def append_one(box):
    box.append(1)

data = []
append_one(data)
print(data)  # [1]
```

---

## 9.2 作用域与命名空间

命名空间是「名字到对象的映射」。模块的全局名、函数的局部名、内置名，都是不同的命名空间。

类定义会创建一个新的命名空间；里面的赋值变成**类属性**。实例化后再创建一个实例命名空间。读属性时：先看实例，再看类，再看基类（粗略版 MRO）。

```python
def scope_test():
    def do_local():
        spam = "local spam"

    def do_nonlocal():
        nonlocal spam
        spam = "nonlocal spam"

    def do_global():
        global spam
        spam = "global spam"

    spam = "test spam"
    do_local()
    print("after local:", spam)
    do_nonlocal()
    print("after nonlocal:", spam)
    do_global()
    print("after global:", spam)

scope_test()
print("in global:", spam)
```

输出大意：`local` 不影响外层；`nonlocal` 改外层函数的 `spam`；`global` 改模块级 `spam`。

## 9.3 最简的类

```python
class MyClass:
    """一个简单的例子。"""
    i = 12345

    def f(self):
        return "hello world"

x = MyClass()
print(x.i)
print(x.f())
```

`x.f` 是**绑定方法**：调用 `x.f()` 时，`x` 会自动传给 `self`。也可以 `MyClass.f(x)`。

`__init__` 在实例创建后立刻调用，用来初始化：

```python
class Complex:
    def __init__(self, realpart, imagpart):
        self.r = realpart
        self.i = imagpart

c = Complex(3.0, -4.5)
print(c.r, c.i)
```

实例属性可以随时加（灵活，但也容易拼错名字而不报错）：

```python
x.counter = 1
while x.counter < 10:
    x.counter = x.counter * 2
print(x.counter)
del x.counter
```

## 9.4 类变量 vs 实例变量

**类变量**所有实例共享；**实例变量**每个对象一份。可变对象当类变量是常见坑：

```python
class Dog:
    tricks = []          # 错：全班狗共享

    def __init__(self, name):
        self.name = name

    def add_trick(self, trick):
        self.tricks.append(trick)

d = Dog("Fido")
e = Dog("Buddy")
d.add_trick("roll over")
print(e.tricks)          # ['roll over']  Buddy 也会了？
```

正确：

```python
class Dog:
    def __init__(self, name):
        self.name = name
        self.tricks = []

    def add_trick(self, trick):
        self.tricks.append(trick)
```

函数里的默认参数坑（第 4 章）和这个是同一类：**共享可变对象**。

## 9.5 继承

```python
class DerivedClassName(BaseClassName):
    pass
```

派生类可以覆盖方法。调用父类同名方法：`super().__init__(...)` 或 `BaseClassName.method(self, ...)`。`isinstance(obj, int)` 检查实例；`issubclass(bool, int)` 检查类关系（`bool` 是 `int` 的子类）。

多继承：`class Derived(Base1, Base2)`。查找顺序是 C3 MRO，`ClassName.__mro__` 能看到。入门先避免菱形多继承，用组合（对象里持有另一个对象）通常更清晰。

## 9.6 「私有」约定

没有严格 private。单下划线 `_name` 表示内部使用，从 `from module import *` 不会导入。双下划线 `__name` 会在类内被改写成 `_ClassName__name`（名称改写），用来避免和子类字段意外冲突，**不是安全机制**。

```python
class Mapping:
    def __init__(self, iterable):
        self.__items = []
        self.update(iterable)

    def update(self, iterable):
        for item in iterable:
            self.__items.append(item)
```

子类即使也定义 `__items`，也不会覆盖父类改写后的那个名字。

## 9.8 综合例子：银行账户

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        if balance < 0:
            raise ValueError("初始余额不能为负")
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款必须为正")
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError("余额不足")
        self.balance -= amount

    def __repr__(self):
        return f"BankAccount({self.owner!r}, {self.balance})"

class SavingsAccount(BankAccount):
    def __init__(self, owner, balance=0, rate=0.02):
        super().__init__(owner, balance)
        self.rate = rate

    def apply_interest(self):
        self.deposit(self.balance * self.rate)
```

`__repr__` 让 `print(account)` 好看，调试时很有用。
