## 1.0 课前甜点

如果您的工作主要是用电脑完成的，总有一天您会想能不能自动执行一些任务。比如，对大量文本文件执行查找、替换操作；利用复杂的规则重命名、重排序一堆照片文件；也可能您想编写一个小型数据库、或开发专用的图形界面应用，甚至是开发一个简单的游戏。

作为一名专业软件开发人员，您可能要处理 C/C++/Java 库，但编码、编译、测试、再编译这些开发流程太慢了；也许您正在给这些库开发测试套件，但总觉得这项工作真是枯燥乏味。又或许，您开发了个使用扩展语言的软件，却不想为这个软件专门设计一种新语言。

那么，Python 正好能满足您的需要。

你可以针对这些任务编写 Unix shell 脚本或 Windows 批处理文件，但 shell 脚本擅长的是移动文件和改变文本数据，而不适合编写 GUI 应用或游戏。 你可以编写 C/C++/Java 程序，但即使只完成一个初始版程序也需要耗费很长的开发时间。 Python 则更为简单易用，同时支持 Windows, macOS 和 Unix 操作系统，并能帮助你更快速地完成工作。

Python 虽然简单易用，但它可是真正的编程语言，提供了大量的数据结构，也支持开发大型程序，远超 shell 脚本或批处理文件；Python 提供的错误检查比 C 还多；作为一种“非常高级的语言”，它内置了灵活的数组与字典等高级数据类型。正因为配备了更通用的数据类型，Python 比 Awk，甚至 Perl 能解决更多问题，而且，很多时候，Python 比这些语言更简单。

Python 支持把程序分割为模块，以便在其他 Python 程序中复用。它还内置了大量标准模块，作为开发程序的基础 —— 您还可以把这些模块当作学习 Python 编程的实例。这些模块包括 I/O、系统调用、套接字，甚至还包括 Tk 图形用户界面工作套件。

Python 是一种解释型语言，不需要编译和链接，可以节省大量开发时间。它的解释器实现了交互式操作，轻而易举地就能试用各种语言功能，编写临时程序，或在自底向上的程序开发中测试功能。同时，它还是一个超好用的计算器。

Python 程序简洁、易读，通常比实现同种功能的 C、C++、Java 代码短很多，原因如下：

高级数据类型允许在单一语句中表述复杂操作；

使用缩进，而不是括号实现代码块分组；

无需预声明变量或参数。

Python “可以扩展”：会开发 C 语言程序，就能快速上手为解释器增加新的内置函数或模块，不论是让核心程序以最高速度运行，还是把 Python 程序链接到只提供预编译程序的库（比如，硬件图形库）。只要下点功夫，就能把 Python 解释器和用 C 开发的应用链接在一起，用它来扩展和控制该应用。

顺便提一句，Python的命名源自 BBC 的 “Monty Python 飞行马戏团”，与爬行动物无关（Python 原义为“蟒蛇”）。欢迎大家在文档中引用 Monty Python 小品短篇集，多多益善！


学习一门编程语言最好的方式就是上手实践，**建议一遍阅读教程，一边在Python解释器或者IDE中进行练习。**

## 1.1 语言的选择

想要入门编程，第一步就是挑选适合自己的编程语言。不同语言定位、用途、上手难度完全不同，下面对比主流编程语言，帮你理清各自的特点与适用场景，最后说明我们为什么选择Python作为入门学习的语言。

### 1.1.1 C语言
- **定位**：经典底层编译型语言，计算机专业的基础必修课
- **优点**：执行速度极快，贴近计算机硬件；《数据结构》《操作系统》《计算机网络》等核心专业课大多以C语言作为教学载体；能真正理解内存、指针等计算机底层原理。
- **缺点**：语法门槛偏高，需要手动管理内存，开发效率低，没有现成丰富的工具库，写基础功能都需要大量手写代码。
- **适合人群**：计算机专业打底层基础、学习操作系统、嵌入式开发；**不适合零基础快速做出可用程序**。

### 1.1.2 C++
- **定位**：在C语言基础上扩展了面向对象特性的高性能语言
- **优点**：性能顶尖，标准库强大；国内算法竞赛（ACM、蓝桥杯）的主流参赛语言；可用于游戏引擎、高性能服务端开发。
- **缺点**：语法复杂，规则繁多，学习曲线陡峭，新手很容易踩内存、指针相关的坑。
- **适合人群**：准备算法竞赛、高性能游戏/引擎开发；不适合纯小白快速体验编程乐趣。

### 1.1.3. Java
- **定位**：企业级后端主力语言，国内开发生态极其完善
- **优点**：跨平台运行，工程体系成熟，大量互联网后端、安卓项目使用；就业岗位多。
- **缺点**：代码冗长繁琐，入门就要理解类、对象、编译配置等复杂概念，新手前期写大量模板代码才能实现简单功能。
- **适合人群**：毕业后从事后端企业开发；不适合零基础快速上手验证想法。

### 1.1.4 Go（Golang）
- **定位**：高并发场景而生的现代编译型语言
- **优点**：语法简洁，并发能力强大，云原生、微服务、服务器开发热门选型，运行效率优秀。
- **缺点**：偏向后端工程开发，日常小工具、数据分析、人工智能领域生态弱于Python。
- **适合人群**：后端云服务、高并发服务器开发，**不作为第一门入门语言**。

### 1.1.5 Rust
- **定位**：安全高速的系统级编程语言
- **优点**：兼顾高性能与内存安全，无垃圾回收，未来系统开发、高性能底层项目的新星语言。
- **缺点**：学习难度极高，对编程基础要求高，不适合零基础初学者。
- **适合人群**：有多年开发经验，做高性能底层软件。

### 1.1.6 Python（本教程的学习语言）
- **定位**：简洁易用的解释型通用编程语言
- **优点**
  1. **语法极其贴近自然英语，门槛最低**，新手不用纠结复杂格式，少量代码就能实现完整功能；
  2. **海量成熟第三方库**：数据分析、爬虫、自动化脚本、人工智能、Web网站、小游戏都有现成工具，不用从零造轮子；
  3. 用途覆盖极广：既能写简单的办公自动化小脚本，也可以做深度学习、大数据项目，学习回报很高；
  4. **不用复杂编译配置**，写完代码直接运行，初学者可以快速看到自己程序运行的结果，更容易获得正向反馈，保持学习动力。
- **缺点**：相比C/C++/Go运行速度偏弱，但对于初学者日常练习、大部分业务场景完全够用。
- **适合人群**：**编程零基础入门者**、想快速实现创意、做自动化工具、数据分析、AI开发的学习者。

如果你是**第一次接触编程，希望用最低的门槛快速感受编程的魅力，快速做出实用有趣的小项目**，**Python就是最适合你的第一门编程语言**，这也是本教程选择Python作为学习内容的原因。

## 1.3 Python解释器

正常情况下，将Python安装到电脑上之后，按照以下步骤就可以激活Python解释器：
1. 键盘点击`Ctrl+R`
2. 输入cmd ->进入终端模式(暂时可以不用管终端是什么，有兴趣可以问一下AI)
3. 然后在终端中输入`python`或者`python3.14`这样携带具体版本号的启动命令
    - 如果出现"找不到命令"等等提示，那么很有可能是因为安装Python之后，没有将Python解释器配置到电脑的环境变量中，环境变量的配置这里不过多赘述，如果有需要，你可以像任意一个AI发送"我已经将Python装到电脑上了，但是终端中输入python，提示找不到命令，很有可能是环境变量没有添加python解释器，请给我一步一步教程进行配置python解释器到环境变量中"，那么大概率它会给你一步一步教程，你只需要跟着完成配置随后重新按照上述启动解释器的教程进行操作。
4. 此时你就成功进入Python解释器的交互模式，随即就可以开始尝试"写代码"了。

### 1.3.1 传入参数

解释器读取命令行参数，把脚本名与其他参数转化为字符串列表存到 sys 模块的 argv 变量里。执行 import sys，可以导入这个模块，并访问该列表。该列表最少有一个元素；未给定输入参数时，sys.argv[0] 是空字符串。给定脚本名是 '-' （标准输入）时，sys.argv[0] 是 '-'。使用 -c command 时，sys.argv[0] 是 '-c'。如果使用选项 -m module，sys.argv[0] 就是包含目录的模块全名。解释器不处理 -c command 或 -m module 之后的选项，而是直接留在 sys.argv 中由命令或模块来处理。

*新手不懂上面解释，可直接跳过，不影响学习*

### 1.3.2 交互模式


在终端输入并执行指令时，解释器在 交互模式 中运行。在这种模式中，会显示 主提示符，提示输入下一条指令，主提示符通常用三个大于号 (>>>) 表示；输入连续行时，显示 次要提示符，默认是三个点 (...)。 进入解释器时，首先显示欢迎信息、版本信息、版权声明，然后才是提示符：

```python
C:\Users\lenovo>python3.14
Python 3.14 (default, April 4 2024, 09:25:04)
[GCC 10.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

和语言教程传统一样，本教程也延续经典传承，新手来讲编程的第一句应该是输出`Hello World!`，这里你只需要在交互模式后面输入`print("Hello World!")`,像这样
```python
>>> print("Hello World!")
Hello World!
>>>
```


### 1.3.2 解释器运行环境

默认情况下，Python 源码文件的编码是 UTF-8。这种编码支持世界上大多数语言的字符，可以用于字符串字面值、变量、函数名及注释 —— 尽管标准库只用常规的 ASCII 字符作为变量名或函数名，可移植代码都应遵守此约定。要正确显示这些字符，编辑器必须能识别 UTF-8 编码，而且必须使用支持文件中所有字符的字体。

如果不使用默认编码，则要声明文件的编码，文件的 第一 行要写成特殊注释。句法如下：

# -*- coding: encoding -*-
其中，encoding 可以是 Python 支持的任意一种 codecs。

比如，声明使用 Windows-1252 编码，源码文件要写成：

# -*- coding: cp1252 -*-
第一行 的规则也有一种例外情况，源码以 UNIX "shebang" 行 开头。此时，编码声明要写在文件的第二行。例如：

Copy
#!/usr/bin/env python3
# -*- coding: cp1252 -*-


*注：Unix 系统中，为了不与同时安装的 Python 2.x 冲突，Python 3.x 解释器默认安装的执行文件名不是 python。*
