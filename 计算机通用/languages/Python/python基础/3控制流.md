# 3. 控制流

对照官网：[4. More Control Flow Tools](https://docs.python.org/3/tutorial/controlflow.html) 的 4.1–4.7。函数从第 4 章单独讲。

程序默认从上往下跑。控制流做两件事：**分支**（走哪条路）和 **循环**（重复到什么时候停）。

## 3.1 `if` 语句

```python
x = int(input("请输入一个整数: "))

if x < 0:
    x = 0
    print("负数，已改成 0")
elif x == 0:
    print("零")
elif x == 1:
    print("一")
else:
    print("大于一")
```

- `elif` 是 `else if` 的缩写，可以有 0 到任意多个。
- `else` 可省略。
- `if` 可以嵌套，但嵌套超过两层就该想办法拆函数或提前 `return`。

条件会被换成布尔语境：`0`、`0.0`、`""`、`[]`、`{}`、`set()`、`()`、`None` 为假，其它一般为真。不要写 `if len(lst) != 0:`，直接 `if lst:`。

```python
name = ""
if not name:
    print("名字是空的")
```

## 3.2 `for` 遍历的是「可迭代对象」

Python 的 `for` **不是** C 那种 `for (i=0; i<n; i++)`。它是：依次取出可迭代对象里的元素。

```python
words = ["cat", "window", "defenestrate"]
for w in words:
    print(w, len(w))
```

### 原理：循环里改正在遍历的列表很危险

`for` 内部其实是「拿到迭代器，反复 `next()`」。如果你在循环里增删**正在遍历的那份列表**，迭代器会跳元素或报错。官网建议：要改内容就先拷一份，或者建新列表。

```python
users = {"张三": "active", "李四": "inactive", "王五": "active"}

# 错：一边遍历一边删
# for user, status in users.items():
#     if status == "inactive":
#         del users[user]   # RuntimeError: dictionary changed size

# 对：遍历 keys 的拷贝
for user, status in users.copy().items():
    if status == "inactive":
        del users[user]

# 也对：收集到新字典
active_users = {u: s for u, s in users.items() if s == "active"}
```

## 3.3 `range()`

需要一组整数时用 `range`。它**不一次造出整个列表**，只是按需产出数字（可迭代、省内存）。

```python
for i in range(5):
    print(i)          # 0 1 2 3 4
```

| 写法 | 含义 |
| --- | --- |
| `range(stop)` | `0 .. stop-1` |
| `range(start, stop)` | `start .. stop-1` |
| `range(start, stop, step)` | 步长可以是负数 |

```python
list(range(5, 10))        # [5, 6, 7, 8, 9]
list(range(0, 10, 3))     # [0, 3, 6, 9]
list(range(-10, -100, -30))  # [-10, -40, -70]
```

要下标时，`range(len(a))` 能用，但更 Pythonic 的是 `enumerate`：

```python
a = ["Mary", "had", "a", "little", "lamb"]
for i in range(len(a)):
    print(i, a[i])

for i, word in enumerate(a):
    print(i, word)
```

`range` 不是列表。`print(range(10))` 看到的是 `range(0, 10)` 对象。需要列表时再 `list(range(10))`。

## 3.4 `break` / `continue`，以及循环上的 `else`

`break` 立刻离开**最内层**循环。`continue` 跳过本轮剩余语句，进入下一轮。

```python
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(n, "等于", x, "*", n // x)
            break
    else:
        # 内层 for 没有被 break，才走到这里
        print(n, "是质数")
```

**循环 `else` 是官网里最容易误解的语法**：它不表示「条件为假」，而是「循环**正常结束**（没被 `break`）」。`while` 同样可以带 `else`。

```python
i = 0
while i < 3:
    print(i)
    i += 1
else:
    print("while 正常结束")
```

`continue` 示例：只要奇数

```python
for num in range(2, 10):
    if num % 2 == 0:
        continue
    print("奇数", num)
```

## 3.6 `match` / `case`（3.10+）

类似其它语言的 `switch`，但更强：可以按**结构**拆数据，不只比相等。

```python
def http_error(status):
    match status:
        case 400:
            return "Bad request"
        case 404:
            return "Not found"
        case 418:
            return "I'm a teapot"
        case 401 | 403 | 404:
            return "Not allowed"
        case _:
            return "Something's wrong with the internet"
```

`_` 是通配，一定放最后。可以解包序列：

```python
point = (0, 1)
match point:
    case (0, 0):
        print("原点")
    case (0, y):
        print(f"在 Y 轴上, y={y}")
    case (x, 0):
        print(f"在 X 轴上, x={x}")
    case (x, y):
        print(f"点 ({x}, {y})")
    case _:
        print("不是一个点")
```

还可以匹配类实例、字典键。入门阶段记住：**先把枚举值、简单元组解包用熟**，复杂模式等用到再查[官网 match 一节](https://docs.python.org/3/tutorial/controlflow.html#match-statements)。

## 3.7 `while` 什么时候用

`for` 适合「有一份东西要逐个处理」。`while` 适合「事先不知道转几圈，靠条件停」：等用户输入、读网络、算到误差够小。

```python
n = 5
while n > 0:
    print(n)
    n -= 1
print("发射")
```

死循环：`while True:`，内部用 `break` 跳出。一定要保证退出条件可达。

## 3.8 综合例子：猜数字

```python
import random

secret = random.randint(1, 20)
print("我想了一个 1 到 20 的整数。")

for turn in range(1, 7):
    guess = int(input("猜一下: "))
    if guess < secret:
        print("小了")
    elif guess > secret:
        print("大了")
    else:
        print(f"对了！你用了 {turn} 次")
        break
else:
    print(f"次数用完了，答案是 {secret}")
```

这里把 `for` + `else` 用在「猜中就 break，没猜中才公布答案」。
