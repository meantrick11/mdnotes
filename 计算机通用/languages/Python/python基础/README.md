# Python 基础教程

本教程以 [Python 官方 Tutorial](https://docs.python.org/3/tutorial/index.html)（中文：[zh-cn](https://docs.python.org/zh-cn/3/tutorial/index.html)）为骨架，按**入门学习顺序**重排，而不是按官方章节号一一照搬。

官网 Tutorial 写给「已经会编程、第一次学 Python」的人，解释偏正式、例子偏短。本教程会：

- 跟着官网把**该讲的都讲到**（数字、字符串、列表、控制流、函数、数据结构、模块、IO、异常、类、迭代器）
- 在可变/不可变、引用赋值、`==`/`is`、短路运算、迭代协议这类**容易踩坑的地方多写一层原理**，但不展开 CPython 实现细节
- 每个知识点配**能直接敲的例子**

建议：**一边读一边在解释器里敲**。第 1 章已经讲过如何打开交互模式。
