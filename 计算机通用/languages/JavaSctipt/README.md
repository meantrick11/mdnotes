## 推荐学习网址

https://zh.javascript.info/

## 推荐学习内容

**第一部分「JavaScript 语言」:**

1. **JavaScript 基础知识**(全读,变量/循环/条件这些会的就快过)
2. **对象基础知识**(对象、对象方法、this)
3. **数据类型**(重点:数组、数组方法、字符串、解构赋值、JSON 方法,数字和日期可略过)
4. **函数进阶**(重点:Rest 参数与 Spread 语法、变量作用域与闭包;递归、柯里化跳过)
5. **错误处理**(只需 try/catch 那篇)
6. **Promise,async/await**(必读,axios 全靠它,别跳)
7. **模块**(导出和导入,看 Vue 代码需要)

**第二部分「浏览器:文档、事件、接口」:**

1. **文档**:搜索元素(getElementById/querySelector)、节点属性、修改文档、样式和类——这些够用了,DOM 遍历/坐标/滚动跳过
2. **事件简介**:事件冒泡、事件委托、浏览器默认行为——理解 Vue 的 @click 和事件修饰符会用到
