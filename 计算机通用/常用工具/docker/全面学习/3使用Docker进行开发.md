# 使用容器进行开发

**Docker的作用就是将能运行的环境进行打包，然后任何一个拉取镜像之后，只要运行，就能确保环境一致，所以和环境大包相关的都可以使用Docker，比如软件开发时的最开始开发环境的同步(开发人员同步拉取同一的Docker镜像(也就是所要用的依赖)，然后进行各自开发+Git进行版本控制)，网安靶场的构建(也是环境统一分发问题)**

**注意：Git是进行源码的版本控制问题，Docker是环境控制问题，环境本质也是文件(比如Python的依赖包)，所以两者获取的时候都是将对应的所需文件下载到本地**

## 启动项目

1. 要开始操作，请将项目克隆下来，或以 ZIP 文件形式下载到你的本地计算机。
`git clone https://github.com/docker/getting-started-todo-app`

进入克隆的项目中
`cd getting-started-todo-app`

2. 获取项目后，使用 Docker Compose 启动开发环境。

`docker compose watch`

你会看到一个输出界面，显示容器镜像正在拉取、容器正在启动等内容。目前不必完全理解这些内容，稍等片刻，相关操作就会稳定并完成。

3. 打开浏览器访问http://localhost，即可看到应用已启动并运行。应用启动可能需要几分钟时间。这是一个简单的待办事项应用，你可以随意添加一两个事项、将部分标记为已完成，甚至删除某个事项。

### 环境中包含什么？

现在环境已经搭建完成，里面具体包含什么呢？从整体来看，有多个容器（或进程），每个都为应用程序承担特定的功能需求：

1. React 前端——一个运行着 React 开发服务器的 Node 容器，使用了 Vite。
2. Node 后端——该后端提供了一个 API，支持对待办事项进行查询、创建和删除操作。
3. MySQL 数据库——用于存储待办事项列表的数据库。
4. phpMyAdmin——一个用于与数据库交互的基于网页的界面，可通过http://db.localhost访问。
5. Traefik 代理 - Traefik 是一款应用代理，可将请求路由到对应的服务。它会将所有针对 localhost/api/* 的请求发送到后端，将 localhost/* 的请求发送到前端，再将 db.localhost 的请求发送到 phpMyAdmin。这样就能通过 80 端口访问所有应用（而非为每个服务使用不同端口）。
