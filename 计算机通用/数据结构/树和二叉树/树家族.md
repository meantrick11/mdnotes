# 二叉树相关各类特殊树完整分类
## 一、按**节点数值规则**划分（值约束）
### 1. 二叉搜索树 BST（二叉查找树）
规则：任意节点，左子树全部节点值 < 当前节点 < 右子树全部节点值；中序遍历升序。
### 2. 平衡二叉搜索树（平衡BST，解决BST退化成链表）
1. **AVL树**：左右子树高度差绝对值≤1，失衡靠旋转调整；严格平衡。
2. **红黑树**：弱平衡，最长路径不超过最短路径2倍；Linux进程调度、C++ map底层。
3. B树 / B+树 / B*树：多路平衡查找树，多用于数据库、磁盘索引，不是二叉树。
### 3. 堆（大/小根堆）
完全二叉树+堆序：父节点 ≥（大根堆）/ ≤（小根堆）子节点；只保证堆顶是最值，**不是BST**。

## 二、按**树形结构形态**划分（结构约束，无数值要求）
### 1. 满二叉树
每一层所有节点全部填满；深度为h，节点总数 = $2^h-1$。
### 2. 完全二叉树
除最后一层外每层全满，最后一层节点**靠左连续排列**；堆的强制底层结构。
> 区分：满二叉树一定是完全二叉树，完全二叉树不一定是满二叉树。
### 3. 完美二叉树
等价满二叉树（教材不同叫法）。
### 4. 斜树（单边二叉树）
所有节点只有左孩子/只有右孩子，BST最坏形态，查找效率退化为O(n)。

## 三、带特殊附加规则的树
### 1. 哈夫曼树（最优二叉树）
带权路径长度WPL最小的二叉树；用于文件压缩编码，**无度为1的节点**。
### 2. 线索二叉树
利用叶子空指针（左/右null）存前驱、后继节点，方便遍历，不递归不栈。

## 四、拓展：非二叉的树结构
1. **多叉树**：节点孩子数量不限（B树、字典树Trie）
2. **字典树 Trie**：按字符存储前缀，用于字符串匹配、搜索提示
3. **并查集（树结构）**：森林，用于连通性判断
4. 图衍生：最小生成树（Prim/Kruskal）

## 快速关系总结
1. 二叉搜索树：只管数值大小，不限树形（可以是斜树）
2. 满/完全二叉树：只管树形，无数值规则
3. 堆：**完全二叉树 + 堆序数值规则**
4. AVL、红黑树：**二叉搜索树 + 平衡高度规则**
5. 哈夫曼树：带权路径最优的二叉树，无查找序规则
