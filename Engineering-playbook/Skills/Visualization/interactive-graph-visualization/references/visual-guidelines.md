# 视觉与交互规范

## 页面层次

1. 标题说清图的主题；一句导读说明推荐阅读顺序。
2. 主图优先显示主路径，再显示分支、例外与回路。节点默认只放短标题和一句职责。
3. 细节按需展开：点击节点后呈现说明、上下游、证据或来源。较大图提供搜索、局部聚焦和视图重置。
4. 图例说明节点类型、边类型和颜色含义；相同颜色在整图中保持同一含义。

## 聚焦与动画

- 选中节点用高亮边框和柔和外发光；直接关联的节点与边保持完整亮度。
- 无关元素约 10%～20% 透明度，仍保留空间参照。
- 状态切换用 150～250ms 过渡；流光 1.5～2.5 秒循环，青蓝色或当前主题强调色。
- 原始边、箭头和标签始终保留；流光只作为方向提示。
- `prefers-reduced-motion: reduce` 时隐藏流光，保留静态高亮。
- 覆盖层不接收指针事件；切换、取消、销毁和导出时清理。

## 图面质量

- 保留足够留白，减少交叉；长链路可用章节或分组视图。
- 深浅主题都要检查文字、边、选中态和淡化态的可读性。
- 窄屏可允许横向滚动、缩放或分段阅读；不强行压缩节点文字。
- 图的空间布局只是阅读辅助，不得暗示未定义的关系或方向。
