# 交互式关系图可视化

## 执行步骤

1. **整理图数据。** 从输入中列出节点、关系、方向、分组、阶段和待确认信息。每个节点、每条边使用稳定唯一 ID，边明确 `source` 与 `target`。检查关系是否有事实依据；不明确的关系标注待确认。数据结构见 [图数据约定](references/graph-contract.md)。
2. **选择阅读结构。** 为图确定一个主要阅读问题和清晰主线。用分组、泳道或阶段表达责任和顺序；分支与回路保留真实方向。布局、颜色和密度按 [场景规则](references/scenarios.md)及 [视觉与交互规范](references/visual-guidelines.md)处理。
3. **绘制交互图。** 优先沿用目标环境现有绘图技术；没有现成框架时使用原生 HTML、SVG、CSS、JavaScript。SVG `path` 保留原始连线和箭头，节点展示简短名称，详细内容在点击后呈现。按需要提供搜索、缩放、重置、主题和导出。
4. **实现关系聚焦。** 点击节点选中，再次点击或点击画布空白取消。由图的邻接关系计算 Direct、Upstream、Downstream、All 四种范围；高亮选中节点、关联节点和边，其余淡化至约 10%～20%。支持键盘 Enter、Space、Escape，遍历使用 `visited` 处理环路与重复边。
5. **实现链路流光。** 在高亮边的原始 SVG `path` 上叠加覆盖路径，使用 `stroke-dasharray` 与 `stroke-dashoffset` 顺 `source → target` 方向运动。流光持续约 1.5～2.5 秒，保持克制；切换节点时清理旧覆盖层。缩放平移时覆盖层与原边同步。尊重 `prefers-reduced-motion`；原始边始终可见。
6. **验证交付。** 实际打开输出，逐项检查点击、取消、快速切换、方向、分支、环路、缩放、窄屏、键盘、静态模式和导出。确认增强没有改变节点坐标或关系语义。交付 HTML 及其必要资源，并说明哪些关系尚待确认。

## 可复用资源

- `assets/graph-focus.js`：独立的图邻接计算和原生 SVG 聚焦控制器；页面需以 `data-graph-node-id`、`data-graph-edge-id` 连接图数据与 SVG 元素。
- `assets/graph-focus.css`：淡化、选中发光和定向流光的基础样式。可直接使用，也可按既有主题调整颜色。

资源是可选实现材料。使用已有绘图库时，将相同的图数据、交互状态和动画覆盖层接入当前组件，不为了使用资源而替换绘图库。

## 完成标准

节点和边能追溯到输入；所有关联范围和流光方向正确；取消聚焦后恢复初始状态；快速切换没有残留动画；减少动态效果时仍能读懂图；交付文件可独立打开。
