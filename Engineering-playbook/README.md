# Engineering-playbook

本文件夹记录一些标准的工程师遇到的常见助推资产，比如；
1. Workflows：包括一个项目从0->1->∞的完整阶段&工作流
2. Templates：记录每一个阶段的产出文档模板，以及可能一些可用的模板文档样例--大部分模板在对应的Native-Team每个阶段都有对应产出模板
3. Teammates：记录一个开发团队基础职能&以及开发上下游可能交流的职能/职位
4. skills:结合Workflow给AI相关的skills，比如开发过程、自己沉淀的个人skills等等。--主要是以能力划分，对应的Team中的阶段性READEM.md会指向外部的能力skills或者有自己的专属阶段性skills
5. SystemDesign：一些系统设计/项目常规架构相关的内容/笔记/设计
6. AI-Native-Team：结合workflow、templates&SKills相关的AI工作流标准。
