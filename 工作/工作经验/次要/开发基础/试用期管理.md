# 试用期管理

## 1. 工作计划

每个月部门负责人会制定试用期工作计划。由人力行政部发起，新员工本人和部门负责人共同确认。月末人力行政部会确认工作完成情况，明确试用期工作表现。

## 2. 试用期满

试用期结束前两周，人力行政部将通知新员工准备试用期转正答辩，并在企微发起申请。准备材料：①试用期工作总结表；②试用期转正答辩 PPT。

## 3. 转正答辩

试用期结束前一周由人力行政部安排转正答辩述会议，会议参与人：直属上级、中心负责人、人力行政部。会议参与人将根据转正述职进行现场评分。评分结果将直接影响转正结果。

## 4. 试用期结束

转正答辩结束后将现场告知转正结果，后续告知岗位职级评定
