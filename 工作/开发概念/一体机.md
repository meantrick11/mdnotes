# 一、什么是一体机
一体机（All-in-One，AIO）核心：**把多个硬件/功能集成在同一个机身内，不再拆分成独立主机、独立外设**。常见几类：
1. **电脑一体机（AIO）**
把主板、CPU、内存、硬盘、电源、音响摄像头全部塞进显示器后背。外观就是一台厚显示器，只需要一根电源线，搭配键鼠就能用，省去主机箱。缺点：硬件很难升级。


2. **打印一体机（MFP多功能一体机）**
一台机器同时支持：打印、复印、扫描，部分带传真。办公最常见。
3. **行业一体机**
工业触控一体机、教学触控一体机、超融合一体机（服务器+存储+虚拟化软件打包一体机，IT项目常用）。

> 一句话：**多组件/多功能合并为单个整机设备，开箱即用，减少布线和部署**。

# 二、最后交付（Final Deliverables / 最终交付）
项目/采购场景里的意思：**全部工作做完，把完整成果正式交给甲方，完成验收签字，是项目收尾节点**。
如果是一体机项目，**最后交付一般包含这几样**：
1. 硬件：全部一体机设备、支架、配件、线材；
2. 软件：预装系统、定制程序、授权许可；
3. 文档：合格证、出厂检测报告、使用手册、运维文档；
4. 实施成果：现场安装、调试、通电测试、培训；
5. 交付凭证：验收单（甲方签字，代表项目正式交付完成）。

⚠️ 区分两个概念：
- 到货交付：设备送到现场（只是货到，不算项目完成）
- **最后交付（最终交付）：安装调试全部完成，功能满足合同要求，甲方验收通过**
