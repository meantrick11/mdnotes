02 / 学习优先级

区分「现在必须形成交付能力」和「先建立认知、随后逐步深入」
核心深入后端 · Agent · 软件工程
持续学习CS · ML/DL · 数据工程 · LLMOps
后续进阶架构设计 · 安全治理
按需补充前端 · 数学统计专项
优先级原则：核心模块必须能独立交付真实项目；支撑模块优先做到理解原理 + 能解决项目问题；分布式和复杂治理要在已有生产实践基础上进阶。以上条形表示学习投入层次，而不是严格的时间百分比。

03 / 分阶段执行路线

阶段是能力里程碑，不是固定月份。每一阶段都以实际交付物验收。
PHASE 01 · 工程闭环

能独立交付一个后端服务

  • FastAPI / PG / ORM / 异步
  • pytest、logging、错误处理
  • Docker、CI、部署
  • 计算机基础持续补齐
验收：一个可部署、有测试和文档的 API 服务
PHASE 02 · AI 能力闭环

能设计和评估 AI 功能

  • 传统 ML 基础与评估
  • Transformer、Embedding、微调
  • RAG 数据处理与检索
  • 分类/分级 POC 对照实验
验收：可复现的基线、评估报告、模型服务
PHASE 03 · Agent 系统

从 Demo 到稳定可用

  • Agent Runtime、工具执行
  • Context / Memory / 状态持久化
  • 评估、Tracing、成本控制
  • 任务恢复与人机协同
验收：完整、可观测、可恢复的 Agent 应用
PHASE 04 · 平台与架构

构建可靠的复杂系统

  • 多 Agent 协作与共享状态
  • 扩展性、缓存与消息系统
  • 权限、安全、租户隔离
  • 性能、可靠性与架构权衡
验收：多组件系统设计文档 + 性能/故障实验
