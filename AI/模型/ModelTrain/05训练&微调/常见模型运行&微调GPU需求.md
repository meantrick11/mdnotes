## 一、常见模型参数规模与资源需求矩阵

先统一估算条件：

- 推理：单卡、Batch Size 1、上下文 4K 左右。
    
- 推理量化：INT4 / INT8，FP16/BF16。
    
- 微调：LoRA、QLoRA、全量微调。
    
- 微调上下文：2K 左右，Gradient Checkpointing 开启。
    
- 表格中的显存均指 GPU 显存，不是系统内存。
    

## 二、核心经验矩阵：模型参数 → 部署、推理、微调

单位：GB 显存。以下采用工程规划值，而不是理论最低值。

|模型参数|FP16 部署权重|INT8 部署权重|INT4 部署权重|INT4 推理建议显存|FP16 推理建议显存|
|---|---|---|---|---|---|
|1B|2GB|1GB|0.5GB|2–3GB|3–4GB|
|3B|6GB|3GB|1.5GB|3–5GB|8–10GB|
|7B–8B|14–16GB|7–8GB|3.5–4GB|6–8GB|18–20GB|
|14B|28GB|14GB|7GB|10–12GB|32–36GB|
|32B|64GB|32GB|16GB|20–24GB|72–80GB|
|70B|140GB|70GB|35GB|42–48GB|160GB+|
|100B|200GB|100GB|50GB|60–70GB|230GB+|
|405B|810GB|405GB|203GB|230–260GB|900GB+|

说明：

- FP16/BF16：每个参数约 2 Bytes。
    
- INT8：每个参数约 1 Byte。
    
- INT4：每个参数约 0.5 Byte。
    
- 推理建议显存包含额外运行开销及一定 KV Cache 预算。
    
- 以上是单卡总显存需求估计；超过单卡容量时，需要多卡切分或 CPU Offload。
    

参考 Hugging Face 的权重显存计算规则及模型推理资源资料。

## 三、模型微调显存矩阵

这张表更适合你的模型微调技术选型。

|模型参数|QLoRA 4bit|LoRA BF16/FP16|全量微调 BF16 + AdamW|
|---|---|---|---|
|1B–3B|6–8GB|8–12GB|24–32GB|
|7B–8B|10–14GB|16–24GB|60–80GB|
|13B–14B|16–20GB|28–40GB|120GB+|
|30B–34B|24–32GB|64–80GB|2–4 × 80GB|
|70B–72B|40–48GB|2 × 80GB|4–8 × 80GB|
|100B|60GB+|多卡|多卡集群|
|405B|230GB+|多卡集群|多卡集群|

这些是相对保守的工程规划范围，假设短上下文、Batch Size 1–2、使用梯度检查点等优化。不同训练框架的最低显存可能更低。

Axolotl+2

特别注意两个容易混淆的地方：

1. QLoRA 4bit 的显存需求并不是简单的模型权重大小。训练时仍然需要保存激活值、梯度以及适配器优化器状态。
    
2. LoRA 不等于只存储 LoRA 参数。基础模型仍然需要加载到显存中。
