## 实验路线
[ ] 需求与基线：定义任务指标、验收门槛和基座模型 Baseline
[ ] 数据准备：清洗、审核、去重、脱敏、划分和版本化
[ ] 训练环境：验证 GPU、PyTorch、依赖、存储及资源预算
[ ] 模型准备：验证基座模型、Tokenizer、Chat Template 和显存
[ ] 训练实现：确定 LoRA 配置、超参数、日志与 Checkpoint 策略
[ ] 小规模试跑：完成 Smoke Test 和小样本过拟合测试
[ ] 正式训练：记录训练指标、系统状态和每次实验配置
[ ] 离线评估：对比基线、分析业务指标及失败样本
[ ] 实验迭代：提出根因假设、控制变量、验证改进
[ ] 模型交付：保存模型产物、版本信息和评估报告
[ ] 生产部署：验证推理性能、执行灰度与回滚测试
[ ] 线上反馈：监控失败模式，将问题纳入下一轮实验

## 学习知识

不是再单独开一条需要从头到尾学完的庞大学习路线，而是围绕一个训练项目，逐渐补齐相关知识。

|知识方向|需要掌握的深度|优先级|
|---|---|---|
|Python、NumPy、Pandas|独立实现数据处理与验证脚本|高|
|Linux、Shell、SSH|独立管理训练服务器|高|
|PyTorch|理解 Tensor、Autograd、训练循环和 GPU|高|
|Transformers、PEFT、TRL|能阅读配置、修改微调流程|高|
|模型评估与实验设计|独立诊断模型质量、设计对照实验|高|
|CUDA 与 GPU 基础|理解显存、精度、性能瓶颈|中|
|Docker|构建可复现的训练环境|中|
|MLflow / W&B|管理实验与比较结果|中|
|vLLM|模型推理服务部署|中|
|DDP、FSDP、DeepSpeed|多卡及大规模分布式训练|后续|
|Kubernetes、Kubeflow|平台化任务调度与训练流水线|后续|

我特别建议你不要忽略 实验设计、评估和错误分析。

因为模型训练工程里存在两种不同的能力：

一种是“我能把模型跑起来”，另一种是“我能解释模型为什么没有达到目标，并且设计实验证明怎样改进”。

后者往往更能体现你是否真正理解模型，而不是只会调用训练框架。
