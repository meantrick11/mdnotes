
# 正式训练：让一次训练可观察、可恢复、可追溯

正式训练关注的不只是 GPU 是否在计算。

还要监控四类信息。

## 7.1 系统指标

包括 GPU 利用率、显存占用、CPU、内存、磁盘空间，以及训练吞吐。

GPU 利用率长期偏低，不一定说明模型结构有问题，也可能是数据加载、磁盘、CPU 处理或多卡通信导致瓶颈。

## 7.2 优化指标

包括 Training Loss、Validation Loss、Learning Rate、Gradient Norm 等。

## 7.4 Checkpoint

Checkpoint 不只是定期保存模型权重。

有两种用途需要区分：

- 训练恢复：保存模型或 Adapter 参数，以及恢复所需的优化器、学习率调度器、训练步数等状态。
    
- 推理部署：保存最终模型或 Adapter，用于加载并推理。
    

例如 LoRA Adapter 文件通常不能单独作为完整模型直接使用，需要与相应基座模型组合，或者在兼容情况下执行权重合并。

Hugging Face

因此，正式训练应该提前决定 Checkpoint 保存频率、存储位置、保留数量、恢复策略，以及磁盘空间预算。
