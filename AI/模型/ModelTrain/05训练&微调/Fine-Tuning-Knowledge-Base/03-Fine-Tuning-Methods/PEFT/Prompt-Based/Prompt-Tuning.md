# Prompt Tuning

> 一句话摘要：训练连续的输入端软提示向量，冻结基础模型权重。 **优先级：P2**。前置：[方法总览](../README.md)；后续：[方法比较](../../../12-Comparisons/PEFT-Methods-Comparison.md)。

## 技术定义与解决的问题

训练连续的输入端软提示向量，冻结基础模型权重。 可用少量任务参数改变模型条件输入；与手写自然语言 prompt 不同。
