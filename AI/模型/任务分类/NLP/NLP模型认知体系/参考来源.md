# NLP 模型认知体系：参考来源

> 核对日期：2026-11-02。以下链接指向原论文或项目官方文档。分类体系本身是对来源的整理，属于本笔记的综合归纳，而非某篇论文提出的统一标准。

| 主题                   | 原始来源                                                                                                                                                                                                                                | 对本体系的支持                                                                                                                          |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Transformer 与编码器、解码器 | [Vaswani 等，*Attention Is All You Need*](https://arxiv.org/abs/1706.03762)                                                                                                                                                           | 原始 Transformer 是编码器—解码器结构，核心计算基于注意力。说明“Transformer”是骨干架构，“Encoder-only / Decoder-only / Encoder-Decoder”是其结构细分，不能用后者覆盖所有 NLP 模型。 |
| BERT 与任务头            | [Devlin 等，*BERT*](https://arxiv.org/abs/1810.04805)；[Hugging Face Transformers：任务如何实现](https://huggingface.co/docs/transformers/main/tasks_explained)                                                                               | BERT 学习双向上下文表示；在基础模型上添加输出层可适配问答、自然语言推断等任务。官方实现文档分别展示序列分类头与 token 分类头。                                                            |
| T5 与生成式任务表达          | [Raffel 等，*Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*](https://jmlr.org/papers/v21/20-074.html)                                                                                             | T5 将分类、问答、摘要等任务转为文本到文本格式，说明任务类型与输出机制是不同维度。                                                                                       |
| 文本向量与双塔编码            | [Reimers 与 Gurevych，*Sentence-BERT*](https://arxiv.org/abs/1908.10084)；[Sentence Transformers：SentenceTransformer 用法](https://sbert.net/docs/sentence_transformer/usage/usage.html)                                                 | 句子可独立编码为向量并用相似度比较，适合语义检索等场景；“Embedding”描述输出与使用方式，不限定某一种底层骨干。                                                                     |
| 联合编码与重排序             | [Sentence Transformers：CrossEncoder API](https://www.sbert.net/docs/package_reference/cross_encoder/model.html)；[Retrieve & Re-Rank 官方示例](https://sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html) | Cross-Encoder 联合处理文本对，输出分数或类别，不能预计算单篇文本的向量；重排序是常见用途之一，并非独立的基础架构类别。                                                               |
| 参数高效微调               | [Hu 等，*LoRA*](https://arxiv.org/abs/2106.09685)；[Dettmers 等，*QLoRA*](https://arxiv.org/abs/2305.14314)                                                                                                                              | LoRA 冻结预训练权重并训练低秩矩阵；QLoRA 在冻结的量化模型上训练低秩适配器。两者属于适配方法，不能与 BERT、T5 等模型实例并列。                                                         |
| 状态空间模型               | [Gu 与 Dao，*Mamba*](https://arxiv.org/abs/2312.00752)                                                                                                                                                                                | Mamba 将选择性状态空间模型用于序列建模，提供 Transformer 之外的骨干架构实例。                                                                                 |

## 使用边界

- 论文支持其提出的方法或模型；“模型家族—架构—预训练目标—任务—输出机制—适配方式”这一组分类维度是为笔记检索和选型而整理的分析框架。
- 官方库文档展示具体实现方式，不等于所有模型或版本都支持相同的任务头、输入长度和训练方法。涉及具体 checkpoint 时应再核对其模型卡与配置。
