# NLP 模型认知体系

这里积累跨任务的 NLP 模型认知笔记。相邻的 `TextClassification`、`TextReranking` 等目录继续记录具体任务；本目录解释架构、模型、训练和任务之间的关系。

## 阅读入口

1. [02-NLP模型多维分类体系](02-NLP模型多维分类体系.md)：先用稳定的分类维度给术语定位。
2. [01-NLP技术发展与模型演进](01-NLP技术发展与模型演进.md)：梳理技术发展线索和今天仍适用的场景。
3. [03-主要模型架构与原理](03-主要模型架构与原理.md)：解释输入、编码、输出及关键机制。
4. [04-代表模型知识图谱](04-代表模型知识图谱.md)：按具体版本记录模型实例及来源。
5. [05-模型能力与NLP任务映射](05-模型能力与NLP任务映射.md)：解释底座、任务头、训练目标和任务的组合。
6. [06-训练微调与推理方法](06-训练微调与推理方法.md)：区分训练阶段、参数更新方法和推理机制。
7. [07-NLP模型选型方法论](07-NLP模型选型方法论.md)：把任务、数据和资源约束转成验证方案。
8. [08-NLP模型技术全景总结](08-NLP模型技术全景总结.md)：汇总分类、映射和选型入口。

八篇主题笔记均已写入。重要概念的原始来源见[参考来源](参考来源.md)，各篇还在相关论述处链接原论文或官方模型卡。模型图谱是认知卡片，不代表相关 checkpoint 已在本地业务数据上验证。

## 记录约定

- 先判断一个术语属于**架构、模型实例、训练目标、输出机制、任务、参数适配方式**中的哪一层，再记录它与其他层的组合关系。
- 模型家族与具体 checkpoint 分开记录；能力、上下文长度、语言支持和部署要求以具体版本及官方资料为准。
- 对“理论上可做”“公开实现支持”“本地实验验证”分别注明证据，不用架构推断替代工程验证。
