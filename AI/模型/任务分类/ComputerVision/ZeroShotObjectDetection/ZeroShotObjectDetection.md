# Zero-Shot Object Detection（零样本目标检测）

输入图片和候选物体类别，模型找出匹配物体的位置与类别。它结合了零样本类别匹配和目标检测的边界框输出。

## 例子

页面示例给出候选类别 `cat, dog, bird`；模型需要在图片中框出符合候选类别的物体，并标注类别。

## 应用场景

按文字类别查找图片中的目标，或统计仓库、商店和活动现场中特定物体的数量。

来源：[Hugging Face：Zero-Shot Object Detection](https://huggingface.co/tasks/zero-shot-object-detection)
