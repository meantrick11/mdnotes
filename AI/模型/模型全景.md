实际模型 = 数据表示 + 网络结构 + 交互方式 + 输出设计 + 学习到的参数

需要强调：这 8 个维度是用于分析模型的框架，并不是八个互斥、必须逐个选择的标准模块。

# 二、各个维度的常见技术清单

## 1. 任务层：模型最终要干什么？

|任务类型|常见任务|输出形式|
|---|---|---|
|分类 Classification|文本分类、图像分类、情感分析|类别 ID、概率|
|回归 Regression|价格预测、相关性评分|连续数值|
|检索 Retrieval|文档搜索、语义召回|相似度、候选排序|
|排序 Ranking|搜索精排、推荐排序|排序分数|
|推理 Inference|NLI、关系判断|蕴含/矛盾/中立|
|信息抽取 IE|NER、关系抽取、事件抽取|实体、关系、字段|
|生成 Generation|对话、翻译、图像生成|文本、图像、音频|
|聚类 Clustering|用户分群、文档聚类|簇 ID|
|检测 Detection|目标检测、异常检测|目标位置、异常分数|

NLI 和 NER 就属于这一层，并不是特定的神经网络结构。

## 2. 数据表示层：模型如何接收数据？

|表示方式|主要原理|使用场景|
|---|---|---|
|数值特征|将输入转成固定维度数值|表格、传统 ML|
|Token ID|文本经过分词映射为离散 ID|NLP、LLM|
|Embedding|将离散对象映射为稠密向量|语言、推荐、检索|
|Image Patch|将图像切分为若干块|ViT|
|频谱 / Mel 特征|将音频转为时频表示|语音模型|
|图结构|节点、边及其属性|GNN|
|时序特征|按时间顺序组织观测值|RNN、SSM、时间序列模型|

注意，Token ID 通常还需要经过 Embedding 层转为向量，才能进入神经网络。

## 3. 基础架构层：模型内部怎样计算？

|架构|核心原理|代表技术|
|---|---|---|
|MLP|多层线性变换 + 非线性激活|前馈神经网络|
|CNN|卷积核提取局部特征|ResNet、ConvNeXt|
|RNN|隐藏状态循环传递|RNN、LSTM、GRU|
|Transformer|注意力机制建模 Token 关系|BERT、GPT、ViT|
|SSM|状态更新建模序列|S4、Mamba|
|GNN|图上节点间消息传递|GCN、GAT|
|Tree Ensemble|多棵决策树集成预测|XGBoost、LightGBM|

其中 XGBoost、LightGBM 属于非神经网络机器学习模型，不需要强行归入 Transformer 等神经网络体系。

## 4. 内部组织层：网络怎样组合？

|组织方式|作用|代表|
|---|---|---|
|Encoder-only|将输入编码为上下文表示|BERT|
|Decoder-only|自回归预测后续 Token|GPT、Llama|
|Encoder-Decoder|编码输入，再解码输出|T5、BART|
|Siamese / 双塔|两路编码后比较表示|Sentence-BERT|
|Cross-Encoder|两段文本联合编码|BGE Reranker|
|MoE|Router 动态选择专家网络|Mixtral、部分 DeepSeek 模型|
|U-Net|下采样、上采样、跳跃连接|图像分割、扩散模型|

严格来说，Cross-Encoder 与 Encoder-only 是可以同时成立的，它们分别描述输入交互方式和主干网络组织方式。

## 5. 交互机制层：信息如何互相影响？

|机制|原理|
|---|---|
|Self-Attention|输入序列内部各 Token 相互关注|
|Cross-Attention|一个序列关注另一个序列的信息|
|Causal Attention|限制模型只能关注当前位置及之前的信息|
|卷积|相邻局部区域之间共享计算|
|门控机制|控制信息保留、遗忘与传递|
|消息传递|图节点聚合邻居信息|
|向量相似度|对已经编码的向量计算匹配程度|
|Late Interaction|独立编码后进行 Token 级匹配|

特别注意：Cross-Encoder 不等于 Cross-Attention。前者描述文本对的联合编码方式，后者是注意力机制的一种形式。

## 6. 输出结构层：模型怎样给出结果？

|输出模块|输出内容|常见用途|
|---|---|---|
|Classification Head|类别 Logits|分类、NLI|
|Regression Head|连续数值|相关性评分、回归|
|Token Classification Head|每个 Token 的标签|NER|
|Projection Head|向量表示|Embedding、对比学习|
|LM Head|词表上每个 Token 的 Logits|语言生成|
|Detection Head|位置、类别、置信度|目标检测|
|Decoder|重建或生成结构化输出|翻译、图像生成|

## 7. 训练机制层：模型怎样获得能力？

|方法|原理|场景|
|---|---|---|
|自监督预训练|从原始数据构造学习信号|BERT、GPT|
|监督学习|通过人工标签学习映射|文本分类|
|对比学习|拉近正样本、拉远负样本|Embedding、检索|
|排序学习|学习正负候选的相对排序|Reranker|
|SFT|使用指令、答案或标注样本微调|LLM、分类|
|LoRA / QLoRA|使用少量可训练参数进行适配|大模型微调|
|蒸馏|用教师模型指导学生模型|模型压缩|
|偏好优化|根据偏好信号优化模型输出|DPO 等|

这些方法可以组合。例如：先自监督预训练，再进行监督微调，最后用蒸馏生成轻量模型。

## 8. 推理和部署层：如何投入实际使用？

|技术|主要用途|
|---|---|
|ONNX Runtime|跨框架模型推理|
|TensorRT|NVIDIA GPU 推理优化|
|vLLM|大语言模型高吞吐推理服务|
|llama.cpp|本地 LLM 推理|
|INT8 / INT4 量化|降低权重存储与计算开销|
|KV Cache|避免自回归生成中重复计算历史 K/V|
|向量索引（HNSW、IVF）|加速大规模向量检索|
|Batching|合并请求提高设备利用率|

这属于工程部署，不是模型本身的神经网络架构。

## 四、把这四个模型放在一张对照表中

|维度|BGE Embedding|BGE Reranker|BERT-MNLI|Qwen 生成模型|
|---|---|---|---|---|
|基础架构|Transformer|Transformer|Transformer|Transformer|
|主干组织|Encoder-only|Encoder-only|Encoder-only|Decoder-only|
|输入交互|Bi-Encoder 式|Cross-Encoder|Cross-Encoder 式|因果注意力|
|输出|向量|分数|三分类 Logits|Token Logits|
|典型训练|对比学习|排序学习|NLI 监督学习|下一个 Token 预测及后训练|
|主要用途|语义召回|候选精排|逻辑关系判断|内容生成与指令执行|

这张表有一个很重要的发现：

BGE Reranker 和 BERT-MNLI 可以使用非常接近的基础模型架构和输入组织方式，但由于训练目标不同，最终能力完全不同。

所以，不能只看模型是不是 Transformer、Cross-Encoder，就判断它适不适合某个业务。
