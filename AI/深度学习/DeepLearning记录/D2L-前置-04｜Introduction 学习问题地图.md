## 从规则程序到数据驱动程序

**已知规则且能可靠覆盖情形时，不必引入机器学习。** 例如购物车的业务规则可以直接编程和测试。天气预测、图像中的人物定位、蛋白质结构预测等问题难以穷举规则，且规律可能随时间变化。这时可以从样本或与环境的交互中估计一个映射；模型重新训练后，行为也可能改变。（书页 21）

### 唤醒词：一个贯穿本章的例子

手机持续监听唤醒词，需要把一段音频映射为 `{是, 否}`。可以给音频片段标注是否包含唤醒词，然后选一个行为由参数控制的**模型族**，用数据挑出合适的参数。随机参数通常不会识别目标词，训练的目的就是让参数产生期望行为。（书页 22–23）

训练循环为：**初始化参数 → 取一批样本及标签 → 根据表现调整参数 → 重复至停止**。参数固定后，模型对新音频作判断是**推断**。本书用小型唤醒词模型和大型助手模型说明：规模、算力及任务不同，但都可以用“数据、模型、目标、调整参数”的框架描述。这里的四步是通用抽象，不表示两者使用完全相同的数据或训练细节。

## 四个核心部件（书页 23–25）

| 部件 | 回答的问题 | 唤醒词例子 |
|---|---|---|
| 数据 | 从什么经验学习？ | 音频片段及其 `{是, 否}` 标签 |
| 模型 | 用什么可调整的映射产生预测？ | 由参数决定判断结果的计算程序 |
| 目标函数 | 如何量化好坏？ | 比较预测与真实标签的损失 |
| 优化算法 | 如何找到较好的参数？ | 基于梯度，逐批更新参数 |

### 数据：数量、形式与质量

一个数据集由样本组成；在监督学习中，样本的**特征**是模型输入，**标签**是要预测且不可作为输入偷看的目标。例如 200×200 的 RGB 图像可表示为 $200\times200\times3=120000$ 个数。固定长度便于批处理，但文字、音频、不同大小的图像可能本来就有变长结构。（书页 23–24）

更多数据能支撑更大的模型，却不能补救错误标签、无关特征或覆盖不足。训练集若缺少某类人群，模型在该人群上的表现可能失效；历史招聘决策等数据还可能继承社会偏差。因此评估数据时同时问：**它覆盖了谁、遗漏了谁、标签是否可靠、部署场景是否与数据来源相似？**

### 模型、目标与泛化

模型是从输入到预测的计算机制，参数是可由数据调整的数值。深度学习侧重多层变换的组合。目标函数规定何为“变好”；常把它写成越小越好的**损失**。数值预测常用平方误差，分类中错误率本身不可微，通常用可优化的交叉熵等替代目标。（书页 24–25）

**训练损失低不等于新样本表现好。** 参数由训练集学习，留出的测试集用于检查泛化；若训练集表现好而新数据表现差，即过拟合。优化时把数据视为固定、以参数为变量，梯度给出局部损失变化方向；用随机小批量估计更新方向，构成随机梯度下降。最终关注的是未见数据上的表现，而非只把训练损失压低。

## 学习问题的分类（书页 25–35）

| 问题 | 输出/反馈的形式 | 典型例子 | 与相邻概念的边界 |
|---|---|---|---|
| 回归 | 连续或可取任意数值的标签 | 房价、降雨量 | 问“多少”，而不是选离散类别 |
| 分类 | 互斥类别或类别概率 | 手写数字识别 | 二分类为两类，多分类为多类 |
| 多标签分类 | 同一样本可有多个标签 | 文章同时贴多个主题标签 | 多个标签可同时为真 |
| 序列学习 | 输入、输出或两者是序列 | 语音识别、文本转语音、翻译 | 顺序和长短都可能重要 |
| 自监督学习 | 从数据本身构造预测目标 | 从前文预测下一个 token | 有预测目标，但无需人工逐条标注 |
| 无监督学习 | 不给预测目标，寻找结构 | 聚类、主成分分析 | 不等于自监督的“数据生成标签” |
| 强化学习 | 行动后得到奖励及新观察 | 游戏、控制、工具调用 | 反馈通常不是逐步给出的正确动作 |

### 回归、分类与决策

回归的关键是**标签形式**，例如用面积、卧室数等估计房价。原书用两个管道维修账单说明线性关系：3 小时收 350、2 小时收 250，若假定“固定上门费 + 每小时费用”，可解得每小时 100、上门费 50。真实数据通常有未观测因素和噪声，不能只靠两点精确拟合。（书页 26–27）

分类输出概率比硬判类别更便于优化，也能表达不确定性。但**概率最高的类别不一定对应最优行动**。书中毒蘑菇例子：即便有毒概率只有 0.2，误食的代价仍可能远大于扔掉可食蘑菇的代价。决策需同时考虑概率和错误成本。作为对原书练习 3 的推导，若误食损失为 $L$、误弃可食蘑菇损失为 1，则“吃”的期望损失是 $pL$，“丢弃”的期望损失是 $1-p$；当 $p>1/(L+1)$ 时丢弃更合适，等号时两者相同。（书页 27–28、44）

多标签分类允许一个输入同时对应多个不互斥的类别；层次分类则让类别间的关系进入损失设计，但具体“哪种混淆更危险”仍取决于任务。例如蛇类在生物学上接近，也不意味着混淆它们的实际代价相同。（书页 28–30）

### 序列与语言模型

序列任务不能假定每个输入都独立、等长。语音识别把长音频变成较短文字，文本转语音方向相反；翻译还涉及输入与输出片段顺序不同。两端都可变长时称为**序列到序列**学习。（书页 30–31）

语言模型预测下一个 token 可视为一次多分类：输入是已有文本，输出是词表各 token 的概率；采样/选择一个 token、追加到上下文，再重复，便逐步生成文本。此处“分类”描述单步预测形式；整段生成文本仍属于生成建模。（书页 28、31–33）

### 自监督、预训练与生成

人工标注昂贵，文本却自带“下一 token”作为训练目标：**自监督**不是没有目标，而是目标由原始数据构造。先在大量数据上预训练得到通用的基础模型，再用较少的目标任务样本微调；偏好反馈与工具访问可进一步把它变成助手或 agent。预训练只教会续写，并不自动保证按人的问题给出合适回答。（书页 31–32）

判别式模型通常从数据到标签；生成式模型产生数据，如描述到图像、文本到语音。原书概览了 VAE、GAN、归一化流和扩散模型的不同建模路径：压缩再解码、用判别反馈训练、使样本概率可计算、逐步去噪。此处是路线图，具体机制留给后续章节。（书页 32–33）

### 与环境交互：强化学习及 agent

离线学习先收集固定数据，再训练模型；现实中模型的输出会改变将来的输入。例如推荐系统先展示某商品，它更可能被点击，下一轮训练数据便更加偏向它。这样会出现**反馈循环与分布偏移**，不能简单把新点击数据当作用户真实偏好的随机样本。（书页 33–34）

强化学习把循环写明：**观察 → 行动 → 奖励 → 新观察**。策略决定在观察下采取什么行动，目标是获得较好的长期结果。难点包括：奖励延迟时哪些动作应负责（信用分配）、当前观察不完整时如何利用历史、以及探索未知动作与利用已知好动作之间的权衡。状态完全可观察时可用马尔可夫决策过程描述；无状态或动作不影响后续状态时，可进一步简化为赌博机/上下文赌博机问题。（书页 34–35）

本书也把能读取工具结果并继续调用工具的语言模型称为 agent。编码 agent 阅读报错、修改代码、重跑测试，形成同样的观察—行动循环；长任务的奖励与验证仍是难题。（书页 35）

## 历史脉络与“深”的含义（书页 35–42）

统计学、概率、信息论和神经网络思想并非同时出现。神经网络的若干关键思想在 20 世纪已有，但数据和计算资源有限时，训练成本很高。互联网数据、存储与 GPU 算力增长，使端到端训练在更多任务上可行。书中举出图像分类、注意力/Transformer、自监督预训练、扩散生成、偏好与可验证奖励等阶段，说明方法演进不只是把旧算法放大。

**深度学习的“深”是多层变换，而且各层操作通常从数据中联合学习。** 端到端训练让系统以最终目标共同调整特征提取与预测，而不是先人工固定特征、再单独训练末端模型。不过端到端也要求数据和目标能代表真实任务；第 5 道练习用驾驶辅助系统提醒：逐像素错误率很低，也可能漏掉对规划极重要的行人。（书页 40–41、44）

原书还用示意图解释规模规律：不同模型大小对应不同计算预算，单个模型的收益会逐渐趋平；跨预算选择更合适的模型，损失随计算投入呈较稳定趋势。图是**示意**，不应从图上读取精确数值。更大的计算投入并不能替代良好的架构、训练目标与数据选择。（书页 41–42）
